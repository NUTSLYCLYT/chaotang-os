| 类别 | 次数 | 代表案例 |
| --- | --: | --- |

## Checklist（新增审查/规格工作逐条过，违者返工）

### A. 写任何状态/判定规格前
- [ ] 先穷举**输入组合全集**（事件类型×工件×时序×代次），再写规则；
- [ ] 末行必须 catch-all（inconsistent/quarantine），全函数由构造保证；
- [ ] 每个终态取值回答"什么证据支撑你"；失败/重试/迟到/无定义四问必过；
- [ ] 词表/字段名必须来自**盘点命令输出**，禁止凭记忆发明。

### B. 写任何事实断言（基线/清单/审查结论）前
- [ ] 跑实际调用口径的盘点命令，命令与输出随文附；
- [ ] grep 命中≠事实：注释、字符串、`ensure_ascii` 类假阳性逐个排除；
- [ ] 数字可由第三方用同命令复现。

### C. 证据协议（每份报告）
- [ ] 时间戳只取命令输出或 git 戳，无记录时写"未记录+可证区间"；
- [ ] 绑定八件套：BASE/HEAD/branch/worktree/change/PREDECESSOR/status/push；
- [ ] push 核验用 ls-remote 时点枚举，且只声明"当前零暴露"；
- [ ] 断言收敛到证据可支持的最窄范围。

### D. 审查含写操作的工具（gate/hook/installer 类）
- [ ] write-destination 穷举：每个 copyFile/writeFile/rm/rename 落点列表；
- [ ] 每落点 lstat：类型/symlink/nlink===1，装卸两径**等强**；
- [ ] 提交点后零 I/O（含 finally 清理），结构测试跨 helper 展开；
- [ ] 红队三问：绕过面/误删面/误伤面，每问至少一个主动构造的反例；
- [ ] **对抗通道先行**，本通道只做闭合复核。

### E. 收尾纪律（Grove）
- [ ] 验收标准规格冻结时定死；新发现仅 P1 安全级可追加为阻塞，其余入台账；
- [ ] 每份报告自问：删掉这段，裁决会变吗？不变就删（Ohno 反过度加工）。
