- 目标：将当前 P0 状态、production 缺口和首发产品策略收成统一基线。

- 目标：将开发工作拆成可独立执行、验证和回滚的十个工作流。
- 输入：当前上线阻塞项和大神会审建议。

## 任务 3：补齐执行治理

- 目标：确保后续跨会话执行不因上下文丢失或事实漂移失控。

## 任务 4：固化用户批准的上线策略

- 目标：将最小 diff 和验证闭环从建议升级为强制执行规则。
