# 部门 Agent「对抗收敛」模板（吸收自 `~/legal-agent` 律师蜂群）

台账 #18 的文档级吸收。源系统：7 角色企业法律决策律师团（本机 git 仓已核实）。
吸收的是**模式**，不是法律领域内容。

## 源模式（legal-agent 实证过的三段式）

```
情境 → 首席拆解调度
     → Phase 1 并行侦察（N 专家独立出报告，互不可见）
     → Phase 2 红蓝对抗（红队攻我方方案，蓝队加固回应，多轮）
     → Phase 3 收敛 BattlePlan（进攻向量 + 防御向量 + 时间线 + 证据清单 + 免责声明）
```

## 泛化为朝堂部门 Agent 模板

| 段 | 通用角色 | 朝堂对应 |
| --- | --- | --- |
| 拆解调度 | Orchestrator | 各部尚书 |
| 并行侦察 | N 个领域专家，独立、互盲 | 司级 agent / 锦衣卫取证 |
| 红蓝对抗 | 红队专职攻击结论，蓝队专职防守加固，多轮 | 御史台（红）× 承办司（蓝） |
| 收敛 | 输出带证据链 + 免责边界的行动方案 | 奏折（含 sourceLabel、红线声明） |

## 关键设计点（源系统教训）

1. **侦察互盲**：Phase 1 专家看不到彼此报告，防从众；汇合只在 Phase 2。
2. **红队是常设编制**，不是"审查一下"——有明确任务书：站在对手方攻击。
3. **收敛必须带免责边界**：法律版是免责声明，金融版是「非投资建议」红线
   （对应台账 #1 户部投资建议红线，两者同构）。
4. **多轮有上限**：辩论轮数封顶，防止不收敛空转。

## 适用判据

部门决策满足任一条即用本模板：结论会被对手方挑战（法务/投资/合规）、
错误代价不对称（漏报 >> 误报）、单专家视角有系统盲区。
日常检索/汇总类任务不用——对抗是贵的。
