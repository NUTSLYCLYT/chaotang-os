# 前端 Agent 工作入口

作用域：`frontend/`。当前没有前端实现，也没有已批准的框架、运行平台或命令。

## 边界

- 这里只放前端工程及其验证，不实现后端内部功能。
- 不要猜测前端一定是 Web、移动端或某个框架；以已验证决策为准。

## 首次搭建要求

首次引入前端技术栈时，在同一变更中：

1. 用最小原型验证运行平台和技术栈的关键假设。
2. 在 `docs/decisions/` 记录选择和取舍。
3. 更新本文件，登记准确的 setup、lint、test、build/run 命令，并接入 CI。
4. 建立 agent 可直接运行的测试闭环；涉及界面时提供可重复的行为验证方式。
