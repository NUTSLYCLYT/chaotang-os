## 🎯 根因（已定位到行）

能力路径返回 `source=rule`/骨架，根因在后端 **`jiqun_ai/src/chaotang_orchestrator.py`**：

```python
# draft_decree() L96-103
try:
    parsed = _parse_json_block(_llm_json(raw_command))   # → 调 DeepSeek
    source = "llm"
except Exception:          # ← L102 裸 except 吞掉真实错误
    source = "rule"        # ← 永远落到这
```

`_llm_json()`（L47-56）调：
```python
ModelAdapter(model="openai/deepseek-chat",
             api_base="https://api.deepseek.com/v1",
             api_key=os.getenv("DEEPSEEK_API_KEY"))   # ← key 没设 → None
```

**实测证据**：
- 运行中的后端进程（:8081, pid 709027）初始环境 **无 `DEEPSEEK_API_KEY`、无 `LITELLM_PROXY_KEY`**。
- `jiqun_ai/` 下**只有 `.env.example`，没有 `.env`** → key 未注入 → `os.getenv` 返回 `None` → DeepSeek 调用无鉴权失败 → 抛异常 → 裸 except → `source="rule"`。
- 仓库历史 `3835373 docs(validation): DeepSeek真奏折`、`9c6e69f ...DeepSeek env已设` 证明：**基建本来是通的，现在只是 key 没配**（config 问题，非 code 问题）。

## 🔧 修复（2 步，~2 分钟）

**① 配 DeepSeek key（必做）**
```bash
cd ~/workspace/jiqun_ai
cp .env.example .env              # 若还没有 .env
# 编辑 .env，填真实 key：
#   DEEPSEEK_API_KEY=sk-xxxxxxxx
# 重启后端，确保进程加载到该 env
```
（若后端用别的 LLM 通路：`LITELLM_PROXY_KEY` + `http://127.0.0.1:4444/v1` 那条 litellm proxy 同理需 key/服务在跑。）

**①-备选 · 不想买 DeepSeek key？用本机 Ollama（:11434，零 key、零成本）**
机器上 **Ollama 已在 :11434 跑**——它是 OpenAI 兼容、无需 API key 的本地 LLM，可同时当
**拟旨大脑** 和 **评测 judge**：
```bash
# 看本机有哪些模型可用：
curl -s http://127.0.0.1:11434/api/tags | python3 -m json.tool   # 没有就 ollama pull qwen2.5（或 llama3.1）
```
- **拟旨大脑**（后端 `chaotang_orchestrator.py` 的 `_DRAFT_*`）：把 `_DRAFT_API_BASE`
  改 `http://127.0.0.1:11434/v1`、`_DRAFT_MODEL` 改 `openai/<本机模型名>`、key 留空。
  （后端运行系统、本环境不可测 → 补丁提案，给后端团队 apply。）
- **评测 judge**（本仓 `judge.mjs`，我可直接用）：
  `JUDGE_API_URL=http://127.0.0.1:11434/v1 JUDGE_API_KEY=ollama JUDGE_MODEL=<模型名> node judge.mjs`
  —— 这样真实 LLM-judge 评分也能跑，**全链路零成本**。

**② 让吞掉的错误可见（建议·后端小补丁，不改行为只加日志）**
`chaotang_orchestrator.py` L102 的裸 `except Exception:` 应记录原因，否则永远不知道为什么 fallback：
```python
except Exception as e:
    logger.warning("draft_decree LLM failed → rule fallback: %s", e)
    source = "rule"
    ...
```
> 这是后端运行系统、本环境不可测 → 以补丁形式给后端团队 apply（同 BL-03 纪律）。
