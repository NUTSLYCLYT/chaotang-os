## A. 战前准备（第 1 小时）

### A1 · 代码就绪（5 分钟）
打开终端，逐条复制运行（在项目根目录 `/home/ubuntu/workspace/frontend/chaotang-web-lyt`）：

```bash
cd /home/ubuntu/workspace/frontend/chaotang-web-lyt
git branch --show-current          # 应显示 feat/v1-3live-vitrine

```
> ⚠️ 小白注意：**build 命令前面那段 `NEXT_PUBLIC_API_MODE=real` 不能省**。省了会报 `[release-gate]` 错、build 直接失败（这是防假数据的安全闸，不是 bug）。
- [ ] build 绿（看到 Compiled successfully）。**红了就⛔找开发，别演示。**

### A2 · 兵部已验证点亮（已完成，仅需确认）

## C. 路演计划（第 3 小时）

### C1 · 路演目标（先记死）
**不是卖货、不是讲技术。是让真商家感受 + 拿到真反馈。**
成功 = 至少 1 人说"想要/愿付钱" 或 点了某个"即将上线"告诉你他要什么。

### C2 · 路演对象
**3-5 个你认识的真小老板**（年收入<1000万、没有专业财务/情报团队那种）。
线下当面 或 屏幕共享。**一次一个，别群演。**

### C3 · 演示动线（照着点，5 分钟）
```
第1步 开场(30秒)·全貌
   打开 /chaotang/start
   说:"这是给你生意配的一整套 AI 班子——情报、财务、获客，一个顶一个部门。"
   手指划过金光 3 卡 + 暗置那些:"这3个现在能用，其余陆续上线。"

第2步 第一刀(90秒)·锦衣卫(即时 wow，不需输入)
   点「锦衣卫·情报」
   说:"它每天帮你盯竞品和行业异动，还按可信度给情报分了级——哪条能信、哪条存疑。"
   指着情报列表 + 可信度分级让他看。

第3步 第二刀(2分钟)·户部(让他参与，最强)
   点「户部·投资决策」，先看那张【演示】卡:"比如这笔扩产，它给了准奏+评分+风险+缺什么证据。"
   然后:"现在您说一笔您正纠结的钱决策，我输进去给您看。"
   → 当场输入他的真决策 → 一起看裁决。★这是全场高潮★

第3.5步 第三刀(90秒)·兵部·销售决策(成交把关)
   点「兵部·销售决策」，指那张"是否签 120 万合同?":
   "它帮你成交前把关——这单它判风险紧急、缺渠道资质，钦天监还一票否决说触了不可逆红线。"
   说:"签大单、对外报价前，它先帮你看会不会被坑。"

第4步 收尾(30秒)·收需求
   回 /start，指暗置板块:"这些陆续上线，您最想先要哪个?"
   让他点「我想先要它」——当场把路演变调研。
```

### C4 · 话术逐字稿（紧张就照念）
- 开场："我做了个东西想给您看 2 分钟——相当于给您的生意配了一套 AI 班子，帮您拿主意、还不让您被坑。"
- 锦衣卫："这个每天替您盯着同行和市场，重要的是它会告诉您哪条消息靠谱、哪条别信。"
- 户部："您最近有没有一笔拿不准要不要花的钱？说给我，它当场帮您算划不划算、会踩什么坑。"
- 收尾："这才刚开头，后面还有获客、合同、人事陆续上。您觉得哪个对您最有用？"
- **全程别说**："它会自动学习/它什么都能干"（不诚实，见 §D）。

### C5 · 收集什么（演完马上记，别靠记忆）
每个商家记 4 件事：
1. 他**第一个主动想点**的是哪个？（= 你的核心价值）
2. 他点的第一个**"即将上线"**是哪个？（= 你下一个该做的）
3. 他**卡在哪 / 哪里皱眉**？（= 可用性问题）
4. 原话：他会**为哪个付钱**？付多少？

### C6 · 路演后（当天收口）
- 看 `/start` 暗置板块被点的排名（运营可查 `pilot_interest` 表）——**点最多的 = 你下一个上线的板块。**
- 把 3-5 人反馈汇总成一页，定**下一个上线板块**（用数据，不拍脑袋）。
- 决定：信号好 → 修 C1/C3 准备公网；信号弱 → 调整再演。
