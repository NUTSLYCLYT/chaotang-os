## 2. 工部相对户部的独特处（功能细化点）
- **铁律9 产线资产锁**：任务命中 成本/报价/BOM/供应链/供应商/毛利/交期/价格/采购 → 整字段上锁，前端不渲染其值，只显字段名 + 转后端。卡上🔒蓝徽；架构司有「产线资产锁全景」看板（按类目聚合）。
- **对外承诺门**：命中对外承诺交期/价格 → 红「需陛下亲裁」（塔勒布·不可逆尾部风险）。
- **跨部会审**：命中成本→拉户部、合同→拉刑部、竞品→拉兵部。
- **真进度条**：在办任务用后端 `progressPct`（户部那块只能占位，工部能真）。

## 3. 数据源 / 真实性
- 决策队列 = `GET /api/court/backend/tasks`（jiqun 持久化 / primary DB 的建设任务）。
- 🟢 现可真（纯函数/任务）：分类、定性裁决、产线锁、对外承诺、跨部会审、在办进度(progressPct)、已交付。
- 🔵 需后端 PACK 研发蜂群：真实可行性兑现、方案/PRD 生成、真实成本/BOM/交期（铁律9 上锁）。
- 队列现在常空 = 后端蜂群未起，态势灯诚实显「兜底/待接后端蜂群」，不造假任务。
