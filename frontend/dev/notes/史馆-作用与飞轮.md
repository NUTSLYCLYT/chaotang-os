# 史馆 · 它到底是什么、有什么用、现在缺什么（2026-06-28）

> 把"史馆"一次说清，免得它被当成"又一个归档页"。

## 1. 史馆是什么

**史馆 = 朝堂的记忆与学习中枢。** 不是档案室，是**让朝堂从过去的真实结果里变聪明**的那个器官。
它的存在只为一件事：**闭合决策飞轮。**

```
上书房问题 → 丞相拟旨 → 军机处会审 → 圣旨/奏折 → 老板裁决
                                                    │
                                                    ▼
                          ┌──────────── 史馆 ────────────┐
                          │  ① 归档：这次决定了什么、谁裁的、依据/缺证/风险  │
                          │  ② 兑现回填：事后这决定到底对不对(投资真回报了吗?)│ ← 命门在这
                          │  ③ 引用旧案：下次类似决策，把"上次证明对/错的案"调出来 │
                          └──────────────────────────────┘
                                                    │
                                          下次决策更准（飞轮转起来）
```

**没有史馆 = 朝堂每次决策都从零开始、永远学不会。** 史馆是"经验"这两个字的载体。

## 2. 现在建成了什么（✅ 真的，不是空壳）

- ✅ **归档**：决策/任务/会审进 `court_archives`/`shiguan_archives`/`tasks`/`decisions` 四张真表。
- ✅ **复盘**（retrospective）、**分析**（analyze）、**统计**（stats）—— 都有真 API。
- ✅ **读真数据**：`shiguan-loaders` 拉真 API（stats/tasks/governance），不是 mock（`mock-archive.ts` 只是 re-export 的 fixture）。

所以史馆的 **①归档 + 复盘** 这半边是**完善且真**的。

## 3. 命门：飞轮没闭（🔴 这是它"不完善"的唯一要害）

**`outcome` 是从任务状态推导的，不是真实"兑现回填"。**
- 现状：`taskOutcome(status)` —— 任务做完 = `success`。全文搜不到"兑现/回填/backfill"。
- 翻译：史馆记的是「**决定了什么 + 任务做没做完**」，**不是「这决定事后到底对不对」**。
- 后果：**"引用旧案"引用的是结果未知的案。** 一个"任务完成但其实是错误决策"的案，会被当成成功经验引出来 → 飞轮**反向**转（学错东西）。

> 一句话：**史馆现在是个好的"档案室 + 复盘工具"，但还不是"会学习的大脑"——因为真实结果没有回流。**

## 4. 怎么让它成真飞轮（完善路径）

| 步 | 做什么 | 在哪 |
|---|---|---|
| ① 真实结果回填 | 决策**事后**把真结果写回史馆：投资真回报了吗、获客真转化了吗、报价真签了吗 | **后端 jiqun**（产线真结果，铁律9） |
| ② outcome 不再靠 status 推导 | `outcome` 字段来源改为"真实兑现记录"，没有就诚实标 `pending`（未兑现），不冒充 success | 后端写 + 前端 contracts/archive.ts 加 `fulfillment` 来源 |
| ③ 引用旧案带"兑现过"标签 | 引用旧案时优先引"已兑现且证明对"的案；未兑现的标注"结果未知" | 前端史馆（已 ready 接） |

## 5. 一条断言钉死"飞轮真转了"（Deming）

```
喂一个决策 → 标记它的真实结果(对/错) → 验证史馆能在下次类似决策时，把这条"事后证明对了"的旧案引出来。
```
**这条 e2e 绿之前，史馆再完善也只是档案室。** 它绿的那一刻，是朝堂第一次真正"长记性"。

## 6. 给老板的一句话

- **史馆已经能"记"**（归档+复盘，真数据）。
- **史馆还不能"学"**（outcome 开环，真实结果没回流）。
- **让它会学 = 后端把真实结果回填 + 一条飞轮 e2e。** 这是后端「第一张卡」的延伸，前端这边已备好接口。
- 在那之前，别对外宣称"朝堂会从经验学习"——它会记，还不会学。诚实点。
