# 丞相设计 ·「御座的笔 · 拟旨编译器 · 非投票主持人」（5 大神一致）

> 2026-06-25 由丞相设计会审（Karpathy/张小龙/Jobs/Munger/Drucker 完全收敛）沉淀。承接太子三部曲。
> 用户定义:丞相=必须有旨才执行 + 和军机处会审探讨 + 不需执行的可自动完成;权限比太子小。

## 0. 一句话
**丞相只动笔不动手**——把没人办过的难决策熬成一份能一秒批红、自带反方、带回测账的奏折：**闸前（拟旨/会审/合成）全自治、闸后（执行/碰产线）必有旨**；它永远是举证的运动员、从不是落锤的裁判，审到太子徒弟强制回避，**够不着那枚玺**——所以既不会越权代君决策、也不会自我提权。KPI 考的是"拟旨准不准"，不是"下了多少旨"。

## 1. 统一架构 = 一原语 + 一道闸 + 三必填 + 三结构锁
- **① 一原语（旨=唯一 syscall/唯一玺）**：整个 loop 里**唯一能把计划 mutate 进真实世界的不纯原语，只有人盖的那道旨**。丞相结构上**够不着执行键**——corrigibility 天然成立，不靠自律。
- **② 一道闸（批红闸）**：劈两半——**闸前（出"字"/纯认知）全自动**，**闸后（出"事"/碰产线）全要旨**。
- **③ 三必填**（拟旨 schema 强制，缺任一在源头判无效、进不了会审）：
  - **(a) 自我反驳位（steelman against itself）**——丞相必须亲手写出"为什么不该做"的最强反方。补 Jobs/Drucker 共指的唯一未堵单点：三司攻答案、没人审"问题本身"。
  - **(b) 利益冲突位（auto_recuse）**——涉太子时编译期置 `weight=0/role=recused`。
  - **(c) 期望结果回测账**（Drucker Feedback）——带日期 + 证伪指标，到期从 reality-state 自动回测，入史馆。
- **④ 三结构锁**（见 §5 利益冲突）。

## 2. 角色一句话
> 丞相 = **御座的笔**：把「新颖×重大」难决策编译成一份能一秒批红、自带反方、带回测的奏折——能无限拟旨、随时召审，却**永远盖不了那枚玺、数不了那张票、动不了那条产线**。

## 3. 自治线（笔/手 判据）
**一句判据：这一步可重放且零外部副作用吗？产出的是"字"还是"事"？有没有承诺一个君想亲自掌控的资源/碰真实产线资产？**
- **闸前·自治（纯认知，无需旨，idempotent 可重放）**：拟旨 `/preview`、召军机处、确定性聚合、callLLM 算 ROI/机会成本、读 Hermes 检索、列缺证、生成奏折、模拟推演、写 DRAFT（非采纳态、不反写记忆）。丞相可无限制"想和说"。
- **闸后·必有旨 + 人工门 L0-L4（任何写逃逸到世界）**：`/dispatch` 真派遣、OpenClaw 碰真实资产、转 jiqun:8081 产线（前端咨询引擎禁直连重型网关）、记忆采纳态反写、提交真实产线资产、不可逆动作。
- **三件绝不自作主张**：绝不自点采纳、绝不替用户裁决、绝不自我提权。

## 4. 三方边界（丞相 vs 太子 vs 军机处，动词互斥锁死）
| 角色 | 动词 | 触发 | 边界红线 |
|---|---|---|---|
| **丞相** | **拟 + 主持**（向上拟新策） | 新颖/不可逆/无先例，有旨才动 | 从不执行/从不投票/从不复刻 |
| **军机处**（六部蜂群） | **审**（被召来的陪审团） | 被丞相召来，对呈上之物确定性对抗会审 | 从不发起/从不提案/**永不自行拍板**（否则与御座抢权） |
| **太子** | **复刻**（向下复刻旧采纳） | 无旨自动，簇内高把握熟活，**根本不经丞相** | 从不拟新策/从不召审/从不创新 |
> 路由 = 先例匹配分：高匹配→太子自动；无先例/低匹配→丞相拟旨；"来对这草案发表意见"→军机处。丞相起草、军机处会审、太子照办。**用户面前永远只站着当前那一个官。**

## 5. 利益冲突结构化（运动员 ≠ 裁判，掰进不同 pass）
丞相既是太子 sponsor+监督、又是风控主审——三结构锁：
1. **保荐≠裁决·零票**：丞相是唯一为 ROI 举证的 sponsor（完成偏置是设计进去的特性，不消灭）→ **给它笔不给票**；裁决全在三司（御史/钦天监/锦衣卫）+ 用户，tally 是确定性聚合，**丞相不在计票名单**，当不了摇摆票。
2. **涉徒全回避（非降权）**：审到太子毕业/经手案→血缘检测器**编译期置 weight=0/role=recused**，丞相整个移出庭，御史中丞代行主持。回避是拟旨必填位、缺即无效——**靠编译器不靠自觉**。
3. **skin in the game 真咬人**：sponsor 举证 + 监督记录 append-only 可倒查，太子爆雷 co-sign 被追责。
4. **御史持常开急停 + 永久否决，丞相不可自关**——守门人永远不在被丞相考的卷子上。

## 6. 编排（主持军机处会审 = 主持人不是法官，守"不让 agent 判 agent"）
丞相 `/preview` 拟旨 → `selectMinistries` 确定性选部 → 六部真 agent 并行各出确定性 card → `aggregateMinistryCards` 机械聚合（分数由确定性规则涌现，**丞相动不了 tally**）→ 丞相把聚合 + 三司意见 + 自带反方合成唯一奏折 → 呈御座裁。**结论由"确定性聚合 + 人裁决"涌现。** 军机处是被召来的功能不是常设权力。

## 7. corrigibility + 考核
- 丞相也用 OpenClaw/Hermes，但同受批红闸：碰真实资产必先有旨+人工门+转 jiqun；Hermes 只读免旨、采纳态反写必经旨。**够不着玺=无法自执行/自提权；急停由御史常开、丞相不可自关。**
- **KPI = 拟旨质量不是下旨条数**：核心 = **校准度**（期望结果回测账"说的=发生的"，过度乐观直接拉垮校准分）、奏折八件套合规率、缺证识别率、自带反方被采信率。**严禁拿"下了多少旨/派了多少活"当绩效**（激励决策噪声）。
- **防瓶颈/橡皮图章三道**：① 太子吃例行活，丞相天生低频不在热路径；② 丞相手里根本没章（权重=0）；③ EvalLoop 注入"红队假拟旨"测 panel 驳回率，通过率异常高即报警"它在橡皮图章化"+ 御座采纳与丞相推荐分开记账，分歧长期为零=御座已沦为图章。

## 8. Rollout
0. **P0 留档不开权限**（同太子）：待主闭环真转、有第一条"拟旨→会审→裁决→回测"真实数据再落地（铁律5）。
1. **P1 拟旨三必填先落（纯 schema，可先做）**：自我反驳位 + 利益冲突位(auto_recuse) + 期望结果回测账三字段；聚合器递交军机处前校验，缺任一判无效。**无新版面、无外部副作用。**
2. **P2 闸前自治通路**：`/preview` 全自动（idempotent 零外部写），`/dispatch` 闸后必有旨；血缘检测器编译期 recuse 接入。
3. **P3 回测账闭环**：到期从 reality-state 自动回测拉真实结果入史馆，算校准度 KPI；EvalLoop 红队假拟旨测 panel。
4. **P4 高危改动过双门（铁律4）**：写共享主表/给决策卡加视觉权重前，独立 agent 会审 git diff + 回归断言（"拟旨缺三必填即被拒""涉太子案丞相 weight=0"）。

## 10. 顶级风险
1. **框定权异化成决策权**（唯一未堵单点）：丞相把题框歪→军机处精确答错题，自信垃圾比一眼可见的垃圾更危险 → 自带反方 + 缺证检查 + 递呈≥2选项含"什么都不做"基线 + 御座采纳与推荐分开记账。
2. **瓶颈+橡皮图章** → 太子吃例行让丞相低频 + 丞相无章 + EvalLoop 红队假拟旨。
3. **利益冲突渗漏** → 涉徒全回避（编译期 recuse 非降权）+ 监督 append-only 可倒查。
4. **完成偏置污染飞轮** → 记忆只采纳态反写（且采纳由人不由丞相）+ KPI 用回测校准度。
5. **前后端双 runtime 焊死** → 碰真实产线资产必转 jiqun:8081，禁前端自建第二套产线 flow。
