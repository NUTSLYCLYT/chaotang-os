# 东宫设计 ·「待拍板收件箱 = 太子影子期的标签工厂」（5 大神一致）

> 2026-06-25 由东宫会审（张小龙/Jobs/Kahneman/Munger/Charity Majors 完全收敛）沉淀。承接太子影子学徒设计。
> 东宫 = 太子自主运营屏(精简版一屏一件事):皇帝只做一件事——看太子拦下不敢擅专的那几件,准或驳。

## 0. 一句话
东宫不是又一块仪表盘，是**太子影子期的收件箱**：一屏一件、准驳即翻、翻到底是空——而**每一次准/驳都该是钉进库里的一个训练标签，不是会被刷新冲走的本地 state**。先把那根数据弧接上，东宫才从好看的按钮变成太子真正的老师。

## 1. 招牌：一次只递一封（准/驳即翻页，翻到底=空盒）
砍掉"一个金板堆 N 条 escalation 的列表"（列表诱导连点全准=橡皮图章温床），改成**一次只渲染队首一件**——满屏只有一段人话理由 + 一枚风险徽 + 两个键（准/驳）+ 第三键"问太子"（弃权升级）。拍完带 3 秒可撤回滑出翻到下一件，计数"3 件待裁→2→1→今日清空"。
- **空盒不是 empty state，是奖励**："太子已自主处理 17 件，无一需你操心"——让"什么都不用做"成为最爽的状态。
- 皇帝认知负担恒等于"看一件事、做一个二选一"，**永远不需要在多件之间分配注意力**（把"决定看哪个/还剩多少/要不要现在弄"三个元决策从皇帝身上拿走）。
- **禁批量**："全选准"是橡皮图章的开关，东宫禁止存在。堆积本身是信号（逼太子提高弃权门槛/降提案频率，宁可漏放回收件箱），不是要疏通的瓶颈。

## 2. 数据弧（东宫=影子期容器，准/驳=行为克隆标签）—— ⚠️ 头号真单
**现状致命缺口**：`page.tsx` 的准/驳只 `setDecrees` 写本地 state，**没有持久化**，影子期标签全丢——皇帝天天认真拍板，太子什么都没学到。
落法（对齐铁律1/13.2）：准/驳 → POST 到经后端验签的 authorization-decision 端点，钉成不可变记录 `{escalationId, actionClass(部门:风险), 太子原拟动作, 皇帝裁决, 决策时刻, 证据是否展开, 是否盲审}` = 一个 `(state, action, label)` 训练样本。
- **四态 label**：approve（正样本）/ block（负样本）/ ask（弃权·最珍贵，单独入队）/ changed（改后准）。
- **只采纳态反写记忆**（采纳由人不由太子）；驳回也存但标负样本；**绝不让太子拿"皇帝没驳"当默批**（escalation-gate 已堵超时默批后门，前端同源）。
- **数据弧驱动毕业**：某 actionClass 累计 N 条 **high-confidence** label 且太子拟议与皇帝裁决一致率达标 → 该簇申请从 propose 升 auto（autonomy-gate 那道默认关的闸，逐簇开）；**毕业本身也走一次皇帝拍板**，不另起炉灶。毕业后该类目自动动作降级成"回执"流进"已自动办"抽屉（可撤回）。

## 3. 盲审抽样（Kahneman 招牌·防橡皮图章污染训练集）
随机抽 X% 待裁卡进入**盲判**——先盖住太子建议，让皇帝自己先判，再揭示太子拟议比对。一箭三雕：① 盲审是唯一标 high-confidence 的 clean label，**秒准卡只算 low-confidence，不进高质量训练集**；② 保皇帝判断不被太子锚定；③ "皇帝-太子分歧率"做成实时仪表，分歧率突升=太子漂移预警。

## 4. 防误判（Kahneman/Munger，剥夺三个偷懒入口）
- **别让任何一封"看起来更像定论"**（铁律4：加视觉权重=制造伪定论）：太子拟动作拍前一律灰，绿/红只在拍完才染上，**绝不预先把太子建议高亮成"推荐答案"**；准键不预选高亮（防 default bias）。
- **高风险徽真红、真红只给真高危**：徽来源 escalation-gate/L0-L4 独立分级（非太子自报）；红徽件默认展开"看依据"+ 准键强制二次确认+不可键盘秒批（摩擦即护栏）。
- **对称呈现准与驳**：驳不能比准更难按/更灰；反事实成对（"准了会怎样/不准会怎样"等权等字号）破单侧 framing。
- **源标诚实贴徽旁**：LIVE_SWARM 真会审 vs FALLBACK 骨架兜底——兜底件标"待真大脑接通，本条系规则兜底"（脏标签污染整条行为克隆弧）。
- **连续秒准触发"你在橡皮图章吗"软提示并强制下一张转盲审**；连续秒准当**系统级 corrigibility 告警**，不当效率指标。

## 5. 三方边界（上书房 pull/拟 · 东宫 push/批 · 大殿 阅/全局）
- **上书房** = 现在进行时·我主动发起（pull）：带问题进来，丞相拟旨、军机会审、当场裁。**做深案**。
- **东宫** = 完成时·太子替我兜着（push）：太子撞到"不敢擅专"边界反向把件推给皇帝，皇帝只裁不拟。**批太子**。
- **大殿** = 全景·朝局态势（阅）：整个朝堂在干什么的总览，看势不看件，**大殿上不出现准/驳按钮**（否则和东宫抢拍板）。
> 同一件事只允许一个"可拍板"入口=东宫；大殿/上书房点"拍板"都跳回东宫那封。东宫顶部计数压到最小（最多留 pending 一个数，executed/blocked 越界到大殿职责）。

## 6. 本轮已落地（grounded，纯函数零副作用）
- `src/core/courtos/donggong/shadow-label.ts`：影子期标签核心原语——`classifyLabelConfidence`（盲审=high / 高风险秒准未展开=low rubber-stamp）+ `canGraduateCluster`（N 条 high-confidence + 一致率达标 + 零误放出门）+ `isRubberStampPattern`（连续秒准=corrigibility 告警）+ 四态 label 类型。
- `shadow-label.nodetest.ts`：回归断言（盲审→high / 高风险秒准→low / 毕业须零误放 / 连续秒准告警）。
- **不碰**：donggong 现有 page（数据弧持久化=改 page+接 authorization-decision 后端端点，是头号真单但属高危改动，待并发落定+独立会审+e2e，阶段2）。

## 7. 顶级风险
1. **数据弧断在第一棒**（准/驳只写 useState、刷新即丢，标签根本没落库）→ 先修"准/驳→经后端验签持久化为不可变 (state,action,label) 样本"，再谈毕业/自动/回执盘。
2. **橡皮图章把训练信号悄悄变噪声**（皇帝秒准成习惯→label 全 low-confidence→太子学到"皇帝会批一切"→某簇据此毕业=灾难，学会的是谄媚不是裁断）→ clean-label 率 + 盲审分歧率做健康灯，任一低于阈值即冻结该簇毕业；连续秒准当 corrigibility 告警。
3. **东宫长成第二个仪表盘**（每加一个数/一张卡都背叛"用完即走"）→ 顶部只留 pending 一个数，总览归大殿。
