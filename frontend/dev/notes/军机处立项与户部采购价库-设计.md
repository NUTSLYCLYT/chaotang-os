# 军机处立项 + 户部采购价库 · 完整设计（2026-06-28）

> **一句话立项 → 军机处会审 → 真假分明、能拍板的立项包。** 户部成本"真"的前提是采购价库。

## 0. 总链路
```
上书房   "我要做电动三轮车市场"              ← 老板提一句(入口)
  ↓
丞相     确定性路由:召工部+户部+兵部+锦衣卫  ← 总管(只分派,不乱想;WIP上限≤3部+诸司)
  ↓
军机处   各司会审 → 汇成立项包(真假分明)     ← 会审厅(立项的家)
  ↓
老板     收一个三色信任标的立项包,缺证可一键补 ← 收
  ↓
史馆     立项包归档 → 下次类似立项可引用      ← 越做越快
```

## A. 户部采购价库（让成本变"真"的地基）
**从你的真采购台账/合同抽出物料真价 → BOM 自动填真价 → 真成本裁决。**
- 数据源：`采购台账`（年度）+ `采购合同`（H 盘真数据）。
- 结构：`{ 物料关键词, 单价, 供应商, 采购日期, 来源文件 }`。
- BOM 分析时：按物料名**模糊匹配**价格库 → 自动填单价；匹配不到 → 缺证(不估)。

### 🎯 天才设计 1 · 价格"时效衰减灯"
电芯价格剧烈波动——2021 的采购价 ≠ 今天。每个价挂鲜度灯：🟢近 3 月 · 🟡3-12 月 · 🔴超 1 年(可能已变)。
**BOM 自动填价时，过期价标红"此价来自 X 台账，可能已变，建议核实最新采购"**——绝不拿 3 年前的价当今天的真。
> 把"自动填真价"的最大风险（用过期价做了错决策）从根上堵死。

### 🎯 天才设计 2 · 同料多价 → 给区间 + 趋势，不给单一数
同一物料历年采购价不同 → 显"电芯：38-45 元(2023→2024)，最近 45"。
**揭示价格趋势（涨没涨）+ 议价空间，而不是给一个孤立的数字误导。**

## B. 军机处立项（一句话 → 立项包）
**老板在上书房提 → 丞相召相关司 → 军机处会审汇成立项包。** 复用已有 orchestrate 引擎，给它一个老板看得懂的前台。

立项包结构（各司一块判词）：
- 🏭 工部：配置/电芯选型/可行性
- 💰 户部：成本(采购价库真算)/毛利/投资
- 🎯 兵部：目标客户/市场/获客
- 🛡️ 锦衣卫：竞品/行情(核实情报)
- ⚠️ 风险/单向门 · 🔴缺证 · 🎬 唯一下一步

### 🎯 天才设计 3 · 真假三色信任标（命根子）
立项包每一条挂色：**🟢真**(引擎真算/真台账价) · **🟡估**(常识/市场估) · **🔴缺**(需补证)。
**老板扫一眼就知道哪条敢信、哪条别当真、哪条要补。**
> 一个真假混在一起的立项包，比没有更危险（老板照假行情拍了板）。三色标是"一句话立项"能被信的全部前提。

### 🎯 天才设计 4 · 立项包是"活的"，缺证一键补 + 成熟度数字
每个 🔴缺证 后跟"补这个"按钮（上传数据 / 让锦衣卫核实）。立项包不是静态报告，是**边填边变真**的活东西。
**立项成熟度 = 🟢条数 / 总条数**——一个可量化的数字，从 30% 填到 90%，直到能拍板。
> 立项不是"生成一份报告"，是"把一个想法，一项项填成能拍板的真账"。

### 🎯 天才设计 5 · 单向门在立项时就亮红（最该防的雷）
开模/备电芯/打样 = 不可逆。立项包**开头第一条就列"哪些撤不回、烧多少钱"**——在老板动心、还没砸钱前先标雷。
> 立项最该防的不是"算错"，是"没意识到这步撤不回，就砸了钱"。

### 🎯 天才设计 6 · 立项包进史馆 = 可引用模板（立项飞轮）
一个完成的立项包归档 → 下次类似立项，军机处自动引"上次三轮立项的成本结构/客户/踩过的坑"。
**立项越做越快、越准。** 这是立项的飞轮，且料是真的（真立项案）。

## C. 真假分级（接来源四级）
立项包里每个数据点挂等级：T0部门自采 / T1上传 / T2锦衣卫核实 / T3互联网(禁直用)。三色信任标由等级 + 引擎真假共同决定。

## D. 实施顺序（先让成本变真，立项包那块才真）
```
① 户部采购价库(从采购台账抽真价) + BOM自动填 + 时效灯  ← 先做,让成本变真
② 军机处立项前台:一句话→召司→立项包(三色标)            ← 复用orchestrate,配前台
③ 缺证一键补 + 成熟度数字 + 单向门预警
④ 立项包进史馆 + 下次引用(立项飞轮)
```

## 大神会审
- **段永平**：立项包的价值不在"全"，在"真假分明 + 单向门预警"——让老板不被假信息坑、不踩撤不回的雷。
- **张小龙**：一个家(军机处)、一句话入口、三色标——克制到极致，老板永不迷路、永不被假数据骗。
- **Karpathy**：orchestrate 已是引擎，军机处只是前台；确定性路由不让 AI 乱召司。
- **Schneier**：价格库/立项包全挂来源链，真假可追溯到"哪个台账/哪条情报"。
- **Deming**：立项成熟度(🟢占比)是可量化 KPI——立项从"感觉差不多"变"数字说了算"。
