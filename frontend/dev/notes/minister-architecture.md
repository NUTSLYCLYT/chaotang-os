# 朝堂部长架构 · 部长由什么做成（5 大神一致天才设计）

> 2026-06-24 由架构会审（Karpathy/段永平/Bezos/张小龙/Naval 一致收敛）沉淀。
> **回答**："各部门部长该是 agent / skill / Hermes / OpenClaw？" —— **这是框错的问题**（等于问"人是大脑还是双手还是记忆"）。部长是**四层身体缝在一个薄编排契约后**的组合，不是四选一。

## 0. 一句话
**部长 = 一颗 agent 判断脑，默认背 Hermes 记忆（护城河，先免费吃满）、按需拿 skill 当工具、只在碰真实产线资产时才伸 OpenClaw 手臂并过确认门。一个 harness 十一行配置，不是十一个雪花 agent。** 把判断租薄，把记忆和方法论养厚 —— 部长才越用越强而非越用越烧钱。

## 0.5 治理原则：以当前最优为主（不锁死任何一版）
这套五层**不是冻结规格，是一组可热插拔的契约——每层都可以变**：
- agent 可换底模/换 seed · skill 可版本化/灰度/替换 · 记忆是数据可迁移 · 手臂可挂可卸 · 编排契约可重抽。
- **决策规则**：任何时候按"当前最优"重选每一层——**不为"上次定了"守旧，也不为"四件套完整"堆料**。某层出现更优解（更强底模、更好 skill、新执行器）就换，部长本体不动。
- **变的是层，不变的是守门**：唯一恒定的是薄编排契约 + 红线（诚实标源/SSOT/人工确认门在 harness 单点强制）。
- **推论（Bezos）**：既然每层可变，就**别在任何线性层做不可逆重投入**——投入留在复利层（记忆），线性层（agent 算力/OpenClaw 劳力）随当前最优随时替换。这正是"我们都可以变化、以当前最优为主"能成立的工程前提。

## 1. 部长的五层（每层用哪个原语，及"别堆"边界）
| 层 | 原语 | 角色 | 别堆什么 |
|---|---|---|---|
| **脑·判断**（本体 always） | **agent** | LLM-in-a-loop：dept-registry seed + 受限 action space + 经 AgentHarness 调 callLLM 接地裁断。判断不可外包给 skill（skill 无 loop/无 state = 硬编码答案）。 | **最便宜、最该可替换的一层**——别在这堆护城河（堆 seed/多 persona 是线性投入，换底模归零）。一壳承载，差异只在 seed。 |
| **记忆·复利**（护城河 always-on，**先吃满**） | **Hermes** | 五大神一致认定的**最高杠杆与第一护城河**。每部默认挂 Hermes（SQLite+FTS5 按 dept 分命名空间），跑 memory→execution→memory 飞轮并**补"反写"那半圈**。免费、复利、先于任何 OpenClaw。让平庸部长随天数自动变强。 | 别只读不写（飞轮永不转）。 |
| **工具·方法论**（conditional 按需借） | **skill** | 部长伸手取的装备，不是部长本身；懒加载进 action space（省 token）。SSOT 单一真相源，禁各部私造平行方法。 | 只服务一个部长、不被横向复用的 skill 是**代码债不是资产**；别为凑数硬塞。 |
| **手臂·重活**（gated 默认不挂，**需求拉动**） | **OpenClaw** | **per-action 闸、非 per-minister 标配**。仅当决策从"咨询"升级到"触碰真实产线资产（报价/BOM/交期/付款/对外承诺/供应商锁定）"才召，且必须 前端→jiqun:8081 代理 + 过人工确认门 + 诚实标源。 | 劳力线性付费、不复利。**绝大多数部长一辈子不接它。** 记忆飞轮没吃满前绝不先装手臂。 |
| **指挥·会审**（部长之上） | **组合** | 军机处/上书房**不是单个部长**，是召集多部长的 conductor = 主 Loop 本体：召六部 agent + 读 Hermes + 秒级→分钟级分层闸 + 聚合奏折 + 守 source-label/SSOT/确认门。 | 把它当"一个大 agent"是**范畴错误**。 |

## 2. 为什么综合能力最强（三镜片全过）
把三种本性完全不同的东西**彻底解耦、各自独立扩展**：判断（便宜/快/无状态/可替换）、记忆（复利/护城河）、执行（贵/有副作用/要闸）。
- **投入只浇在复利层**（Hermes 记忆 + 可横向复用 skill），**线性层按需租**（agent 算力 + OpenClaw 劳力）。
- 于是同一份力气，部长每过一个裁决周期更强（旧案更厚、画像更准），**成本却被钉在租用线上**——能力曲线向上复利、成本曲线被钉住。这就是"综合能力最强且最优化"的定义。
- **差异落在数据不在代码**（seed + 记忆命名空间 + skill 清单 + 有无手臂），才能涌现、能审计、能横向复制。
- 可逆（四层契约后热插拔，无单向门）· 长期（复利资产居中，易过时的 agent 隔离成可替换光标）· 可扩展（碰 mock 部门可逐个渐进升级，不需大爆炸重写）。

## 3. 各部门变体（按本质增，默认不堆）
| 部门 | 组成 |
|---|---|

| **钦天监** | 传感/预测型：agent 极薄做调度壳，本体偏 forecast 方法论 skill + cron 节律 + Hermes 趋势复利。无手臂。现碰 mock→先补真 agent+诚实空态。 |
| **锦衣卫** | 采证→核查→可信度分级→入库把关的 **skill-gate 流水线 + cron + 极薄 agent 壳**（非自由判断官）。锦衣卫 skill 已存在直接用。现碰 mock→先接真数据源+诚实空态。 |
| **太医院** | agent 脑 + 健康/医疗资源 skill + Hermes，无手臂。**铁律：只做健康资源台，绝不诊断/开处方**。现碰 mock→先 agent+诚实空态。 |

| **军机处 / 上书房** | **编排层=组合**（主 Loop 指挥位）。不是单个大 agent。现碰 mock→先把读路径接真主库 tasks。 |

## 4. 搭建顺序（贴既定 rollout：杠杆在记不在做）
1. **先搭记忆**：所有部长默认挂 Hermes 命名空间 + 补反写半圈，免费复利先吃满（回报最高、不需新决策、不碰红线）。
2. **方法论 skill 工具化**：SSOT 单表沉淀，懒加载（锦衣卫/礼部/刑部/钦天监），只给真有方法的部门。
3. **碰 mock 五部补 agent 本体 + 诚实空态**：先答"第一条真实数据从哪来"（铁律5），answerable 才接、答不出就诚实空着，绝不假 LIVE。
4. **抽薄编排契约**：harness 单点强制 source-label/SSOT/确认门；军机处/上书房读路径接真主库 tasks。
5. **最后才 OpenClaw 手臂**：需求拉动、per-action 挂、必经 jiqun:8081 + 人工确认门。

## 5. 反模式（最该避免）
- ✗ 把四原语当互斥候选问"户部是 agent 还是 skill"（框错的问题）。
- ✗ 记忆飞轮吃满前就给各部焊上 OpenClaw 手臂（为没有复利的昂贵执行付费，造空转产线能力）。
- ✗ 把每个部长写成 N 个 bespoke 雪花 agent 而非一壳 N 行配置（差异进 Python 分支 → 涌现/审计/复制全废）。
- ✗ 把投入砸在 agent 层（堆 seed/多 persona）当架构（线性消耗，换底模归零，造金鱼记忆部长）。
- ✗ 给所有部门配齐四件套显"完整"（加法伪装成架构，造一排模板部长 + 空转飞轮 + 维护地狱）。
- ✗ 把史馆做成独立 agent（造第二遍记忆层）、把军机处做成一个大 agent（范畴错误）。
- ✗ 碰 mock 部门急着接 live agent 充门面、用假数据凑齐四件套（把 DEMO 标成 LIVE）。
