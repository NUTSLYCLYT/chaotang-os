# 朝堂 · 一页产品定义（PRD · 2026-06-28）

> **朝堂 = 给小老板配一套 AI 班子，帮你拿钱、单、人、情报的主意——还不让你被坑。**

## 1. PRD（是什么 / 给谁 / 凭什么）
- **目标用户**：年收入 < 1000 万、**没有专业财务/销售/情报团队**的小老板。痛点：拿不准的决定（要不要花这笔钱、接这个单、信这条消息）没人帮判；请专业团队太贵、学专业工具太难。
- **核心价值**：你生意上每一个拿不准的**钱 / 单 / 人 / 情报**，问朝堂 → 得到一个**带证据、带风险、能照着做**的判断，且**记着帮你复盘**。
- **差异化**：横向"包裹式"——不比垂直工具深，但**一个顶一套班子、对大多数小老板够用**；护城河是**诚实**（不假装 LIVE、缺证显性、高风险人工门）。

## 2. 首发能用的 3 真面（其余白名单挡住、逐个调通）
| 真面 | 用户做什么 | 产出 |
|---|---|---|
| **户部·投资决策** | "这笔钱该不该花" → **一句话录入** | 准奏/缓议 + 评分 + 风险 + 缺证 |
| **兵部·销售决策+验客** | "这单该不该接 / 这客户对不对" | 成交把关 + 目标客户(ICP)验证 + 人扳机外联 |
| **锦衣卫·情报** | "市场/对手有什么我该知道" | 情报 + 可信度分级 + 异动预警 |
- **冻结项**：电池交易（独立产品，已冻进 `dev/_attic/frozen`，非核心）。

## 3. 工程要求（架构约束）
- 一套系统、67 版面、白名单单点控开放（`launch-whitelist.ts`）；架构大、运行小。
- 主库 `tasks` 单数据总线；确定性编排（router→merge，不让 AI 当指挥）+ WIP 上限 + 全链路 trace。
- 诚实层：`sourceLabel`(real/fallback/mock) + 缺证显性；guard 家族进 CI。
- 触真实产线资产 → 转后端 jiqun（铁律9）；前端边缘 decode-only、后端权威验签（铁律1）。
- **部署：多租户·公网共享**。

## 4. 上线前必过的 3 道门（缺一不可公网）
1. **C1 · token 验签**：后端签带 `tenantId` 的真签名 JWT，禁 `alg:none`。
2. **C3 · 多租户隔离**：6 表加 `tenant_id` + **数据层默认过滤**（不靠每端点手加 WHERE）。
3. **飞轮快回路**：从已有"采纳/推翻"数据学起（不等几月后 outcome），推翻率下降 = 在学。

## 5. 验收标准（可量化）
- 3 真面：`guard:pilot` 全绿（realDataSource + verifiedReal + ahaVerified）。
- 通信：`doctor:comm` 全通（jiqun 200 / 主库有数据 / 端点 200）。
- 安全门：`guard:auth` + `guard:tenant` STRICT 全绿才许公网。
- 飞轮：`agent_decisions` 有 outcome 数据 + 推翻率周环比下降。
- 真用户：≥1 个真小老板用完说"还好我问了"或愿付费。

## 6. 测试计划
- 单元/纯函数：hubu/bingbu/prospect/decision-extract/reality-state nodetest（已绿）。
- 集成：5 真面端点 200 + 跨租户读返回空断言（C3 后）。
- E2E：户部一句话→裁决；兵部验客→人扳机；飞轮喂决策→标结果→引旧案。
- 视觉：start/3真面 Playwright 截图（已做）。
