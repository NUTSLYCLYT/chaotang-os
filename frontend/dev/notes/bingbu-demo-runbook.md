# 兵部销售指挥部 · 真人 Demo 跑本（给做销售的老板看）

> 目的：让老板当场体验"问一句他真纠结的销售问题 → 兵部出带证据的答复"。
> 用他的真反应倒逼第4步「外联作战清单」该怎么设计——别我们拍脑袋。
> 时长：10–15 分钟。

## 0. 演示前（自己先跑通一遍）
- 生产：`pnpm start`（:3050），公网 `app.mingshuoxny.com/chaotang`；本地 `pnpm dev` → `localhost:3002/chaotang`。
- 确认三盏灯：
  - LiteLLM 大脑：`curl http://127.0.0.1:4444/health/readiness` 应 200（追问要它）。
  - 兵部有真数据：开 `/departments/ops`，中栏「今日待陛下拍板 · N 件」N>0。
  - 自己已登录（追问要真 session；用 e2e 假 token 会 Unauthorized）。

## 1. 开场（不讲 AI、不讲三省六部）
一句话：
> "你上周最难拍板的一个销售决定是什么？越具体越好——要不要接这单、合同有没有坑、客户值不值得谈。"

让他说一个**真问题**。不要替他想。

## 2. 当场把他的问题打进上书房
- 进「上书房」→ 下旨框，原样打他的话。例：
  > "客户要签独家代理合同，含违约金条款，预付30%，要不要签？"
- 下旨。这会写进主库 tasks。

## 3. 切到兵部，让他看队列
- 进「六部 → 兵部」(`/departments/ops`)。
- 指给他看三件事（都是真的，不是 demo 假数据）：
  1. **左栏销售编制 8 司**：兵部尚书/价策司/攻坚司/渠道司… 每司今日经手数。"这是一个完整销售部的编制，谁忙一眼看到。"
  2. **中栏他那张卡**：主办司徽章 + 兵部裁决（升维复核/补证/推进）+ 缺证 + 需跨审(户部/刑部) + 唯一下一步。"它已经把这单拆成销售部该问的问题。"
  3. 高危单会标 **"须人工确认·不得自动外发"**——"它不会替你乱承诺。"

## 4. 点「追问兵部」——这是 wow 时刻
- 点卡上的「追问兵部」。等几秒。
- 出来的不是一段聊天，而是：
  - 主答复
  - **证据**（逐字引用它依据的数据）
  - **假设**（数据缺时它明说假设了什么）
  - **冲突声明**（"这结论涉及付款，需刑部复核"）
  - **接地徽标**（绿"已校验" / 红"未接地·降级"——它对自己数字负责）
- 话术："ChatGPT 给你一段话，它给你证据、缺口和它会被谁推翻。"

## 5. 点卡 → 右栏详情
- 点那张卡，右栏出：主办/协办司各自判词 + 缺证清单 + **可生成的销售资产**（报价检查单 / battlecard / 大客户攻坚计划）。
- "这些它现在就能起草，但一律内部草案，要发经你确认。"

## 6. 收口问题（为第4步外联取真需求）
问他三句，记下原话：
1. "如果它帮你把'今天该打哪几个客户 + 开场白草稿'都备好，你按一下拨号——你要不要？"
2. "你最怕 AI 替你对客户做的哪件事？"（划单向门边界）
3. "刚才哪一屏让你觉得'这个有用'？"

## 失败兜底（别慌）
- 追问转圈很久 / 报错：说"大脑在排队"，改用**右栏详情**讲（详情是本地纯函数算的，不依赖大脑，秒出）。
- 队列空：先回第2步在上书房多下一两个销售旨意。
- 追问报 Unauthorized：你没登录/会话过期，重新登录。

## 演示后
