## #1 锦衣卫外部价数据源（GitHub 实搜 · 免费开源）

### 裁决：主用 akshare，HTTP 化用 aktools，全球兜底 yfinance
| 源 | 星 | 给什么 | 适配度 |
|---|---|---|---|
| **akfamily/akshare** | ⭐20.8k | 中国大宗/有色金属现货+期货：**碳酸锂(电池级)、铜、铝、镍**现货价；聚合上海有色/生意社/期货所 | ★★★★★ 中国电池厂首选 |
| **akfamily/aktools** | ⭐1.4k | akshare 的 HTTP API 包装（非 Python 服务可直接 HTTP 调） | 后端集成用 |
| **ranaroussi/yfinance** | ⭐24.4k | Yahoo 全球期货/ETF（锂相关 ETF、LME 金属） | ★★★ 全球兜底 |

### 诚实边界（必须讲清，否则又踩"假外部价"红线）
- ✅ **采购侧竞争能真比**：akshare 给**原材料现货价**（碳酸锂/铜/铝）→ "你电芯/铜排买得比当前行情贵吗"。电芯成本≈锂价驱动，可换算对比。
- ❌ **销售侧竞争无好免费源**：竞品**成品电池包售价**是商业不透明数据，GitHub/免费 API 都没有靠谱源 → 这一侧只能**锦衣卫人工录入/情报核实**，或继续标 ⚪。**绝不用 akshare 的原材料价冒充竞品成品价。**

### 锦衣卫消费设计（接现有 competitive-edge 灯）
```
后端 jiqun(铁律9:外部副作用/抓取在后端)：
  akshare/aktools → 取碳酸锂/铜/铝现货价 → 核实+标来源+时间戳 → 写一张"外部行情"表
前端(本仓,咨询/展示)：
  competitiveEdge('buy', 你的电芯采购价, 锂价换算的市场参考) → 🟢采购有优势/🔴吃亏
  数据带 sourceLabel + 时效(akshare 拉取时间) + "原材料行情,非竞品成品价"标注
```
- **「每天调研」= 后端 cron**（你说过先不搞自动任务 → 冻结）。现在：**按需拉一次 + 快照入库**，标清拉取时间。
- 映射判据：原材料行情比"买价侧"；成品售价侧维持 ⚪ 待人工情报。

## #2 下旨 → 立项 管线（你说"我来设计"）

### 总流程
```
1. 老板下旨(上书房/录入决策) → command 文本
2. classifyDecree(已建)：
     ├─ dispose(准/驳/批) → 既有裁决管线(不生新立项)
     └─ initiate(做/开拓/研发) → 进立项管线
3. 开创性下旨 → 建立项对象，按"是否触真产线资产"切分(铁律9)：
     ├─ 咨询性立项(无重资产，如"该不该做三轮·核成本")
     │     → 前端 runtime 建轻量立项对象 + 写主库 tasks(咨询语义、decode-only)
     └─ 产线性立项(触真资产：真备料/真报价/真采购/真交付)
           → POST 后端 jiqun /api/swarm/run 建真任务(铁律9，前端禁自建第二套产线)
4. 立项对象 → 丞相确定性路由召相关司(工/户/兵/锦衣卫) → 军机处会审 → 立项包(三色真假标)
5. 立项包=活对象：成熟度(🟢占比)/缺证/待裁/后续兑现弧；唯一真相在主库 tasks(铁律2 SSOT)
6. 用户裁决(采纳/补证/驳回/追问) → 持久化(铁律13.2.7 任务不丢)
7. 史馆归档 → 下次类似开创性下旨自动引旧立项(立项飞轮)
```

### 切分判据（一句话）
**这道开创性下旨，是"先想清楚"(咨询)还是"真去备料/报价/采购"(产线)？** 前者前端轻量立项，后者转后端真任务。三轮现在是**咨询立项**(还没真投产)，进入真备料/真报价时**升级转后端**。

### 数据契约（不新建平行类型，铁律2）
- 立项对象 = 主库 `tasks` 一行（带销售/财务/产品语义），import 现有 `contracts/task.ts` + `reality-state.ts` 的 sourceLabel。
- 前端落地放 `src/core/courtos/`，类型从现有 contracts import。
- 写主库走现有 `upsertPrimaryTask`；触真资产转 `jiqun :8081`。

### 落地顺序
```
① 前端:下旨入口接 classifyDecree → 开创则建咨询立项对象写主库 tasks → 上户部卡(把硬编码三轮卡变真下旨产物)
② 立项对象进军机处会审视图(复用 orchestrate 引擎)
③ 触真资产的立项 → 转后端 jiqun 真任务(需后端配合)
④ 立项包进史馆 + 下次引用
```

### 高危门（铁律4/13.2）
- 立项写主库 `tasks` = 写共享主表 → 提交前过独立会审 + 一条回归断言（如"咨询立项写 tasks 不污染 briefing 奏折读取"）。
- 立项包里每条挂 sourceLabel；触发开模/备料/真报价 = 单向门 → 人工亲裁。
