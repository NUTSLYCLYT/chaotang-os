# 朝堂瘦身 · 四刀整改天才设计（5 大神评价 → 4 刀收敛）

> 2026-06-25 由 7 角色批判评价(官比事多)+ 4 刀整改会审沉淀。承接六司设计套件。
> 判决:7 个会上桌投票的官 → **4 个真办事 + 1 枚保险丝 + 1 个出局做供给的军火库**。

## 0. 一句话
7 个官砍到 4 个真办事的（**丞相执笔 / 红线层守门 / 东宫待拍板 / 史馆兑现问责**），钦天降成保险丝、翰林移出做军火库，空洞补上、信号变纯；但**这刀能不能落地全押一件事——史馆能不能接到 jiqun 第一条真实兑现数据**：接得到飞轮真转、官越砍越强，接不到就是纸面砍官、东宫钦天翰林三处半残冻死。**先锤死那条真源，再谈解冻。**

## 1. 瘦身后统一架构
一条主 Loop + **4 个真坐裁决桌的官** + 1 条三面同表的确定性防线 + 会审产线 + 1 个供给层 + 1 枚保险丝。**没有第二套奏折/红线表/BlastRadius/兑现状态机。**

| 官 | 收编自 | 职责 | 关键机制 |
|---|---|---|---|
| **丞相·执笔** | （中书并入） | 拟旨，缺证检查吃"该类决策历史兑现率" | 笔/手闸 + 三必填 |
| **红线层·守门** | 门下+御史+锦衣卫 | 一张红线表三个面 | block-before/witness-after/intel-only + arbitrate + 金丝雀 |
| **东宫·待拍板** | 太子 | 唯一"裁决前"实体，一名一屏一事 | 单调棘轮 authority_gear（GEAR_0 影子→GEAR_N 复刻） |
| **史馆·兑现问责官** | （升格） | 补 outcome 空洞，归档即开兑现票据 | 外部事实锚点四态机，欠债怼回主 Loop |
| 钦天监（保险丝·半官） | — | 只剩死法地图否决，并入红线表 fatal_pattern | 三件套旋钮降 advisory/DEMO |
| 翰林院（军火库·出名册） | — | 只递弹药不投票，归基础设施层 | 确定性淘汰阈值，github 侦查冻结 |

## 2. 四刀招牌设计
### 刀① 太子+东宫合一 —「东宫·监国棘轮」
单实体/单屏/单档位。撤太子全部路由/类型/store/名册。东宫挂**单调棘轮 `authority_gear`**（只能往上一格、人可随时一键降档/冻结——刹车永远比油门好踩，corrigibility）：`GEAR_0 影子只读`（复用 shadow-label≠LIVE）→ `GEAR_1+ 全 LOCKED`。"影子收件箱"和"自动复刻器"是**同一根棘轮的两个档位**，不另起裂变炉灶。**裂变/A2A 冻结为 docs 留档 + LOCKED 槽**。上调唯一依据=史馆真实校准样本 + 人工解锁门 + env 闸（默认关）。

### 刀② 三监工→一条确定性红线层 —「一张红线表，三个量程档位的同一把尺」
不合并三个执行器（时间位不同，强并会焊死前后端 runtime），而是抽出唯一真相 `RedlineRule[]`（SSOT）。每行带 `enforcement: block-before | witness-after | intel-only` 决定哪个面执行 → 三面退化为对同表的纯函数投影 `projectFor()`，物理上不可能再各维护平行 map。
- **单一 severity**（internal<external<irreversible，L0-L4 派生）——删两套平行 BlastRadius。
- **门下**=T-0 进程内事前物理挡；**御史**=T+ε 进程外事后只挡入史；**锦衣卫**=对外 intel-only 永不叫停、只升情报旗给东宫。
- **金丝雀探针**：每条红线挂"合成坏样本"，周期灌进三面，任一面没拦住=这条防线腐烂→自检告警（**监工监不到，先监工监工自己**）。
- **arbitrate() 确定性仲裁**：近因优先/不可逆优先/对外只升级，留完整 trace。

### 刀③ 补 outcome 问责 owner —「兑现票据 + 史官记账」
不增角色，史馆从"被动归档员"升"史官·兑现问责官"。决策进采纳态归档那一刻**强制开一张兑现票据**：①承诺（赚多少/做成什么，可机读）②兑现判据（确定性事实锚点，不是形容词）③到期日 ④价值来源（jiqun 产线交付/财务流水/客户签收）。**无票据不得归档（fail-fast）**。到期外部锚点回填四态（兑现/落空/打折/失联，**严格区分"没做成"与"没测到"**）；**欠债自动怼回上书房**（防空转咽喉）；仅"采纳+兑现确认"态反写记忆，**禁 LLM 自评**；史官只读记账、绝不自动追单（corrigibility）。

### 刀④ 翰林移出 + 钦天瘦身 —「翰林=军火库，钦天=保险丝」
- **翰林**=军火库/平台供给层：锻造能力、记账，但**不坐裁决桌、不投票**，给军机处递弹药自己不开枪。治理名册 7→6。
- **钦天**=保险丝：只有一个确定性行为——命中"已知必死"图样→硬熔断（确定性否决+L≥3 人工门）。**死法地图并入刀②统一红线表 fatal_pattern 行**（不另起平行表）。**三件套旋钮全降 advisory-only/源标 DEMO**——没校准的概率判断一律不得装裁判，等史馆真实校准样本+双门才逐个解冻。

## 4. 优点
1. **直击官比事多**：7→4 真办事官+1 保险丝，太子删除、三监工同表、翰林归位、钦天瘦成查表。
2. **补上全局最大空洞**：史馆升兑现问责 owner，首次让"拍板有没有变成真实价值"有人负责，零新增版面，首次闭合 PDCA。
3. **corrigible+防空转配平**：东宫棘轮单调只增+人工零阈值降档；史馆只读问责+欠债怼回=既不失控也不空转。
4. **确定性防线可审计**：一行三面+单 severity+arbitrate trace+金丝雀，把"防线本身腐烂"从不可见变可见。
5. **诚实源标贯穿**：没校准的概率判断（钦天三件套、东宫影子）全降 advisory/DEMO，杜绝装饰性裁判用假数据冒充 LIVE。
6. **守铁律3/5/13.9**：复用 grounded 原语，溶得进不给新屏；每刀 resolve 后强制 simplify 删僵尸；碰产线仍转 jiqun。

## 5. 仍存缺点（说真话）
1. **头号系统性风险——全盘解冻命脉死绑"史馆能不能接到第一条真实兑现数据"**。东宫棘轮上调、钦天旋钮解冻、翰林 candidate 激活，三处解冻条件都是"史馆攒够真实校准样本"。若 jiqun 产线/财务/签收无可机读兑现事件源，票据永远"失联"，台账退化成一墙红灯，**整改沦为纸面砍官+三处半残冻死**。MVP 前必须先锤死一条真源。
2. **统一红线表成最热高危共享单点**：一条 matcher 写宽即 block 全朝堂，中心化红线=中心化故障；金丝雀样本会随真红线腐烂给假绿。
3. **"一张表三个面"不是真合一模块**（仍是三条跨进程路径），易被误读成"已合并完"无人再收敛→养新僵尸（铁律3反噬）；必须靠 R1/R2/"仅一处 BlastRadius 声明"CI 断言钉死。
4. **砍完短期更弱、空气官换名仍是空气**：东宫 GEAR_0=旁观预测器、钦天保险丝初期稀疏低命中，不把影子命中率/拦截价值显眼上墙=白砍。
5. **二义性投毒**："落空"与"失联"不严格分态把"未测量"误记成"失败"，污染兑现率、毒化学习样本。
6. **高危改动密集全部命中铁律4**（写共享红线判据+给叫停加权重+写共享史馆主表+决策卡视觉权重）→ 每刀必须独立会审+一条回归断言。
7. **反馈环极长**：兑现滞后数周数月，短期 outcome 信号稀疏，飞轮转得慢。

## 6. 落地顺序（守铁律3 resolve 先于 simplify + 数据拉动）
0. **刀①撤太子**（最干净独立先拿下）：删太子路由/页面/类型/store/名册，东宫升唯一实体；resolve 跑绿双门 → simplify grep 双实现留东宫删太子+死函数；回归断言"待拍板队列零太子残留+影子 source≠LIVE"。−1 空气官。
1. **刀②抽统一红线表 SSOT**（高危共享，强制独立会审，刀④前置）：resolve 新建 redline-table.ts 迁判据，门下御史读新表得等价结果，断言"历史样本新表投影===旧硬编码零漂移" → simplify 删本地硬编码+第二套 BlastRadius，CI 断言"BlastRadius 只剩一处声明"。
2. **刀③接第一条真兑现源**（数据燃料，优先级最高，①②④解冻全靠它）：史馆归档加兑现票据字段先人工回填验"第一条真实兑现数据从哪来"，溶不进真源就冻结绝不先建看板；优先接 jiqun 产线真实交付事件成确定性回填锚点。
3. **刀④翰林移出+钦天死法并入红线表**（依赖第1步）：翰林标基础设施改 6 角色名册+删旧投票通路；钦天死法迁红线表 fatal_pattern 挂 pre-commit，旋钮降 advisory，断言"命中 fatal_pattern 必触发人工门""未校准旋钮绝不参与放行"。
4. **刀②补仲裁+权责链+金丝雀**：arbitrate()+owner/stopAuthority+响应超时，每条红线挂 canary，断言"irreversible veto 永压 pass"+故意注入一面失效→探针必红（验探针真有效防假绿）；锦衣卫旗溶入东宫，单测"锦衣卫永不返回 block"。
5. **刀③闭合学习环**：兑现确认态反写记忆杠杆+历史兑现率喂回缺证检查+欠债怼回上书房。飞轮真转。
6. **数据拉动逐个解冻**（长期不许诺时间）：史馆攒满 N 条真实校准样本后才放东宫 GEAR_1/钦天某旋钮/翰林 candidate，三同时+双门，每次只解冻一个、删一个旧 advisory 态；每步先答"第一条真实数据从哪来"，答不出继续冻。
