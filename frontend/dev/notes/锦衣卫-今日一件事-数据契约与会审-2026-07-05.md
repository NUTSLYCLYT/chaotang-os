## ② 数据契约：仙狐后端（jiqun_ai）需产出（不在本仓做）

「今日一件事」要真正点亮，仙狐分级采集须为每条信号提供：

| 字段 | 含义 | 前端消费 |
|---|---|---|
| `leadTime.edgeFirstSeenAt` | 边缘/非主流源**首次**捕获时间(ISO) | 算领先度起点 |
| `leadTime.mainstreamHitAt` | 主流媒体首次命中(ISO)；未命中=仍领先 | 算领先度终点 + 衰减 |
| `credibility` 真值 | 需真区分 low/medium/high/verified（现 rowToSignal 硬编码 medium） | `isTrusted` 判 gold 象限 + 来源等级 |
| `soWhat`（可选） | 一句「对我们=?」 | 卡上「所以呢」块；缺则隐藏不臆造 |

配套后端改动：`intel_signals` 表加 `edge_first_seen_at` / `mainstream_hit_at` / `credibility` 列；
`rowToSignal` 真实透传；仙狐区分「边缘源 vs 主流源」两级采集并记首见时间。

诚实纪律（铁律4，已用测试锁）：**无 `edgeFirstSeenAt` → 领先度不可算 → 卡不渲染，绝不显示写死数字。**
