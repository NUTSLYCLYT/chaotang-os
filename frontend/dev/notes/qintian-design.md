# 钦天监设计 ·「尾部审计 + 逆周期温度计 + 校准良心」（5 大神一致）

> 2026-06-25 由钦天监会审（Taleb/Howard Marks/Kahneman/Andrew Ng/Munger 罕见高度一致）沉淀。
> 用户定位:预测/情景推演官。大神收口:钦天监不是预言官,是承保人——从不预测车祸,只定费率和拒保线。

## 0. 一句话
**钦天监不是算命的，是朝堂的尾部审计官 + 逆周期温度计 + 校准良心**：不报涨跌、不给点位，只回答**「在什么组合下朝堂会死、现在离死多近、上次我说的话兑现了吗」**，并据此把审查旋钮**越顺越拧紧、越热越收**。它是唯一被允许说「我不知道，但我知道我有多不知道」的官。

## 1. 三条主轴
- **主轴1 · 输出=情景+压测+校准，绝不产点预测**（点预测是 Goodhart 诱饵：一旦考"准不准"必回归均值押稳的，把肥尾藏进 base 情景换准确率）。
  - base 情景重定义为**「参考类基率锚」**，禁带采纳权重、**禁任何视觉权重**（加粗放大即诱饵），真正进风控只有 pessimistic 尾部 + preActions。
  - `QintianScenario.probability/confidence` 语义改为「我们对这条路径**还没被证伪**的把握」，区分"还没出事"(无证据)与"安全"(有证据)；DEMO 态 probability 一律 **null** 而非 0.5 假中位。
  - **判据：任何情景给不出 falsifier（一旦出现即证伪我的可观测触发器）即非法、拒入库**；"长期向好"这类不可证伪话术不准出口。
- **主轴2 · 三件招牌物落到现有契约、不新建平行类型**：
  - **(a) 死法地图 Ruin Map**（reverse stress test）：复用 `triggerConditions+preActions`，从"假设朝堂已死在这一项"倒推致死条件链，**correlation 取最坏=1** 算联合概率地板 p10/p1，输出左"要死需这 N 件同时成立"、右"其中几件已从史馆真实事件勾选成立"。
  - **(b) 逆周期温度计**：0-100 热度分 → 审查旋钮档位（只读已发生事件密度）。
  - **(c) 验签谱/认输墙**（self-refutation ledger）：复用 `QintianCalibrationRecord`，每条预测落库即冻结 `resolveBy + 可机判 resolution_criteria`，到期由确定性 resolver（不让 agent 判 agent）对照史馆真实 verdict 打分。
- **主轴3 · 守铁律**：源标诚实（seed→DEMO 水印、禁进风控聚合）；只采纳态反写；高风险尾部否决转 jiqun 后端人工门。**首屏 C 位给认输墙+温度计**（先看"离死多近""上次错多惨"），**base 情景永不占 C 位、永无视觉权重**。

## 2. 逆周期温度计（5 路信号，只读"已发生"，禁前瞻词）
0-100 = 5 路可量化、可独立审计信号加权（全取自朝堂自有真实事件流，不接外部行情、不依赖预测模型）：
| 信号 | 权重 | 含义 |
|---|---|---|
| **相关性奔1** | 25 | 各决策依赖证据是否塌缩到同一信源/假设（evidenceIds 重合度）→奔1=分散是幻觉、系统性引信 |
| **连胜计数** | 25 | 史馆连续"采纳且 confirmed、零 refuted"链长→连胜是过度自信的麻醉剂，越长越危险 |
| **复制速度** | 20 | 太子裂变/方案复刻环比加速度→加速即过热 |
| **估值热度** | 15 | 承诺回报÷参考类历史中位 + blast-radius 近30天爬升斜率 |
| **缺证率倒挂** | 15 | 决策推进速度 vs 证据补全速度的差→信心涨得比证据快即热 |

输出**只映射三档审查旋钮**（非买卖信号）：`0-40 常温`(标准审查) / `40-70 偏热`(缺证门收紧、人工门下移一级、需双证) / `70-100 过热`(p10 地板自动抬高、高相关敞口强制拆分、reverse stress 转必跑、不可逆走后端双签)。**档位人工可一键覆盖并留痕；温度计自身也进验签谱（事后看高温窗口是否真更高事故率）。**

## 3. 接四司风控（尾部一票否决方，不投期望收益票）
丞相每拟高风险旨 → 钦天监推**「死法倒推签」（Pre-Mortem Wall）**：不问"会成吗"，强制写最可能三种死法，只对死法专算 p10/p1，过**亏不起(不可逆付款/违约金)、框不住(blast-radius 超阈)、传得开(对外承诺/独家锁定)** 三条 ruin 红线，**命中任一即否决（靠后果不可逆，不靠概率高低）**。签头盖当前温度（越顺越逼你先想怎么死）。**关键边界：钦天监输出不可被"采纳"成行动，只能调旋钮+给红线，真行动权在丞相/太子**（让预测者没有押对赚分的通道，就没动机刷准确率）。

## 4. 校准 KPI（只考校准度，绝不考命中率）
命中率奖励押稳的、惩罚说真话的尾部预警→必教模型沉默。三主考 + 五防刷分：
- **主考**：Brier reliability 项（说70%的事是否真约70%发生）+ discrimination/sharpness 下限闸 + 尾部稀有事件单独分桶×3。
- **五锁**：① 只结算带可机判 resolution_criteria 的预测；② coverage 下界（沉默=弃权=记最差，堵死"不预测就不会错"）；③ **惊讶罚**（漏报肥尾 ruin→单次重罚压过所有积分，让"想准不敢报尾部"数学上不划算）；④ 反 sandbagging（概率长期诡异吻合人类答案=在抄，触发审计）；⑤ 只采纳态反写 + 确定性聚合器对照史馆客观 verdict，**钦天监不许给自己预警判分**。
- 元规则：**奖励"叫对了狼"而非"从不叫狼"**——不奖"你说对了"，奖"你说的概率配得上世界的真实频率，敢到期自动打自己脸"。

## 5. 去 mock + 第一条真实数据（诚实化优先于真实化）
- **断奶**：seed 一律显式标 DEMO（灰底水印 + "尚无真实情景，待第一条决策归档"），p10/旋钮/风控聚合**一律不读 seed**；五路信号哪路无真实台账就那路灰显缺位，**绝不填满骗出好看热度分**。
- **第一条真实数据 = 回填弧**（不去外面找新数据源）：每张进军机处的奏折，其 `preActions+triggerConditions` 本身就是"对未来的下注"。用户采纳时把"假设/触发条件/预期 payoff"冻结为预测记录（source=primary），史馆归档时事后兑现回填 verdict。
- **两条腿**：压测镜片靠四司联审实时就能真（基于真实敞口当场算）；温度计+校准曲线靠史馆回填弧慢慢变真（满 30 条到期记录才点亮曲线、摘 DEMO 徽）。冷启动 <10 对整板标 MIXED「积累中」。

## 6. 三方边界（钦天监 vs 丞相 vs 御史）
- **钦天监** = 尾部+周期镜片（事前/未来向）：「我们会不会死」（系统尾部），调旋钮+给 ruin 红线，不拍板。
- **丞相** = 拟旨执行镜片（当下决策）：「这道旨该不该下、怎么下」（行动权所在）；钦天监给它情景输入与死法地图，但丞相才采纳。
- **御史** = 合规廉政镜片（事后/已发生违规）：「有没有人做了不该做的」（合规问责）。
- 交汇（高风险不可逆）走联审，确定性聚合不互判。

## 8. Rollout
0. **断奶诚实空态**（本周）：forecast BFF 接 reality-state，seed→DEMO 水印，禁 seed 进聚合；回归断言"seed 不得渲染成 LIVE/不进聚合"。
1. **逆周期温度计点亮**（信号来自现有 tasks/报价/签约/史馆表，最快能真）：5 路确定性计算器→三档旋钮；每路一条单测。
2. **死法地图接四司联审**（不依赖 forecast 表、基于真实敞口当场算）：高风险拟旨推死法倒推签，p10/p1+三红线否决；双门（独立会审+回归断言"悲观情景不得渲染成已定论/不得加视觉权重"）。
3. **验签谱回填弧**（等主 Loop 真转）：采纳冻结预测→史馆兑现回填→确定性 resolver 算 Brier，满30条点亮、摘 DEMO 徽。
4. **校准 KPI + 防刷分五锁**，认输墙挂首屏 C 位。

## 9. 顶级风险
1. **温度计变新 Goodhart 靶子**（决策者拆小金额/做杂证据压相关性刷绿）→ 配方半盲(只露档位不露权重)+定期换信号+加人不可优化的外部锚(真实违约/退款密度)。
2. **退化成没人看的装饰仪表盘** → 第一天就硬接一道有牙齿的真实闸门（过热档强制抬 p10/拆高相关敞口），宁可管得少而硬。
3. **framing 反噬**（悲观情景加帝金环→御座误当高概率未来）→ reverse stress 视觉低饱和、永远并排基率墙、硬标"可能性不是预测·p1级"；决策卡视觉权重改动过铁律4双门。
4. **验签谱判定被污染**（resolution_criteria 写模糊/resolver 偷用 LLM 判）→ resolver 必确定性机判、结算条件预冻结不可改、refuted 与 confirmed 一样显眼。
5. **seed 漂移**（急着上线用 seed 冒充 turso）→ 冷启动 <10 对整板标 MIXED「积累中」，绝不假装。
