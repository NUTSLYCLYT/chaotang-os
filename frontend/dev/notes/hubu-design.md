## 0. 一句话

户部 = **老板的 CFO 驾驶舱**：把现金/预算/报价/融资/投资/税务变成「今天最该拍的几件 + 一拍即决 + 永不被盲点坑」，
产出比真办公更可信（带证据/缺证/风险/来源）的财务奏折。**不是财务仪表盘，是决策闸门。**

## 2. 面板内容（substance：v1 拍板卡 ⊕ 遗产三引擎，让数字从"—"变真）

**拍板卡（中栏卷轴的每一张）= 30 秒拍板单元：**
- 头：优先级徽(P0朱/P1金) + **清洗后真标题** + 预算 / **ROI** / **回收期**（来自 ROI 引擎，不再"—"）。
- **可信度灯**：数据完整度 × 风险敞口 → 🟢有据/🟡有假设/🔴需复核/⚪缺证。
- **圣裁四段**（对齐铁律13.2.6 奏折最小合法字段）：
  - 结论 = 户部裁决 = 遗产 `recommendVerdict` → **准奏 / 削减分阶段(adjust) / 缓议补证(hold) / 驳回(reject)**。
  - 依据 = 优先级评分(0-100) + 风险敞口 + 哪条最关键。
  - 缺证 = 缺哪条证据才能更确定（显性，不藏）。
  - 风险 = 最大风险一句（尾部/单向门）。
- **圣裁印**：`ScrollSealBadge` 朱红印——准奏盖朱印、驳回盖灰印，**须绑真实裁决事件**(DESIGN §3，无事件不盖)。
- **动作**：`ActionButton` 四变体——准奏(gold)/补证(soft)/驳回(danger)/追问户部(ghost)。
- **单向门强制门**：贝索斯单向门(预付/独家/违约金/大额) → 卡上「需陛下亲裁」+ 印章留空待盖，禁一键静默(铁律13.2.5)。

**右栏 ROI×风险四象限**（遗产 §4.2 可视化，户部独有杀手图）：
左上 高ROI低风险=绿「优先投」｜右上 高ROI高风险=黄「谨慎」｜左下 低ROI低风险=灰「观望」｜右下 低ROI高风险=红「否决」。待批项目点在象限里，老板一眼看清全盘。

**左栏省税高光**：「本月已帮你合法省税 ¥X」——税务岗(Schneier 内核)的自带 ROI 钩子，让价格敏感的小老板愿意付费。

## 3. 三引擎（遗产 §4，让卡上数字变真的发动机）

- **ROI 引擎**：`computeROI=(rev-cost)/cost`；`payback=cost/月现金流`；优质门槛 ROI>20% 且回本<18 月。
- **风险矩阵**：`riskExposure=预算规模系数×风险系数`；high×大预算→敞口>70→触发 hold/reject。
- **优先级评分**：`0.4·ROI + 0.3·战略价值 + 0.3·(100-敞口)` → 0-100 → P0/P1/P2。
- **裁决规则**：评分≥75且敞口<50→准奏；60-75→削减分阶段；40-60或敞口>70→缓议；<40或ROI负→驳回。

> 这三引擎是**纯函数**，可在前端算(无副作用咨询)；一旦触碰真实付款/对外报价→转后端 jiqun(铁律9)。

## 4. 班底（一引擎多班底，已建 `hubu-roster.ts`）

小公司轻班底 6 岗(出纳/会计/税务/融资/投资/预算，v1 默认)；大公司 = 基础 6 + 财务总监/成本/内审/财资；用户可增减。
每岗一位守护大神内核(开发态会审镜片，AGENTS.md §12.1)：出纳·大野耐一 / 会计·达利欧 / 税务·Schneier / 融资·马克斯 / 投资·贝索斯 / 预算·马克斯。

## 5. 五大神一致

- **张小龙**：首屏只给最急 6 件，复杂折叠；班底默认收起；省税高光当钩子。**默认就好用，定制可选不强迫。**
- **Rams / Jobs**：less but better——一张数字全真、敢让老板签字的卡，胜过十张漂亮但写"—"的卡。先让数字变真，再美化壳。
- **贝索斯**：单向门强制人工亲裁门，不让 AI 静默替老板承诺。
- **马克斯 / 塔勒布**：风险敞口四象限 + 尾部风险；缓议/驳回敢说出口，应声虫无价值。
- **德鲁克**：老板要决策不要数据洪水——每个面板元素自问「这帮老板更快拍板了吗」，否则砍。
