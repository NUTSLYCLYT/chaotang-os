# 朝堂 OS · 整体美工 UI 升级方案（看了就会用 · 用了就会买）

> 日期：2026-06-23　主控：礼部 + 工部前端匠　依据：17 页 1440 实测（`dev/screenshots/audit-2026-06-23/`）+ 视觉圣经 + 素材库盘点
> 北极星不变：电影级 AI 决策操作系统 —— 进的是真朝堂，不是模板 dashboard。
> 本方案的唯一 KPI 不是"更好看"，是**转化**：让陌生老板 3 秒看懂、10 秒上手、用一次就信、信了就付费。

## 二、设计方向（一个有观点的方向，不留遮羞布）

**方向名：电影级朝堂决策舱（Cinematic Court OS）**
延续本仓冻结的**暗金 / 帝金 + 玻璃拟态真景深 + HUD 驾驶舱**，加一条统领纪律：

> **每一个房间都站在金殿里。** 内容可以是表单、是数据、是空态，但它必须站在有纵深、有暖光、有器物感的朝堂场景中——绝不允许"裸黑底 + 卡片网格"再出现。

三条视觉信条（统领全部改动）：
1. **一屏一主角**（十戒#1）：圣旨 / 大殿 / 人物 / 数据，只能有一个当 hero。
2. **金光预算 ≤ 8%**（十戒#2）：帝金 `#F0C66A` 是权力与状态信号，不是装饰底色。
3. **动效解释状态**（十戒#6）：展卷=进入、落印=确认、聚光=待办、变红=高危。只碰 `transform/opacity/clip-path`。

### 审美基准（用户硬要求 · 每页过六关，缺一不验收）

这是本方案的"质量门"。每个主线页改完，逐条打勾才算完成；任一条不过，打回。

| 关 | 要求 | 可验收判据（不是口号） |
|---|---|---|
| 1 **整洁** | 界面不堆砌、不杂乱 | 首屏 ≤ 3 个信息块抢眼；无原始 JSON/log 文字墙；同类元素间距统一（8/12/16 网格）；留白是设计不是漏排 |
| 2 **对称** | 构图平衡、有秩序 | 中轴对称或主从平衡（如大殿御座轴线、卷轴居中+左右等宽栏）；左右玻璃栏宽度/内边距镜像一致；卷轴横幅双finial 等高 |
| 3 **清晰明了** | 内容一眼读懂 | eyebrow→title→一句话三级递进；红黄绿状态语义统一；正文 ≥13px 行高 1.85；3 秒答得出"是什么/能不能做/下一步谁办" |
| 4 **细节皆艺术** | 每个细节都讲究 | 角标/描边/印章/封签/分隔线都是器物级处理（`.hud-corner` `.metal-edge`）；按钮三态（hover/focus/active）都被设计；数字滚动、入场错峰、呼吸光都到位；无一处"默认 Tailwind 卡片" |
| 5 **古风不失韵味** | 中式宫廷气质贯穿 | 标题用 Noto Serif SC 衬线（`.display-serif`）；器物语言（圣旨/卷轴/印玺/脉案/簿册/源流图）替代通用 card/list/form；暖光+暗角+低透明纸纹；帝金作权力信号；忌塑料感扁平卡 |
| 6 **艺术性/高级感** | 拿得出去、像作品 | 1440 首屏单独截图即可当宣传图；有记忆点（唯一视觉主角）；层次靠尺度对比与景深，不靠堆装饰；通过 `pnpm harness:three-axis-ui` 三轴评审不低于基线 |

> 一句话压舱：**整洁=做减法，对称=立秩序，清晰=讲层级，细节=器物化，古风=衬线+器物+暖光暗角，艺术=一屏一主角且能截图传播。** 六关本质是把"高级感"翻译成可勾选项，杜绝"凭感觉说好看"。

## 三、核心武器：`<CourtSceneShell>` —— 方差归零的那一个组件

把 `/overview` 大殿那套 9.5 分的"壳"**抽成一个产品级组件**，强制所有 C/D 级页面套进去。这是整个方案的杠杆点：**改 1 个组件，抬升一半页面。**

### 3.1 组件解剖（anatomy）

```
<CourtSceneShell scene="throne" sourceLabel="LIVE" hero={<...>} dock={<...>}>
  ...page content...
</CourtSceneShell>
```

| 层 | 内容 | 复用 / 新增 |
|---|---|---|
| L0 场景背景 | scene preset → 素材库电影背景图 + 暗角 vignette + 局部暖光 | 复用 `public/assets/*` + CSS radial-gradient 暗角 |
| L1 氛围层 | 低透明纹理 / 极轻噪点 / 缓慢呼吸光 | 复用 `.animate-breathe` `.animate-pulse-glow` |
| L2 HUD 边框 | 四角金线角标 + 金属描边 | 复用 `.hud-corner` `.metal-edge` |
| L3 主角槽 hero | 立绘 / 圣旨卷轴 / 群臣 —— 由页面传入，**唯一视觉主角** | slot |
| L4 内容区 | 业务内容（表单 / bento / 列表）压在场景之上，玻璃面板托底 | 复用 `GlassPanel` |
| L5 来源铭牌 | 右上角 `SourceLabelPlaque`（见 §五） | 新增 |
| L6 底部操作台 dock | `按此下旨 / 展卷 / 问丞相 / 资料` 等主动作，常驻 | 复用 `GlobalInteractionBar` 范式 |

### 3.2 五个 scene preset（直接映射素材库，零新素材）

| preset | 背景素材 | 主角默认 | 用于 |
|---|---|---|---|
| `throne` | `scene-overview-throne` / war-room | 御座轴线 | 御座裁决、命令中心 |
| `council` | `scene-overview-throne`（群臣大殿图） | 群臣分列 | **大殿会审 grand-council**、三省 |
| `study` | `public/study/study-v3-scene.webp` | 圣旨卷轴 | 上书房、单问题决策 |
| `office` | 对应部门 `*-bg.png` | 部门大臣立绘 | 六部、太医、锦衣卫 |
| `archive` | `assets/shiguan` | 档案大殿 | 史馆、藏书阁、蜂群（技术页也站殿内） |

### 3.3 三态也站在金殿里（关键）

`DataState` 的 loading/empty/error **不再是裸骨架**，而是嵌在 shell 内：
- loading → "群臣就位中…"（聚光呼吸）
- empty → "此案待开"（卷轴未展，给一个明确主动作）
- error / FALLBACK → 场景压暗 + 明示徽章（**绝不伪装成 LIVE**，见 §五 / 铁律 §13.2）

> 验收：套上 shell 后，**全站不存在任何"白底/纯黑底 + 居中文字"的裸页**。

## 四、转化漏斗的视觉设计（"看了就会用 / 用了就会买"逐层拆解）

把抽象目标翻译成每一屏可验收的视觉动作：

### 4.1 T+0–3s · 看了就会用（首屏记忆点）
- **一屏一主角**：进任何页，0.5s 内眼睛被唯一 hero 抓住（大殿=御座、上书房=圣旨、部门=大臣）。
- **首屏可截图传播**：每个核心页的 1440 首屏必须单独拎出来就是一张"宣传图"。验收=截图入 `05-our-best-shots/`。
- **eyebrow→title→一句话**：`.page-eyebrow`(10px 描金) → `.page-title`(24px 衬线帝金) → 一句白话说清"这是什么"。戏剧化尺度对比，别只差 2px。

### 4.2 T+3–10s · 唯一主动作（零迷路）
- **CTA 唯一且帝金**：每屏只有一个"下旨 / 裁决 / 上书"主按钮用帝金实心；次动作降为描边/幽灵按钮。金光预算钉死 ≤8%。
- **三态被设计**：hover 微浮起+金线亮、focus 金描边、active 落印反馈。复用现有 `StatusPillButton`，补 hover/active。
- **下一步谁办**：底部 dock 永远回答"接下来点哪"。

### 4.3 用的过程 · 用了就信（信任 = 付费前提）
- **`SourceLabelPlaque` 当卖点**：把诚实做成视觉资产。`LIVE`=帝金器物铭牌（这是真本事）、`LIVE_SWARM`=蜂群环、`MIXED`/`FALLBACK`/`DEMO`=明示降级。**用户信"它不骗我"，才敢把真决策交给它 → 才会买。**
- **证据可见**：上传=证据器物（封签/卷宗），不是普通附件。缺证用红黄绿明示，别藏。

### 4.4 关键时刻 · 落印仪式（掌控感 = 敢买）
- **高风险人工确认门做成"落印"**：股权/合同/报价/付款等（铁律 §13.2#5）触发 `SealConfirm` —— 卷轴展开 + 帝印悬停 + 用户亲手"落印"才生效。把"系统替我做了重大决定"的恐惧，转成"我盖章我掌控"的爽感。这是 SaaS 决策类产品最强的付费锚点。

## 五、设计系统增量（不破冻结资产的前提下，只新增 4 件）

冻结红线不碰：`globals.css`(727行) / `design-tokens.ts` / 18 keyframe / 帝金色值 / 启动时序。

| 新增组件 | 职责 | 复用底座 |
|---|---|---|

| `SourceLabelPlaque` | 来源铭牌器物（§4.3） | reality-state 归一（SSOT，铁律§13.1）+ gold-text |

## 六、主线逐页升级蓝图（直升主线 9 页 · 按 ROI 排序）

每页格式：现状分→目标分 · 改法 · 素材 · 过哪几关。

### Phase 0 — 抽 `<CourtSceneShell>` + 把现有卷轴模板组件化（杠杆，先做）

- 验收：在 `/overview`（电影壳）和 `/manor-dept/finance`（卷轴壳）上替换不掉分；过关 1/2/4。

### Phase 2 — 填中部黑洞：太医院 / 户部 / 军机处（统一改法复用 3 页）

4. **一条回归断言（铁律#4）**：如"FALLBACK 不得渲染成 LIVE 帝金徽""裁决落印前不得写库"钉成测试。

6. **构建双门**：root `tsc --noEmit` + `pnpm build`（build 更严，每改 tsx 必跑）。
