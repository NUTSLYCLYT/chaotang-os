## 二、用户重点四项的专业设计

### 1) 薪酬体系（薪酬司）
- **岗位价值评估**：IPE / 海氏(Hay) 三要素(知识技能·解决问题·责任) → 岗位点数 → 职级。
- **宽带薪酬**：每职级设带宽 `min / mid(=市场50分位) / max`；带宽重叠度 ~40%。
- **定薪**：新人按 0.8-1.0 分位值；调薪走"绩效×当前分位"矩阵(高绩效低分位涨最多)。
- **人力成本**：月薪×12×1.4(社保公积金)；人力成本率 = 人力成本/营收(行业基准对标，锦衣卫填外部)。

### 2) 激励政策（激励司）
- **短期**：① 绩效奖金(年终/季度，与考核挂钩) ② **销售提成**(阶梯/封顶/回款挂钩/团队分配) ③ 项目奖。
- **长期**：① **期权(Option)** ② 限制性股权(RSU) ③ **虚拟股/分红权**(不稀释控制权，适合小老板) ④ 超额利润分享。
- 设计原则：短期保当期、长期绑核心；小老板优先**虚拟股/分红权**(给钱不给控制权)。

### 3) 期权激励 ESOP（激励司·专业要点）
| 要素 | 标准 |
|---|---|
| 期权池 | 总股本 10-20% |
| 行权价 | ≥ 授予时公允价(税务合规) |
| 归属 vesting | 4 年 + 1 年 cliff(满1年归属25%，之后按月/季) |
| 行权窗口 | 归属后 + 离职后 90 天内 |
| 加速归属 | 被并购/IPO 触发 |
| 离职回购 | 未归属作废；已归属按约定价回购 |
| 退出 | IPO/并购变现；设回购条款防僵局 |
> 红线：期权涉真股权=不可逆+法律(铁律9)，**必须转刑部+专业律师**，前端只做方案咨询。

### 4) 奖惩措施（考功司正向 + 劳关司负向）
- **正向阶梯**：即时奖(≤当天) → 月/季度之星 → 晋升 → 长期激励授予。
- **负向阶梯**：口头提醒 → 书面警告(留痕) → **PIP(30-60天)** → 调岗降级 → 解除(走辞退会审)。
- 红线：负向到"解除"必走辞退跨部门会审(劳关+刑部+户部)，证据不全禁硬来(见 termination-review)。

## 三、各司专业产出文件标准（务必专业）

### 统一文件标准（每份产出必含 9 段）
```
①标题 + 文号 + 版本 + 日期    ②适用范围/对象
③事实依据(每条带 sourceLabel:LIVE/上传/缺证)   ④专业分析(引擎算法/标准)
⑤结论与建议(分级:可行/有条件/不可行)   ⑥风险与缺证(显性,不藏)
⑦法律/合规依据(劳动法条/政策文号)   ⑧成本/影响(户部口径)
⑨审批与生效(签批链/人工确认门)
```

## 四、与已建引擎/系统的对接
| 已建 | 对应司产出 |
|---|---|
| promotion-review | 考功司《转正评估报告》 |
| termination-review | 劳关司《辞退合规方案》(劳关+刑部+户部会审) |

| policy-declaration | 申报司《高新认定自检报告》 |

- 复用：decree-classifier(下旨路由)、project-maturity(立项成熟度)、reality-state(sourceLabel)、planUnifiedReview(跨部门门)、dept-external-hook(薪酬/人力成本对行业基准)。
- 跨部门确定性门(spec §7)：定薪/激励→户部；辞退/期权/劳动风险→刑部；组织调整→兵部+户部。
- 铁律9：真发offer/真定薪/真授股/真解除=产线资产→转后端；纯咨询(该不该/怎么定)→前端。
