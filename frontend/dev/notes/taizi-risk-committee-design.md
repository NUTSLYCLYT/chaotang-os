# 太子 · 投行级四司联合审查风控（5 大神一致）

> 2026-06-25 由四司联审风控会审（Taleb/Howard Marks/Ray Dalio/Munger/段永平 完全收敛）沉淀。承接 `taizi-design.md` + `taizi-fission-a2a-design.md`。
> 用户意图:引进投行机制+联合审查,御史/钦天监/丞相/锦衣卫四司联审太子行动,确保黑天鹅不发生或及时止损、损失永远可控。

## 0. 一句话
> 别赌黑天鹅不来——把太子设计成"它来了也死不了"：**四司各戴对抗镜片、背靠背具名写死法、任一司单票否决（没有赞成章可盖），触线机器自动熔断；越顺越审、亏得起·框得住·传不开。还没出事是预警，不是许可证。**

## 1. 统一机制（一台机器，6 个齿轮）
1. **源头双筛**（段永平 stop-doing，~95% 流量，无人开会）：每个太子行动先过确定性脚本双筛——**能力圈**（超圈→不做）+ **本分**（欺骗用户/赚一次性钱/伤长期信任→不做）。审得再细救不了本就不该做的事。
2. **联审取消"赞成章"**（Taleb/Munger via-negativa）：委员会**物理上没有 yes 可盖**，橡皮图章无章可盖。四司唯一动作 = 各自**背靠背、密封、具名**写下"这个行动最可信的一种死法 + 触发阈值"，或**沉默**（沉默=我这条镜片没发现该死的东西，不是背书）。系统把四份死法聚合成熔断线（取最严）。
3. **单票否决，非多数通过**：任一司可独立一票封喉，无需说服其余三家；放行是默认态。推翻否决只能升 L3+ 人工门复议，不能三比一碾过。
4. **可信度加权 + 记分飞轮**（Dalio dot-collector）：盲投后按各司"该类风险历史命中率"加权；每轮分歧/事后兑现入史馆，回算命中率、校准下轮权重——**评审层自己越审越准**。
5. **逆周期温度计**（Howard Marks）：钦天监出 0-100 周期热度分（估值热度/复制速度/连胜次数/相关性是否奔1/缺证率），**只调审查旋钮不预测涨跌**——越顺越审、越热越紧、连胜越紧；高温时单分号上限自动收窄、新分号默认冻结。
6. **引擎边界**：触真实产线资产→联审过了也不在前端执行，必转 jiqun:8081 后端 + L3-L4 人工门；急停常开、不可自关。

## 2. 三道防线（职责物理隔离，写入/放行权只在二、三道，被审方拿不到）
- **第一道·前台（太子/影子学徒）**：自带源头双筛 + 事前 max-loss 预声明 = 自我约束 + 第一手风险申报。只产生行动与申报，**不持有放行权，不能关自己的刹车**。
- **第二道·中台风控（四司 + Hermes）**：独立于前台的对抗会审 + 持续测量。御史看门狗 7×24 盯阈值，Hermes 实时算敞口/杠杆跨线自动升级，四司背靠背盲投、任一单票否决。**不与前台共享 KPI、不互看草稿。**
- **第三道·后台（人工门 L0-L4 + 御座 + jiqun）**：不可逆/真实产线/否决复议/解冻重启的最终人审。机器只能升级到这里，**人只能"确认更严或叫停"，不能把机器判的停改成松**。史馆归档回填命中率喂回第二道。

## 3. 四司对抗镜片（KPI 对立、异源喂养、各自能单票否）
| 司 | 投行职能 · 镜片 | 一票否决于 |
|---|---|---|
| **御史台** | 合规内审 · **本分/铁律违反**（向后看·确定性脚本，不被叙事说服） | 自我提权/关急停/改自己的闸 · 源标偷换(FALLBACK伪装LIVE) · 越毕业权限边界 · 违本分/赚一次性钱 · 绕人工门。**只议合不合法、有没有撒谎** |
| **钦天监** | 压力测试 · **悲观下行/尾部**（向前看·悲观偏置，禁基准预测） | p10 地板下伤本金(亏不起) · 越封顶(框不住) · 舱壁挡不住(传得开) · 下行无地板/凸性朝下。**"亏得起·框得住·传不开"缺一即否** |
| **丞相** | 决策委主审 · **能力圈+收益/周期**（二阶思维，唯一为 ROI 举证的 sponsor） | 超毕业配方/看不懂(能力圈外) · 周期错配(高温猛攻/低谷收缩) · blast-radius 过大且撤不回。**举证角色非裁判，审自己徒弟须回避/降权** |
| **锦衣卫** | 对手尽调/KYC · **对手真伪/反社工**（外部·当下欺诈，默认对手在装） | 对手 KYC 不过(掐掉纸面完美的 A2A) · 情报被投毒却被当真 · 太子被社工/钓鱼裂变 · A2A 多太子收敛同一对手/情景 |

> 对抗张力固化：丞相善意 ↔ 三司恶意；御史看内部历史违规 ↔ 钦天监看外部未来尾部 ↔ 锦衣卫看外部当下欺诈。

## 4. 分级触发闸（判据=可逆性×blast-radius×触真实产线，非太子自评；Hermes 实时算敞口自动升级）
- **绿档·自动放行（目标≥90-95%，L0-L1）**：可逆 + 单笔<p10地板 + 能力圈内 + 同配方已毕业 + 无外部副作用 → 前端直接放行，仅**事后抽样审计**（税务抽查式）。
- **黄档·单司 flag（L2）**：只踩一条红线→只惊动对应那一司（对手陌生→锦衣卫；下行变大→钦天监；配方边缘→丞相；触用户承诺→御史）。一司能挡不劳四司。
- **红档·四司全到强制联审（L3-L4）**：开新分号/新品类 · 触真实产线资产 · 不可逆/违约金/预付款/独家 · 敞口越阈/加杠杆 · A2A 开新对手/放大额度 · 新配方首战 · 太子请求破例/改闸（→自动顶格）。触"真实产线+不可逆"必转 jiqun:8081 + 人工门。
- **相关性触发（中间地带杀手）**：多太子/多裂变线 correlation 奔1（同方向同押）→合并敞口触发联审。**单看个体永远低估，这是多数委员会漏掉的那条线。**
- **逆周期动态调阈**：热度越高触发线越往下压；高温几乎所有 L2 升格联审、新分号默认冻结。**中间无"温和审查"灰档**（杜绝看起来稳健其实脆弱）。

## 5. 黑天鹅防控（结构兜底，不靠预测）
封顶(position limit 写死，亏到上限自动冻结，太子无权自解) · **杠铃**(~90%极保守+~10%期权式试错，禁中间带杠杆伪稳健) · **凸性筛选**(只做 heads-win-big/tails-lose-small) · 舱壁隔离 · **A2A 一律按 correlation=1 算总敞口**(危机时相关性奔1) · **p10 地板定仓位**("最坏5%世界里王国仍活着"才毕业) · 压力测试测"死不死"非"会不会"(reverse stress test 从 ruin 倒推) · 尾部预算+干火药(黑天鹅来时是买家不是被迫卖家) · **每月强制注入一次"假黑天鹅"演练**(模拟对手违约/配方投毒/清算所挤兑/源标集体掉FALLBACK，过不了的配方先冻结)。

## 6. 止损协议（机器的事，不是会议室的事——最贵的亏损都是"再等等"）
1. **阈值即代码，入场那刻写死**：放行同时必须填硬地板（亏损达X% / 对手异动 / 源标偷换 / 实战分跌破p10）；**填不出止损线的不许放行**。
2. **三层级联熔断**（看门狗+异动雷达持续测，越线自动触发）：单太子止损 → 蜂群/舱壁止损(correlation信号全类冻结) → 全域熔断(A2A清算所停摆+所有裂变暂停)。
3. 软线(降速/缩仓/转人工) / 硬线(冻结写权+暂停A2A+回滚) 分级。
4. **事件型止损**（不等亏损显形）：锦衣卫探到对手违约/源标造假→绕过回撤阈直接熔断。
5. **Time-stop**：影子学徒/裂变线超期未出"第一条归档→兑现真实数据"→自动降级回沙盒。
6. **corrigibility**：急停常开不可自关，太子无权关/调高自己的止损；改阈值本身→四司联审+人工门。**停得快、复活慢（解冻必须 L3-L4 复核）。**
7. **CI 钉死回归断言**："熔断触发后零新单写入主库 tasks"（铁律④）。

## 7. "损失永远可控" = 结构保证（三条全过才算可控，缺一即拒）
① **亏得起**（事前 max-loss 预声明 + p10 地板定仓，即使四司一致看错也被封顶单框住）· ② **框得住**（三层敞口闸 + position limit 硬封顶，A2A 按 correlation=1 算，亏到上限自动冻结无人 override）· ③ **传不开**（舱壁隔离 + 权限不可裂变，一个影子学徒崩只崩它自己）。机制是 **via-negativa**（先把能 ruin 朝堂的东西一件件拆掉）而非加预测层。

## 8. 防橡皮图章（命门：四司必须真去相关、真各自掉脑袋、ruin 级真能单票否）
① 物理无"赞成章"（只能出具名死法/沉默）· ② **单票否决非多数**（"橡皮图章的反义词不是审得更严，是给每个人单独的红色按钮"）· ③ **背靠背盲投**（切断第一票锚定/从众）· ④ 输入去相关+异源喂养（四要同时被同一谎言骗穿才放行）· ⑤ **skin in the game 具名反向挂钩**（谁漏写死法谁担责，责任无法分散）· ⑥ 可信度加权命中率飞轮 · ⑦ KPI 对立物理隔离不串供。

## 9. Rollout
0. **源头双筛先落地**（纯确定性脚本，~95%流量，复用 censor 四闸）：本就不该做的在门口砍掉，最快见效。
1. **分级闸+单票否决最小闭环**：绿/黄/红三档，Hermes 算敞口自动升级，红档转 jiqun+人工门。一条真闭环不增页面。
2. **止损协议机器化**：阈值即代码+三层级联熔断+急停常开不可自关；CI 钉"熔断后零新单写主库"。
3. **背靠背盲投+具名死法**：四司密封提交，系统聚合取最严；输入去相关、互不可见、物理隔离。
4. **可信度加权+史馆飞轮**：分歧/兑现入史馆回算命中率校准权重（只采纳态反写）。
5. **逆周期温度计+假黑天鹅演练**：热度分调审查旋钮；每月注入假黑天鹅验熔断真响；A2A 星形清算所按 correlation=1 接全域熔断。
- **守土**：全程不在前端自建第二套产线 flow/奏折/质门；真实产线质量基线回 jiqun_ai_fresh。

## 10. 顶级风险（5 大神共识）
1. **头号**：联审退化成四个橡皮图章（盖了章的灾难比没人管更致命，发"已会审"许可证去加杠杆）→ 单票否决+源头stop-doing+背靠背盲投+逆周期调严。
2. 四司退化成"一个脑子"（同源数据+互看草稿+全票才停，意见相关性危机时也奔1）→ 输入去相关+盲投+各自掉脑袋。
3. 太子被社工/投毒裂变 → 锦衣卫 adversarial KYC + 异动雷达 + 御史诚实纠察 + 源标诚实。
4. 相关性盲区（单看都合规、合并已逼近 ruin）→ 按 correlation=1 算 + 相关性触发联审。
5. "还没出事"被当许可证 → 逆周期温度计越顺越审 + 每月假黑天鹅。
6. 太子自我提权/关急停 → 急停常开不可自关 + 改阈即顶格联审。
7. 止损靠"有人记得拉闸" → 阈值即代码+机器自动+CI 回归断言。
