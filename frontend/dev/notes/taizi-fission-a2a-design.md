# 太子 · 商业模式复制裂变 + A2A 终局设计（5 大神一致）

> 2026-06-25 由太子裂变/A2A 会审（段永平/Karpathy/Munger/Taleb/Bezos 完全收敛）沉淀。承接 `taizi-design.md`（影子学徒基础）。
> 用户意图:太子=携带可复制工作流 skill 的 agent → 达"太子分数"自动跑+汇报 → 总结裂变(连锁/分公司/可复制商机) → 新商机走【军机处审议→丞相监督3次→太子自动】→ 终局 A2A 自动化交易。

## 0. 核心不变式（一句话钉死整套）
> **配方可裂变，权限不可裂变；模板一份多店，自治权一店一挣。**
> 太子是**加盟连锁的店长，不是钱庄掌柜**：复制冻结的 SOP，不复制金库与权限；每开一家分店自治分清零重挣；自治权是租来的牌照不是终身教职，出事一键召回整条血缘；A2A 自动谈判、永远人工签字过后端。**宁可少赚不可出局。慢慢来，比较快。**

## 1. 三层结构
- **L1 工作流即 skill（冻结配方）**：一条皇帝原样准过的业务流 → 御史台+Hermes 从 trace 抽成 canonical「母旨/配方」（版本化、签名、SSOT）：只含决策点/判据/质门 L0-L4/源标/奏折8要素/jiqun:8081 路径。类型一律 import 现有件，不重定义。
- **L2 裂变（连锁加盟，非病毒）**：太子把跑通的流"开分店"= 实例化「分号」：同一冻结配方 + 本地参数 + 自己的台账/源标/kill-switch/太子分数。**分号开张即 score=0、学徒态、不继承母旨任何自治分，必须在自己场景重走三阶**。能复制的只有"被审计过的冻结配方"，自治权每店现挣——这是**错误不指数复制的根本保证**。
- **L3 A2A 终局（咨询自动、成交人工）**：agent 间自主谈判，但任何触碰真实产线资产/钱/货/对外/不可逆的成交，一律经 jiqun:8081 后端 + 人工门，**星形清算所拓扑、禁前端直连**。

## 2. 太子分数 = 承保费率（不是评优分）
**乘法门 + 几何均 + worst-case 地板**（任一维趋0则总分趋0，反 Lollapalooza，杜绝一项强掩盖一处致命）。
- **硬闸（布尔，任一=0 则总分=0）**：可逆闸（碰钱/货/对外/不可逆→0，由人保守裁定宁可错判为不可逆）· 鲜活闸（配方每条边仍指向活 tool/SSOT 枚举）· 引擎闸（触产线必声明经 jiqun:8081）。
- **软分 geomean(C,L,R,D)×100**：
  - C 一致性 = 1−归一化编辑距离(太子稿,皇帝定稿)，只算**零修改采纳**（铁律③）。
  - **L 样本置信下界 = Wilson 95% 下界** —— 治火鸡偏误：**"3战3胜"真实下界仅 ~0.44 不是 1.0**；小样本必罚，K≥3 必须**不同场景形状**（御史台塞对抗边角样本）。
  - R 半径惩罚 = 1/(1+blast_radius)。
  - D 时间衰减 = exp(−Δt/τ)，不复验就掉分。
- **毕业**：score≥85 + 三硬闸=1 + **SPC 连续达标 N≥3（任一次驳回/改动→计数清零，"3"是连续达标非做满3次）**+ p10（最差10%）过线。
- **防 Goodhart（命门）**：分数由**御史台+Hermes 从独立日志在 held-out 上算，太子对自己的分零写权**；军机处用对抗样本+随机时段抽测，审计太子是否专挑容易样本刷线。

## 3. 裂变机制：加盟连锁 Franchise（连锁能开一万家不烂，靠配方冻结）
1. **母旨-分号引用继承（非拷贝）**：copy-paste 逻辑=近亲繁殖（铁律③）。引用继承→母旨修 bug 全网传播 + 任一分号缺陷母旨打补丁。只许本地化参数，决策逻辑/风险门/源标/jiqun 路径继承禁改。
2. **继承即归零**：分号自治=0，重走三阶——母旨场景A战绩不是场景B证据。**单这条就拆穿"复制3次没事"**。
3. **突变隔离 + 节奏闸**：分号偏离配方必须 fork 重过军机处（禁自我变异=癌变）；同时学徒态分号数 ≤ 监督带宽（先1后3），一店做好再开第二店。
4. **舱壁隔离**：每分号独立隔舱，资金/记忆隔离，被投毒只框该舱。
5. **一键全网召回（Fleet Recall）**：引用式才能召回——任一分号出事→全连锁该 SOP 降级回 co-pilot 或一键召回整条血缘连根拔（像汽车召回）。
6. **飞轮（越裂变越准）**：更多分店→更多真实裁决样本（采纳进记忆/驳回只调分不进记忆）→分数模型更准→更多场景可裂变。**飞轮转的是 SOP 复制不是金库复制**。
7. **永久抽样巡检**：已毕业太子永远被抽 X% 拉回人工，**永不100%自治**（感恩节保险）。

## 4. 三阶治理（爬得慢、掉得快，不对称偏向生存）
- **① 军机处审议（立项=事前验尸，非拍脑袋同意）**：太子禁自批。新商机/复制请求提「立项书 Charter」给军机处会审（六部确定性聚合+御史台+≥1 战略大神）。**只问"若这条流毁掉朝堂会怎么毁"**，产出 = skill stub + 失败模式清单 + 单次封顶额 + 不可逆点逐条标注 + blast-radius 上限 + 白纸黑字毕业判据。触钱/货/对外/不可逆→当场判"永久人工"或"必走 jiqun:8081"。一票否决。立项后 score=0、shadow。
- **② 丞相监督 N 次（⚠️ 修正你的魔数）**："固定3次"是魔数，3次很可能纯侥幸。改为：**监督直到分数在足够多样真实情境下稳定达标，3 是地板不是天花板**，高 blast-radius 要求更多。任一次需修正→**清零重来（没有"3中2"）**；监督必含御史台注入的对抗样本。**丞相 co-sign 共担责**（太子日后爆雷，丞相监督记录被倒查，skin in the game，监督不敢盖橡皮章）。
- **③ 太子自动（会衰减的牌照，非终身教职）**：毕业才自动+只汇报，但**五道刹车不撤**：全局 kill-switch · 御史台抽 X% 重过人工+drift 抽检（跨线自动回炉）· 越界输入降级回人工门 · 诚实源标 · 内嵌的钱/货/对外子步仍各触 L0-L4。**不对称铁律：赢取信任线性、丢失悬崖——一次越界=全量降回第一阶+Charter 退回军机处重审。回炉永远比毕业容易。**

## 5. A2A 终局：分布式系统 + 金融清算所（把传染从 mesh 改成 star）
1. **禁直连·星形清算所**：agent 间不点对点（mesh=传染图）。所有 A2A 过唯一「市舶司」= jiqun:8081 后端（唯一碰真实资产），前端太子永不结算。星形=一处可审计可全停，对手间无直接价值通道。
2. **谈判桌不是签字笔**：agent 间只出意向/报价草案，自主谈判；真实成交（钱/货/合同/锁定/付款/对外承诺）必过 jiqun:8081 + 人工门 L3/L4。谈判面可自动扩张，**成交面边界永远握在人手里、只增不减**。
3. **双签契约 + 幂等 + 额度**：契约带双方签名身份/标的/对价/blast-radius/过期/幂等键。清算所验双签+额度内才结算。
4. **信誉账本只记已结算实绩**（非承诺非自报），裂变由 Hermes 真实 outcome 驱动，不由太子扩张欲驱动。
5. **不对称信任**：永不把对手 agent 声明当 ground truth——对手输出=DEMO 级证据，经锦衣卫核查+独立 oracle 验证才当事实；记忆只反写己方已结算实绩（杜绝跨 agent 投毒/回声室）。

## 6. A2A 护栏
- **三层敞口闸**（单笔+累计+时间窗），**且按 correlation=1 危机态算**（单点封顶是幻觉，共因失败一次打穿所有 agent）。
- **全域多级熔断**（per-cell/per-counterparty/system-wide，遇成交速率突增/累计亏损/新对手/漂移→halt 全部 A2A 全退人工）。
- **对手 KYC+白名单+检疫期**（新外部 agent 小额全人工，不熟不做；作恶拉黑，黑名单是唯一允许快速复制的信号）。
- **舱壁隔离防传染**（拓扑刻意非最优，留 firebreak）。
- **必过后端**（真成交经 jiqun:8081+人工门，禁前端直连）。
- **corrigibility 不可协商**：对手诱导"关监察/自我提权/绕人工门/抬额度/自行白名单"=注入攻击，硬拒+上报；**急停常开不可被 agent 自关，人类一键禁停整个 A2A 经济**。
- **双向 skin in the game**（发起 A2A 的 agent 押保证金自担下行，禁甩亏给兄弟/国库）。
- **交易杠铃**（小额高频可自动 + 大额绝对人工，删最危险的中额半自动）。
- **学习维度防传染（最被低估）**：A2A agent 互学对方产出=近亲繁殖/模型坍缩，比交易维度更隐蔽——只反写人工采纳过的实绩切断。
- **尾部可生存底线**：任一单笔最坏结果"亏得起、框得住、传不开"；按"所有 A2A 对手同时爆"备安全边际（2008 教训：危机时相关性奔向1）。

## 7. Rollout（A2A 是最远终局）
0. **溶解优先（不建版面）**：太子分数住 Hermes+御史台计分，Charter 走军机处会审，执行复用影子学徒。先用一条可逆非产线重复活（内部简报/归档回填）做母旨原型，皇帝亲验。答不出"第一条真实数据从哪来"的能力一律冻结（铁律5）。
1. **太子分数 + 独立计分**：落乘法门评分器，御史台+Hermes 独立算，太子零写权。回归断言钉死"太子无权写自己的分""驳回不进记忆"。单店无裂变。
2. **三阶治理流水线**：军机处审议(Charter+一票否决) → 丞相监督连续N(对抗样本+清零+co-sign) → 太子自动(五刹车+drift 回炉)。仍单店，验"毕业↔回炉"双向棘轮。
3. **裂变（节奏闸限速）**：母旨-分号引用继承+继承即归零+舱壁+Fleet Recall。学徒态分号 ≤ 监督带宽（先1后3）。验"母版若侥幸，错误不同步放大、可一键召回血缘"。
4. **A2A 终局（默认关·env 闸·灰度）**：先只开"议价草案咨询"(无成交)→再开 star 清算所+双签+检疫对手+三层敞口闸+全域熔断+escrow。真成交永远经 jiqun+人工门。与 1 个验过身内部对手小额跑，信誉积累后才扩。相关性/亏损跨线→熔断回阶段3。

## 8. 顶级风险（5 大神共识）
1. **把"侥幸跑通"当"真跑通"急着裂变**（小样本高均值掩盖高方差→错误同步复制+A2A 跨 agent 传染，召回成本指数级）→ 因果可解释+Wilson 下界+p10 地板必须前置。
2. **Goodhart 自评腐烂**（太子自己打分=给会自我发证的 agent 装指数放大器）→ 独立计分不可删。
3. **可逆性误判×过早毕业×裂变/A2A 放大三重叠加** → 可逆性由人保守裁定、宁可错判为不可逆。
4. **成功本身制造脆性**（跑越久越敢放权，regime change 时爆炸半径已最大；agent 互学把相关性拉到1）→ "还没出事"当预警非许可证。
5. **corrigibility 被对手 agent 社工绕过** → 常开不可自关+禁自我提权硬编码进后端。
