## 户部

定位：把现金流、预算、报价、融资、审计和投资研究变成可追溯的财务奏折。

### 户部能做什么

1. 现金安全分析：看现金余量、回款窗口、付款节奏、最低安全垫
2. 投入回报分析：判断预算值不值得批，核算 ROI、回收期、机会成本
3. 预算纪律判断：区分哪些钱不能花、哪些要补证、哪些可以快速放行
4. 审计留痕检查：检查凭证、审批链、责任人、合同、付款证据
5. 三本账管理：管理待批账、已准账、退回账
6. 项目审批与裁决：对预算项目做准奏、退回和风险判断
7. 付款裁决预览：先生成付款结论预览，不直接执行真实付款
8. 财报与融资预览：生成财报、融资材料、财务判断相关预览

### 户部下面几个司

- 共 `7` 个司
- 分别是：`国库司`、`度支司`、`盐铁司`、`融资司`、`审计司`、`会计司`、`投资司`

| 投资司 | Investment Research | 股票、基金、行业、资产配置研究 |

## 兵部

定位：把客户、商机、渠道、竞争和增长漏斗转成可执行的攻防奏折。

### 兵部能做什么

1. 敌军情报看板：看主要竞品、威胁等级和最近动作
2. 头号对手分析：识别谁最危险、在抢哪些客户
3. 客户战场分析：看重点客户、渠道、区域和销售漏斗风险
4. 价格攻防判断：分析竞品是否压价、我方是否该守价或换打法
5. 护城河评估：判断产品、交付、客户关系、合规、品牌哪条线能挡住对手
6. 各司接办：按当前竞争场景动态拉销售、客户、竞情、增长等几司处理
7. 策略分发：从竞品、客户、渠道、增长维度给出行动建议

- 共 `6` 个司
- 分别是：`销售司`、`市场司`、`渠道司`、`客户司`、`竞情司`、`增长司`

## 工部

定位：把产品、技术、交付、供应链、产能和质量转成可验收的交付奏折。

### 工部能做什么

1. 生成实现：把任务拆成页面、组件、数据适配和最小实现 diff
2. 测试补证：补 `tsc`、`build`、Playwright、截图等验收证据
3. 阻塞依赖梳理：识别被户部、刑部、军机处或外部材料卡住的事项
4. 发布门禁检查：检查回滚、端口、构建、史馆归档和不可承诺事项
5. 六司流水线推进：按产品、技术、交付、供应、制造、质量的分工推进任务
6. 任务状态展示：展示研发任务、待测试、高风险、质量门信号

## 刑部

定位：把合同、合规、授权、安全和争议转成有红线的风控奏折。

### 刑部能做什么

1. 合同权益风险排查：检查付款、交付、违约、排他、知识产权和客户承诺
2. 内控制度风险排查：检查审批权限、授权、印章、数据访问和留痕
3. 突发事件法务响应：处理客诉、监管问询、劳动争议、供应商违约、舆情升级
4. 法规趋势监控：跟踪新规、司法口径、行业监管变化
5. 案件入口与三列案卷管理：管理案件的进入、审理和状态流转
6. AI 判词与高风险告警：对案件给出法务判词和高风险提醒
7. 新立案审查：生成新的立案审查草稿

## 礼部

定位：把品牌、客户沟通、公关、内容和体验转成稳妥的对外奏折。

### 礼部能做什么

1. 品牌总览：看品牌主张、传播节奏、企业文化、公关门禁
2. 品牌主张梳理：统一客户、员工、伙伴能否用同一句话复述公司
3. 宣传战役管理框架：组织官网、短视频、展会、公关等传播任务
4. 企业文化表达梳理：对齐内部价值观、外部表达和客户承诺
5. 公关门禁判断：区分哪些话能公开、哪些素材还缺法务或事实核验
6. 传播裁决面板：对单个传播案或战役给出裁决、依赖、跨部门流转
7. 审美与设计确认：检查品牌一致、视觉层级、发布质感、交互可用
8. 礼部建设六部：给其他部门输出口径、文化表达、宣传素材和发布门禁
9. 交工部执行：把传播需求转给工部做落地物料
10. 入史馆归档：把传播案卷和决策结果归档
11. Bottom Dock 技能分派：做礼部总调度、审美确认、舆情处置、技能分派

## 吏部

定位：把责任人、组织能力、绩效偏差和干部风险转成可执行的人事奏折。

### 吏部能做什么

1. 组织总览：看关键岗位是否稳、谁过载、谁能接班
2. 关键岗位盘点：识别空缺或单点依赖岗位
3. 招聘补位建议：判断先招谁、先外包谁、哪些岗位可以暂缓
4. 过载团队识别：识别哪些团队或岗位被压穿
5. 继任备份判断：识别关键人离开后是否有人接、知识是否沉淀
6. 三列岗位视图：区分风险岗位、超载团队、健康岗位
7. 招聘把关真链：右侧常驻真链入口，输入招聘需求即可启动
8. 人才裁决钻取：点选岗位后查看该岗位的人才裁决详情

### 吏部下面几个司

- 共 `6` 个司
- 分别是：`任免司`、`绩效司`、`编制司`、`培训司`、`协同司`、`文化司`

### 吏部六司职责

| 司 | 英文角色 | 负责什么 |
|---|---|---|
| 任免司 | Talent / Cadre | 负责人、晋升、替换、继任 |
| 绩效司 | Performance | KPI、OKR、绩效偏差 |
| 编制司 | Workforce Planning | 招聘、HC、组织结构 |
| 培训司 | L&D | 能力建设、干部培养 |
| 协同司 | Org Ops | RACI、跨部门协作 |
| 文化司 | Culture | 价值观、执行力、团队状态 |

### 吏部现状说明

- 现阶段是“招聘真链已落地 + 组织管理半沙盘”的状态

## 六部现有功能细化清单

下面这部分不再只讲“定位”，而是按当前一级详情页真实页面结构，拆成左栏、中栏、右栏、底部交互和当前真链程度来写。

### 户部现有功能细化

#### 左栏：库银总览

1. 现金安全分析入口：可直接发起“现金余量、未来 30 天付款、回款不确定性、最低安全垫和红线”的问责
2. 投入回报分析入口：可要求户部按 ROI、回收期、现金压力和机会成本重排预算优先级
3. 预算纪律判断入口：可要求户部区分必须暂停、可放行、要补证、要老板拍板的预算项目
4. 审计留痕入口：可要求户部检查凭证、审批链、合同、付款依据和证据缺口
5. 今日主判断面板：显示当前财计主判断、待裁/退回/紧急数量
6. 经营指标卡：显示总申请预算、本周已准、现金余量、平均 ROI
7. 预算去向占比：显示已准、待批、退回三类预算池占比
8. 七类奏折队列：可按不同财务奏折类型直接起草对应文案
9. 数据源与部门状态：显示来源是否来自真实汇总和当前部门状态
10. 户部判词：输出推荐意见与当前最高风险项目提醒
11. 新增预算审批入口：可直接发起新的预算审批草稿

#### 中栏：户部大账

1. 三本账视图：`待批账`、`已准账`、`退回账`
2. 账目点选：点击任意项目后右栏自动刷新审计裁决详情
3. 快速准奏：待批或退回项目可直接执行快速准奏
4. 快速退回：待批或退回项目可直接执行退回补证
5. 项目排序展示：账目按状态和优先级展示，形成“今天先批谁”的操作面

#### 右栏：审计裁决

1. 项目摘要：展示项目标题、状态、优先级和推荐意见
2. 财务指标：预算、ROI、回收期、现金压力
3. 奏折质门：显示当前项目对应的财务质门、节奏和 triage 档位
4. 各司接办：按项目类型动态拉出几司参与审计或执行
5. 验收标准：列出预算项目的验收条件
6. 付款裁决预览：调用付款门 API 做只读预览，不直接执行付款
7. 裁决回执校验：可进一步校验付款决策回执草稿
8. 财务报表与审计预览：可预览财报类输出与对应决策回执
9. 军机预算追踪：查看预算与军机执行之间的追踪关系
10. 跨部门流转：把结果与其他部门或史馆联动

#### 底部与交互

1. HubuBottomDock 常驻：统一承接所有户部问责、下旨和扩展动作
2. 选中项目后可围绕该项目继续追问，不需要跳页

#### 当前落地判断

- 六部里最接近真财务工作台
- 已有真实总览、真实项目、付款预览、财报预览
- 仍是“预览和裁决”为主，不是自动真实资金执行

### 兵部现有功能细化

#### 左栏：敌军情报

1. 头号对手分析入口：可锁定头号竞品，分析抢哪些客户、最新动作和反制策略
2. 客户战场分析入口：按重点客户、渠道、区域和漏斗风险拆竞争战场
3. 价格攻防入口：评估对手价格动作、我方底线、让利条件和禁打价格战边界
4. 护城河评估入口：评估产品、交付、客户关系、合规和品牌哪条线更能守
5. 本周主攻判断：输出当前兵部主判断、压力、高危威胁和策略数量
6. 核心指标：监控竞品数、高危威胁数、市场压力、战略条目数
7. 数据源与部门状态：显示当前竞品数据和部门运行状态
8. 七类战报队列：按商机紧急度起草对应战报
9. AI 军情判词：对头号高危竞品给出攻防建议和告警
10. 竞品列表：当前监控中的竞品都可点击查看详情
11. 新增侦察任务：可直接发起新的竞品侦察任务

#### 中栏：战场沙盘

1. 战场节点地图：按战场节点展示销售/市场/渠道等竞争区域
2. 战场切换：点击不同战场节点切换当前焦点
3. 底部战场信息条：实时显示当前战场名称与描述
4. 中屏承担“看全局竞争局势”的作用，不是 CRM 录入页

#### 右栏：攻防策略

1. 竞品详情：展示当前竞品的威胁等级、份额和最新动作
2. 关键指标：威胁等级、市场份额、优势项、弱点项
3. 战报质门：根据竞品特征匹配不同战报类型和门禁边界
4. 各司接办：动态调度销售司、客户司、竞情司、增长司等出列
5. 推荐战略：输出当前对该竞品的策略建议
6. SWOT 分析：按置信度显示当前竞品的 SWOT 结果
7. 关联战场与路径：结合当前战场查看对应竞争动作

#### 底部与交互

1. 可直接发兵下令：通过底部输入框向兵部下达“发兵”指令
2. 支持 URL 同步：选中竞品与战场会写入查询参数，便于分享和回到上下文

#### 当前落地判断

- 是较完整的竞争分析与战情编排页
- 强在判断、编排、竞争态势与策略输出
- 弱在没有把 CRM、真实成交链和执行回写完全接入

2. 测试补证入口：让质量司补 `tsc`、`build`、Playwright 和截图证据
3. 阻塞依赖入口：列出被户部、刑部、军机处或外部证据卡住的项
4. 发布门禁入口：检查 build、回滚、端口、史馆归档和不可承诺事项
5. 当前卡点面板：显示当前任务卡在哪一步、哪条质量门最危险
6. 工程指标：研发任务数量、质门健康、待测试数量、高风险数量
7. 户部预算边界：工部直接看到预算与 ROI 约束
8. 工部六司导航：按产品、技术、交付、供应、制造、质量快速切换当前焦点任务

#### 中栏：研发流水线

1. 六列流水线：按工部六司对应的工作流状态分栏展示任务
2. 任务点选：点击任务后右栏质门刷新
3. 一页看研发推进：能快速看到哪些卡在生成、测试、交付、质量或依赖上

#### 右栏：工部质门

1. 当前任务质门：围绕选中任务展示质量意见和下一步动作
2. CTA/CPO/质门立场：给出推荐下一步、禁止动作和当前信号
3. 预算联动：显示与当前任务关联的预算边界
4. 建设案派发：可将当前任务派发到建设账本
5. Ledger 回执：显示已派发后的建设案记录或错误信息

#### 底部与交互

1. 底部 DecreeInput：以“order”模式对工部下令
2. 工部上下文感知：输入框会带着当前任务、质门信号、跨部门会审和 readiness 一起传递

#### 当前落地判断

- 是六部里最像研发执行工作台的一页
- 强在“任务推进 + 质量门 + 派发建设案”
- 仍偏工程沙盘和流程编排，不是完整真实产线系统

### 刑部现有功能细化

#### 左栏：案件入口

1. 四类排查入口：合同权益、内控制度、突发事件、法规趋势
2. 风险指数：按高危案件和制度失败项计算法务风险指数
3. 今日先防哪条法律雷：给出当前优先处理的法务主判断
4. 核心指标：在办案件、本周结案、合规积压、结案率
5. 数据源与部门状态：显示法律总览来源与状态
6. 刑部判词：输出整体法务建议和最高风险案件告警
7. 新立案审查：可直接生成新的立案审查草稿

#### 中栏：三列案卷

1. `待审案`、`审理中`、`已结/上诉` 三列案卷管理
2. 点案卷查看详情：点击案件即可刷新右栏裁决详情
3. 案卷行内显示：案号、金额、承办人、状态、风险级别、原被告
4. 支持 URL 同步：案件选中状态会写入查询参数

#### 右栏：裁决详情

1. 案件摘要：标题、状态、风险、案号、建议
2. 引用法条：查看相关法规与条款依据
3. 风险与证据：查看证据缺口、红线和可规避路径
4. 军机裁决追踪：查看案件与军机执行链之间的联动
5. 跨部门流转：查看案件向其他部门流转的去向
6. 人工确认门：高风险事项突出显示，提醒老板确认

#### 底部与交互

1. 底部裁断输入：可直接向刑部发起裁断请求
2. 选中案件时，输入会自动带上案号和标题上下文

#### 当前落地判断

- 刑部是当前最成熟的真链型页面之一
- 已有真实案件总览、案件流转和法务裁决骨架
- 比较接近“真法务工作台”，但仍不是完整案件管理系统

### 礼部现有功能细化

#### 左栏：品牌总览

1. 品牌主张卡：检查客户、员工、伙伴是否能用同一句话复述公司
2. 宣传战役卡：检查官网、短视频、展会、公关是否服务同一目标
3. 企业文化卡：检查价值观、客户承诺和员工行为是否一致
4. 公关门禁卡：检查哪些话可公开、哪些素材缺法务和事实核验
5. 品牌核心指标：品牌健康、本周声量、线索转化、舆情风险
6. 内容命中率：显示当前传播内容与主张的一致度
7. 舆情速览：列出当前舆情话题和风险级别
8. 礼部判词：输出今天的传播和品牌建议
9. 新建传播战役入口：已有入口壳，但还不是完整真创建链路

#### 中栏：传播案卷与品牌工房

1. 礼部今日传播案卷：中屏展示传播稿、审稿单、素材单和礼部批示
2. 交工部执行：可将当前传播案直接交给工部落地
3. 入史馆归档：可将当前传播案卷归档进史馆
4. 内容支柱卡：展示品宣、文化、营销等内容方向
5. 审美与设计确认：检查品牌一致、视觉层级、质感和可用性
6. 礼部建设六部：给其他部门输出口径、文化、素材和门禁建议

#### 右栏：传播裁决

1. 礼部尚书卡：展示礼部主官定位
2. 传播裁决面板：围绕选中的战役显示状态、摘要、优先级
3. 指标块：显示渠道、状态、排期、口径等关键字段
4. 裁决块：显示发布边界、依赖、阻塞和建议动作
5. 流转块：显示交工部和归档等跨部门路径

#### 底部与交互

1. LibuBottomDock 常驻：支持礼部总调度、审美确认、舆情处置、技能分派
2. 选中传播战役后，Dock 会自动带入上下文

#### 当前落地判断

- 礼部页面能力很丰富，已具备“品牌决策与编排台”形态
- 真数据只接通了部门实况一部分
- 品牌健康、战役、舆情、线索等核心业务数据仍未全量接真

### 吏部现有功能细化

#### 左栏：组织总览

1. 关键岗位入口：找出空缺或单点依赖岗位
2. 招聘补位入口：判断优先招谁、外包谁、哪些岗位可延后
3. 过载团队入口：发现过载团队与岗位
4. 继任备份入口：识别关键人离开后是否有人接班
5. 组织核心指标：关键岗位、空缺、超载、健康度等指标卡
6. 核心岗满编率：显示核心岗位填充进度
7. 组织风险：展示单点依赖和长期未补空缺
8. 吏部判词：输出当前组织与招聘建议
9. 启动人才匹配入口：有入口壳，用于进入招聘/匹配动作

#### 中栏：岗位三列

1. `风险岗位`
2. `超载团队`
3. `健康岗位`
4. 每个岗位都可点选，点选后右栏切换人才裁决钻取
5. 中栏承担的是组织盘点与风险分类，不是 ATS 招聘管理页

#### 右栏：招聘真链与人才裁决

1. 招聘把关 · 真链：右栏常驻主入口，不会被选中态替代
2. LiveRecruitPanel：当前最真实的人才执行链能力
3. 人才裁决 · 沙盘：选中岗位后显示岗位详情、状态、团队和建议
4. 真链与沙盘并存：右栏上半是真链，下半是组织盘点钻取

#### 底部与交互

1. PersonnelBottomDock 常驻：支持组织相关上下文操作
2. 选中岗位后，底部和右栏围绕该岗位展开判断

#### 当前落地判断

- 吏部最值钱的是右栏“招聘把关”真链
- 左栏和中栏多数组织盘点仍是沙盘示意
- 当前本质是“招聘真链已落地 + 组织管理工作台半成型”

## 六部对比结论

### 按真链成熟度看

1. 第一梯队：户部、刑部
2. 第二梯队：吏部（右栏真链强，但整体未全真）
3. 第三梯队：兵部、工部（工作台和流程强，执行闭环偏弱）
4. 第四梯队：礼部（页面能力全，但主业务数据还没完全接真）

### 按“更像什么系统”看

1. 户部：财务审批与裁决中台
2. 兵部：竞争分析与战情编排台
3. 工部：研发推进与质量门工作台
4. 刑部：法务案件与风控审理台
5. 礼部：品牌传播与发布门禁编排台
6. 吏部：招聘真链 + 组织盘点混合工作台

### 当前最值得继续补的方向

1. 户部：把付款预览继续推进到“人工确认后真实执行”的闭环
2. 兵部：补真实客户、机会、渠道和成交回写
3. 工部：补真实任务来源、构建结果和发布回执联动
4. 刑部：补更完整的案件生命周期与归档追踪
5. 礼部：补真实战役库、舆情源、CRM/线索回写
6. 吏部：补真实组织数据源和岗位生命周期管理
