# 朝堂自学习飞轮 · 为什么没转 + 天才设计（2026-06-28）

> 深入浅出：你以前**真的造过**这台学习机器，齿轮全在。它没转，不是没造，是**两头的管子没接上**，
> 而中间那台"偏好机器"在没有结果兜底时，正悄悄帮你把偏见做大。

## 二、为什么没转 · 两个断点（这是要害）

把它想成一台机器：**一头进"真实结果"→ 中间齿轮校准"该信谁"→ 一头出"下次更准的决策"。**
你把整台机器造好了，但**两头的管子都没接**：

### 🔴 断点 ①：进料口是孤儿 —— 真实结果从没进来过
- `/api/court/study/outcome` 回填端点**存在**，但**全仓没有任何 UI 在调它**（grep 实证：零调用）。
- 没有任何一个老板工作流的时刻，让他标"这个决策后来对了/错了"。
- 后果：`outcome` 列**永远 NULL**（dev 库 agent_decisions 空）。**机器没油。**

### 🔴 断点 ②：出料口没接 —— 就算结果进来也不改决策
- `loadAttributionCalibration()`（按真实 outcome 算部门可信度）**存在**，但 **orchestrate 决策时根本没调它**（grep 实证：orchestrate 里零引用）。
- orchestrate 只用了 `applyPriors`（boss 偏好），**没用 attribution 校准（真实结果）**。
- 后果：哪怕 outcome 被填满，学到的"谁兑现率高"也**不会改变下次决策**。学了白学。

### ⚠️ 更危险的：在转的那半边，学的是"讨好"不是"对"
- 唯一真转的是**偏好半飞轮**：老板拍板 → `boss_preferences` → `applyPriors` → 下次把老板偏好的部门排首位/高亮。
- 但它学的是「**老板冲突时爱选谁**」（preference），**不是「谁选对了」（outcome）**。
- **没有结果校准兜底，这台偏好机器会把老板的偏见越放越大**——老板每次选错户部，系统就更把户部往前推。**它在帮你犯同一个错，而不是纠正你。**（Deming：没有数据兜底的偏好学习 = 系统性放大偏差。）

## 三、天才设计 · 接上两根管子 + 让结果压过偏好

不用重造，**用已有齿轮，接两根管子**：

### ① 接进料口 —— 零额外动作的回填（Musk：成本压到物理下限）
**别建复盘表单**（老板永远不会主动打开）。让回填发生在他**下次做类似决策的那一刻、顺手一点**：
> 老板下次又要决策类似的事 → 史馆主动弹一句：「**上次这种『扩产』你准奏了，后来怎么样？**」
> 三个按钮：**[对了] [错了] [还没见分晓]**（可选填一句/实际数字）→ 一键调 `/study/outcome`（已存在）。
**回填成本 = 一次点击，且发生在他本来就在的地方。** 这是它能不能真转的物理上限。

### ② 接出料口 —— 把 attribution 校准接进决策（用已建的函数）
orchestrate 现在 load 了 advisor signal + applyPriors。**再加一步**：load `loadAttributionCalibration(dept)` →
让"真实兑现率"参与排序/加权：**历史兑现率高的部门，意见权重更高；被现实反复证伪的，降权**。
（函数已在，只差在 orchestrate 里调一下 + 让它进 routeSnapshot。）

### ③ 让结果压过偏好（Deming：数据 > 偏好）
当"真实兑现率"和"老板偏好"打架时，**让结果说话**：
> 系统温和提示：「你偏好户部，但历史上户部这类判断**兑现率只有 40%**——要不要再看一眼？」
**偏好机器从"主人"降级为"被结果校准的建议"。** 这一条，把"放大偏见"反转成"纠正偏见"。

## 四、怎么知道飞轮真转了（Feynman 自检 · 一条 e2e）
```
喂一个决策 → 用"上次怎么样"钩子标它真实结果(对) → 下次喂类似决策
→ 验证：① outcome 列被填  ② attribution 校准把这个部门权重抬了  ③ 引用旧案引出这条"兑现过且对了"的案
```
**这条绿之前，自学习是假的（机器空转）。绿的那一刻，朝堂第一次真从现实学习。**

## 五、最小第一步（Musk 极限执行）
**就接进料口那一根管子**：在"下次类似决策"的时刻弹"上次怎么样 [对/错]"→ 调已存在的 `/study/outcome`。
**一个钩子，复用整台已建机器，让 outcome 列第一次有真数据。** 出料口（②③）随后接。

## 六、一句话给老板
- 你**造过**一台完整的学习机器，**但它两头没接、还在空转**。
- 没转的真因：①真实结果没入口（孤儿端点）②结果没接进决策（校准没 wire）③在转的偏好半边在放大你的偏见。
- 解法：接两根管子（都用已建齿轮）+ 让结果压过偏好。**第一步就一个"上次怎么样"的一键钩子。**
- 在它绿之前，别说"朝堂会自学习"——它现在会记账、会讨好，还不会从对错里学。诚实点。
