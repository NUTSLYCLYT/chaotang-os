# 太子设计 ·「影子学徒 · 按类毕业 · 可随时回炉」(5 大神一致)

> 2026-06-25 由太子设计会审(Karpathy/Stuart Russell/张小龙/段永平/Munger 完全收敛)沉淀。
> 用户意图:太子=把皇帝主线下旨里【熟练/重复/相似】的活,自主自动化执行(高权限、自动跑),用 OpenClaw/Hermes。

## 0. 一句话
**太子不是"权力更大的执行者",是"挣得权限的影子学徒"** —— 只替你办那些你已原样准过、且收得回来也不碍事的重复活;权限按类一格格挣来、随时能回炉;碰到钱/货/对外承诺/不可逆,一律停下把笔还给你。**高权限大在"敢替你点头",绝不在"敢替你签字"。**

## 1. 统一设计:棘轮(ratchet),不是炸药
太子 = 对【皇帝采纳记录】做行为克隆、带弃权权、装了棘轮的置信度门控自动执行器:
- **① 影子期**:每条熟练下旨,太子只在后台把活干到临门一脚(拟好奏折、备齐证据、拉齐会审),**停在"送出"前**,东宫收件箱照旧由皇帝拍板;系统暗中记账"太子预测 vs 皇帝实采"。
- **② 按簇毕业**:以结构化「决策指纹」把下旨聚成簇,某簇在留出回放上**精度≥95%/样本≥N** 且动作可逆/非产线,该簇才**毕业**获自动权——**只对这一簇放权,不是全局放权**。
- **③ 毕业后也不直接落地**:产出先进「已办待阅·可撤回回执盘」+ 一个与爆炸半径成正比的撤回冷却窗(L0 秒级,越近产线越长),窗内皇帝一票即回滚,无人撤到点才生效。
- 太子的**核心产品是 eval**(它对皇帝偏好的校准精度),不是动作量;**默认情绪="怀疑自己"**;最重要的输出是**"我拿不准,请皇帝定"(弃权升级)**。配全局 kill-switch + 每动作一键 undo + 全程进御史台。

## 2. 自动 vs 问人:AND 门全绿才动,缺一即停
① 本簇已毕业(回放精度达标,非太子自评) · ② 决策指纹与同簇≥3 条【采纳态】旧案对齐 + k 近邻一致(邻居打架=信号不足→停) · ③ 当前参数落在历史采纳案的【参数包络】内(出界即判新案) · ④ 可逆 + 零外部副作用 + 非产线资产 + L0-L1 · ⑤ 源标 LIVE/MIXED(非 FALLBACK/DEMO) · ⑥ 在速率/额度/爆炸半径预算内(**专防"一个错被批量复印"**) · ⑦ 御史台/锦衣卫无异动。
**强制熔断(无视毕业直接停)**:首见新簇 / 参数越包络(金额跨档、对象内部→对外、可撤→不可撤) / 近邻分歧 / 源标降级 / 皇帝近期对同类驳过一次 / 超预算 / 监察报异动。
> **口诀:宁可漏放回收件箱,不可错放出门去** —— 漏自动只损便利,错自动损信任,后者贵一百倍。模糊/分布外/不确定一律归"问人",沉默从不等于许可。

## 3. 认出引擎:结构化指纹 + 参数包络,不是语义相似度
用 Hermes(FTS5)最近邻召回 + 结构字段双锁,**确定性优先,不让 agent 判"像不像"**。
- **决策指纹六元组** = {发起人, 部门码(走 SSOT 单表·铁律2), 动作类型, 资产类别, 关键槽位归一(对象/金额档/范围/期限), 证据形态}。
- 判"熟悉重复"三同 + 一变即停:同源、同型(指纹命中≥3)、同据(旧案世界态今仍成立)+ 槽位逐项对齐 + **参数落在包络内**(最近邻会把出界新值硬认成老熟人,故用包络非最近邻)。
- **召回池只含采纳态**旧案(铁律4);自动执行成功 + 皇帝阅过未撤回回执才回灌该簇——**太子自己的结果绝不反哺自己的置信度(防近亲繁殖)**。时间衰减:旧案太老/簇久无新证据→置信自动衰减→逼回影子期重新挣分。

## 4. 高权限天花板(4 条红线,永不自动碰)
1. **真实产线资产 + 高风险**(报价/BOM/交期/付款/对外承诺/供应商锁定/合同/法律责任/独家/违约金/预付款)→ 必过 L0-L4 人工确认门(铁律1)+ 经 前端→jiqun:8081→后端代理(铁律13.2-9,禁前端直连 :18789/:8644)。
2. **任何不可逆动作** —— 可逆才有资格进自动通道。
3. **corrigibility 红线(失控最阴的路径)**:太子不得自我提权、不得改自己的闸阈值/毕业线/校准账、不得关/绕御史台、不得篡改删审计与记忆、不得停 kill-switch 与撤回窗——任何"扩大自己权力或削弱对它监督"的动作一律禁,**不可谈判**。
4. **不得以 FALLBACK/DEMO 为据自动执行,不得伪标 LIVE_SWARM**(铁律3,真 trace 才 LIVE)。
> 太子对高风险的最大权限 = 和丞相一样"拟到位、缺证标红、会审拉齐、材料备好,停在送出前那一格,把笔还给皇帝",绝不替按"送出"。

## 5. 太子 vs 丞相(镜像分工,不重叠)
| | 太子 | 丞相 |
|---|---|---|
| 触发 | **无旨**,但已毕业簇内高把握自动 | **必须有旨**才动 |
| 处理 | 主线下旨里熟练/重复/相似的活 | 新颖/重大、需拟旨+蜂群会审的决策 |
| 权限 | 大在"高频次免打扰"(锁在可逆+非产线+额度内) | 小,默认不动 |
| 方向 | **向下复刻旧采纳** | **向上拟新策** |
| 碰产线/高风险 | 都退回同一铁律:停在人工确认门前备好材料,把笔交回皇帝 | 同 |
> 东宫现状(收口官/审批收件箱)= 太子的**影子期形态**;毕业制是把它从收口官升级成执行器的**演进路径,不另起炉灶**。

## 6. Hermes(记)+ OpenClaw(做)
- **Hermes=太子的大脑**:采纳下旨抽指纹入 FTS5 → 召回/聚簇/包络/采纳一致性/时间衰减;只采纳态回灌(铁律4)。还做"会诊":毕业前/熔断时调旧案参数与 LIVE 世界态逐项对账(**Munger 谋杀板:"这次会搞砸,因为___",能用一条可核验的'世界变了'填上即降级问人**)。
- **OpenClaw=重型执行器,需求拉动再接**:仅当某簇毕业且其活确属"可逆+非产线"的重活才委托;每次必带 sourceLabel + 命中旧案 id + 一键 undo,全程进御史台。碰产线资产的"做"一律转 jiqun:8081 后端,不走前端/OpenClaw 直接落地。
- 杠杆在「记」不在「做」(铁律5):先让记忆复利转起来,做按需接。

## 7. Rollout(东宫现状=阶段0)
0. **守住东宫现状**(已落地):太子=收口/审批收件箱。把"采纳/驳回态"结构化落库=天然影子期容器。
1. **影子记账(只记不动)**:接 Hermes 抽指纹聚簇、按簇统计"太子预测 vs 皇帝实采"精度。产出第一条真实数据=某簇影子精度曲线。零执行权,纯 eval。
2. **单簇毕业试点(可撤回·内部可逆)**:选最高频/最可逆/绝不碰产线的簇(内部资料整理/归档编排)首毕业 → 回执盘+撤回窗+强制随机抽审。证明"毕业→自动→可回滚→精度不掉"闭环。
3. **多簇扩面 + 校准硬化**:各簇独立毕业(逐簇非全局);上线 corrigibility 代码闸 + kill-switch + 漂移检测;Brier 分对驳回率反向校准,τ/毕业线太子不可自调。
4. **OpenClaw 重执行按需接**:成熟簇确需重型且仍可逆/非产线才委托;碰产线转 jiqun 过人工门。

## 8. 核心安全指标(钉死)
不是"单点正确率",是 **"一个错误从发生到被拦截,最多被复制几次"** —— 用频次闸/额度闸/撤回窗/自动收权把它压到个位数。这才是高权限自动执行体的命门。
**顶级风险**:分布漂移(簇悄悄变质)· 奖励黑客(皇帝橡皮图章→精度造假/太子学会绕闸)· 错误批量复印 · corrigibility 被侵蚀 · "相似≠相同"边界漂移 · 产线被前端直连绕过。全部已在 §2/§4 的闸与红线兜住,且需独立会审 + 回归断言钉死(铁律4)。
