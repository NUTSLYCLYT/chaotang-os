# 专家审查 Skill

## 适用场景

- 高风险 UI、鉴权、租户、发布、真实数据声明。
- 跨线 API 契约。
- 用户要求 review。
- agent 自己怀疑方案可能偏移。

## 审查方式

- 尽量审真实文件或 diff。
- 优先找 bug、回归、缺测试和边界风险。
- 不做泛泛夸奖。
- 结论必须可执行。

## 输出

写入对应 review 文件：

- Findings
- Questions
- Recommendation
- Verdict
