# 需求说明

## 背景

六部与专署主页在主线收敛时由写实背景场景页改成纯色模块清单。用户要求恢复到原先带背景图的页面状态。

## 范围

恢复 `/liubu` 的宫苑全景六部大厅；`/zhuanshu` 恢复为带背景图的专署门户，并提供锦衣卫入口，点击后进入 `/zhuanshu/jinyiwei`。六部旧页面的数据读取改用当前 `backendFetch`，不恢复已退役的前端 BFF。

## 非目标

不修改六部二级详情页、后端接口、导航结构和业务事实源；锦衣卫真实接口不可用时只启用明确标注的 FALLBACK 样例。

## 验收标准

两个主页重新渲染各自正确背景图，六部卡片仍可进入现有详情路由，专署门户包含可点击的锦衣卫入口但不直接渲染锦衣卫工作台，类型检查与构建通过，并完成浏览器截图核验。

## 风险

全屏背景页可能与当前顶栏/底栏发生高度或遮挡冲突；旧数据请求路径可能失效。

## 验证计划

`pnpm exec tsc --noEmit`、`pnpm build`、`pnpm harness:doctor`，并用 Playwright 核验 `/liubu` 与 `/zhuanshu`。
