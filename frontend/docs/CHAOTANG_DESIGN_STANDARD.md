# chaotang-design · 朝堂OS 设计标准（以上书房为准）v1

> 日期：2026-07-06 · 定位：**上书房是朝堂OS 的设计基准页**，所有主闭环版面（军机处/史馆/六部/庄园/钦天监/锦衣卫）
> 一律照此标准对齐，禁各页另起一套。本标准 = 冻结帝金视觉系统（`globals.css`/`design-tokens`）之上的**排布与交互契约**。
> 判据：任何页面改版，先问"跟上书房标准一致吗"；不一致必须在 PR 说明为何偏离。

---

## 0. 一句话
**每个版面 = 一个决策工位**：顶身份条 + 左待办队列 + 中主卷（决策/会审卷轴）+ 右情报/证据 + 底命令轴。
不是 dashboard，不是营销页，不是卡片海。老板一眼看出"该我处理什么、正在处理什么、处理完去哪"。

---

## 1. 布局骨架（常驻三栏）

| 区 | 职责 | 标准 |
|---|---|---|
| **顶·身份流程条** | 部门导航 + 身份 + 流程 stepper（如军机处 立项→会审→封询→盖章） | 全局 `ChaotangTopNav`；页内 stepper 当前步高亮金、已完成绿✓、未到暗 |
| **左·待办队列** | 该处理的事排队，高危/紧急置顶 | 金边卡片（见 §3），风险色，sourceLabel，未读/已处理态 |
| **中·主卷** | 注意力中心：决策卡 / 会审卷轴 / 奏折 | EdictStage 卷轴；默认结论态，翻面下钻（见 §2） |
| **右·情报/证据** | 抬头看天：情报/趋势/风险/证据，不抢中栏 | 诚实标来源；无真数据=占位"待接入"不点亮 |
| **底·命令轴** | 输入/下旨/主命令 | 决策态降格（见 §4） |

- **对称靠语义对仗，非像素镜像**：左"待决"↔右"待知"，中"正决"。两翼等重但**都比中栏暗**（§4 光焦）。
- 移动端退化：优先保中栏主卷；左队列收顶部/下拉，右情报收底部顺序展开。

---

## 2. 中栏主卷 = 决策卡（结论优先 + 翻面下钻）
- **默认结论态**：一句话圣裁 + 建议动作 + `sourceLabel` + 缺证/风险徽 + **朱批五键**。
- **翻面下钻**（不跳页可逆，Norman）：背面 = 正文/证据/成本拆分/缺证/风险；内容多→展开详情。
- **高风险强制翻面 + 拦门**：命中高危词（合同/报价/付款/股权…）→ 默认落证据页 + 采纳前人工确认，禁一键静默。
- **会审中态**（军机处等）：主卷显示「六部会审直播」——各部渐进出块（户部先出成本、刑部合规再出），带真 stage 事件；见 `SwarmDeliberationLive`。

## 3. 朱批五键（SSOT · 唯一裁决动作集）
`采纳 / 补证 / 复核 / 驳回 / 追问` —— `VerdictActionBar`。全站决策卡共用这一套，**禁各页各造按钮组**。
终态（采纳/驳回）后锁定，防重复/矛盾裁决。

## 4. 注意力状态机（张小龙 · 同屏只留一套主动作）
- 卷轴展开=**决策态** → 底部命令轴**降格成一句提示**，中栏五键独占注意力；收卷=提问态复原。
- **Norman 物理光焦**：两翼常驻但默认降一档明度（`opacity 0.82`）；选中左栏项时两翼短暂再压暗 220ms 吸回中栏。
- 一屏只有一个主角。**别让 stepper/计数器/侧栏抢中栏的戏。**

## 5. 金色层级（帝金语义分档 · 不是全刷金）
| 档 | 用法 | 样式（`ImperialButton`） |
|---|---|---|
| **主动作** | 就按这个（采纳/下旨/展卷） | `gold`：满帝金填充 + 发光 |
| **强次动作** | 金染填充 | `primary` |
| **次动作** | 默认金边亮起、清楚可点（补证/详情/卡片） | `secondary`：默认淡金边+底，非灰 |
| **最低** | 链接/toggle | `ghost`：无边向金靠 |
- **全档必做 hover/focus/active 三态 + focus-visible 环**（Norman affordance：能点一眼看得出）。
- ❌ **禁全刷金**（层级塌）；❌ **禁点亮死/未接线按钮**（假承诺，Norman 红线）。

## 6. 诚实标（真链路纪律 · 硬红线）
- 一切面向老板的结论带 `sourceLabel`（LIVE/LIVE_SWARM/LIVE_ENGINE/MIXED/FALLBACK/DEMO）。
- **DEMO/FALLBACK 禁伪装 LIVE**；空态标"今天没有/待接入"，**禁 mock 假数据冒充真实**。
- 无真数据的版块=诚实占位、不点亮、不造飞轮（铁律5）。

## 7. 视觉冻结（复用，不重造）
- 禁改 `globals.css`(727行)/`design-tokens`/18 keyframe/帝金色值/启动时序。
- 复用 12 utility class + `GlassPanel`/`SignalPulseDot`/`EnterStagger`/`PageHeaderShell` 等；动画只碰 `transform/opacity/clip-path`。
- 部门色/名/官印取 SSOT：`AGENT_META`(nameCn/color) + `agentColors` 11码。

## 8. 克制（Rams/张小龙 · 天才设计的第二天才）
- 别堆满：核心先成卷轴/主工作面，附属才进两翼。
- 认怂徽/锚点/邀功等花活**按需出现**，不常态、不每卡都挂——出现太频=从"神"变"吵"。
- 最好的 IA 往往是**没新增版面**的那个（铁律5）。

## 9. 验收（每个版面改版对表）
- [ ] 三栏骨架 + 顶流程 + 底命令轴，一眼是朝堂OS（非 dashboard/营销页）
- [ ] 中栏决策卡结论优先 + 翻面 + 朱批五键 + 高风险拦门
- [ ] 金色三档层级 + 三态；无全刷金、无点亮死键
- [ ] 注意力状态机：一屏一主动作、两翼比中栏暗
- [ ] 诚实标齐、无 DEMO 冒充 LIVE、占位不造假
- [ ] 截 1440/768 双档，无横向溢出
- [ ] 复用冻结视觉资产，未重造
