## 北极星

上线第一版卖的是“老板决策闭环”，不是完整 ERP、OA、CRM 或通用 Agent 平台。

一句话北极星：让企业老板从一个真实经营问题出发，经过 AI 内阁会审，形成有证据、有风险门、有归档的可追溯裁决。

P0 闭环：

```text
上书房今日预案
-> 丞相筛选
-> 军机处会审
-> 合法奏折
-> 老板裁决
-> 高风险确认门
-> 史馆归档
-> 下次引用旧案
```
