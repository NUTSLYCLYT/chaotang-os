# 09 AI Box Edge Plan

本文件目的：记录 AI 盒子、本地边缘设备和企业私有化硬件方案，但明确它不是 CourtOS P0 上线前置条件。
优先级：P1/P2。

本地 AI 盒子不是 P0 上线前置条件。它是企业私有化、展厅演示和本地视觉/语音智能体的后续增强。

## 能做什么

- 作为客户私有化、本地演示、离线知识库和边缘视觉的方案储备。
- 区分迷你主机、Jetson、GPU 工作站三种硬件路径。
- 为销售话术和企业客户安全诉求提供可选增强。

## 不能做什么

- 不能阻塞 P0 裁决闭环上线。
- 不能在没有客户需求前采购复杂硬件。
- 不能把 Jetson 当成本地大语言模型主力推理设备。

## 当前结论

现在不要把 AI 盒子作为 P0 上线必需项。

P0 第一优先级是：

1. 产品闭环跑通。
2. 老板能看懂。
3. 客户愿意试用。
4. 数据能归档。
5. 风险能控制。
6. 演示能震撼。

AI 盒子会引入硬件采购、系统安装、模型部署、散热、运维、联网、安全、售后、故障排查和现场部署复杂度。它会拖慢上线。

## 适合放到 AI 盒子的能力

- 本地知识库。
- 本地向量库。
- 本地 LLM 推理。
- 本地语音识别和合成。
- 本地视觉识别。
- 展厅离线演示。
- 客户数据隔离。

## 不适合第一阶段放到 AI 盒子的能力

- P0 裁决闭环。
- 基础登录权限。
- 史馆归档主链路。
- 发布门禁。
- 线上客户验证。

## 验收标准

- 没有网络时能跑演示样板。
- 数据不出客户本地环境。
- 能导出审计日志。
- 与云端版本有清晰边界。

## 触发条件

遇到以下客户或场景，再把 AI 盒子升级为正式方案：

1. 客户不愿意数据上云。
2. 政府、国企、制造业要求本地部署。
3. 企业有大量内部文档。
4. 需要本地知识库问答。
5. 需要本地摄像头、设备、传感器接入。
6. 需要边缘视觉识别。
7. 网络环境不稳定。
8. 需要离线演示。

## 三档产品形态

### 1. 演示盒子：迷你主机

用途：商会演示、客户拜访、离线展示。

建议：

- CPU：i5 / i7 / Ryzen 7。
- 内存：32GB 起。
- 硬盘：1TB SSD。
- 系统：Ubuntu / Windows + WSL。

能力：

- 跑前端 demo。
- 跑后端 demo。
- 跑本地数据库。
- 跑离线演示素材。
- 做客户现场展示。

这是近期最实用的盒子形态。

### 2. 边缘 AI 盒子：NVIDIA Jetson

用途：未来视觉智能体、摄像头识别、工厂设备边缘监控、本地小模型、低功耗部署。

注意：

- Jetson 更适合边缘视觉、小模型、设备侧智能。
- 不作为大型语言模型主力推理设备。
- 硬件价格和型号变化快，采购前必须联网复核官方页面。

### 3. 企业私有化盒子：GPU 工作站

用途：后期客户付费私有部署。

建议：

- CPU：i9 / Threadripper / Xeon。
- GPU：RTX 4090 / RTX 5090 / RTX 6000 系列。
- 内存：128GB 起。
- 硬盘：2-4TB NVMe。

能力：

- 本地大模型。
- 私有知识库。
- 向量检索。
- 企业文档问答。
- 本地 Agent 调度。
- 私有化部署。

这不是 P0。
