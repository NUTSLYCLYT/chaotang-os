# 朝堂 OS · 激励经济 · 可信度飞轮 · 设计 SoT

> 立于 2026-07-01。让各部 agent「加速进化、知识库快进、飞轮生效」的激励体系。
> **核心纠偏**：AI agent 不吃胡萝卜大棒——真正进化的是**知识库**，不是 agent。
> 「奖惩」重塑的是**信任、审查、知识、预算**，不是情绪。
> 大神镜片：芒格(激励错位最贵·复杂即脆弱)·格鲁夫(看真实产出不看忙)·张小龙(游戏化是配角)·德明(数据互证)。

---

## 0. 北极星（整套体系只挂这一个指标）

**决策事后兑现率**（史馆回填的真结果 + 御史核过）。其余全是它的辅助。
> 激励"真兑现"，系统长成会赚钱的；激励"看起来对/够勤快"，系统长成会演戏的（芒格）。

---

## 1. 双货币：朝币（花的）× 星星（攒的）· 绝不互换

| | 朝币 | 星星 |
|---|---|---|
| 怎么得 | 交付被采纳/真兑现就发 + 皇帝打赏 + 被别司召用挣得 | **只在「史馆确认真兑现 + 御史核过」时铸**（稀缺） |
| 能干嘛 | **花**：换 token 额度 / 召 agent / 用 skill | **不能花**，只攒；5 星升一品 |
| 本质 | 内部预算 + 资本（算力/能力的购买力） | 永久声誉 / 真战功 |

**互换锁**：星星买不到（朝币 ≠ 星星）→ 勤快/刷量换不到声誉，声誉只能靠真兑现挣 → 堵古德哈特。

---

## 2. 朝币 ↔ token：激励经济与成本经济合一（接 `consumeLlmBudget`）

- **每岗 = 保底额度(floor) + 挣来的增配(bonus)**：保底保关键但安静的司（刑部/御史）不饿死；增配奖高功。
- **耗尽 = 优雅降级**：降便宜模型 / 排队 / 诚实上奏「预算已尽，要追加吗」+ 标降级成色。不崩、不卡真活。
- **老板控总额（真金），朝币按功自动分配**。预算是防浪费护栏，不是卡死真活的墙；老板永远能追加。

---

## 3. 资本市场三机制

**① 皇帝打赏**：老板随时赏朝币（看谁不够/干得好）。**只给朝币（预算），不给星星（声誉）**——防偏袒污染 merit。
自带「御赏」记（一句话故事），全程留痕、人人可见（透明防滥）。

**② 丞相审批划拨**：户部持账并执行划拨（金融领域=户部本职·铁律6）；丞相在额度内审批；超额/不可逆 → 皇帝亲批（人工确认门）。
> 户部管钱、丞相批、皇帝裁大额、御史审账。

**③ 朝币换 agent + 技能（能力市场）**：司花朝币召别的 agent / 用 skill；贵技能花更多 → 先用便宜的。
**被召的 agent 挣到朝币** → 有用的富、没人召的饿 → 市场自动筛出真有价值的 agent/技能。
技能住翰林院，被买次数 = 真实需求信号 → 翰林据此炼新/淘汰旧。

## 4. 品级 + 称号（声誉的台阶，可升可降）

- **品级**：5 星升一品。奖=自主（低风险自动放行）+ 更大朝币预算 + 会签加权；**责=御史用更高标准盯、犯错追责更重**（权责对等，防一品躺平）。
- **称号**：靠一次标志性战功授（户部抓出巨亏「铁算盘」/御史揭造假「直臣」/钦天监预判中势「司天」）。稀有·带永久加成·是个故事。
- **可升能降**（否则通胀）：翻车/被劾 → 扣星、降品、夺号。
  **护诚实失败**：诚实赌输扣少量星；**渎职（幻觉/缺证乱报）扣巨量 + 夺号**。诚实的失败要护，演戏的成功要重罚。

---

## 5. 御史审账 + 谁 owns 什么（接御史台体系）

- **账本（朝币/星星/token）也是数据，也会被刷** → 御史抽查；star 只在兑现+御史核过时铸；账本可复现。
- **御史「token & 效率」奏折具体化**：报每司 token-ROI（挣朝币 ÷ 烧 token），揪浪费、建议重分配。
- ownership（铁律6）：户部=持账/划拨 · 吏部=可信度考评 · 史馆=兑现回填 · 翰林院=能力市场 · 御史+锦衣卫=审账抓刷 · 皇帝=打赏/大额终裁。

---

## 6. 两条不可破的铁律（防经济烂掉）

**① 套利锁（最重要）**：朝币只在「老板采纳 / 史馆真兑现」时铸，**绝不在「产出一个奏折 / 跑一次查询 / 互相召用」时铸**。
挣口挂真结果、不挂动作 → token 套利（刷量换朝币换 token 再刷）无利可图。**这是整个经济不烂的唯一锁。**

**② 配角铁律**：朝币/星星/品级/称号永远是**配角**，只在点开某司时作「信任背书」露一眼（像看简历勋章），**绝不占主舞台**。
主舞台永远是老板的真决策和真奏折。**一旦星星比奏折更抢眼，这设计就该砍**（张小龙：游戏化让用户更信结果，不是让用户上瘾于过程）。

---

## 7. 落地顺序（先通一环，别同时铺开）

整套经济命脉只有一环：**「司因真兑现挣朝币 → 朝币换 token 额度」**。
1. **先做这一环真的**：接 `consumeLlmBudget`(已有) + 史馆兑现回填 → 一个司真的因奏折被采纳而多分 token。
2. 这一环转起来后，打赏/划拨/能力市场/品级称号才是它的"利息"。**这一环不转，其余全是空中楼阁。**
> 别在一条真链都没通时，给不存在的经济设计金融衍生品（芒格：复杂是脆弱的温床）。
