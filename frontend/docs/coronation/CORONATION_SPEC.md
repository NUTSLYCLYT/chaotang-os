# 登基 90 秒门槛流 · 可执行规格 + 表象-状态保真契约

> 来源:2026-06-09 大神会审(Jobs/黄仁勋/Minsky/Kahneman,张小龙补位)收敛结论。
> 适用:朝堂皮肤的 `登基动画 → 大殿(第一站) → 上书房(下第一道旨)` 门槛流。
> 性质:设计宪法 + 原型规格。**后续所有朝堂皮设计须遵循本文 §3 的六条原则。**

---

## §0 一句话目标(成功标准)

让一个**看不懂 AI 的东方小商户**,在 90 秒内:
1. **秒懂**:不靠文字说明,就明白"我有一班大臣替我办事"(= agent 能力的具身化)。
2. **起鸡皮疙瘩**:在「下旨→满朝回奏」那一秒,身体里产生"算力军团从今天替我干活"的占有感。
3. **愿意走进来**:结尾留下一个"属于他自己的具体结果",让他想下第二道旨。

可量化验收:5 个真实小商户实测,盯眼睛——**≥3 人在"回奏那一秒"明显亮起**,且**≤1 人中途走神/想跳过**,才算封神。

---

## §1 流程节拍(秒级脚本)

火力分配铁律(Jobs):**99% 的工程与打磨砸进 §1.3 那一秒**,§1.1/§1.2 是 packaging,服务于它,不得喧宾夺主。

### 1.1 登基动画(已有 /intro 22.5s,SCENE_DURATIONS 冻结,不重做)
- 复用现有 6 幕。唯一新增要求:动画**结尾不落在 logo,落在"空荡的、属于你的大殿"**——占有感先于能力感(Minsky)。

### 1.2 大殿 · 群臣就位(第一站,~20-30s)
- 镜头拉过空殿 → **群臣逐一就位,每位对应用户"真实已开通"的一个 agent**(没开通的位置留空/虚影,不是满编)。
- 关键:就位不是装饰动画,是**"点名我现在拥有哪些能力"的真实清单**的具身演出(见 §2 契约)。
- 丞相最后就位,躬身,把舞台交给用户:请下第一道旨。

### 1.3 上书房 · 第一道旨 → 满朝回奏(★ 杀手锏,封神点)
这一秒是整个产品的 iPhone-划屏时刻。精确规格:
1. 用户说/打一句话(给 2-3 个"开局示例旨意"降低冷启动)。
2. **相关大臣依次苏醒、互相递数协作**——不是一个大臣应答,是一条"我一句话 → 一群人为我连锁运转"的**因果链**(A 转头看 B → B 调数据递 C → C 回奏)。这条链是 aspiration 的点火器(Minsky)。
3. **必须塞一位"谏官出列"**:至少一位大臣亮灯后躬身提一条**把关意见/异见**(如"陛下,此事户部预算不足"或"锦衣卫探得风险三条")。→ 让用户瞬间懂:这是会替我把关、有独立判断的臣子社会,不是复读机。**这是"秒懂 agent ≠ 听话机器"的关键一拍。**
4. **延迟预算**:首字回奏 < 1.5s,谏言 < 3s。**等 3 秒转圈 = 帝国梦当场死**(Jobs)。真 agent 慢时见 §2 的"诚实演出"。
5. **aspiration 靠涌现击中,绝不打字幕**:全程**禁止**出现"通往 AGI / 拥有帝国"之类 slogan 字幕(= PUA、浮夸,鸡皮疙瘩变尴尬)。让他**感觉到**,不被告知。

### 1.4 峰终收尾(Kahneman · 决定要不要回来)
- 结尾那一帧**不能**是通用的"圣旨已发"跳回一堆面板。
- 必须是**一个具体的、属于用户自己的结果**(他那道旨产出的真东西)。
- 留存钩子从"你将得到帝国"偷偷转成"**你已是君主,退出 = 退位**"(损失厌恶 ≈ 2× 获得喜悦)。

### 1.5 对照暗门(张小龙补位 · 必做)
- 提供"**跳过 / 30 秒速通**"入口,并埋点统计选择率。
- 判据:若相当比例真实用户选跳过,说明浓皮在帮你流失而非封神——**数据说话,不靠创始人自我感动**。

## §2 表象-状态保真契约(比视觉资产更该冻结的地基)

> 全员一致:批准方向,**否决"华丽戏服"**。条件全压在这一条。

**契约定义**:朝堂里每一个大臣的**每一个可见状态**(就位/转头/亮灯/思考/回奏/告退去查/沉默/办不成),**必须由一个真实 agent 的真实状态驱动**,不得是写死的脚本动画。

**必须如实演出的状态(不许只演成功态)**:
| 大臣表象 | 必须映射的真实 agent 状态 |
|---|---|
| 亮灯/苏醒 | 该 agent 真的被这道旨激活 |
| 思考/沙漏 | agent 真在跑(检索/推理) |
| 告退去查、半晌方回 | agent 真在长任务(诚实演出"慢",不假装秒回) |
| 回奏 | agent 真产出了结论 |
| 沉默/摇头/"臣办不成" | agent 失败/查无/低置信 —— **必须诚实演出,不许跳过** |
| 谏言/异见 | agent 真给出了把关/反对(非脚本台词) |

**度量:表象-状态保真率** = (由真实 agent 状态驱动的可见态) / (全部可见态)。
- 目标 = 1.0。**< 1 即判定"卖戏服"**,进入返工。做成一个可监控数字(借鉴 charity-majors/Deming:没度量的飞轮和没飞轮账面无法区分)。

**验收红线(Jobs,任一触发即推倒)**:
1. 用户对丞相说的话,若和"普通对话框打字"产出**完全相同** → 整个朝堂判 **cosplay**,隐喻没改变交互本身,推倒重来。
2. 原型用预录脚本做"永远成功、6.3s 内整齐回奏" → 它训练用户形成"agent = 秒回顺从太监"的**错误心智模型**,真用时落差摧毁信任(Minsky)。**原型即使用假数据,也必须跑在一个真实的状态机上**(假的是数据内容,不假的是"成功/失败/慢"的状态分支)。

**对"假数据原型"的硬约束**:可以假**数据内容**,不可以假**状态真实性**。谏官的异见可以是预设的,但"何时亮灯、是否有人沉默、回奏快慢"必须来自一个真状态机——否则就是 §2 红线 2。

## §3 设计宪法(后续所有朝堂皮设计须遵循)

1. **门槛优先(Threshold-first)**:封"那一秒",不均匀打磨所有面板。资源跟着"封神点"走,不跟着空板块走。
2. **保真高于流畅(Fidelity > Fluency)**:宁可诚实地慢/失败,不要华丽的谎。流畅度不是真实,画面越流畅越要替用户挡住"它全能"的陷阱。
3. **涌现而非口号(Emergence, not slogan)**:aspiration 靠"一句话→群臣连锁协作"的因果链点燃,绝不打字幕喊。
4. **一张皮,但解耦(One skin, decoupled)**:产品聚焦只 ship 朝堂皮;但代码第一天就把**世界层(大臣叙事)与功能层(agent 能力契约)硬切分**,别把能力焊死在隐喻里。
5. **真模型而非戏服(True model, not costume)**:每个角色真映射一个能力;加入"谏官"等会反对的角色,因为智能来自冲突的解决而非和谐叠加。
6. **本地化隐喻,普世概念(Localized metaphor, universal concept)**:见配套战略——"你指挥一支 AI 团队/拥有自己的帝国"是普世 aspiration;朝堂只是东方皮,欧美用别的皮承载同一概念。

---

## §4 落地顺序(给实现者)

1. 先用纸面/假数据把 §1.3 那一秒的**状态机**画出来(状态分支:成功/慢/失败/谏言),再谈视觉。
2. 把 §2 契约做成代码层的断言 + 一个"保真率"埋点。
3. 90 秒原型(假数据内容、真状态机)→ 立刻怼到 5 个真实小商户面前盯眼睛(黄仁勋)。
4. 同步做**事前验尸**(Kahneman):写下"这个 demo 害了我们的那半年,为什么"——大概率答案是"锚定得太高",据此约束隐喻只承诺 agent 真做得到的事。
5. 改前端须**另开 git worktree**(主线树有并发 agent)。
