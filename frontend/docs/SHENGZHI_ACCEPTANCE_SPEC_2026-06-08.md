## 二、圣旨验收 6 条（任一不满足 = 正确的废话 = 失信）

1. **第一眼一件事**：第一行 = 可直接签字的硬判（推/不推·上/不上·放/不放）**＋ 可逆性标签**（单向门/双向门·掉得了头/掉不了头）。禁"建议综合评估"。缺时间的老板第1需求就是"告诉我做什么、能不能掉头、要不要签字"，一眼之内。
2. **丞相统筹**：必须 RESOLVE 一个具体跨部冲突（户部现金 vs 工部技术 vs 兵部市场），**点名"绝对不要做的那一件"**，给带数字带时点的排序动作。不是各部各说一遍（葡萄干拌屎还是屎）。
3. **钦天监前瞻**：给**可证伪的刹车阈值**（碳酸锂跌破X即砍·良率连N月不过90%即停）＋ 分**不变量 vs 变量**（Bezos：让我押不变量不押运气）＋ 预判**尾部/最坏**（Taleb：相关性尾部、一次赔穿，不是平均值）＋ 点**催化剂时点**（Munger）。禁只点风险类别名不给数字 = 占卜剧场。
4. **质量门**：按**不可逆性 × 现金流占比**卡，不是按难度。单向门/bet-the-company → 必须人工签字 + 签前听最强反对。双向门 → 敢说"别上报、快做"。禁把每题都推"需人工复核"（=甩锅机器）。
5. **证据**：真数据（真锂价曲线、独立失效事件数）不是体感。
6. **卡在哪（Ohno 现地现物）**：落到真实瓶颈 + 可落地下一步（卡哪道工序 / 哪月断粮），不是战略空话。

## 三、失信红线（出现即用户当场关掉、永不再用）

- "建议综合评估 / 谨慎决策 / 平衡风险 / 小步快跑保留多路线" —— 两头堵、没数字、没掉头判断。
- 钦天监只点"需关注价格波动/交期风险/政策变化"类别名、不给阈值 —— 假远见。
- 质量门 80% 落在"需人工复核" —— 甩锅遮羞布（从没真裁决过）。
- 全员和谐、从不弃权/否决 —— **权威洗白**（Munger：给数据不足的判断盖红章背书 → 社会认同+权威+解除怀疑三偏误叠加 → 用户比没工具更敢签会赔穿的合同 = 收智商税）。

## 四、头号死法（panel 一致）

退化成"正确的废话生成器" + 质量门变甩锅 + 钦天监变占卜剧场。
缺时间的老板第一次看到答非所问（如当前 dry_run 拿"江南丝绸加税"冒充冷库储能问题）或两头堵，
三次就看穿、流失不回。**修好"不说谎"（去污染）之前，对外一次都不能演。**
