# 朝堂公文与用印标准（2026-06-29 · 顶级美工定稿 v1）

> 一句话：**世界 500 强公文的专业骨架 + 中式官印的权威落款 + 朝堂帝金的视觉品牌**。
> 凡朝堂对外/对内正式文件（奏折/报告/方案/决议/合同附呈），一律按本标准排版用印。

## 一、设计方向（冻结）

| 维度 | 标准 |
|---|---|
| 视觉品牌 | 暗金驾驶舱 · 帝金 `#F0C66A`/`#D4A84B`/`#8A6A2A`（复用 design-tokens，禁改） |
| 官印 | 帝金朱印——朱红印泥 `#BE2E26`（落款）+ 帝金线 `#D4A84B`（UI 内嵌），见 `src/components/DeptSeal.tsx` |
| 字体 | 标题 Noto Serif SC（衬线·庄重）× 正文 Inter/Noto Sans（无衬线·清晰），刻意配对 |
| 信息结构 | BLUF（Bottom Line Up Front）——结论先行，世界 500 强/军方公文通则 |

## 二、公文结构（9 段·世界 500 强 + 朝堂奏折融合）

```
┌─────────────────────────────────────────────┐
│ ① 抬头区   机构名 + 部门官印(右上) + 文号 + 密级 + 日期  │
│ ② 标题     一行说清「谁·对什么·下什么结论」           │
│ ③ 执行摘要  BLUF:3-5 句给结论+建议+金额/期限,先看就够   │
├─────────────────────────────────────────────┤
│ ④ 背景与问题   为什么发起(1段)                       │
│ ⑤ 分析与依据   数据/测算/条款,每条带来源标(真/估/缺)   │
│ ⑥ 结论与建议   分条,可执行,带责任人(DRI)与期限         │
│ ⑦ 风险与缺证   坦白未知项+高风险项(高风险须人工确认门)  │
│ ⑧ 后续与质门   下一步动作 + 通过标准                  │
├─────────────────────────────────────────────┤
│ ⑨ 落款区   承办司 + 会审司 + 部门官印(朱红) + 签批日期  │
└─────────────────────────────────────────────┘
```

**铁律继承**：⑤ 每条数据带 sourceLabel（真/估/缺 三色，铁律13.2）；⑦ 高风险（股权/合同/重大付款/对外报价）必过人工确认门（铁律13.2.5）；⑧ 质门即「奏折必含八要素」（圣裁/分奏/证据/缺证/风险/后令/质门/来源）。

## 三、用印规范（谁盖·盖哪·盖几个）

| 场景 | 用印 | 位置 |
|---|---|---|
| 单部门出具 | 该部门官印（朱红） | 落款区右下，压「承办司」名 |
| 军机处会审通过 | 军机处中枢印 + 各会审部门印 | 落款区横排，军机处居中 |
| 对外正式（报价/合同附呈） | 部门印 + 需老板朱批（高风险门） | 印在右下，朱批在印左 |
| UI 内嵌（卡片/页眉） | 帝金线变体（不喧宾夺主） | 角标位，size ≤ 48 |

## 四、排版细则（帝金系统复用）

- 抬头机构名：`.page-title`（24px 帝金渐变 serif）；文号/密级：`.page-meta`（11px `#b6ab8c`）。
- 段落标题：`.section-title`（16px serif）+ `.section-eyebrow`（10px uppercase 字距）。
- 正文：`.body-copy`（13px / 1.85 行高 / `#c6bb9d`），段距 > 行距制造呼吸（节奏≠均匀）。
- 数据表：金属描边 `.metal-edge`，表头帝金、奇偶行微差，禁纯灰底。
- 三色来源标：真 `#4ADE80` / 估 `#F0C66A` / 缺 `#F87171`，语义化非装饰。
- 金光预算 ≤ 8% 版面（奢侈靠克制，见 dark-luxury-playbook）。
