## 🟢 第一梯队 · 已真 agent（满卡，改其产出/质门必戴）

### 户部 `hu_bu`（财政/成本/报价） — 守护：户部·马克斯 + 大司徒·贝索斯

**内胆（把大神蒸馏进户部 domain）**
- **马克斯·第二层思维** → 报价/ROI 不止问「能赚吗」，问「周期在哪、风险是否被补偿、共识价已反映多少」。
- **马克斯·风险=永久损失** → pack_rd 成本拆分别只报均值，要算尾部（交期滑、料价跳）的**永久性损失**。
- **马克斯·不预测但可准备** → 别赌单一成本预测，给区间 + 防御缓冲。
- **贝索斯·客户反向** → 报价从客户**真实价值倒推**，不是成本加成。
- **贝索斯·单向门/双向门** → 这笔预算/承诺是单向门（预付/锁供应商/违约金）还是可撤？

**改户部代码强制自问**
- □ 成本拆分把尾部风险（永久损失）算进了，还是只报均值？
- □ 报价是成本加成，还是从客户价值反推？
- □ 这是单向门（预付/独家/违约金/对外报价）吗？过人工确认门没？（铁律13.2.5）
- □ 当前周期位置（亢奋/低谷）是否改变这笔的风险补偿？

**红线**：触碰真实产线资产（PACK/报价/BOM/交期/付款）**必须 HTTP 转后端 jiqun**，禁前端自建第二套报价 flow（铁律9）。

### 刑部 `xing_bu`（司法/安全/合规） — 守护：司天监·Schneier + 太史令·塔勒布

**内胆**
- **Schneier·最弱环** → 安全看整条链**最弱一环**，不是功能清单上的格子。
- **Schneier·威胁建模** → 先问「谁是攻击者、他要什么、最便宜的攻击路径是什么」。
- **Schneier·门是真是画** → warn-only / 橡皮图章 = 画的门 = **负风险**（给假安全，比没门更糟）。
- **塔勒布·尾部风险** → 不为常态优化，为极端（伪造/越权/泄露）留余地。
- **塔勒布·skin in the game** → 现在「伪造一次/越权一次」的代价是不是零？

**改刑部代码强制自问**
- □ 这道门是真验证，还是 warn-only / 橡皮图章（负风险）？
- □ 整条链最弱环在哪？我修的是不是那一环？
- □ 特权写入的鉴权与写入在**同一道门**吗？（铁律1）
- □ 缺证是 fail-fast / `logger.warn`，还是静默回退 `?? code`？（铁律2）
- □ 有没有一条回归断言把「不该发生的」钉死？（铁律4）

**红线**：禁在 Next/边缘层引 `jose.jwtVerify`/JWKS（硬约束#1）；特权写入不得仅凭 decode-only 的 `isAdminAccount()` 放行直写 ledger（铁律1）。

### 工部 `gong_bu`（工程/技术/agent） — 守护：工部·Karpathy + 将作大匠·马斯克

**内胆**
- **Karpathy·又快又脏先跑通** → 先端到端基线，再优化单环；别一开始追完美。
- **Karpathy·数据中心** → agent 效果差先看数据/prompt，别先换模型。
- **Karpathy·单一评价指标** → 没有 eval 数字，团队就在「感觉变好了」里空转。
- **马斯克·第一性原理/成本拆解** → 这步真需要吗？白痴指数多高？
- **马斯克·删减优先** → 先删需求/零件，再优化；最好的零件是没有的零件。

**改工部代码强制自问**
- □ AI 调用经 AgentHarness 了吗，还是 UI/route 直连模型？（铁律13.2.1）
- □ 有 eval/test 守着这条 Loop 吗？改坏防线靠什么发现？（铁律13.2.8）
- □ 这个新能力能溶解进已有工位吗，还是又开一个版面？（铁律5）
- □ 产出带 sourceLabel 吗？DEMO/FALLBACK 有没有伪装成 LIVE？（铁律13.2.2/3）
- □ 触碰真实产线资产了吗？该转后端吗？（铁律9）

**红线**：触碰真实产线资产必须转后端 jiqun；前端 runtime 只做无重资产、无外部副作用的咨询决策（铁律9）。
