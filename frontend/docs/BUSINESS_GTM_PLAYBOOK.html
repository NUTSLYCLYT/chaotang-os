1. 产品定位与核心叙事

1.1 我们是什么

先知和导师 = AI Agent 时代的实战经营决策操作系统

用一句话向企业老板解释：
"你提一个真实的经营问题，AI 蜂群替你分析、拆路径、
 给方案、控风险、归档复盘，你只需要做最终裁决。"

三省六部不是古风皮肤，是治理框架：

层级 功能 对应企业场景
上书房 老板提问/下旨 战略决策输入口
丞相台 AI 拟方案 方案生成与汇报
军机处 多视角会审 风险评估与投票
六部 专项执行（财务/法务/工程/情报/规制/礼仪） 各部门 AI 蜂群分工
史馆 归档复盘 决策记录与学习闭环

1.2 我们不是什么

误区 正确认知
❌ 企业 BI 工具（Tableau/PowerBI） BI 看数据，我们做决策
❌ 通用 AI 助手（ChatGPT企业版） 没有业务上下文积累，对话即忘
❌ 流程自动化（RPA/n8n） 自动化执行流程，我们做决策判断
❌ ERP 系统 ERP 管资源，我们做战略和问题解决
✅ 我们是 把老板的经营判断力 × AI蜂群算力 = 更快更准的决策

1.3 目标客户画像

首批目标（0-10个客户）：

行业：制造业中小企业（特别是有供应链/品质/销售/成本压力的）
规模：100-500 人，年营收 3000万-5亿
角色：老板/总经理/运营VP
痛点：
  1. 信息太多、决策太慢（会议漫长、判断靠感觉）
  2. 人才贵但决策质量不稳（高管离职即断层）
  3. AI 想用、不知道怎么用到自己生意里
心理账户：
  → 愿意为"提高决策速度和质量"的工具付年费 5-30万
  → 不愿意为"AI 玩具/Demo"付一分钱

2. 商业模式选择与建议

2.1 三种可选模式对比

模式 A：高接触实施 + 年费授权（Palantir / Harvey AI 路线）

核心逻辑： 你帮客户把蜂群配好、接进业务流程，收实施费 + 年度许可费。

客户旅程：
  发现（转介绍/演示）
  → 免费 2 小时诊断（摸清客户最痛的 3 个决策场景）
  → 签 POC 合同（3 个月 ¥2-5万）
  → POC 证明价值 → 转正式合同（年费 ¥10-30万 + 实施费）
  → 年度续费 + 追加蜂群模块

优点： - 现金流最快，1 个客户就能支撑团队运转 - 客户绑定深，流失率低 - 铭硕经验可直接复用

缺点： - 扩展慢，每个客户需要人工接入 - 强依赖创始人销售能力

适用阶段： 现在 → 获得前 10 个客户

模式 B：垂直 SaaS（行业模板 + 自助订阅）

核心逻辑： 把铭硕电池蜂群抽象成"制造业蜂群包"，其他同类企业自助配置，按月付费。

客户旅程：
  内容/SEO/转介绍 发现
  → 官网注册试用（14天免费，数据不出门）
  → 自助配置蜂群（引导流程 + 模板）
  → 转付费（月付/年付）
  → 升级 Pro（更多蜂群数/API 额度）

优点： - 可规模化，不强依赖人工 - 月经常性收入（MRR）清晰可预测

缺点： - 需要非常好的产品自助体验（还需打磨） - 获客成本高，需要持续内容投入 - 冷启动慢

适用阶段： 6-18 个月后，有了 5-8 个行业模板后推出

模式 C：私有化部署授权（自托管版）

核心逻辑： 代码部署到客户服务器，数据完全自有，一次性授权费 + 年度维保。

客户画像：国企/政府/大型制造业/金融（数据不能上云）
定价：¥30-100万 部署授权 + ¥5-15万/年 维保
销售周期：3-12 个月（需要招标/采购流程）

优点： - 单笔合同价值高 - 品牌背书强（有大客户名字）

缺点： - 销售周期极长，现金流压力大 - 需要专门的实施团队

适用阶段： 18 个月后，有了商业版稳定产品再做

2.2 建议路线（三阶段叠加）

第一阶段（现在 - 6个月）
├── 主力：模式 A（高接触实施 + 年费）
├── 目标：签下 3-5 个付费客户
├── 重点：铭硕做成完整案例包，用案例获取客户
└── 收入目标：月收入 ¥5-15万

第二阶段（6 - 18个月）
├── 主力：模式 A 继续 + 模式 B 开始（SaaS 化）
├── 目标：5-8 个行业模板上线，开放自助试用
├── 重点：把实施经验固化成产品引导流程
└── 收入目标：MRR ¥30-80万

第三阶段（18个月+）
├── 主力：模式 B 规模化 + 模式 C 大客户专线
├── 目标：100个付费客户，其中5个私有化
├── 重点：合作伙伴渠道（咨询公司/行业服务商）
└── 收入目标：ARR 超 1000万

3. 定价体系设计

3.1 价格锚点原则

定价不是算成本，是定位客户心智。 你的价格要让客户觉得"这是一个认真的企业工具"，而不是"AI 玩具"。

3.2 推荐定价方案

方案一：年费制（推荐首选）

产品层级 内容 定价
入门版 云托管 + 3个预配蜂群 + 上书房决策 + 史馆归档 ¥3,600/月 或 ¥36,000/年
专业版 云托管 + 10个自配蜂群 + 全六部权限 + 优先客服 ¥8,000/月 或 ¥80,000/年
旗舰版 私有化部署 + 无限蜂群 + 专属客户成功 + 定制开发 ¥20,000/月 或 ¥200,000/年起
实施费 首次蜂群配置 + 数据接入 + 培训 ¥30,000-80,000（一次性）

方案二：POC 首客价格（铭硕模式）

目标：让客户愿意先试，降低决策门槛
方式：
  1. 免费诊断（2小时，你来线上/线下）
  2. POC 合同：3个月，¥15,000-30,000
     → 帮配 2-3 个核心蜂群
     → 你们陪着跑 3 个月
     → POC 结束客户说"有用" → 转正式合同
  3. POC 费用可抵扣正式合同首年费用（给客户正向激励）

方案三：按 AI 调用量计费（未来）

适合：已有大量用户后的增长层
计费：按每月 AI 决策次数（Tokens × 蜂群数量）
底层：LiteLLM 已有用量追踪能力
当前：暂不开放，保持简单定价

3.3 价格心理学技巧

1. 年付优惠 ≥ 2个月免费（¥8k/月 → ¥80k/年 = 86折）
2. 旗舰版价格不要列具体数字 → 写"联系销售" → 定制报价权
3. 推荐方案标 ⭐ "最受欢迎"（引导中间价位）
4. 实施费单独列，不要打包进订阅费（让客户感知价值）
5. 报价时先给高位（旗舰版），让客户往下选（锚定效应）

6. 流量获取策略

核心原则：10-20 用户阶段，0 付费广告。先靠人，再靠内容，最后靠投放。

6.1 阶段一（0-3个月）：创始人直销

目标：签下前 3 个付费客户

行动 1：铭硕案例包制作（最高优先级）

产出物：
  A. 1页纸 PDF：案例摘要（可微信转发）
     → 铭硕是什么公司（1行）
     → 他们遇到了什么决策问题（3个痛点）
     → 朝堂 OS 做了什么（蜂群结构）
     → 结果是什么（必须有数字）

  B. 视频：铭硕老板 2 分钟口述（手机拍即可）
     → "之前我们决策是这样的..."
     → "用了朝堂 OS 之后..."
     → 不需要剪辑，真实感更重要

  C. 幻灯片：10页演示 PPT
     → 痛点 → 方案 → 案例 → 功能 → 定价 → Q&A
     → 用于 30 分钟演示用

行动 2：创始人朋友圈内容（每周 2-3 条）

内容策略（不要推销产品，讲故事和观点）：

类型 A - 案例故事：
  "最近帮一家做锂电池的老板，用 AI 蜂群 3 天解决了
   困扰他半年的供应商选择问题，具体是这样的..."

类型 B - 观点输出：
  "为什么中小制造业老板用不好 AI？
   不是技术问题，是没有给 AI 注入业务上下文..."

类型 C - 过程展示：
  "今天给客户配蜂群第 3 天，上书房已经能处理
   40% 的日常决策询问，截图如下..."

禁忌：不要发"我们是全球最好的AI平台"类广告文案

行动 3：精准陌拜 10-20 家目标企业

来源渠道（优先级排序）：
  1. 铭硕的上下游客户（最高转化率，有背书）
  2. 老板/团队的前同事/校友
  3. 行业展会参展商名录（制造业展会）
  4. 企业信息查询平台（天眼查/企查查搜同行）

接触方式：
  → 加微信：发"我是给铭硕配 AI 系统的，方便聊 10 分钟吗"
  → 不发产品介绍，发铭硕 1 页案例 PDF
  → 约 20 分钟微信视频通话（不是上门拜访）
  → 通话内容：70% 听对方说痛点，30% 讲案例

行动 4：飞书/企业微信 ISV 生态

飞书开放平台、企业微信应用市场可以做上架
好处：
  → 客户在用飞书/企业微信，直接在里面找到你
  → 平台帮做基础推广
  → 可以接飞书多维表格（数据源）

行动：注册飞书 ISV 账号，把朝堂 OS 做成飞书应用
（前端工作量：飞书 SSO 接入 + 基础权限改造，约 1 周）

6.2 阶段二（3-12个月）：内容驱动

目标：建立搜索可被发现的内容资产

内容矩阵规划

渠道 频率 内容类型 目的
微信公众号 1篇/周 深度案例 + 观点 沉淀 + 搜索
知乎 2-3篇/月 问题解答（行业痛点） 长尾SEO
视频号/抖音 1条/周 老板问题+AI现场演示 信任感建立

小红书 3-4条/周 AI工具使用技巧 触达年轻企业主

内容策略核心：「问题 → 方法 → 工具」路径

错误内容：
  "朝堂 OS 发布 v2.0，新增 10 大功能" （没人关心你的产品）

  "供应商频繁交期延误，AI 帮我 3 天建了个预警系统"

7. 销售流程与成单路径

7.1 标准销售漏斗

阶段 1：发现（Discovery）
  触发：朋友圈/案例/转介绍
  行动：加微信，发 1 页案例 PDF
  目标：约到视频通话

阶段 2：诊断（Diagnosis）
  触发：同意聊 20 分钟
  行动：电话/视频通话，了解 3 个核心痛点
  工具：诊断问题清单（见下方）
  目标：确认是否适合，约演示

阶段 3：演示（Demo）
  触发：确认有痛点，愿意看演示
  行动：30-45 分钟在线演示（用真实场景）
  工具：定制化演示脚本（针对他们的痛点）
  目标：确认价值，触发采购流程

阶段 4：提案（Proposal）
  触发：演示后有兴趣
  行动：发定制报价单（含实施方案）
  注意：报价在演示后 24 小时内发
  目标：签 POC 合同或直接年费合同

阶段 5：成交（Close）
  触发：客户回复有意向
  行动：处理疑虑，调整条款，签合同
  目标：收取首款，启动实施

7.2 诊断通话问题清单（20分钟框架）

开场（2分钟）：
  "我先简单介绍我们是做什么的，然后想多了解你们，
   这样我才能判断朝堂 OS 是否适合你们。"

了解业务（10分钟）：
  1. 你们公司主要做什么？现在多少人？
  2. 你每天在经营上花最多时间的决策是哪几类？
  3. 你现在这些决策是怎么做的？主要靠谁/靠什么工具？
  4. 哪个决策如果能更快、更准，对你来说价值最大？
  5. 你们对 AI 工具的接受度怎样？有用过什么吗？

了解痛点（5分钟）：
  6. 现在最大的经营挑战是什么？
  7. 如果这个问题解决了，你的生意会有什么改变？
  8. 你理想的解决方案是什么样的？

判断和介绍（3分钟）：
  "基于你说的情况，我觉得朝堂 OS 可以帮你的是..."
  如果不适合：直接说，不浪费双方时间
  如果适合：约演示

9. 风险与反制预案

9.1 主要风险清单

风险 概率 影响 应对
AI 大厂出同类产品 高 高 深入垂直行业，大厂打不过你对某行业的深度
客户决策周期太长 中 高 推 POC 降低决策门槛，先小钱试
无法证明 ROI 中 高 一开始就帮客户建立量化基准（Before/After 数字）
实施周期超预期 中 中 标准化实施流程，控制在 3 周内
LLM API 成本上涨 低 中 多 Provider 路由（DeepSeek/Claude/本地模型）
客户流失（不续费） 中 高 90天内让客户看到一个明显成果，黏性最高

9.2 护城河建设（长期）

1. 业务上下文积累：
   客户用越久，蜂群越了解他们的行业和业务，迁移成本越高

2. 行业数据：
   不同行业的决策模式、常见问题、有效方案形成行业知识库

3. 客户网络效应：
   同行业客户互相推荐（"我们电池行业都在用"）

4. 合规和安全积累：
   私有化部署资质、行业合规认证（ISO、数据安全等级保护）
