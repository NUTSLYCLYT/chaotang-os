## 1. 改造① · effectiveExecMode（自主执行总闸）
- **入口**：`import { effectiveExecMode } from '@/features/donggong/lib/autonomy-gate'`
- **接线点**：未来"决定某动作 propose 还是 execute"的派单处（动作分发 / dispatch）。
  - ⚠️ **不要直接调契约 `execModeFor()`**——它只是总闸开启后的纯判定。一律走 `effectiveExecMode(grant, risk)`。
  - 当前 `execModeFor` 零调用点，所以接线 = 新增派单逻辑时直接用 `effectiveExecMode`。
- **开关**：后端按类目实测达标后，设 env `DONGGONG_AUTONOMY_ENABLED=true` 才放开（否则永远 propose）。
- **AC**：
  - [ ] flag 关（默认）时，任何 grant/risk → `effectiveExecMode` 返回 `propose`。
  - [ ] flag 开时，高危/未毕业仍 `propose`，已毕业可逆类目才 `execute`。
  - [ ] 全仓 grep 无"直接调 `execModeFor(`"的运行期调用点（只允许 autonomy-gate 内部调）。

## 2. 改造② · resolveTimeoutVerdict（堵 defaultOnTimeout 后门）
- **入口**：`import { resolveTimeoutVerdict } from '@/features/donggong/lib/escalation-gate'`
- **接线点**：升级 SLA 超时的解析处（轮询/cron/查询时判定到期裁决）。
  - ⚠️ **不要直接采信 `esc.defaultOnTimeout`**。一律：
    `const v = resolveTimeoutVerdict(esc, risk, nowEpoch, createdEpoch, { verifiedReadOnlyInfo })`
  - `verifiedReadOnlyInfo` 必须来自**独立分类器**（≠ 请求方自报），否则不传（默认 false → escalate）。
- **AC**：
  - [ ] 高危/critical 动作超时 → 返回 `escalate`，**绝不 `approve`**（即便 esc.defaultOnTimeout='approve'）。
  - [ ] 非 verifiedReadOnlyInfo 的动作超时 → `escalate`。
  - [ ] 未到期 → `null`（不动作）。
  - [ ] E2E：高危 escalation 超时后状态仍 pending/escalated，绝不 approved。

## 3. 改造③ · memorialTrustBanner（反事实奏折 source 红线）
- **入口**：`import { memorialTrustBanner, normalizeMemorialSource } from '@/features/donggong/lib/memorial-trust'`
- **接线点**：奏折/反事实奏折的**渲染处**（如 `src/app/(dashboard)/donggong/page.tsx` 或 memorial detail 组件）。
  - 来源取自上游 `decree/draft` 响应的 `data.source`（实测 rule 期 = `'rule'`）：
    `const src = normalizeMemorialSource(resp?.data?.source); const banner = memorialTrustBanner(src);`
  - `banner` 非 null 时，在奏折顶部显著渲染该水印（rule/unknown → "规则生成·非智能判断·请人工复核"）。
- **用户侧（张小龙）**：收宫廷隐喻，给一盏灯——**绿灯=已替你办了，红灯=等你拍板**。
- **AC**：
  - [ ] `data.source==='rule'` 的奏折渲染出"非智能判断"水印。
  - [ ] `source==='llm'` 时不渲染水印。
  - [ ] E2E：mock decree/draft 返回 `source:'rule'` → 页面出现水印文案。

## 4. 改造③ · 闭环（后端，规格）
- 每个 `execute` 级动作留**影子记录**："若当时升级给人会怎样"。
- 人类选定路径后**回灌实际损益**，给反事实奏折打分（防"不可证伪的恐吓机器"）。
- 落点：`scribe`(史官)审计流 → 训练数据导出（RLVR 飞轮）。属后端审计副产物，前端只读展示分数。
