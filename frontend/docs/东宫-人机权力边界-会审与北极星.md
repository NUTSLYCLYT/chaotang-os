# 东宫（太子自主运营模式）· 人机权力边界 —— 大神会审 + 产品北极星

> 两轮大神会审（共 8 位，跨 AI/产品/finance 三镜片）+ 落地改造。
> 议题：「东宫(自动执行) vs 皇帝(人工治理) 两个体系」是否成立。
> 现实前提：实测底层 LLM「大脑」当前 rule/骨架兜底（`decree/draft` 返回 `source=rule`），智能体真实推理能力**尚未接通**（见 `tests/swarm-eval/FINDINGS.md`）。

## 一、裁决（跨两轮、8 位大神，零分歧）

| 轮次 | 阵容 | 结果 |
|---|---|---|
| 1（finance/risk） | Bezos · 塔勒布 · 芒格 · 达利欧 · 马斯克 | 3 反对 + 2 有条件赞成 |
| 2（AI/产品） | Sam Altman · 张一鸣 · 张小龙 · Jobs（Karpathy 掉线） | **4/4 反对** |

**共识（仅 Bezos 重复）**：
1. **不是"两个独立体系"**，而是 **"一个系统 + 一个可连续回收的授权刻度(autonomy 0→1) + 默认向上 escalate"**。
2. 边界由 **可逆/不可逆** 划定，不由 **成功次数** 划定。
3. **能力=0 时谈自动执行是架构与能力的致命错配**（Jobs：「架构 100 分能力 0 分，0 乘任何东西都是 0」；Altman：「conviction=0 给了最大 position size」）。
4. **反事实奏折** 是全场唯一被一致点名的真正好设计，但在 rule 期是"瞎子写的体检报告"，需加 `source` 红线。
5. 元风险：**完整的架构会自欺**——让团队误以为系统已强，从而拖延"接通并验证大脑"这件唯一要紧的事。

## 二、太子的存在意义（重定义，回答"这样会不会废了太子"）

**不会。大神把太子从"危险的自动开关"升级成"会随信任增长的代理曲线"。** 太子的意义有三层，无一依赖"今天就自动执行"：

1. **监国学徒，非第二皇帝**：太子=还没继位、靠表现赚信任的人。Day 1 全自动权的太子叫篡位。"默认 propose、逐类毕业"是最忠于"太子"二字的设计。
2. **"可增长授权"的唯一容器**：皇帝权威固定（终审），太子权威是唯一会长大的那个。太子 = 自主权刻度盘 + 爬刻度盘的实体。刻度盘本身就是产品。
3. **参谋长/秘书层（今天就值钱）**：替你起草/调研/分诊/产出反事实奏折，90% 的活它干、你 3 秒拍板。

**KPI**：今天=采纳率（草案不改直接批占比）+ 决策提速；大脑接通后增加=毕业类目数（只涨不跌的增长曲线）。

## 三、落地改造（把大神的话变成代码红线 · 带验收标准）

> ⚠️ 这些改动落在 `src/lib/contracts/authorization.ts` 与 `features/governance` —— **正被「东宫/donggong」窗口活跃开发**。建议与该窗口协调后再 apply，避免冲突。本节是规格，非擅自改。

### 改造 1 · 全局默认 propose + 毕业前置 gate（建议一）
- **现状病灶**：`ExecMode` 可达 `execute`，"毕业"判据是"rule 兜了 N 次没出事"。
- **改**：在大脑接通前，`execModeFor()` 对**所有类目硬返回 `propose`**（feature flag `DONGGONG_AUTONOMY_ENABLED=false` 默认关）。渐进授权状态机**冻结保留、不启用**（别删骨架、别开）。
- **毕业前置硬条件**（AC）：某类目要升 `execute`，必须同时满足 ① 大脑接通（`brain-check` 🟢）② 该类目实测 conviction≥8（人评/对账）③ 有可量化目标函数 + 快反馈 ④ **该动作可逆**（错了能撤、不涉及不可逆的钱/合同/人事/对外承诺）。任一不满足 → 永久 `propose`。
- **验收**：E2E——flag 关时任意动作请求 execute → 强制降级 propose；不可逆类目即便 flag 开也 propose。

### 改造 2 · 堵死 `defaultOnTimeout` 后门（芒格点名）
- **现状病灶**：皇帝不回、信息类 SLA 到 → 默批。= 把"不作为"变成"批准"，且可被"伪装成信息类"绕过。
- **改**（AC）：超时**永不默批**高危/不可逆；默批只允许**真·只读信息类**且需**独立分类校验**（分类来源 ≠ 请求方自报）。高危超时 → 升级提醒 + 保持 pending，绝不放行。
- **验收**：E2E——高危动作 + 超时 → 状态仍 pending/escalated，绝不 approved。

### 改造 3 · 反事实奏折加 `source` 红线 + 闭环（Jobs 力捧 + 张一鸣/Altman 红线）
- **改**（AC）：奏折每条结论标 `source: 'rule' | 'llm'`；**rule 期必须明示"此为规则生成、非智能判断"**（UI 显著提示）。
- **闭环**：每个 execute 级动作留"若当时升级给人会怎样"的**影子记录**；人类选定路径后**回灌实际结果**给奏折打分（防"不可证伪的恐吓机器"）。
- **用户侧**（张小龙）：收起宫廷隐喻，给一盏灯——**绿灯=已替你办了，红灯=等你拍板**。
- **验收**：奏折渲染含 source 标识；rule 期带"非智能判断"水印；execute 动作产生影子记录。

### 改造 0（最高优先级，非代码）· 把资源压到"接通大脑、验证单一部门"
- 「先让一个部门真的会说一句人话，比设计十一个部门的官制重要一百倍」（张小龙）。
- 用 `tests/swarm-eval/brain-check.mjs` 作 gate：🟢 之前，上面 1/2/3 都只是"冻结骨架"，不启用。

## 四、一句话北极星
**东宫 = 一个系统里"会随信任增长的代理曲线"，不是与皇帝并立的第二体系。自动权是一个类目一个类目实测赚来的，不是架构图上设计出来的（Altman）。现在唯一该做的，是接通大脑、验证一个部门会不会"说一句人话"（张小龙），其余宫殿暂缓。**
