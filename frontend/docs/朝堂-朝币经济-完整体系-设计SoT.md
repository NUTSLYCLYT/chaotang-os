# 朝堂 OS · 朝币经济 · 完整体系 · 设计 SoT

> 立于 2026-07-01。朝币 = 平台内**效用积分（utility credit）**，非货币、**不可提现**（避免证券化/虚拟货币监管）。
> 覆盖：早期营销裂变、买技能/人物/皮肤/token、用户挣币、A2A 交易手续费。
> **最高铁律**：营销币绝不能换真算力（否则"注册farm→免费token"印钞漏洞）。挣真资源的币只挂真兑现，不挂动作。
> 大神镜片：芒格(激励错位最贵/复杂即脆弱)·Schneier(反女巫/审计账本)·张小龙(游戏化是配角)·德明(数据互证)。

---

## 0. 定位（先划红线，免得做成 P2P 币）

- **不可提现**：朝币只在平台内花，换不成现金 → 是"点卡/积分"，不是货币，绕开虚拟货币/支付牌照监管。
- **配角**：朝币/皮肤/称号永远是配角，主舞台是真决策与真奏折（一旦比奏折更抢眼就该砍）。

---

## 1. 三种朝币分账（防印钞的命门 · 绝不混）

| 币种 | 怎么来 | **能买什么** | 关键约束 |
|---|---|---|---|
| **营销朝币** | 注册送1万 / 转发裂变 / 活动 | **只买外观**：皮肤·人物·装饰·称号框 | ❌不可换token/算力 · 有上限 · 会过期 · 防女巫 |
| **兑现朝币** | 真兑现（老板采纳·史馆回填真结果） | 真资源：**token/算力·技能·召 agent** | 挂真结果不挂动作（堵刷量套利） |
| **充值朝币** | 用户真付钱买 | 真资源 + 外观 | 走真支付·有购买条款·不可提现 |

> **核心**：营销币和真资源之间**有一堵墙**。farm 小号只拿到"换皮肤的券"，永远换不到真算力 → 套利归零。
> 这一堵墙，是整个经济不被薅垮的唯一锁。

---

## 2. 早期营销裂变（你要的拉新）

- **注册送 1 万营销朝币**（只能买外观，先让新用户"有得花、想留下"）。
- **转发裂变**：老用户转发 → 新用户注册 → **双向发营销朝币**（拉新奖 + 被拉奖）。
- **⚠️ 反女巫（Schneier·必做，否则裂变=被刷垮）**：
  - 注册领 1 万需过门槛：手机/实名/设备指纹去重 + 行为门槛（完成一次真操作才解锁大额）。
  - 推荐奖**阶梯 + 上限**：被拉新用户"真活跃"才结算拉新奖（防拉僵尸号）。
  - 同设备/同IP/同实名多号 → 只算一份。
  - 营销币**不可换真资源** → 就算刷穿也只是刷了一堆换不了钱的皮肤券，**薅羊毛无利可图**（这是最强防线）。

---

## 3. 挣朝币（四条口）

1. **真兑现**（→兑现朝币·可买真资源）：老板采纳 / 史馆回填真结果。**挂真结果，不挂"产出一个奏折/跑一次查询"**（堵套利）。
2. **营销**（→营销朝币·只买外观）：注册/转发/活动。
3. **充值**（→充值朝币）：真付钱。
4. **A2A 被服务**（→兑现朝币）：你的 agent/技能被别人调用 → 你挣。有用的富、没人用的饿 → 市场自动筛。

---

## 4. 花朝币（买什么）

| 买 | 用哪种币 | 说明 |
|---|---|---|
| **token/算力** | 兑现/充值（禁营销币） | 接 `consumeLlmBudget`·每岗保底额度+增配 |
| **技能** | 兑现/充值 | 翰林院能力市场·贵技能贵·被买次数=真需求信号 |
| **召 agent** | 兑现/充值 | A2A：召别司 agent，币归被召方 |
| **人物/皮肤/装饰** | **营销/充值均可** | 纯外观·不影响能力·营销币主战场 |
| **A2A 手续费** | 均可 | 见 §5 |

---

## 5. A2A 交易 + 朝币手续费（你要的）

用户间交易（转让技能/人物/成果/召用服务）→ **用朝币付手续费**（平台抽成）。
- 手续费**营销/兑现/充值币均可付**（手续费不是"换真资源"，是消耗，安全）。
- 交易本体若涉及真资源转移，走兑现/充值币。
- **御史审每一笔**：异常交易（同人对倒刷手续费返利 / 洗币）→ 锦衣卫内查采证 → 御史拦。
- **不可提现** → A2A 只是平台内流转，不构成资金盘。

---

## 6. 星星 / 品级 / 称号（声誉层 · 与朝币彻底分开）

- **星星**：只在"史馆真兑现 + 御史核过"时铸，**买不到、A2A 转不了**（声誉不可交易，否则烂）。5星升一品。
- **品级**：解锁自主+更大预算+会签加权；**权责对等**（一品犯错追责更重）。
- **称号**：一次标志性战功授（铁算盘/直臣/司天）·稀有·永久加成。
- **可升能降**：翻车/被劾扣星降品夺号；**护诚实失败**（诚实赌输扣少·渎职扣巨量+夺号）。

---

## 7. 反 farming / 反欺诈 铁律（整套经济不烂的地基）

1. **营销↔真资源隔离墙**（最重要）：营销币永不换 token/算力 → 印钞漏洞归零。
2. **真资源币只挂真兑现**：挂结果不挂动作 → token 套利无利可图。
3. **反女巫**：多号去重（设备/实名/IP）+ 行为门槛 + 拉新按"被拉者真活跃"结算。
4. **上限 + 过期**：营销币有获取上限、有效期，防囤积套利。
5. **御史审账**：朝币/星星账本可复现、被抽查；对倒/洗币/刷返利 → 锦衣卫采证→御史拦。
6. **不可提现**：全程平台内效用积分，不出金 → 不构成资金盘/证券。

---

## 8. 御史审账（接监察制衡体系）

账本也是数据也会被刷 → 御史抽查每司 token-ROI + 朝币异动；星星只在兑现+御史核过时铸；账本可复现、可点回原凭。**审计审计者：御史报告自标成色。**

---

## 9. 落地顺序（先做能真见效、风险低的）

1. **早期营销币先上**（拉新裂变·只买外观·反女巫）—— 低风险、直接拉新，且**不碰真算力所以薅不垮**。
2. **兑现朝币等主闭环**：决策→兑现→朝币这一环真转起来（接 `consumeLlmBudget` + 史馆回填），才发能换真资源的币。
3. **真资源购买（token/技能/人物）** 等有真资源、真价值可交付时再开。
4. **A2A + 手续费** 最后（需前面全通 + 御史审账成熟）。
> 每步先答"第一条真实数据/真价值从哪来"（铁律5）。营销币是唯一能先上的，因为它不承诺真价值、只承诺外观。
