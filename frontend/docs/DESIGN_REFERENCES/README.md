# 朝堂设计参考库 · DESIGN_REFERENCES

这里是**你的品味的高带宽入口**。给 AI 喂一百个形容词，不如喂一张你觉得"高级"的截图。
每次做 UI / 调视觉前，让 agent **先看这里再动手**——参考是方向盘，冻结的帝金 token 是刹车。

## 礼部必读

- `COURTOS_VISUAL_BIBLE.md`：朝堂视觉圣经，定义审美目标、工具、案例借鉴、禁忌和验收方式。
- `05-our-best-shots/`：朝堂自己的满意截图；一旦有通过人工审美的版本，优先沉淀到这里。

每次涉及上书房、大殿、礼部、卷轴、人物、动效、移动端美工，先按视觉圣经走，再动代码。

## 怎么用（三步）

1. **存图**：把你真心觉得高级的截图丢进对应子目录，文件名写清"你喜欢它哪一点"。
   - 例：`01-dark-luxury/linear-巨数字+单金强调.png`、`03-motion-detail/边框流光-慢速-状态指示.mp4`
2. **开工时点名**：跟 agent 说"先看 `docs/DESIGN_REFERENCES/` 再给方向"，或直接点某张图"照这张的层级感来"。
3. **沉淀**：方向定下来后，把最终满意的朝堂截图存进 `05-our-best-shots/`，它会变成下次的内部参照（自己的样板比外站更准）。

## 子目录约定

| 目录 | 放什么 | 看它学什么 |
|---|---|---|
| `01-dark-luxury/` | 暗色奢侈站截图（Godly/Awwwards 同类） | 近黑底 + 单一暖金强调的比例感 |
| `02-bento-dashboard/` | bento / 驾驶舱布局 | 空间权重=信息优先级，一屏 1 个 hero |
| `03-motion-detail/` | 动效片段（gif/mp4） | 哪些动效在"解释流程"而非炫技 |
| `04-typography/` | 排版样本 | 衬线×无衬线配对、巨数字层级、宽字距 label |
| `05-our-best-shots/` | **朝堂自己的**满意截图 | 内部一致性基准，优先级最高 |

## 红线（存图也要守）

- 参考只学**手法与构图**，**禁逐像素照搬**别人的完整品牌设计（版权）。
- 任何方向最终都要落回本仓**冻结的帝金 token + 已有 utility class**，不重造 `globals.css`。
- 截图里好看的"发光/流光/脉冲"，先去查本仓 `.animate-*` 是否已有同款（多半有），优先复用。
