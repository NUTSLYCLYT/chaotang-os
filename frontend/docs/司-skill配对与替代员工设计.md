# 司 × Skill 配对 + "真能替代员工"设计基线（2026-06-28）

> 北极星：**用户真的可以用 · 真能替代员工 · 真能执行具体任务**。不是顾问答话，是交付真活。

## 一、关键质变：顾问(分奏) → 执行者(交活)

当前户部 `askHubu` 是**顾问**：拉真数据→研判→给一段带把握度的分奏。这有价值，但**替代不了员工**——员工是"把事做完交活"，不是"给建议"。

**替代员工 = 司能产出一份用户本来要花钱请人做的真交付物（report/文章/分析/帖子），人确认后即"事毕"。**

| 层级 | 司做什么 | 替代谁 | 户部现状 |
|---|---|---|---|
| L1 顾问 | 拉真数据→给分奏判断 | （只是参谋） | ✅ askHubu 已有 |
| **L2 执行者** | **接任务→产真交付物→人确认→交活** | **真替代初级员工** | ⬜ 缺这一臂 |

这一臂就是我早先标的"产线右臂/executor 缺口"。**替代员工的价值全在 L2。**

## 二、司 × Skill 配对（按"能产真交付物"配）

大神方法：① 按真职业配不按官名 ② 优先自带真数据源的 skill ③ 一司一 skill 配最高杠杆 ④ 配不上就老实留空。

| 司 · 职业 | 最合适 skill | 产出的真交付物(替谁的活) | 真源? | 强度 |
|---|---|---|---|---|
| **户部** 金融分析师 | `financial-statements`/`stock-analysis` | 真估值报告(替初级分析师) | ✅ | 🟢强 |
| **工部** 产品技术官 | `pm-prd`/`feature-dev` | 真 PRD/技术方案(替初级PM/研发) | ✅ | 🟢强 |
| **刑部** 风控合规官 | `security-scan`/`security-and-hardening` | 真合规/风险报告(替风控专员) | ✅ | 🟢强 |
| **锦衣卫** 情报官 | `锦衣卫`+`deep-research` | 真竞品/舆情简报(替研究助理) | ✅ | 🟢强 |
| **兵部** 竞争战略官 | `pm-competitor` | 真竞品分析(替战略分析师) | ✅ | 🟢强 |
| **礼部** 品牌营销官 | `xiaohongshu-write`/`wechat-write`+`post-to-*` | 真写+发的种草文(替内容运营) | ✅ | 🟢强(可发=真执行) |

→ 7 强配 + 2 半配 + 2 冻结。**配不满才诚实。**

## 三、可复用脚手架：execute<司>（不止 ask）

从户部抽出，所有司照填。**比 ask 多了"产交付物 + 确认门 + 交活"：**
```
execute<司>(task):
  ① 拉<司>真数据源        (铁律5·没真源不准跑)
  ② 鉴权门               (不可匿名烧)
  ③ 跑匹配 skill 产真交付物 (report/文章/分析 = 真artifact)
  ④ 接地/质门校验         (数字接地·缺证标灰·禁假冒LIVE)
  ⑤ 高风险→人工确认门     (发布/付款/对外→L0-L4 gate)
  ⑥ 交活 + 写台账         (可下载/可发布的真交付物 + outcome底座)
```
切分判据(铁律13.9)：碰真实产线资产(发布/付款/交易)→必过确认门，重资产转后端 jiqun。

## 四、价值落点（用户为什么付费）
- 上传财报 → 户部出真估值报告（省一个分析师）
- 说"做篇小红书种草" → 礼部写好+(确认后)真发布（省一个内容运营）
- 说"查竞品X" → 锦衣卫出真情报简报（省一个研究助理）
- 说"这个需求做个PRD" → 工部出真PRD（省一个初级PM）

**每一个都是"说一句话→拿到一份真交付物→省一个人"。这就是真能替代员工。**

## 五、落地顺序（先窄后宽，先证一个）
1. **把户部从 L1 顾问升到 L2 执行者**——产一份真"估值报告"交付物(可下载)，跑通 execute 脚手架。
2. 抽脚手架 → 7 个强配司各填一个 skill。
3. 2 半配司：接数据源后激活。2 冻结司：明着标灰。
4. **每个司上线前一问**：用户说一句，它交的活，真能替代谁？答不出=没做到替代。
