# 朝堂 OS · 钦天监 · 先知蜂群 · 预测系统 · 设计 SoT

> 立于 2026-07-01。钦天监升级为**校准型先知蜂群**：大事/重要决策/关键时刻触发，
> 预判国际·产业·金融**大趋势**（方向型），自我进化，是朝堂的差异化。
> 大神镜片：塔勒布(尾部/反脆弱·标不确定)·泰特洛克(超预测·方向+校准+记分)·索罗斯(反身性)·芒格(反过来想)。
> **核心铁律**：一个自信却在编的"先知"比没有更毒。差异化 = 方向+置信+可证伪+自记分+不准降权，不是"敢预测"。

---

## 0. 定位

钦天监 = **校准型先知蜂群**，不是算命。它不赌精确数字（假精确=幻觉），它给**方向 + 置信 + 触发条件**，并**记自己的分**。

---

## 1. 每条预测必带三件套（反幻觉锁 · 缺一即非法预测）

| 件 | 内容 | 为什么 |
|---|---|---|
| **方向** | ↑ 涨 / ↓ 跌 / → 横 / ⚡ 转折 | 方向型可判、可证伪；精确数字是假自信（塔勒布） |
| **置信** | 低 / 中 / 高（**校准过，不许总是高**） | 没标不确定的预测=过度自信=最毒 |
| **触发/时限** | 什么会证实/证伪它、在何时前 | **让预测可证伪** —— 不可证伪的预测就是穿龙袍的幻觉 |

> 例：`锂/电芯料价 ↑ · 置信中 · 触发:碳酸锂现货连续 2 周破 X 或供应收紧 · 窗口 Q3`。
> **禁**：`锂价将到 8.2 万/吨`（假精确 + 无置信 + 无触发 = 非法预测，御史拦）。

---

## 2. 先知蜂群 = 多镜片并行 + 校准聚合（差异化核心）

不是一个 AI 猜，是一组**不同角度的镜片**并行推演、再聚合（超预测式面板）：

| 镜片 | 看什么 | 真数据源 |
|---|---|---|
| **料价/供应链**（bottom-up） | 关键料价方向（电芯/锂…） | 🟢 **H盘同料跨日期价=真时序**（今天就有） |
| **宏观/金融**（top-down） | 利率/汇率/大宗/资本流向 | 🟡 待接真源（web/feed，无免费可信源则诚实标待接） |
| **产业/竞品** | 行业供需/政策/技术拐点 | 🟡 锦衣卫情报喂（对内已建） |
| **反身性**（索罗斯） | 市场预期如何反过来改变基本面 | 结合上三镜 |
| **尾部/黑天鹅**（塔勒布） | 什么会让上面全部预测崩 | 永远问"哪里可能错" |

**聚合 = 校准，不是投票**：镜片分歧→标"分歧大·置信低"；一致→"置信高"。**差异化：不是单点预测，是带尾部对冲的校准面板。**

---

## 3. 触发时机（事件驱动 · 省 token）

钦天监**不常驻烧 token**，在关键时刻才出：
- **重要决策前**：报价/立项/大额付款前 → 先给"相关料价/市场方向"预判。
- **大事发生**：料价突变/政策/竞品动作(锦衣卫异动雷达触发)。
- **关键时刻**：季度/年度节点。
> 平时静默，大事出列。这也接朝币经济（预测耗算力，从钦天监预算扣）。

---

## 4. 自我进化（这是"先知"能进化的唯一机制）

```
预测(方向+置信+触发) ──归档史馆──▶ 到触发窗口，史馆核：应验了吗？
   ▲                                          │
   │                              命中/落空 → 记 Brier/命中率(校准分)
   └─ 校准分回流：准的推理模式加权、翻的降权/标反例 ◀─┘
```
- **钦天监自己的可信度 = 它的历史命中率**（接激励:准→挣星、可信度加权;常翻→降权,预测被打折）。
- **越用越准**：不是模型变聪明，是**校准分让"信哪种预测"变准** + 反例进知识库(翰林编修炼)。

---

## 5. 御史审钦天监（互查 · 防先知自己幻觉）

御史抽查钦天监预测：①**过度自信**(标高置信却常翻)②**幻觉**(预测无真数据支撑)③**校准漂移**(说80%其实命中40%)。
反过来钦天监在御史制衡里**看宏观/大势**(判御史发现是孤例还是趋势)。**先知查项目、御史查先知、守卫兜底。**

---

## 6. 第一条真数据（铁律5 · 务实）

- **料价镜片 = 真·今天可做**：H盘同料(电芯)在 `210910/220225/230317…` 不同日期 BOM 里的价 = 一条真时间序列 → 真方向 + 真置信。
- **宏观/金融/国际镜片 = 诚实标"待接真源"**（无免费可信外部源前，不编大趋势）。**禁**：现在就让 LLM 硬编"国际形势"当预测——那是最大的先知幻觉。
- 落地顺序：先做料价镜片真链（预测呈奏·标置信·御史过度自信巡查），跑通后再逐个接宏观镜片真源。

---

## 6.5 推演透明层（2026-07-01 · 每条预测摊开它怎么想的）

预测不只给方向，展开成可查推演链（6 段 + 语气铁律）：
1. **判据链**：信号→推断→方向，每步挂真数据；无数据的一步标"推测·下调整条置信"。
2. **历史吻合**：类比**必引真历史数据点**（禁编"历史上类似"），**且必找反例**（只找支持=确认偏误·芒格）；吻合/反例比例定置信。
3. **内在逻辑**：讲因果机制 + 它有多紧，**永不称"必然"**；每条因果附"什么会打断它"（因果≠必然）。
4. **多米诺（跨部级联）**：顺真部门真决策走（电芯↑→户部成本↑→兵部不涨价破红线/涨价丢单）；每级连到"该做什么"。
5. **蝴蝶/尾部（塔勒布）**：专问"什么小事会让主线全崩"，标低概率·高冲击，给对冲。
6. **反向证伪**：明写"什么成立会推翻自己"。

**语气铁律**：全程概率+条件语言（倾向/约中/若X则Y/存在反向可能），**禁肯定词**（必将/一定/肯定/毫无疑问）。
御史抽查：钦天监预测出现肯定词 = 过度自信 → 拦。

## 7. 差异化一句话

**朝堂先知蜂群 vs 普通 AI 预测**：普通 AI 给一个自信的答案、从不复盘；朝堂给**方向+置信+触发的可证伪预测，归档、到期核验、按命中率给自己记分、不准就降权、还被御史抽查**。
**别人是算命先生，朝堂是会被追责、会自我校准的先知台。** 这才是差异化，也是唯一不烂成幻觉放大器的做法。
