## 1. 史馆 = 自我进化引擎（三件事 · 一条闭环）

```
①归档(史官)        决策 + 证据 + 成色 入史
②兑现回填(史官)    这单赚了/亏了 · 回填 outcome
③翰林编修司 ◀────  吸收翰林：从①②提炼教训 → 炼成可复用资产(guard / skill / 模板 / 反例)
        │
   ┌────┴──── 自我进化飞轮 ────────────────────────┐
决策 → 御史/锦衣卫巡查发现病 → 史馆归档 → 翰林编修提炼 → 炼成守卫/skill → 入库
   ▲                                                              │
   └──────────────── 下次自动更好 / 自动拦，零人工零token ◀───────┘
```

## 2. 编制（铁律6：部=领域，司=角色）

- **史馆 = 领域**（scribe·归档+学习）。
- **翰林编修司 = 史馆下一个司**（不再是独立"院"）。主管=总编修；编修=各域 agent（把户/兵/刑…的反复发现炼成各域守卫/skill）。
- 翰林编修 = 史馆学习流水线的**出口端**——和史馆一条线，**禁两套并行学习**（铁律3）。
