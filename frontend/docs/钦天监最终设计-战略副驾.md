# 钦天监最终设计 · 战略副驾（2026-06-28）

> 定位升级:钦天监 ≠ 预测器,是**战略副驾**——唯一读得到全系统积累、做时间维+全局维综合的司。
> 一句话:**先甩你自己历史的冷统计,再说这次哪里不一样。**

---

## 〇、核心定位
钦天监是**横向综合司**(区别于户部这种"读一个域"的纵向司):
```
史馆全部决策+兑现   ┐
各部门全部证据       ├─(本租户·信任加权)→ 钦天监综合 → 战略副驾输出
锦衣卫已核情报       ┘
```
真数据源 = 系统自己积累的真数据。越用越准 = 自学习飞轮。
代价:它是**复利司,最后成熟**——冷启动时数据薄、最弱却最像全知,必须配最保守的置信度。

---

## 一、1 引擎 × 3 问法（同一引擎,三种问法)

| 模式 | 问什么 | 核心方法 | 独有输出 |
|---|---|---|---|
| **趋势预测** | 往哪走?(无决策) | 史馆时序+情报外推 | 情景树+概率+时间分层 |
| **决策结果预测** | 我这么做会怎样? | **史馆同类旧案 base rate(杀手锏)** | 结果分布+可逆性+死法 |
| **战略分析** | 全局态势,该怎么打? | 跨司综合 | 主要矛盾+不对称打法 |

三种问法共用 `dept-agent` 引擎 + 同一份综合上下文,只换 role prompt 与综合侧重。

## 二、天才设计(逐条,都进施工)

### ① 史馆当沙盘 · 参照类预测(Kahneman 外部视角 · 杀手锏)
决策结果预测**不让 LLM 拍脑袋**:从史馆捞 K 个最相似旧案 + 它们**真实兑现的结果**,按 相似度×新近×已兑现 加权 → 给"你自己历史上这么干的真实结局分布"。
> 真分析师靠 base rate,钦天监系统化地从你的历史算。只有它读得到全史馆,所以只有它能做。

### ② 先外后内(Kahneman · 顺序不能反)
**先报外部视角**(你历史上这类决策的冷 base rate)→ **再报内部视角**(但这次这几点不同)。
顺序锁死:人天生高估"这次不一样",先甩 base rate 压住过度乐观。**这是帮老板做对不可逆决策的核心机制。**

### ③ 可逆性标签(Bezos 单向门/双向门)
每个决策先判可逆性:
- 双向门 → "直接试,错了能回头,预测准不准没那么要紧"
- 单向门 → **拉高证据门槛 + 必跑死法地图 + 标人工确认**
同一预测,对不同决策类型给不同行动建议。

### ④ 主要矛盾定位(战略方法 · 集中优势)
战略分析不堆建议,找出**那一个主要矛盾**(解了它全盘松动)→ 集中兵力指向它。不对称:对手软肋 × 你的强项的交点。**价值在指出"就打这一个点"。**

### ⑤ 死法地图进每个预测(Taleb · 生存优先)
复用已有 `ruin-map`/`tail-audit`,三种问法**强制带"这条路怎么死"**。先问会不会死,再问能不能赢。

### ⑥ 自校准置信度(钦天监已有 /calibration)
报的置信度用**自己历史校准记录自动打折**(过去过度自信→这次调低)。对自己诚实的预测司,准十倍。

### ⑦ 决策沙盘(决策副驾,不只预测)
老板可并排比较多选项:每个 → 结果分布+可逆性+死法 → 一张决策对照表。

### ⑧ 数据厚度仪表(防假精确 · 最关键 UI)
每条预测显式标"综合了 N 条史馆案 + M 条情报,数据厚度:薄/中/厚"。N/M 小显黄、大才显绿。**把"算命"和"基于证据的推断"视觉上彻底分开。**

### ⑨ 时间分层(诚实不确定性)
趋势分近期/中期/远期,置信度随时间显式衰减,不给远期假精确。

## 三、四个护栏（不能省)
1. **租户隔离(Schneier 死线)**:综合只限本租户。跨租户读 = 数据泄露。**这正是"脊柱无租户字段"地基 blocker——钦天监踩在它上面,补它前租户字段必须先有。**
2. **信任加权**:已兑现旧案 > 待验;已核情报 > 脏情报(安全门已挡);近 > 远。
3. **样本厚度硬门**:史馆同类案 < 5 条,只给"参考类比"**不给概率分布**(防 3 样本的假统计)。
4. **防回音室**:外部证据(上传/情报)权重 > 内部回音;仅内部数据的预测要标明。

## 五、施工时序(诚实)
钦天监是**复利司,排最后**——要等户/刑/工跑出真数据、史馆有真案、租户字段落地,它才有东西综合。
- **前置(硬依赖)**:① 租户字段(地基 blocker)② 史馆有真兑现案(主闭环先转起来)。
- **可先做且无依赖的**:`buildSynthesisContext` 骨架 + `qintian-agent` 人设 + `reference-class` 算法(可用现有 mock 案先测算法,真案到位即生效)。
- **判据**:钦天监上线前一问——"它这条预测综合了几条**真**案?" 答 0 = 别上,标 DEMO。

## 六、一句话
**钦天监 = 战略副驾:读全系统真积累,3 种问法(趋势/决策/战略),先甩你自己历史的冷 base rate 再说这次哪里不同,每条预测带死法、可逆性、数据厚度、自校准。它替代的不是预测员,是战略分析师——而且越用越准。**
