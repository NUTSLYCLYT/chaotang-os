# 礼部目标令：大殿世界级视觉战役

## 目标

把 `/dadian` 从“可用的朝堂仪表盘”升级为“老板一眼相信 AI 内阁正在运转的沉浸式世界窗口”。

## 第一套指定方案：帝国天幕 / 活体朝堂

- 视觉母题：暗金宫殿、低光空气、天幕光束、御座圣旨、群臣出列。
- 交互母题：老板一键下旨，群臣轮流奏报，风险朱砂线触发，史馆归档，最终进入御座裁决。
- 技术约束：不引入重 3D 包，不依赖大视频，不牺牲加载速度；优先 CSS transform / opacity / filter / existing React state。
- 评审标准：第一眼不是 SaaS，不是古风皮肤，而是一个有秩序、有状态、有权力感的 AI 指挥系统。

## 礼部自迭代流程

1. 自搜创意：每轮参考 Awwwards / FWA / Webby / Apple Design Awards 的沉浸式、功能性动效、空间 UI。
2. 自拟方案：每次只选一个艺术方向，不同时混搭多套风格。
3. 自审风险：性能、可访问、信息遮挡、是否像游戏而失去软件可信度。
4. 自改实装：只改可复用组件和大殿首屏，不污染全局 token。
5. 自验收：`pnpm exec tsc --noEmit`、`pnpm build`、桌面/移动 Playwright 截图、资源加载检查。

## 下一轮必须突破

- 把 `source DEMO` 改成真实 traceId：由 `/api/court/orchestrate` 或后端 jiqun 事件流驱动群臣发言。
- 给每个部门增加“发言质量评分”：废话少、风险准、下一步明确。
- 给裁决按钮增加真实副作用边界：准奏、补证、复核、驳回都要落史馆。
