# 先知和导师 · 铭硕样板运行档案

> 日期：2026-06-06  
> 运行目标：用现有铭硕数据跑第一条“先知和导师”客户样板链路  
> 数据源：`/home/ubuntu/kb/docs` 本地知识库  
> 结论等级：内部会审稿，可用于下一步补证与客户样板设计；未经客户确认前不作为正式评估结论对外使用。

## 1. 用户真实问题

铭硕当前最适合先跑的问题不是“泛泛做一个 AI agent 系统”，而是：

```text
2026 年专利资产评估与增长预测能否站得住？
如果要提交评估机构，哪些证据已经足够，哪些必须补齐，下一步由哪些蜂群执行？
```

这是第一条样板链路，因为现有数据已经覆盖公司档案、审计财务、销售台账、专利收益预测、专利贡献率和待补事项。

## 2. 先知判断

### 2.1 当前最关键矛盾

铭硕有真实专利使用证据和明确增长叙事，但财务历史与 2026 预测之间存在强烈跳变，需要用合同、回款、交付、产能和口径一致性补强。

已知事实：

- 公司主营为锂电池、电芯、电池管理系统、电源研产销和技术服务，成立于 2018-01-29，审计意见为标准无保留。
- 2023-2025 年审计营业收入分别约为 310.63 万、142.42 万、152.83 万。
- 2025 年净利润约 -153.65 万，所有者权益约 -494.18 万，资产负债率约 173.3%。
- 专利相关产品 2026 年收入预测在不同材料中存在两个口径：约 2046.44 万与 3000 万。
- 已上传 2026 年合同/回款证据金额 1405.63 万，占 3000 万预测的 46.85%；2026 年 1-5 月财务报表营业收入 1427.12 万，占全年预测 47.57%。

### 2.2 先知结论

这不是“有没有专利价值”的问题，而是“增长预测证据链能不能闭合”的问题。

第一优先级不是再写漂亮报告，而是补齐三条证据链：

1. 历史销售台账与审计收入对账。
2. 2026 预测口径统一。
3. 2026 合同、回款、交付、产能、客户协议闭环。

## 3. 导师行动路径

### 3.1 一周内最小可交付

交付一份“专利评估证据包 v1”，而不是再做新页面。

证据包结构：

```text
A. 公司与审计底稿
B. 三年财务画像
C. 2023-2025 销售台账与审计收入对账表
D. 2026 合同/回款/发票/出库/交付清单
E. 2026 收入预测统一口径表
F. 专利-产品-客户-订单映射表
G. 专利技术贡献率 35% 说明
H. 待补事项清单与责任人
```

### 3.2 不可直接对外承诺

以下内容在补证前不能作为强承诺：

- “2026 年收入必达 3000 万。”
- “华为生态入口必然带来持续订单。”
- “全部历史销售均可完整印证专利使用。”
- “专利贡献率 35% 已被外部评估机构接受。”

可对外表达为：

```text
公司已有合同、回款、认证和 1-5 月收入支撑 2026 年增长预测的阶段性合理性；
但正式评估需补齐台账覆盖、收入口径和交付/产能证据。
```

## 4. 三省六部会审

### 户部

判断：财务数据真实度较高，但历史盈利能力弱。专利评估不能只讲技术先进，必须解释亏损与负净资产。

重点动作：

- 统一 2026 收入口径：2046.44 万与 3000 万必须拆清楚是“专利相关产品口径”还是“销售增长优化口径”。
- 补齐 2023-2025 台账到审计收入，当前台账覆盖率只有 2023 年 62.4%、2024 年 36.6%。
- 对 471.50 万其他应付款做债主明细和关联方属性判断。

### 工部

判断：技术与产品映射可做成样板资产。

重点动作：

- 建“专利-产品-应用场景-客户订单”结构表。
- 把华为光储一体、低温电池、电芯、启动电源作为四条产品证据线。
- 每条产品线补测试报告、工艺流程、交付记录、售后记录。

### 锦衣卫

判断：最需要查证外部可信材料。

重点动作：

- 核验华为认证级解决方案开发伙伴证书。
- 收集华为入口截图、后台询盘、客户沟通记录。
- 核验 2026 合同与银行回单的一致性。

### 刑部

判断：对外材料要避免夸大预测和误导性陈述。

重点动作：

- 所有预测标注“基于合同/回款/认证/交付导入，不构成业绩承诺”。
- 专利贡献率 35% 定义为评估建议口径，而不是确定事实。
- 对缺口事项列明补证责任和截止日期。

### 礼部

判断：客户样板叙事应从“铭硕定制报告”抽象为“AI agent 帮企业补齐评估证据链”。

重点动作：

- 对外案例标题：AI agent 帮新能源企业完成专利评估证据链会审。
- 不先卖系统，先展示问题识别、证据补强、责任分派和归档闭环。

### 史馆

判断：本次运行应归档为第一条 reference implementation。

重点动作：

- 归档本次问题、证据、会审结论、待补事项、责任蜂群。
- 下一次建议优先引用“台账覆盖率缺口”和“2026 口径冲突”。

## 6. 第一轮结论

铭硕样板成立，但第一条样板不应讲“AI agent 已经全自动解决经营问题”。

更准确的样板是：

```text
先知和导师用 AI agent 在半天内识别出专利评估材料的关键矛盾，
把分散的公司、财务、销售、专利、预测资料组织成会审结论，
并把下一步补证任务分派给客户蜂群。
```

这已经能证明产品方向：用户不是要一个聊天机器人，而是要一个能看懂真实材料、指出缺口、组织执行、沉淀复盘的 AI agent 操作系统。
