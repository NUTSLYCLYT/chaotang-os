# 任务：军机处页面

## Status

Draft

## Product Definition

- 用户确认：用户于 2026-07-17 通过“自动交付”提出新增军机处页面，随后确认该页面只查看过去已经完成的会审数据且历史需要跨重启永久保留；在任何页面、存储、API 或数据库实现开始前，用户明确要求“停止新增军机处页面”。任务保持 `Draft` 并终止交付。
- 问题：现有 `/study` 已能下旨并在 multi 路径展示当次军机处会审结论，但整个系统不持久化会审记录，响应结束后没有可查询的历史数据源，因而无法直接实现真实历史页。
- 目标用户：需要回看重大事项会审依据与结论、但不在该页面执行操作的经营决策者。
- 目标：提供只读军机处历史页，展示过去完成的 multi 会审记录及每条记录的会审原因、相关部门意见、冲突、证据充分性、风险可接受性和最终需要老板关注的关键裁决点；页面本身没有写操作。
- 非目标：不在军机处页面下旨、重新会审、编辑、删除、审批或裁决，不展示 single 记录，不伪造历史数据，不在页面加载时调用真实模型。
- 已有改动依赖：保留当前已验收但未提交的 39 司、分层回奏、军机处会审与丞相三项建议实现；本任务不得覆盖这些用户已有改动。

## Acceptance Criteria

- [ ] 军机处页面是纯只读历史页，没有下旨、重新会审、编辑、删除、审批或老板裁决控件，也不会因打开、刷新、筛选或查看详情而调用真实模型。
- [ ] 历史列表只包含已经完成的 multi 会审记录；每条记录可只读查看原旨意、会审原因、相关部门及其司级/部级意见、军机处结论、冲突、证据充分性、风险可接受性和需要老板关注的关键裁决点。
- [ ] 历史数据来自真实已完成的下旨流程，不使用前端硬编码、示例数据或跨测试残留；记录保存期限与服务重启后的行为按用户确认的数据保留规则实现。
- [ ] 新页面拥有稳定本地路由和从现有页面可发现的导航入口，且不破坏 `/`、`/study` 与现有 BFF/API。
- [ ] 页面不得在用户未主动操作时调用真实模型，也不得展示伪造或跨会话残留的会审数据。
- [ ] frontend lint/typecheck/test/build、相关烟雾检查、harness 与 `git diff --check` 全部通过。
