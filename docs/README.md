# 朝堂 OS 项目文档

本目录是项目级文档唯一入口，承载整体产品、跨前后端架构、发布方案、商业化、历史总账和跨线交接资料。

## 目录约定

| 路径 | 内容 |
| --- | --- |
| `PROJECT_PRODUCT.md` | 当前项目产品定位、客户、商业化、GTM、路线和产品红线。 |
| `2026-launch-development-roadmap.md` | 2026 高质量上线的跨线开发顺序、质量门禁、付费内测与变更协议。 |
| `README.md` | 当前项目级文档入口和归属规则。 |

## 归属规则

- 描述朝堂 OS 整体产品、整体路线、商业化、跨线架构、跨线交接、launch、GTM、历史吸收、项目总账的文档，放在这里。
- 只描述前端实现、页面体验、视觉系统、浏览器验证、前端部署的文档，放在 `frontend/docs/`。
- 只描述后端运行服务、flow、agent、provider、API、数据源、后端 harness、后端评测的文档，放在 `backend/docs/`。
- 新增文档时先判断它是项目级、前端级还是后端级；不要把整体项目叙述写进前端或后端局部 docs。

## 当前迁移

2026-07-09 已将前后端 docs 中明显属于整体项目、跨线交接、产品总账或历史总体设计的文档迁移到本目录。

2026-07-09 已将历史归档中仍然有价值的产品描述整合进 `PROJECT_PRODUCT.md`。旧归档中的技术实现、部署、接口、代码路径、运行命令和历史排障内容不再保留为项目级文档。当前事实以根级 manifest、`AGENTS.md`、前后端 active harness、doctor 输出和本目录当前文档为准。
