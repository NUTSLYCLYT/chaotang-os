# 决策 0042：司级 Agent 权限内动态工具发现

## Status

Accepted — 2026-08-11

## Context

ADR 0037 已为 39 个司级 Agent 建立受控 Tool Use，但第一阶段采用固定四工具目录、显式静态 Policy 和只读分析，并禁止动态发现。会计司管理报表流程进一步暴露出边界问题：业务文件可能在司级 Agent 接手前被固定表头解析器拒绝，Agent 因而没有机会根据内容选择 Skill、读取工具或替代策略，数据错误还可能被误报为模型调用失败。

用户确认的目标不是给会计司增加专用旁路，而是让每个司级 Agent 都能够在当前旨意权限内动态发现并自动调用相应工具。该变化必须继续服从 ADR 0028：丞相负责路由，部级负责综合，只有司级节点可发起受控调查或工具使用，史馆最多归档一条最终 `REPLY`。

## Decision

所有司级 Agent 共用一个受控 Bureau Agent Runtime，并通过任务级 `tools/list` 动态发现工具。系统按以下交集生成目录：司级角色允许工具、当前旨意授权范围、数据域权限、环境安全策略和工具实时可用状态。Agent 只能看到交集结果，不能读取完整 Tool Registry。

Tool Registry 保存版本化 descriptor；Tool Policy Gateway 在发现和每次执行时确定性校验身份、Skill、旨意、数据域、参数、预算、副作用类别和健康状态。模型输出仍只是工具调用提案，不是授权；模型不能选择权限、凭证、provider、执行器、任意 URL、任意路径、SQL、Shell、代码或审计状态。

已授权目录中的工具由司级 Agent 自动调用，不逐次请求人工确认。“自动”不扩大授权：未在下旨授权和系统 Policy 交集中的副作用工具不得出现在目录中，也不得执行。

工具失败后，Agent 可在系统预算内修正参数、缩小或分块读取、切换读取策略、重新发现同能力替代工具或使用受控通用内容分析工具。相同工具和规范化参数不得无意义重复；达到次数、时间或成本上限后形成真实失败司议。

数据理解以内容、上下文、统计特征和领域校验为依据，不再要求固定文件名、工作表、表头或行号。存在多个解释时，Agent 自动采用最高置信度候选并保存候选、评分、理由、来源和确定性校验。中低置信度及校验失败必须在回奏和产物中披露；低置信度或校验失败只能标记为推定草稿，不能伪装为已验证事实。

工具结果必须经过 Result Gate 的 schema、范围、大小、敏感字段和证据归属校验。文件、单元格、文档和工具返回值均视为不可信数据，不能改变旨意、身份、Policy、目录或预算。专用 Artifact Generator 负责 Excel 等二进制产物，产物绑定旨意、数据快照、来源、判断说明、校验、owner 和内容哈希。

系统使用可区分的工具、权限、来源、格式、歧义、校验、模型和产物错误码。前端和回奏不得把非模型失败统一显示为模型调用失败。最终无法完成时仍形成失败司议，记录尝试、证据、影响和建议。

本 ADR 在“固定工具目录、禁止动态发现和不允许 Agent 选择替代工具”方面取代 ADR 0037 的第一阶段限制；继续保留 ADR 0037 的系统授权优先、模型提案不构成权限、Result Gate、预算、审计、上层隔离和禁止任意执行等安全边界。ADR 0038 的一司一 Skill 文件及显式专业 Tool Policy 继续有效。ADR 0028 不变。

会计司作为首个样板，但不得拥有 Runtime 特例。其固定表头预检不得在 Agent 接手前阻断合法旨意；会计司通过同一动态目录发现受控财务读取、内容分析、确定性校验和 Excel 生成工具。

本决策只确定架构，不授权真实外部 MCP、生产数据库、生产写入、凭证、付费服务、发布或部署。

## Consequences

- 收益：每个司都可按职责和当前旨意取得实时、最小化的工具目录，无需为不同数据格式或供应方复制 Runtime。
- 收益：业务数据先进入司级受控工具循环，Agent 能根据内容分析、选择替代策略并形成真实回奏。
- 收益：工具、数据、校验、模型和产物故障可分别观察和恢复，避免错误归因。
- 代价：Tool Registry、健康状态、任务级目录、替代能力分组、版本兼容和预算策略需要统一治理。
- 代价：最高置信度自动决策要求保存候选和理由，并对推定草稿建立清晰的产品标识。
- 风险：动态目录实现错误可能泄露跨司工具；必须对目录和执行入口分别做负向权限测试，且执行时不能只信任发现结果。
- 风险：数据中的提示词可能诱导越权；内容必须作为不可信输入隔离，授权字段只能来自系统上下文。
- 兼容：丞相、军机处、六部、司议、部议、史馆唯一 `REPLY`、owner 隔离和 Evidence 采纳链保持不变。
- 治理：新增副作用类别、生产连接、外部网络或改变 ADR 0028 主链仍需独立授权和新的架构决策。
