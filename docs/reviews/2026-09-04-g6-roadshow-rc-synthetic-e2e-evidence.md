## Safe roadshow claims

The following claims are currently supportable:

- The ext-dev mainline has a coherent local RC surface for demonstration.
- V2 frontend, backend decision flow, Scene Pack V1, Junjichu handoff, Honglusi
  gate UI, and `/study` synthetic execution are connected.
- Product-authority, Harness, backend, frontend, browser smoke, and synthetic
  E2E evidence exist for the current convergence direction.
- The system can show one user-visible story:
  input → decision → evidence labels → next actions → case/task persistence →
  controlled execution → downloadable artifact → archive.

## Unsafe roadshow claims

The following claims remain unsafe:

- production deployment is complete;
- real customer data has been processed by the RC;
- Honglusi has production third-party capability ingestion;
- external publication channels are enabled;
- business success has been measured with real traffic;
- every historical branch or dirty donor has been fully integrated;
- legacy entrypoints can be retired today;
- synthetic acceptance is equivalent to real provider/customer acceptance.

## Remaining RC blockers

The project is roadshow-usable but not fully released. Remaining blockers:

1. production credential and deployment boundary is still intentionally closed;
2. dirty donor worktrees and old branches still need selective triage;
3. legacy direct/swarm/flywheel/knowledge entrances need observation-backed
   convergence;
4. Mingshuo requires a fact-pack successor before real vertical execution;
5. at least 30 golden tasks and business result receipts are still needed before
   a stronger release claim;
6. independent security and architecture review must be re-run on any runtime
   successor that changes routing, credentials, evidence, or external effects.
