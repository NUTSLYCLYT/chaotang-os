# WebP Asset Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Do not dispatch subagents for this plan.

**Goal:** Convert the 27 PNG files under `frontend/public` and `docs/product/assets` to WebP without breaking runtime or documentation references.

**Architecture:** A focused Node.js module owns the fixed migration manifest, metadata-preserving conversion, and post-conversion audit. A native `node:test` file drives the converter through temporary fixtures first, then becomes the repository guard for the real asset set; application code only changes public asset extensions.

**Tech Stack:** Node.js >=22, native `node:test`, existing `sharp` 0.34.5 from the frontend dependency tree, Next.js frontend, PowerShell verification commands.

## Global Constraints

- Only process `frontend/public/**/*.png` and `docs/product/assets/**/*.png`; exclude `.superpowers` screenshots and all other formats.
- Preserve every image's directory, basename, width, and height; only change `.png` to `.webp`.
- Encode images with an alpha channel as lossless WebP; encode opaque images as lossy WebP with `quality: 82`.
- Delete a source PNG only after its WebP decodes, has matching dimensions, and preserves alpha when required.
- Update only references that resolve to the 27 migrated files; do not rewrite absent historical screenshots, deleted assets, temporary names, or examples.
- Preserve all unrelated user changes in the dirty worktree.
- Do not access the network, change ADR 0028, commit, stage, push, deploy, or create external resources.
- Use Codex only; do not call Claude CLI, Claude runner, or `gstack-claude`.
- The unchanged final version must pass the full acceptance sequence 10 consecutive times; any failure or material code, configuration, or acceptance change resets the count to 1.

```js
  const directory = await mkdtemp(path.join(tmpdir(), "webp-assets-"));
  t.after(() => rm(directory, { recursive: true, force: true }));
  const opaquePng = path.join(directory, "opaque.png");
  const alphaPng = path.join(directory, "alpha.png");
  const opaqueWebp = path.join(directory, "opaque.webp");

  assert.equal(alpha.lossless, true);

  assert.deepEqual([alpha.width, alpha.height], [2, 2]);
  assert.equal((await sharp(await readFile(opaqueWebp)).metadata()).format, "webp");
  assert.equal((await sharp(await readFile(alphaWebp)).metadata()).hasAlpha, true);
});
```

- [ ] **Step 3: Implement the minimal safe converter**

Create `scripts/webp-assets.mjs`. Resolve `sharp` from `frontend/package.json`; read source metadata; write to a sibling temporary WebP; decode and compare format, dimensions, and alpha; rename the validated temporary file to the requested destination; return the conversion metadata. Use `webp({ lossless: true })` for alpha and `webp({ quality: 82 })` otherwise. On failure, remove only the explicitly created temporary file and leave the PNG untouched.

```js
export async function convertPngToWebp(sourcePath, destinationPath) {
  const source = await sharp(sourcePath).metadata();
  const lossless = source.hasAlpha === true;
  const temporaryPath = `${destinationPath}.tmp`;
  try {
    const pipeline = sharp(sourcePath).rotate();
    await (lossless ? pipeline.webp({ lossless: true }) : pipeline.webp({ quality: 82 })).toFile(temporaryPath);
    const output = await sharp(temporaryPath).metadata();
    if (output.format !== "webp" || output.width !== source.width || output.height !== source.height) {
      throw new Error(`Invalid WebP output for ${sourcePath}`);
    }
    if (lossless && !output.hasAlpha) throw new Error(`Alpha channel lost for ${sourcePath}`);
    await rename(temporaryPath, destinationPath);
    return { width: source.width, height: source.height, hasAlpha: source.hasAlpha === true, lossless };
  } catch (error) {
    await rm(temporaryPath, { force: true });
    throw error;
  }
}
```
