# 删除上书房本地兜底警告文案

## 目标

从上书房界面删除“真实任务库暂不可读 · 当前为本地兜底骨架，请勿当作最终裁决依据”整条状态提示，不保留空容器或占位。

## 范围

- 删除 `DevStudyWorkspace` 中承载该提示的状态节点。
- 删除仅供该节点使用的 `.warning` 样式及窄屏覆盖。
- 将现有源码契约测试从“文案必须存在”改为“文案不得出现”。
- 不改变上书房的数据来源、兜底数据、下旨交互或不可变业务流基线。

## 验收

- 组件源码不再包含目标文案或对应状态节点。
- 样式表不再包含无引用的 `.warning` 规则。
- 针对性测试、前端 lint、类型检查与完整前端测试通过。
