# V5 写实宫廷策略游戏 UI 设计

## 目标

在不改变 V5 信息架构、角色权限与页面数量的前提下，将欢迎页、上书房和六部司级页重构为接近既有 `junjichu.webp`、`shiguan.webp` 的写实宫廷策略游戏界面。

## 视觉原则

- 风格比例为 70% 写实策略游戏、30% 清晰政务系统。
- 全屏空间背景使用真实场景图片，不以渐变或手绘纹样替代。
- 导航和外壳采用黑檀木、青铜、暗金；正文阅读面采用暖米色奏章纸。
- 朱红只用于确认圣旨、御批和关键异常；暖金用于身份、选中态和空间照明。
- 允许木纹边框、铜制包角、印玺按钮、奏折卡片与轻微光晕，但不得覆盖正文或降低对比度。
- 不添加龙纹堆叠、宝箱式卡片、战斗数值、角色养成等与业务无关的游戏元素。

## 页面设计

### 欢迎页

- 军机处场景图全屏铺底，叠加从左至右的深色可读遮罩。
- 左侧为产品名称、核心价值和“开启朝堂”朱红印玺按钮。
- 右侧以小型奏章浮层呈现一条真实案卷动态，避免传统企业官网卡片阵列。

### 上书房

- 军机处场景作为御前空间背景，顶部使用深木导航。
- 中央主操作为实体奏章式“一句话下旨”面板。
- 左侧最近三案表现为奏折签，右侧或下方展示 Agent 理解、丞相分流和已发生轨迹。
- 保持一个主操作、三条最近案卷和单个选中案卷，不增加流程总览。

### 六部司级页

- 使用军机处场景的局部暗化版本作为政务工作台背景。
- 左侧案卷队列采用暗木卷宗架；右侧事实和证据使用米色卷宗正文。
- 锦衣卫补证采用暗红情报札记，不使用现代 SaaS 警告条。
- 处理按钮采用朱红印玺式，其他操作使用暗木或铜边次按钮。
