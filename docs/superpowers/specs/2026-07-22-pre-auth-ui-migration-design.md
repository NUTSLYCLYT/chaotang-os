# 登录前 UI 迁移设计

## 范围

将 `dev` 分支的登录前体验迁入当前分支：`/enter`、`/login`、`/register`、`/invite` 和邀请码落地页。迁移的是视觉、表单输入、前端格式校验和登录前页面之间的链接。

欢迎页修订后，根路径 `src/app/page.tsx` 承担登录前欢迎引导，健康检查展示迁至 `src/app/health/page.tsx`；既有 `/study`、`/shiguan`、BFF、`backendClient.ts` 和后端 API 不变。

## 完整欢迎页修订

根路径欢迎页以 `dev` 的公开欢迎页为视觉和内容基准，完整保留其信息架构与中文文案：四项页内导航、英雄区、问题标签、可交互的本地奏折预览、企业痛点、五殿解决方案闭环、适用场景、四张能力证明卡和预约体验转化区。

实现继续使用当前项目的 React、Next `Link`、CSS Module 与内联 SVG，不迁入 `dev` 所使用的 Tailwind、`lucide-react`、base-path、路由跳转动效、认证或后端依赖。奏折输入只更新内存中的静态预览；登录和注册按钮只进行普通页面导航。

## 架构与组件

新增一个专用的登录前视觉壳，承载暗色朝堂主题、标题、说明、表单区域和页面间链接。其样式使用专属类名前缀或 CSS Module，避免影响既有页面的全局样式。

各路由页面只使用 React/Next 内建能力：

- `/enter` 展示邀请令牌的视觉状态；不验证令牌，也不跳往受保护页面。
- `/login` 展示账号和密码输入，进行必填校验。
- `/register` 展示用户名、邮箱、密码和确认密码，进行本地格式与一致性校验；从查询参数显示邀请码。
- `/invite` 与 `/invite/[code]` 展示邀请码输入或落地信息，并将邀请码带至注册页。

图标与动效优先用 CSS 和内联图形实现，不迁入 `dev` 的依赖升级或认证相关组件。

## 数据流与行为

页面状态仅存在于组件内存中。查询参数只用于邀请码的展示与页面内跳转。表单成功通过本地校验后，显示“认证服务尚未接入”的非成功状态；不会调用 `fetch`、写入 localStorage/cookie，或创建任何会话。

这确保界面可演示，但不把纯 UI 误表述为真实身份认证。

## 错误处理与可访问性

表单字段保持标签、`required`、合适的 `autocomplete` 属性和可见的错误信息。提交期间不产生异步等待状态。页面需在窄屏可用，并尊重用户的减少动态效果偏好。

## 验证

为本地表单校验和邀请码链接参数增加针对性测试；运行前端 lint、typecheck、test、build，以及根 harness。构建后检查五个登录前 URL 的响应与关键文案，不触发表单提交和任何真实服务调用。

## 明确不做

不迁移 `dev` 的 `AuthGate`、`lib/auth/**`、`lib/backend-api.ts`、服务端路由、数据库、全局 WebSocket/Toast/Onboarding 设施，也不改变依赖清单或根布局。

## 视觉对齐修订（用户于 2026-07-22 确认）

第一阶段的 CSS 重建未包含 `dev` 登录前页面使用的背景资产，因此与 `dev` 的空间感和层次不同。本修订允许从 `dev` 迁入单个已跟踪的背景资源 `frontend/public/shangshufang/bg-shangshufang-scene.webp`，并仅修改 `features/pre-auth` 的 CSS Module 和共享视觉壳。

视觉壳将使用该资源作为满屏背景，并叠加与 `dev` 一致的深色双向渐变、低透明度金色网格、左右金色光带和底部渐隐层。登录、注册、邀请码、邀请码落地与入口页复用同一壳，保留各自的标题和本地交互。响应式布局在窄屏隐藏装饰线条、改为单列；所有装饰层均为 `aria-hidden`，并继续尊重减少动态效果偏好。

不迁移 `dev` 的 Tailwind、lucide、motion、图片路径辅助函数或任何认证依赖；不会改变表单和无后端副作用的行为。

## 欢迎页与根路径修订（用户于 2026-07-22 确认）

`dev` 的欢迎页位于根路径，并使用独立的 `courtos-vision-hero.png` 背景、金色网格、中心光轴、欢迎内容、局部演示面板和登录/注册入口。用户确认将它迁移到当前分支根路径 `/`，并将原有前端健康检查展示迁至 `/health`。

欢迎页以 `features/welcome` 下的独立组件和 CSS Module 实现，不迁入 Tailwind、lucide、路由动画或真实业务/认证调用。演示输入仅更新本地展示内容；登录和注册入口使用普通链接。需要从 `dev` 迁入唯一欢迎页静态资源 `frontend/public/assets/intro/courtos-vision-hero.png`。页面在窄屏保持可读、允许纵向滚动，并尊重减少动态效果偏好。
