# 军机处无案卷完整主舞台设计

## 已确认的体验

当当前用户没有经过军机处的案卷时，页面继续展示会审主舞台，而非以全页“暂无匹配案卷”卡片替代布局。

- 左栏：保留部门、状态、关键词筛选，以及“进行中 / 已归档 / 办理失败”三组空列表。
- 中央：保留舞台结构，显示“暂无会审案卷，等待下旨后进入会审”的空状态；不渲染案卷标题、处理路径、部议或会审结论。
- 右栏：保留固定六部目录，均以“未参与”展示。

## 状态边界

此体验只适用于读取成功且当前筛选结果为空。加载、读取失败继续使用已有加载/错误卡片；用户筛选后无匹配结果仍应显示筛选语义，不得将其伪装成系统从未有案卷。

页面不产生或补全任何业务数据：没有案卷时不展示模拟节点、进度、部门意见、回奏或史馆入口。

## 验证

离线场景测试应断言：空案卷数组仍输出三栏模块、三组空列表、等待下旨的中央文案与六部未参与目录；同时继续断言无写操作控件或伪造业务字段。运行军机处定向前端测试、lint、typecheck 和 build。
