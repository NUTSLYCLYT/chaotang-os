# 登录前输入框焦点边框设计

## 目标

登录、注册和邀请码页面的所有输入框获得焦点时，不再显示输入框外侧的焦点轮廓，仅通过输入框自身边框变为金棕色来表达焦点状态。

## 范围

- 覆盖共享 `.input` 样式及通过 `composes: input` 复用它的 `.codeInput`。
- 保留输入框默认的 1px 边框、尺寸、圆角、背景、文字和占位符样式。
- 不修改按钮、链接、导航或其他控件的焦点样式。
- 不修改 React 组件、表单行为、认证接口或 ADR 0028。

## 样式契约

`.input:focus-visible` 继续设置 `border-color: #c38b4b`，并改为 `outline: none`。删除现有 `outline-offset`，不增加 `box-shadow` 或伪元素焦点环。由于邀请码输入框组合共享的 `.input` 类，因此同样获得该焦点行为。

## 测试与验收

- 先增加 CSS 契约断言，要求焦点块保留金棕色边框、声明无轮廓，并且不存在 `outline-offset`。
- 运行测试确认旧样式因仍有 2px 外轮廓而失败，再做最小 CSS 修改并确认通过。
- 验证按钮的 `.button:focus-visible` 仍保留原有轮廓，避免扩大变更范围。
- 运行前端 lint、typecheck、完整测试、build、仓库 harness，并对同一最终版本连续执行 10 轮完整验收。

## 验收标准

- 登录、注册和邀请码输入框获得焦点时只改变自身边框颜色。
- 输入框焦点时不存在额外的 outline、outline offset 或新增阴影。
- 输入框失焦后恢复默认边框颜色。
- 按钮和其他控件焦点样式保持不变。
