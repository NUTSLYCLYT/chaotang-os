# 丞相微信式聊天框设计

## 目标

将上书房左侧抽屉中的“与丞相对话”改为微信式消息列表：丞相消息在左、陛下消息在右，双方均显示现有画像与独立气泡。输入区固定在聊天区域底部，消息区独立滚动。

## 已确认方案

- 采用 A“经典微信式”布局。
- 丞相使用 `/shangshufang/portrait-chancellor.webp`，陛下使用 `/shangshufang/portrait-wang.webp`。
- 头像为方形圆角，气泡最大宽度受限，左右消息有清晰方向。
- 等待状态作为丞相侧气泡展示；错误信息保留可访问的提示样式。
- 输入框缩小并固定在聊天区域底部，不随消息滚动。
- 气泡正文与输入框使用 12px 字号，人名使用 10px 字号。
- 左右抽屉只向 dock 区域重叠 1px，遮住 dock 顶部边框，不覆盖 dock 按钮或正文。
- 抽屉底部 padding 为 0；输入表单不再增加顶部 padding 或边框，输入区域严格保持 40px 高。
- 删除“仅提供咨询，不代表下旨……”整段说明。
- 不修改咨询请求、消息类型、DeepSeek 调用或业务治理基线。

## 验收

- 双方消息均有头像和气泡，方向符合微信习惯。
- 消息很多时只滚动消息区域，输入区仍在底部。
- 输入框高度小于原来的 68px。
- 对话正文与输入框字号为 12px，人名字号为 10px。
- 抽屉与 dock 只发生 1px 边框重叠。
- 页面源码中不再出现被要求删除的说明文案。
- 既有抽屉宽度、最近回奏和咨询提交行为不回归。
