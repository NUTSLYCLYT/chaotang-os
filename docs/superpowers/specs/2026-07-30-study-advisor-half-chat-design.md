# Study 辅政侧栏 1:1 对话区设计

## 目标

调整 `/study` 左右辅政侧栏，使人物头部以下的正文区与对话区各占一半，并缩小人物头像，
为丞相和钦天监对话提供稳定、充足的阅读空间。

## 已确认设计

- 左右侧栏继续共用 `AdvisorDrawerShell`，不得分别维护比例。
- 人物头部以下采用严格 `1:1` 分区：
  - 上半区显示回奏或钦天监工作区；
  - 下半区显示对话记录与输入框。
- 上半区和下半区均设置 `min-height: 0`；上半正文和下半消息分别在自身区域滚动。
- 输入框固定在下半区底部，不随消息滚动。
- 人物图片统一从当前约 `118×128px` 调整为 `90×96px`，并同步收紧头部上下留白；
  姓名、身份字号与图片渐隐效果保持不变。
- 完全移除钦天监“转为拟旨”按钮，不保留隐藏入口或占位空间。
- 钦天监聊天、正式推演、触发器复核及其他真实数据能力保持不变。
- 丞相回奏、聊天、错误与重试能力保持不变。

## 实现边界

- 共享比例和头像尺寸只在 `AdvisorDrawerShell` 中定义。
- 钦天监按钮移除只修改 `QintianPanel` 的呈现；不修改后端 API 或 execution authority。
- 不调整侧栏宽度、动态边界、开合动画、背景、输入框视觉或人物资源。

## 验收

自动化测试必须先失败再通过，并锁定：

1. shell body 与 footer 都使用相同 flex 比例；
2. 两区均有可计算高度并保持独立滚动；
3. 人物图片为 `90×96px`，头部留白已收紧；
4. Qintian 源码和可访问界面均不存在“转为拟旨”按钮；
5. 正式推演、触发器复核、聊天及丞相功能断言继续通过。

浏览器验收左右侧栏，确认 1:1 分区、头像尺寸、固定输入框和按钮移除均符合预期。
