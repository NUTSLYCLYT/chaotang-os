# 锦衣卫通用公共证据路由设计

## 已确认的产品决定

采用方案 C：使用统一缺数协议和按事实类别路由的可信公共数据源。锦衣卫只提供可溯源事实，原司级 Agent 独立形成办理意见。

## 目标与边界

系统处理行情、公司披露/监管、新闻、社会公开信息、百科与实体消歧等公共事实。来源可覆盖全球地域，但必须免费、合法且可公开访问；不使用付费订阅、付费 API 或私人凭据。它不接受任意 URL，不登录私有系统，不绕过付费墙或验证码，不执行任何外部业务动作，也不让锦衣卫替代司级 Agent 作出结论。

## 缺数判定

司级 Agent 在需要外部事实时，必须比较：用户提供材料、史馆召回证据与事实槽位的时效要求。若结论依赖的事实不存在、已经过期或不能被现有材料可靠覆盖，必须输出 `NEEDS_DATA`。

`NEEDS_DATA` 至少包括：问题、所需事实槽位、决策用途、最大可接受时效与已知证据 ID。司级不得用抽象建议掩盖这类缺口；若不依赖缺失事实，才可直接返回 `READY`。

## 调查流转

```text
司级 Agent → NEEDS_DATA → 锦衣卫事实路由 → 冻结证据包 → 原司级 Agent 恢复一次 → READY 或明确限制
```

现有安全边界继续有效：仅司级可请求；同一司级最多恢复一次；同一旨意继续受全局调查、抽取和总时限预算约束；丞相、部级、军机处只消费司级意见而不直接调查。

## 事实类型与证据层级

事实类型由代码拥有的注册表声明，并映射到批准来源：

1. 行情与市场数据：持牌、交易所或其他经批准的公开行情来源；每项需定义证券标识、市场、币种、报价时间与时效。
2. 公司披露与监管：交易所、监管机构及公司正式公告；优先原始公告。
3. 新闻与事件：来源登记的新闻发布者或公共通讯来源；保存发表时间与事件时间。对于满足质量和事实类型要求的候选材料，优先采用最新发布内容；新闻可作为事件线索和交叉确认，不能自行覆盖高风险核心事实。
4. 社会公开数据：政府、统计机构、公共事业机构或等价权威发布者。
5. 百科与实体消歧：Wikidata/Wikimedia 等；只用于背景、名称解析与实体对齐，不单独支持实时或高风险结论。

来源选择优先级为：官方、监管、交易所、原始公告，其次是经批准的专业公开源，最后才是新闻和百科补充。在同一质量层级且满足事实时效要求时，新闻或事件材料按最新发布时间优先。来源冲突或覆盖不足时，证据包必须保留为部分、阻断或不可用状态。

## 安全与可审计性

所有外部读取继续经过受限 HTTPS 客户端。来源注册表固定协议、域名、路径、允许参数、解析器、响应上限、重定向策略、时限、速率限制、质量上限与适用事实类型；模型和用户均不能注入 URL。

证据包记录来源、获取时间、发布日期/事实时间（可得时）、内容最小摘录或结构化字段、内容哈希、质量等级、时效判断和限制。回奏仅引用原司级显式采用的证据 ID；调查审计和未采用材料留在锦衣卫独立库。

## 故障行为

网络关闭、注册来源不可用、无匹配来源、解析失败、证据冲突、数据过期或调查预算耗尽时，锦衣卫返回可审计的限制。恢复后的司级仅能基于证据包形成保守意见，并必须说明无法确认的事实；不得编造或将推测伪装为事实。

## 待用户确认的产品决定

首批接入的具体数据提供者及其可再分发限制、稳定性和免费公开访问条件仍待技术审查。这些决定需要在任务从 Draft 转为 Ready 前明确。
