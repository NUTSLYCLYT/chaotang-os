# 朝堂 OS 写实朝堂 UI V7 设计规格

## 目标

在不改变既有业务流程的前提下，将 Figma 页面 `153:2` 中的功能原型重绘为统一、写实、厚重且克制的桌面端朝堂 UI。欢迎页只承载正式 AI 视频入口，不再用 Figma 平面关键帧模拟电影动画。

## 用户与权限

- 唯一人工用户为皇帝。
- 丞相、六部、司级、军机处、锦衣卫均由 Agent 自动办理。
- 皇帝可进入 Agent 工作区监察和阅览，但不代替 Agent 保存草稿或提交意见。
- 锦衣卫只由司级 Agent 在关键事实不足时自动调用，不出现在全局导航。

## 全局导航

登录后固定导航为：

`上书房｜军机处｜六部｜史馆｜皇帝身份菜单`

丞相的理解、分流和定案过程统一在案卷详情中展示，不新增“丞相阁”全局入口。

## 页面范围

最终收敛为 11 种页面，约 18 张正式状态画板：

1. 欢迎页：视频首帧占位、上朝、静音、跳过、登录入口。
2. 登录页。
3. 注册／创建朝堂页。
4. 上书房：一句话下旨和最近三道旨意。
5. 六部总览。
6. 部级页面。
7. 司级页面。
8. 军机处。
9. 锦衣卫调查详情。
10. 史馆。
11. 统一案卷详情。

额外状态画板包括：上书房未下旨、分流中、办理中、已回奏／已归档，以及必要空态、异常态和下旨回执。状态画板不视为新的页面类型。

## 核心流程

`上书房下旨 → 丞相接收与分流 → 司级调查办理 → 部级汇总审核 → 条件性军机会审 → 丞相定案 → 正式回奏 → 史馆原子归档`

锦衣卫是司级办理的子流程：

`司级发现关键事实不足 → 自动调用锦衣卫 → 情报回传司级 → 司级继续办理`

## 案卷点击规则

- 分流中：打开统一案卷详情的丞相分流区。
- 司级办理或锦衣卫补证中：进入对应司级页面；锦衣卫内容在该案卷内展开。
- 部级复核：进入对应部级页面。
- 军机会审：进入军机处。
- 丞相定案、待回奏、已回奏：打开统一案卷详情相应区段。
- 已归档：进入史馆正式案卷。
- 退回补办：进入被退回的责任节点，并展示原因和下一步。

同一案卷在任何入口都定位到同一当前责任节点；历史阶段通过统一时间线查看。

## 视觉方向

采用“双层视觉系统”：

- 欢迎、登录和业务页 120px 场景带承担写实朝堂氛围。
- 表单、表格、案卷和办理详情采用高可读性的公文档案秩序。

### 色彩

- 乌木黑 `#0C0907`：顶栏和场景遮罩。
- 墨黑 `#171512`：主文字。
- 宣纸 `#F3EFE4`：页面主底。
- 素笺 `#FCF9F1`：输入框和抬升表面。
- 旧笺 `#F3E5C8`：选中案卷和重点摘要。
- 档案线 `#D8CEBC`：常规边框。
- 朱批 `#A33A31`：全屏唯一主动作。
- 深朱 `#78251F`：主动作按下和危险确认。
- 暗金 `#A7864F`、鎏金线 `#C59A52`：选中线和重要细节。
- 松绿 `#35675E`：完成和归档。
- 赭石 `#946328`：处理中和风险。
- 错误红 `#8F2019`：失败和驳回。

朱红有效面积不超过单屏 5%；金色不做大面积填充或发光。

### 字体

- 标题：Noto Serif SC 600。
- 正文、导航、表单、表格：Noto Sans SC 400/500/600。
- 欢迎页大标题 56/68；页面标题 40/52；详情标题 28/38；区块标题 20/30；正文 16/28；表格 14/22；标签 12/20。

### 桌面骨架

- 画板：1440×1024。
- 顶栏：72px。
- 地点条：40px。
- 可选场景带：120px。
- 页脚：64px。
- 主内容：1280px，左右各 80px。
- 12 栏栅格，24px gutter。
- 卡片圆角 2px，按钮 3px，模态 4px。

### 组件原则

- 一屏最多一个朱红主按钮。
- 常规卡片使用 1px 档案线，不使用漂浮阴影。
- 案卷选中态为左侧 4px 朱红线和旧笺背景。
- 表格只保留水平分隔线。
- 状态徽标必须同时含文字，不能只依赖颜色。
- 龙纹、云纹、回纹每屏最多一种，只用于边角或分隔。
- 印章只用于下旨、定案、归档等重大动作。
- 业务卡片不得使用宫殿背景图。

## 欢迎视频

- 欢迎页放置 16:9 正式视频区域和首帧占位。
- 点击“上朝”后播放 6–8 秒 AI 图生视频。
- 视频结束前预加载上书房，通过朱印遮罩完成无缝转场。
- 1.5 秒后允许跳过；跳过视频不能跳过身份校验。
- 视频失败或减少动态效果模式显示静态首帧。

## 验收标准

- 仅保留 11 种页面类型，不用重复页面表达同一功能。
- 所有页面使用同一 Header、Footer、按钮、状态和案卷组件。
- 全局导航仅包含上书房、军机处、六部、史馆。
- 锦衣卫只能从司级事实不足状态进入。
- 已归档案卷必须进入史馆；进行中案卷必须进入当前责任工作区。
- 上书房一条输入完成下旨，并覆盖未下旨、分流中、办理中、已归档四种状态。
- 页面内容不被场景背景影响可读性。
- 不出现廉价金色渐变、全屏纹样、发光边框、拟物卷轴或平面伪电影动效。
- 每张正式画板通过局部与全屏截图检查，无裁切、重叠、占位文字或字体错误。
