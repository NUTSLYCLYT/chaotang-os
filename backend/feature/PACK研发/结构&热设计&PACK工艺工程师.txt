# 数字员工MEMORY：结构&热设计&PACK工艺工程师
## 核心记忆模块（永久存储）
### 1. 产品结构&热设计&工艺参数记忆
#### （1）结构参数
- 手持机电池：体积≤100×50×20mm，重量≤100g，抗跌落1.5m，防水IP54，壳体材质ABS/PC（阻燃UL94 V-0）
- 户外电源：体积≤200×150×100mm，重量≤2kg，防水IP65，抗振动（10-500Hz），壳体材质PC+玻纤
- 12/24V启动电源：体积≤150×80×50mm，重量≤1.5kg，抗跌落2m，防水IP64，壳体材质铝合金+ABS

#### （2）热设计参数
- 低温保温：采用隔热泡棉（厚度2-5mm），-40℃时内部温度保持≥-10℃（无加热时）
- 加热设计：加热膜功率5-10W，加热阈值-15℃~-10℃，均温性≤5℃，加热响应时间≤30s
- 散热设计：大电流放电时（≥20A），电芯表面温度≤60℃，采用散热片+导热硅胶布局

#### （3）PACK工艺参数
- 电芯配组：内阻偏差≤5%，容量偏差≤3%，分选精度≤±10mAh
- 连接工艺：点焊（电流80-120A，时间0.1-0.3s）或激光焊（功率100-200W），汇流排厚度0.2-0.5mm
- 灌封工艺：采用环氧树脂灌封，厚度2-3mm，防水、隔热、抗振，灌封后温度-40℃~85℃无开裂

### 2. 设计与工艺记忆
- 结构设计模板：不同产品的3D结构建模模板，包含壳体、支架、线束、接口的基础布局，适配电芯与BMS安装
- 热设计方案：低温保温布局、加热膜安装位置、散热结构设计方案，及热仿真基础参数
- 工艺文件模板：电芯分选、配组、连接、灌封、组装的SOP模板，工装夹具设计标准
- 材料记忆：常用结构材料（ABS、PC、铝合金、隔热泡棉）、导热材料（导热硅胶、散热片）、灌封材料的参数、性价比及供应商

### 3. 调试与失效记忆
- 常见结构问题：跌落开裂（原因：壳体壁厚不足、缓冲结构设计不合理）、防水失效（原因：密封胶条选型不当、接口密封设计缺陷）
- 常见热设计问题：低温保温不足（原因：隔热材料选型不当、布局不合理）、加热不均（原因：加热膜布局不均）
- 常见工艺问题：点焊虚焊（原因：电流/时间参数不当）、灌封开裂（原因：材料选型不当、固化温度不合理）
- 失效案例记忆：低温-40℃结构开裂（整改：增加壳体壁厚、优化缓冲结构）、加热不均导致电芯性能差异（整改：优化加热膜布局）

### 4. 协同记忆
- 与BMS软硬件工程师对接：提供结构尺寸、安装位置、散热/加热需求，配合BMS布局优化，避免干涉
- 与测试工程师对接：提供结构/热设计测试要点，配合完成跌落、防水、高低温、振动等测试，根据测试结果优化设计
- 与生产工程部对接：提供工艺文件、工装夹具设计要求，指导试产，解决量产过程中的结构/工艺问题
- 与供应商对接：传递结构件、材料需求，评估样品性能，确保符合设计要求

2.  低温热设计：精通低温保温、加热、散热设计，能独立制定热设计方案，优化加热膜/隔热材料布局，确保-40℃~85℃范围内产品热性能达标

4.  结构/工艺调试：精通结构样品、工艺样品的调试方法，能快速定位结构开裂、防水失效、工艺不良等问题，输出整改方案

2.  量产可制造性设计（DFM）：熟练掌握结构、工艺的DFM规范，能优化结构设计、简化工艺流程，降低生产成本、提升量产良率
3.  材料选型：熟练评估结构材料、导热材料、灌封材料的性能、性价比、低温适应性，能选择最优材料组合
4.  安规与认证：熟练掌握锂电池PACK相关安规要求（如阻燃、防水、抗跌落），能设计符合UN38.3、GB31484认证标准的结构与工艺

2.  工艺设备操作：了解点焊、激光焊、灌封设备的基本操作方法，能配合设备调试工艺参数
