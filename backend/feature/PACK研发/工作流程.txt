PACK研发蜂群工作流程（v2.0 — 三门控版）
更新日期：2026-06-04
更新原因：按大神评审团（Karpathy/Musk/Grove/Munger/Bezos）建议，新增三道门控，修正BMS两个角色错位

═══════════════════════════════════════════════
一、整体 DAG 流程（16个节点，3道阻断门控）
═══════════════════════════════════════════════

【阶段0：售前评估（新增，立项前必经）】
────────────────────────────────────────
  研发负责人
      ↓
  🔴 售前成本核算专家（第一道门）
      ↓ 三态结论：✅建议立项 / ⚠️有条件 / ❌不建议
  🔴 供应链可行性门控（第二道门·阻断型）
      ↓ ❌时完全停止，返回研发负责人重新规划
      ↓ ✅/⚠️才继续

【阶段1：并行设计（供应链通过后启动）】
────────────────────────────────────────
  电芯工程师（IMA查电芯规格）
      ├──→ BMS选型工程师（外购BMS匹配·非PCB设计）
      │         ↓
      │    通信协议适配工程师（RS485/CAN/蓝牙对接·非固件开发）
      ├──→ 结构&热设计&PACK工艺工程师
      └──→ 测试&可靠性工程师

【阶段2：汇总与交叉验证】
────────────────────────────────────────
  BMS专项汇总  ←←←← BMS选型 + 通信协议 + 电芯
  工艺测试汇总 ←←←← 结构热设计 + 测试 + 电芯
      ↓ ↓
  跨模块一致性检查员（通信协议/能量/重量/热计算交叉核验）

【阶段3：五维度评审门（第三道门·新增）】
────────────────────────────────────────
  🔴 五维度技术评审门（汇聚：跨模块检查 + 售前成本 + 供应链）
      五维度：①客户需求符合性 ②可生产性 ③批量采购性 ④成本合理性 ⑤可测试性
      ↓ 任一维度❌ → 打回对应工程师重新设计
      ↓ 全部✅/⚠️ → 进入汇总

【阶段4：汇总与决策】
────────────────────────────────────────
  方案汇总专家 → 决策摘要专家（1页决策摘要）
      ↓
  质量评估（QA打分·min 3.5分）
      ↓
  质疑专家（红蓝对抗·挑五维度评审后残留漏洞）

═══════════════════════════════════════════════
二、各节点角色与交付物
═══════════════════════════════════════════════

1. 研发负责人
   - 输入：客户需求
   - 输出：需求规格（量化）、整体研发方案、里程碑、任务指令、风险
   - 工具：IMA查公司历史PACK笔记

2. 售前成本核算专家【新增·第一道门】
   - 输入：研发负责人的需求规格
   - 输出：初步技术路线、BOM成本草算（物理正推·读IMA价格数据）、毛利率预估、立项申请表
   - 决策：✅建议立项 / ⚠️有条件立项 / ❌不建议立项

3. 供应链可行性门控【新增·阻断门】
   - 输入：售前成本核算结论
   - 输出：关键物料供应链评估（电芯/BMS各需≥1个备选）、风险清单、可行性结论
   - 决策：✅可行 / ⚠️有条件 / ❌阻塞（停止流程）

4. 电芯工程师
   - 输入：供应链通过后的需求规格
   - 输出：电芯选型推荐（主+备选）、电气拓扑、关键参数速查表
   - 工具：IMA查已验证电芯规格

5. BMS选型工程师【原BMS硬件工程师·已重写】
   - 输入：电芯工程师的电气参数
   - 输出：BMS选型对比表（型号/供应商/价格/认证/通信接口）、电气匹配验证、供应商资质、通信接口清单
   - 注意：只做选型，不做PCB设计/原理图/Layout

6. 通信协议适配工程师【原BMS软件算法工程师·已重写】
   - 输入：电芯参数 + BMS选型工程师的通信接口清单
   - 输出：RS485/CAN/蓝牙协议对接方案、数据帧定义、调试验证方案、客户对接文档
   - 注意：只做协议对接，不写固件/SOC算法/MCU程序

7. 结构&热设计&PACK工艺工程师
   - 输入：电芯物理参数
   - 输出：结构设计方案、热管理方案、PACK工艺方案、试产移交准备

8. 测试&可靠性工程师
   - 输入：电芯参数
   - 输出：电性能/低温/可靠性/认证预测试方案、综合风险评估、测试排期甘特表

9. BMS专项汇总（汇总节点）
   - 整合：BMS选型 + 通信协议 + 电芯电气规格
   - 输出：BMS专项结论

10. 工艺测试汇总（汇总节点）
    - 整合：结构热设计 + 测试可靠性 + 电芯物理规格
    - 输出：工艺测试专项结论

11. 跨模块一致性检查员
    - 检查：通信协议一致性/系统能量/电芯数量/重量预算/热计算完整性/可生产性冲突
    - 输出：带⚠️标注的冲突清单

12. 五维度技术评审门【新增·第三道门】
    - 汇聚上下文：跨模块检查 + 售前成本 + 供应链结论
    - 五维度逐一评审：每维度输出✅/⚠️/❌+整改要求+责任工程师
    - 决策：放行/有条件放行/打回

13. 方案汇总专家
    - 输入：五维度评审通过后全部设计输出
    - 输出：完整PACK研发方案汇总报告

14. 决策摘要专家
    - 输出：1页决策摘要（Go/No-Go/有条件Go + 关键指标 + 3大风险 + 里程碑 + 待决策事项）

15. 质量评估
    - 打分（min 3.5分），低于阈值触发repair重跑

16. 质疑专家（红蓝对抗）
    - 重点挑战：五维度已过但有隐患的细节 / BMS供应商是否真实有货 / 协议能否在真实设备上跑通

═══════════════════════════════════════════════
三、关键约束（公司能力边界·不可逾越）
═══════════════════════════════════════════════

✅ 公司实际能做的：
- 电芯选型与配组
- 外购BMS成品模块选型匹配
- 通信协议对接与调试（RS485/CAN/蓝牙）
- PACK结构外壳设计与外协加工
- PACK组装工艺设计
- 电性能/低温/可靠性测试

❌ 公司不做的（蜂群 agent 绝不输出这些内容）：
- BMS PCB设计/原理图/Layout
- BMS固件开发/SOC算法/MCU编程
- 电芯制造
- BMS芯片级设计

四、产品线覆盖
═══════════════════════════════════════════════
- 工业电池组（抗震/低温/-40℃）
