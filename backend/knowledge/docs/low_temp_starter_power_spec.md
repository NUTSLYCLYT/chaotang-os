## 产品定位

为车辆类发动机平台提供应急启动供电，用于原启动电瓶亏电、或环境温度过低导致原电池
无法放电的场景。核心卖点：能量密度大、放电倍率大、耐低温。

## 电气参数

| 项目 | 参数 |
|------|------|
| 电芯类型 | 聚合物锂离子电芯，7S3P组合 |
| 单体标称电压 | 3.7V DC |
| 电池组标称电压 | 25.9V DC |
| 电池组容量 | 36Ah |
| 电池组总能量 | 932.4Wh |
| 输出峰值电流 | >3000A |
| 持续供电时间 | 20A ≥ 1h |
| 启动次数 | ≥30 次 |
| 工作温度 | -40℃~55℃ |
| 储存温度 | -43℃~70℃，相对湿度25%~90% |
| 主机重量 | ≤20kg |

## 保护参数（技术保障特点）

| 故障类型 | 一级报警阈值 | 处理动作 |
|---------|------------|---------|
| 总压过高 | ≥29.96V | 断开电池主继电器 |
| 总压过低 | ≤17.5V | 断开电池主继电器 |
| 单体过高 | ≥4.25V | 断开电池主继电器 |
| 单体过低 | ≤2.5V | 断开电池主继电器 |
| 放电过流 | >3500A | 断开继电器（50ms） |
| 充电过流 | >80A | 断开继电器 |
| 温度过高 | ≥60℃ | 断开所有继电器 |
| 温度过低 | ≤-42℃ | 断开所有继电器 |
| 短路保护 | 3600A | 断开主继电器 |

## 维护要点

- 存储时应使电池处于约50%~60%充电状态，约30天补充电一次防止过放损坏。
- 首次使用前需完全充满；避免正负极短接或反接。
- 充电采用CPU+PWM控制的专用充电器，恒流50A充至29.4V后转恒压，充满自动停止。
