# 低温电池相关行业标准

## 国家标准

### GB 38031-2020 电动汽车用动力蓄电池安全要求
- 适用范围：电动汽车用锂离子电池和电池包/系统
- 低温相关条款：
  - 第6.1.3条：低温放电性能测试（-20°C，1C放电，容量≥初始容量70%）
  - 第6.1.4条：低温充电保护（-10°C以下禁止充电或自动限流）
- 强制标准，出口车辆必须满足

### GB/T 36276-2023 电力储能用锂离子电池
- 适用范围：固定式储能系统用锂离子电池
- 低温相关条款：
  - 第7.2.5条：低温放电容量（-10°C，0.5C，≥额定容量60%）
  - 第7.3条：高低温循环耐久性测试（-20°C ~ 55°C交替循环500次）
- 推荐标准，但招标中普遍引用

### GB/T 31485-2015 电动汽车用动力蓄电池安全要求及试验方法
- 包含过充、过放、短路、跌落、挤压等安全测试
- 低温存储测试：-40°C存储24h后恢复常温充放电
- 已被GB 38031-2020部分替代，但储能领域仍有引用

## 行业标准

### IEC 62619:2022 工业用锂离子电池安全要求
- 国际标准，出口储能产品必须满足
- 低温测试条件：-20°C放电性能 + -40°C存储恢复
- 安全测试覆盖热失控传播、外部短路、过充

### UN 38.3 锂电池运输安全标准
- 运输必备认证，覆盖所有锂电池
- T.1 高度模拟：模拟高海拔低气压
- T.2 温度测试：-40°C ~ 75°C循环
- T.3~T.8：振动、冲击、外短路、撞击、过充、强制放电

### UL 1973 固定式储能电池标准
- 北美市场必备，UL认证
- 包含低温性能测试和环境适应性测试
- 与IEC 62619互认趋势明显

## 项目投标常见认证要求

根据我司历史投标经验，不同场景的认证要求：

| 应用场景 | 必备认证 | 加分认证 |
|---------|---------|---------|
| 国内电网储能 | GB/T 36276, GB 38031 | CQC自愿性认证 |
| 出口欧洲 | IEC 62619, UN 38.3, CE | TUV认证 |
| 出口北美 | UL 1973, UN 38.3 | FCC |
| 工业特种 | GB/T 相关标准 | 第三方检测报告 |
| 通信基站 | YD/T 2344 | - |

## 合规注意事项

1. **认证周期**：新产品首次认证通常需要3-6个月，送样+测试+报告
2. **认证成本**：国内标准认证约5-15万元/型号，国际标准约20-50万元/型号
3. **标准更新**：GB/T 36276在2023年大幅修订，旧版报告可能不被新项目接受
4. **属地要求**：部分地区要求当地检测机构出具报告（如欧洲需Notified Body）
