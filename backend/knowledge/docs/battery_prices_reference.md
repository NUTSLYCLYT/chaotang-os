# 电池产品参数与价格区间(内部参考)

> 来源:产品部人工维护价目 `knowledge/battery_prices.yaml`(版本 1.0,更新于 2026-04-01,维护人:产品部)。
> 本文档为该 yaml 的机器转写,数字不在此处修改——改 yaml 后重跑 scripts/ima_prices_to_knowledge.py。

## LFP-40C-100Ah(磷酸铁锂电芯)
- 容量:100Ah
- 电压:3.2V
- 温度范围:-40°C ~ 60°C
- 循环寿命:≥3000次 (常温), ≥1500次 (-20°C)
- 放电倍率:1C (常温), 0.5C (-40°C)
- 能量密度:160Wh/kg
- 价格区间:350-420元/只
- 起订量:1000只
- 交期:6-8周
- 备注:特种低温王牌产品。-40°C放电保持率≥70%（经第三方低温测试报告验证，报告编号待补登记）。注意：此≥70%为本特种电芯实测值，不可外推到通用LFP（通用LFP -40°C约30-50%）。低温充电仍须主动加热（锂析出安全约束，与放电保持率无关）。对客户引用≥70%时须注明测试报告依据。

- 循环寿命:≥4000次 (常温)

- 备注:储能标准品，性价比最优
