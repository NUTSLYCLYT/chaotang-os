## 角色详细定义

### 角色1：采购工程师 / Sourcing工程师（主要用户）

| 属性 | 内容 |
|------|------|
| **代表人物** | 马景博及采购团队 |
| **使用权限** | **全流程读写** |
| **使用场景** | 发起搜寻任务、监控流水线状态、查看各阶段输出、审核评估结论、确认供应商推荐、录入资源库 |

**使用流程：**
```
① 输入需求 → ② 监控分解任务 → ③ 审核基础信息表
→ ④ 审核产品参数表 → ⑤ 审核初步评估表 → ⑥ 审核最终报告
→ ⑦ 做出采购决策
```

**典型输入示例：**
> 「搜寻适合储能应用、循环寿命≥3000次的磷酸铁锂电芯供应商，要求单体容量≥100Ah，能量密度不限，重点关注国内一二线厂商」

**典型输出期望：**
- 完整供应商评估报告（含推荐等级）
- 可直接查阅的供应商资源库条目
- 风险预警提示

---

### 角色2：研发工程师 / 产品规划师（内部协作）

| 属性 | 内容 |
|------|------|
| **使用权限** | **只读**：产品信息表、竞品分析结论 |
| **使用场景** | 提供目标参数需求、接收产品技术参数表、参考竞品分析 |

**提供信息（输入）：**
- 目标应用场景（储能/动力/备电等）
- 关键技术指标要求（容量/电压/倍率/循环等）
- 优先关注的参数维度

**接收信息（输出）：**
- 电芯产品信息表（清洗版）
- 参数对比分析表
- 技术规格匹配度评估

**使用示例：**
> 研发工程师：「我需要找适合工商业储能集装箱的280Ah铁锂电芯，重点看循环寿命和低温性能」→ 系统输出符合参数要求的产品清单

---

### 角色3：测试工程师（内部协作）

| 属性 | 内容 |
|------|------|
| **代表人物** | 肖艺及测试团队 |
| **使用权限** | **只读**：搜寻任务清单、供应商初步评估表 |
| **使用场景** | 接收样品任务、参考初步评估结果制定测试计划 |

**接收信息（输出）：**
- 样品需求清单（含数量/规格/测试要求）
- 供应商初步评估表（响应能力/配合度参考）
- 推荐优先测试的供应商列表

**不接收信息（保护原则）：**
- 虚拟询价估算价格（避免测试工程师被价格预期锚定）
- 供应商详细商务信息（避免影响测试客观性）

**使用示例：**
> 测试工程师收到：「推荐A、B两家供应商优先测试，C家备选。请安排循环寿命和针刺测试」

---

### 角色4：产品部（内部协作）

| 属性 | 内容 |
|------|------|
| **代表人物** | 郭云辉及产品团队 |
| **使用权限** | **只读**：竞争力分析报告、产品推荐表 |
| **使用场景** | 参考竞品分析进行产品规划、参考供应商推荐进行选型 |

**接收信息（输出）：**
- 竞争力分析报告（成本竞争力/技术竞争力对比）
- 产品推荐表（含S/A/B/C推荐等级）
- 风险评估报告摘要

**使用示例：**
> 产品经理参考：「基于竞争力分析报告，储能新品线优先推荐A供应商电芯，B供应商作为备选」

---

### 角色5：采购负责人 / 总经理（管理层）

| 属性 | 内容 |
|------|------|
| **使用权限** | **只读**：最终结论、供应商资源库概览 |
| **使用场景** | 审批重要供应商引入、查阅供应商资源库、查看战略级供应商评估 |

**接收信息（输出）：**
- 供应商资源库（汇总视图）
- S/A级供应商推荐报告摘要
- 重大风险预警（⚠️标识）

**不关心细节（分层展示）：**
- 不需要看到具体数据收集过程
- 不需要看到数据清洗中间步骤
- 只看最终结论和关键风险提示

**使用示例：**
> 总经理查阅：「近期新增S级供应商3家，A级供应商5家；⚠️风险提示：D供应商存在法律纠纷，建议暂缓引入」

## 用户交互指南

### 需求输入规范
用户输入越清晰，任务分解越精准。建议包含：
- **应用场景**：储能/动力/备电/特种等
- **核心参数要求**：容量/电压/倍率/循环寿命等（带数值或范围）
- **优先级维度**：成本优先/性能优先/产能优先等
- **供应商偏好**：指定厂商/排除厂商/重点关注类型

### 输出消费规范
| 用户类型 | 推荐输出格式 |
|---------|-------------|
| 采购工程师 | 完整报告（所有章节）+ 资源库直接可读条目 |
| 研发/产品规划 | 参数对比表 + 技术评估摘要 |
| 测试工程师 | 任务清单 + 样品要求 + 测试优先级 |
| 产品部 | 竞争力分析图 + 推荐表 |
| 管理层 | 执行摘要（1页）+ 风险预警 + 资源库概览 |

## 使用约定

1. **数据时效约定**：超过6个月的供应商数据自动标注「⚠️数据过期」，采购工程师需判断是否重新收集
2. **估算标注约定**：虚拟询价结果必须标注「📌估算参考」，不得作为正式商务依据
3. **置信度约定**：系统推断结论标注置信度（高/中/低），人工决策前需核实低置信度项
4. **定期更新约定**：资源库中每条供应商信息附带「最后更新日期」，超期自动触发复检提醒
