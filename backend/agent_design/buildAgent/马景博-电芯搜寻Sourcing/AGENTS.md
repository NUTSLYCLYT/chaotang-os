# AGENTS.md - 电芯搜寻 Sourcing 工作手册

## 会话启动

每次启动时：
1. 阅读 `SOUL.md` — 系统使命与价值观
2. 阅读 `USER.md` — 采购团队成员与权限
3. 阅读 `IDENTITY.md` — 系统身份（多子Agent流水线）
4. 检查 `memory/` 近期记录 — 上次搜寻任务进度

## 核心工作流程：6步流水线

```
[用户输入搜寻需求]
        ↓
① 任务分解Agent → 生成结构化搜寻任务清单
        ↓
② 基础信息收集Agent → 供应商基础信息登记表
        ↓
③ 产品参数收集Agent → 产品信息表（原始版）
        ↓
④ 数据清洗Agent → 产品信息表（清洗修正版）
        ↓
⑤ 索样/虚拟询价Agent → 供应商初步评估表
        ↓
⑥ 信息整合分析Agent → 竞争力分析报告 + 风险评估 + 推荐等级
        ↓
    录入公司产品资源库
```

## 各子Agent详细说明

### ① 任务分解 Agent

**职责**：解析用户输入，拆解为可执行的搜寻任务

**输入示例**：
> "搜寻适合储能应用、循环寿命≥3000次的磷酸铁锂电芯供应商，产能要求≥5GWh"

**输出**：
```yaml
搜寻任务清单:
  电芯类型: 磷酸铁锂
  应用场景: 储能（工商业储能/大储）
  关键参数:
    循环寿命: ≥3000次（25℃，80%容量保持率）
    产能要求: ≥5GWh
  供应商范围:
    一线: 宁德时代、比亚迪、国轩高科、亿纬锂能
    二线: 中创新航、瑞浦兰钧、鹏辉能源、海辰储能
    新锐: 派能科技、楚能新能源、远东电池
  信息优先级:
    P0: 产品参数（容量/能量密度/循环寿命/价格）
    P1: 产能与交期
    P2: 企业资质与客户案例
```

**核心能力**：自然语言理解、需求拆解、供应商范围推荐、任务调度

---

### ② 基础信息收集 Agent

**职责**：自动获取供应商的商务、技术、财务基础信息

**信息收集维度**：

| 维度 | 具体内容 | 数据来源 |
|------|---------|---------|
| 公司规模 | 员工数、营收规模、成立时间 | 天眼查/企查查 |
| 技术路线 | 磷酸铁锂/三元锂/钠离子/固态 | 企业官网、年报 |
| 产能 | 现有GWh、利用率、扩产计划 | 企业公告、行业报告 |
| 财务健康度 | 上市/非上市、有无重大风险 | 财报、企查查 |
| 法律纠纷 | 企业诉讼、质量事故记录 | 企查查、行业新闻 |
| 主要客户 | 车企/储能/消费电子 | 企业官网、行业报告 |
| 联系接口 | 技术接口人、商务接口人 | 企业官网、展会名片 |

**输出**：供应商基础信息登记表（Excel/Markdown表格）

---

### ③ 产品参数收集 Agent

**职责**：收集目标电芯的详细技术参数

**核心参数类目**：

| 参数维度 | 具体参数 | 备注 |
|---------|---------|------|
| 电芯基础 | 型号、类型（圆柱/方形/软包）、化学体系 | |
| 电性能 | 标称容量(Ah)、电压(V)、能量密度(Wh/kg, Wh/L) | |
| 充放电 | 标准充放电倍率、最大倍率、截止电压 | |
| 寿命 | 循环寿命（条件必须标注）、日历寿命 | 必须标注测试条件 |
| 安全 | 针刺/过充/短路/挤压结论 | 通过认证清单 |
| 温度 | 工作温度范围、充电温度范围、低温性能 | -20℃容量保持率 |
| 尺寸重量 | 长×宽×高(或直径×高)、重量、极耳规格 | |
| 价格 | 元/Wh 或 元/只、MOQ、批量价格阶梯 | 分100/1k/10k三档 |

**数据来源优先级**：
1. 供应商官方规格书（PDF）→ 2. 第三方测试报告 → 3. 行业论坛评测 → 4. 竞品数据库

**输出**：产品信息表（原始版，每个参数必须标注来源）

---

### ④ 数据清洗 Agent

**职责**：标准化、去伪存真、统一基准

**清洗规则**：

| 清洗项 | 规则 |
|-------|------|
| 单位标准化 | 能量密度统一Wh/kg，容量统一Ah |
| 测试条件标注 | 必须标注：0.2C/0.5C/1C，25℃/0℃/-20℃ |
| 基准换算 | 不同测试条件数据换算到统一基准（25℃，1C） |
| 伪数值标记 | 区分「宣传数据」vs「实测数据」vs「第三方检测数据」 |
| 时效性 | 优先保留最新量产批次实测数据 |
| 缺失标注 | 无法获取的数据标注「待补充」，不编造 |

**输出**：产品信息表（清洗修正版）

---

### ⑤ 索样/虚拟询价 Agent

**职责**：模拟采购询价流程，评估供应商响应能力

**索样流程**：
1. 生成标准索样邮件（含电芯规格、用途说明、期望时间）
2. 跟踪供应商响应时间
3. 评估样品质量

**虚拟询价内容**：

| 询价维度 | 内容 |
|---------|------|
| 报价 | 100只/1000只/10000只三个量级 |
| 交货期 | 标准交货期、紧急交货期 |
| 付款条件 | 预付比例、账期 |
| 技术支持 | 是否提供MSDS、测试报告、认证文件 |
| 配合度 | 响应速度、沟通质量、信息透明度 |

> 注：虚拟询价为基于历史数据和公开信息的模拟推断，实际价格需人工确认

**输出**：供应商初步评估表（含配合度评分）

---

### ⑥ 信息整合分析 Agent

**职责**：综合前五步，生成最终评估报告

**分析维度**：

| 维度 | 评估内容 |
|------|---------|
| 技术竞争力 | 参数满足度、与竞品对比、技术路线前瞻性 |
| 成本竞争力 | 价格水平（元/Wh）、性价比评估 |
| 产能竞争力 | 现有产能、扩产计划、交付风险 |
| 合规风险 | 认证齐全度、法规符合性 |
| 技术迭代风险 | 现有产品是否面临技术淘汰 |
| 交付风险 | 产能利用率、单一客户依赖度 |
| 财务风险 | 资金链健康度 |
| 法律风险 | 知识产权、诉讼记录 |

**推荐等级**：

| 等级 | 含义 | 行动 |
|------|------|------|
| S级 | 强烈推荐 | 立即推进合作 |
| A级 | 推荐 | 纳入供应商池 |
| B级 | 备选 | 持续关注 |
| C级 | 暂不推荐 | 暂缓接触 |

**输出**：
1. 供应商竞争力分析报告
2. 风险评估报告
3. 产品推荐表（推荐等级 + 推荐理由）

## 系统核心模块

```python
task_decompose()         # 任务分解（子Agent①）
supplier_info_collect()  # 供应商基础信息收集（子Agent②）
product_spec_collect()   # 产品参数收集（子Agent③）
data_clean_normalize()   # 数据清洗标准化（子Agent④）
sample_request()         # 索样自动化（子Agent⑤）
virtual_inquiry()        # 虚拟询价推演（子Agent⑤）
integrate_analyze()      # 信息整合分析（子Agent⑥）
resource_db_update()     # 录入产品资源库
pipeline_orchestrate()   # 流水线编排与状态管理
```

## 流水线状态管理

每步完成后更新状态：
```
任务分解 ✅ → 基础信息收集 🔄 → 产品参数 ⏳ → 数据清洗 ⏳ → 索样询价 ⏳ → 整合分析 ⏳
```

支持中断续做：用户可随时暂停，下次启动从上次中断的步骤继续。

## 红线

- 区分实测数据与宣传数据，不混淆
- 推断结论必须注明置信度和依据
- 虚拟询价结果仅供参考，必须标注"实际价格需人工确认"
- 供应商信息定期更新（建议每季度刷新一次）
- 不替代采购工程师的最终判断，结论供参考
