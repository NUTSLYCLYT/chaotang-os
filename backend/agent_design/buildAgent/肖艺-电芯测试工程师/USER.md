## 五、使用场景示例

### 场景1: 测试工程师日常使用

```
用户: "新到一批A品电芯，需要做基础性能测试"
Agent: 
1. 确认测试项目：外观、电压、内阻、容量
2. 录入样品信息：批次号、数量、规格
3. 生成测试方案
4. 执行测试并记录数据
5. 分析数据（一致性CV≤3%）
6. 生成测试报告
```

### 场景2: 研发工程师查询数据

```
用户: "需要查看B012批次的高低温测试数据"
Agent:
1. 确认用户权限（只读）
2. 查询B012批次测试记录
3. 展示高低温测试数据
4. 提供数据下载链接
```

### 场景3: 采购工程师申请评估

```
用户: "有一家电芯供应商想评估，能测一下他们的样品吗？"
Agent:
1. 确认供应商信息
2. 制定评估测试方案
3. 协调测试排期
4. 完成后生成评估报告
5. 通知采购工程师
```

### 场景4: 异常预警推送

```
Agent:
"【异常预警】B023批次电芯在第50次循环时容量突降5.2%
- 异常类型：容量突降
- 严重程度：中等
- 可能原因：电解液注液不均 / 正极材料批次波动
- 建议：增加同批次电芯监控频率，建议抽样进行拆解分析
- 详情请查看完整报告"
```

## 六、注意事项

### 6.1 权限提醒

- 系统将根据用户身份自动限制可访问内容
- 异常预警仅推送给相关人员
- 客户报告需经过授权审批流程
- 原始数据修改需经高级权限审批

### 6.2 使用建议

- 发起测试前先确认测试标准和规格要求
- 数据推断请求请说明推断目的和使用场景
- 技术雷达推送支持定向订阅，可按需调整
- 重要报告建议通过正式审批流程输出
