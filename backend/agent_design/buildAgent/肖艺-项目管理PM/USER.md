# USER.md - 电池PACK项目管理Agent用户体系

## 用户角色体系

| 用户类型 | 角色 | 典型用户 | 主要需求与使用场景 | 使用频率 |
|---------|------|----------|-------------------|----------|
| **主要用户** | 项目经理/PM | 肖艺（项目管理工程师） | 全项目管理、进度监控、风险处理、报告生成、团队协调 | 每日 |
| **内部协作** | 研发工程师 | 结构设计工程师、电气工程师、BMS工程师 | 接收设计任务、提交设计进度、参与技术评审、处理设计变更 | 每周多次 |
| **内部协作** | 采购工程师 | 马景博团队（电芯搜寻Agent用户） | 接收采购任务、反馈到货进度、提供成本数据、处理供应商问题 | 每周 |
| **内部协作** | 生产/工艺工程师 | 生产计划员、工艺工程师、生产线主管 | 参与试产策划、提交生产问题、确认SOP、反馈产能信息 | 试产阶段每日 |
| **内部协作** | 质量工程师 | 测试工程师、质量主管、体系工程师 | 提交测试报告、更新FMEA、处理客诉、跟踪质量问题闭环 | 每周 |
| **客户/销售** | 客户代表 | 终端客户项目负责人 | 查看项目进度、接收里程碑通知、提交需求变更、参与设计评审 | 每2周 |
| **客户/销售** | 销售工程师 | 销售团队、客户经理 | 获取项目信息用于客户沟通、协助需求澄清、协调资源 | 每周 |
| **管理层** | 部门负责人 | 研发总监、质量总监、生产总监 | 查看整体项目看板、审批重大决策、资源协调、绩效评估 | 每周 |
| **管理层** | 总经理/高管 | 公司管理层 | 战略层面项目状态、关键风险预警、投资回报分析 | 每月 |

## 部门协作关系

### 与研发质量部内部协作
1. **电芯测试Agent协同**
   - 同步测试计划与进度
   - 共享测试结果与质量数据
   - 协同处理测试异常

2. **研发工程师协作流程**
   - 设计任务分配→进度反馈→设计评审→问题处理
   - 技术变更→影响评估→实施跟踪

### 与采购部协作
3. **电芯搜寻Agent协同**（马景博团队）
   - 物料需求传递→供应商寻源→样品确认→批量采购
   - 交期监控→风险预警→替代方案

4. **成本协同**
   - BOM成本核算→价格谈判支持→成本变更评估

### 与生产部协作
5. **试产导入流程**
   - 试产计划制定→资源准备→试产执行→问题解决
   - SOP确认→人员培训→量产准备

6. **生产问题闭环**
   - 问题报告→原因分析→措施制定→效果验证

### 与质量部协作
7. **质量保证流程**
   - 测试计划协同→测试执行跟踪→结果分析
   - 质量问题管理→纠正预防→持续改进

8. **认证支持**
   - 认证要求传递→测试安排→文件准备→认证跟踪

### 与销售/客户协作
9. **需求管理流程**
   - 需求收集→需求澄清→需求确认→变更管理

10. **客户沟通**
    - 进度汇报→问题沟通→评审参与→验收支持

## 用户场景示例

### 场景1：项目经理日常管理
```
用户：肖艺（项目经理）
时间：周一上午9:00
操作：
1. 登录系统，查看周末自动生成的《项目周报》
2. 检查风险预警列表，针对高风险项制定应对措施
3. 召开项目例会，使用实时看板同步进度
4. 分配新的设计任务给研发工程师
5. 评审采购部提交的关键物料交期风险
```

### 场景2：研发工程师任务更新
```
用户：张工（结构设计工程师）
时间：周三下午
操作：
1. 收到任务提醒：完成Pack结构设计
2. 上传3D模型和工程图
3. 更新任务状态：已完成90%，预计周五完成
4. 报告一个设计问题：某个安装孔位与客户壳体冲突
5. 参与设计评审会议，使用共享评审文档
```

### 场景3：客户查看进度
```
用户：王经理（客户项目负责人）
时间：周五上午
操作：
1. 收到邮件通知：项目里程碑"详细设计完成"已达成
2. 登录客户门户，查看详细设计文档
3. 查看项目甘特图，了解下一阶段计划
4. 提交一个需求变更：增加电池包IP防护等级
5. 查看变更评估报告，确认接受进度影响
```

### 场景4：管理层决策支持
```
用户：李总（研发总监）
时间：月度经营会前
操作：
1. 登录管理看板，查看所有在研项目状态
2. 识别高风险项目：3个项目进度延迟超过15%
3. 查看资源冲突分析：2个关键工程师被过度分配
4. 审批一个重大设计变更请求
5. 导出月度项目绩效报告
```

## 安全与合规

### 数据安全
- 项目敏感数据（成本、客户信息）加密存储
- 基于角色的访问控制（RBAC）
- 操作日志完整记录，可审计

### 合规要求
- 符合公司信息安全政策
- 保护客户知识产权
- 符合电池行业数据管理规范

### 备份与恢复
- 每日自动备份项目数据
- 关键操作可回滚
- 灾难恢复计划
