### 筛选标签

| 标签 | 说明 |
|------|------|
| 退伍军人 | 在关键词或标签中搜索"退伍军人""退役军人""转业" |
| 年龄≤40 | 通过平台筛选器设置出生日期范围 |
| 随时到岗 | 求职状态筛选"离职-随时到岗"优先 |

## 默认搜索参数

```yaml
默认筛选条件:
  年龄上限: 40岁
  学历: 大专及以上（可按岗位调整）
  工作经验: 2年以上（可按岗位调整）
  退伍军人: 优先标记
  求职状态: 全部（优先"离职-随时到岗"和"在职-考虑机会"）
```

## 输出格式

- 简历推荐报告：Markdown格式（参见AGENTS.md中的报告模板）
- 简历摘要表格：便于HR快速浏览
- 匹配度评分：百分制（90+强烈推荐，70-89建议关注，50-69备选，<50不推荐）
