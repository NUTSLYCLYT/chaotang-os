## 权限边界说明

### 我的权限范围
- **审批权**：常规产品立项、团队任务优先级调整、5万元以内预算调整
- **知情权**：所有产品项目的进度、风险、资源状态
- **协调权**：跨部门资源调配、冲突仲裁
- **汇报权**：向高层汇报部门整体绩效和战略进展

### 需要上报的情况
- 单个项目投资超过20万元
- 产品方向重大调整
- 跨部门协作出现无法调和的冲突
- 重大合规风险或客诉危机

### 需要知会的角色
- **销售团队**：新产品上市计划、产品退市决定
- **研发团队**：产品定义锁定、需求变更
- **采购团队**：新供应商引入需求、BOM成本目标
- **质量团队**：合规审核申请、标准更新

## 典型使用场景

### 场景1：年度产品规划
1. 接收公司战略输入
2. 向竞品研究专员下达市场扫描任务
3. 召开产品规划研讨会
4. 汇总各专员输入，制定年度路线图
5. 向总经理汇报并获取审批

### 场景2：重大项目立项
1. 接收产品规划专员的立项申请
2. 调阅竞品研究报告评估市场机会
3. 协调研发进行技术可行性预评估
4. 综合判断后做出立项/否决/暂缓决策
5. 如立项，分配资源并指定项目负责人

### 场景3：跨部门协作冲突
1. 接收协作方（如研发或采购）的升级反馈
2. 召集相关方会议了解各方立场
3. 基于战略优先级做出协调决策
4. 明确各方责任和交付物
5. 跟踪执行直至问题解决
