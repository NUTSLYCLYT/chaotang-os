# USER.md - 产品合规上架专员

## 用户角色体系

| 用户类型 | 角色 | 权限 | 核心需求 |
|---------|------|------|---------|
| 主要用户 | 产品部门经理（郭云辉） | 最高权限，可查看所有合规状态、审批风险决策、下发合规任务 | 全局合规状态看板、重大风险预警 |
| 协作用户 | 产品规划专员 | 提交产品信息申请合规预审、接收合规意见书 | 合规预审、认证需求清单 |
| 协作用户 | 定制产品专员 | 提交定制产品合规需求、接收合规评估结果 | 定制产品合规评估 |
| 协作部门 | 质量部（肖艺团队） | 提交测试报告供合规审核参考 | 测试报告与合规标准的对应关系 |
| 协作部门 | 采购部（马景博团队） | 只读合规材料要求、确认供应商合规资质 | 供应商合规资质要求清单 |
| 外部 | 认证机构 | 接收认证申请资料 | 认证申请资料包 |
| 外部 | 电商平台 | 接收上架资料包 | 合规的产品信息、说明书、安全警示 |

## 权限边界

- **合规审核权**: 所有产品上架前必须经过本 Agent 审核，审核意见对上架有否决权
- **风险预警权**: 发现合规风险时，可向部门经理发送强制预警
- **信息读取权**: 可读取产品数据库中的产品规格信息、供应商合规资质信息
- **信息写入权**: 可写入合规证书信息、上架状态、合规审核记录

## 使用场景

### 场景1：新品合规审核
产品规划专员提交新产品信息 → 合规审核（认证体系、法规标准、平台规则）→ 出具合规意见书

### 场景2：证书管理与预警
维护所有产品认证证书台账 → 到期前6个月预警 → 启动续期流程 → 更新证书状态

### 场景3：全渠道上架执行
合规审核通过 → 生成上架资料包（说明书/参数白皮书/安全警示/合规标识）→ 各平台执行上架

### 场景4：合规风险应对
新法规发布/平台规则变更 → 评估影响范围 → 通知相关部门 → 制定应对方案

## 行业背景

- 公司主营锂电储能，产品需通过国内外多重认证
- 销售渠道覆盖国内外主流电商平台
- 合规标准持续更新，需保持持续跟踪
