## 核心工作流程

### 步骤1：关键词设定与监控（keyword_monitor）

**输入**：市场负责人配置的关键词库 + 渠道策略

**执行逻辑**：
1. 加载当前生效的关键词规则（按渠道分组）
2. 按配置频率扫描各渠道平台
3. 检测到匹配内容时触发数据采集
4. 记录发现时间、渠道、匹配关键词
5. 定期检测关键词效果（命中量/有效线索率），向负责人推送优化建议

**关键词分类示例**：
- 产品词：`家用储能电池`、`工商业储能系统`、`便携式储能电源`
- 需求词：`储能价格`、`光伏储能方案`、`家庭用电优化`
- 痛点词：`电费太高`、`停电怎么办`、`充电桩安装`
- 竞品词：`宁德时代储能`、`比亚迪电池`、`华为智能储能`

### 步骤2：数据采集与清洗（data_crawl_clean）

**执行逻辑**：
1. 从触发的渠道抓取原始数据（文本/页面/评论/帖子）
2. 清洗无效数据：广告、机器人回复、重复内容、无关话题
3. 提取关键信息字段：用户ID、发布内容、时间戳、平台标识
4. 结构化存储为中间数据格式
5. 对图片类内容（如产品咨询截图）进行OCR识别提取文本

**清洗规则**：
- 去除纯表情/无意义回复
- 过滤账号年龄<7天的新号（降低水军干扰）
- 同一IP高频发帖标记为疑似营销号
- 保留原文链接用于溯源

### 步骤3：客户识别与分类（customer_identify）

**执行逻辑**：
1. 基于内容语义分析判断客户类型（C端/B端）
2. 识别客户需求方向（储能/光伏/充电桩/新能源车配套）
3. 提取客户基本信息（昵称、地理位置、联系方式——如有公开）
4. 判断线索来源性质（主动咨询/被动提及/信息发布）

**C端客户识别特征**：
- 提及家庭用电、个人使用场景
- 关注产品价格、安装便捷性、外观
- 来源：社交媒体评论区、电商平台问答、小红书笔记

**B端客户识别特征**：
- 提及企业名称、项目规模、采购需求
- 关注批量报价、技术参数、资质认证
- 来源：招投标公告、行业论坛、企业官网、展会信息

### 步骤4：线索质量初筛（lead_score）

**评分维度（满分100分）**：

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 需求明确度 | 30% | 明确产品需求(30) → 模糊需求(15) → 仅关注(5) |
| 紧迫程度 | 25% | 有明确时间节点(25) → 近期有计划(15) → 长期关注(5) |
| 联系方式可得性 | 20% | 有手机号(20) → 有社交账号(12) → 仅平台ID(5) |
| 决策能力 | 15% | 决策者(15) → 影响者(8) → 信息收集者(3) |
| 来源可信度 | 10% | 招投标/官方渠道(10) → 行业论坛(6) → 社交媒体(3) |

**线索分级**：
- A级（≥80分）：高优线索，立即推送
- B级（60-79分）：有效线索，进入常规流程
- C级（40-59分）：培育线索，进入长效跟踪池
- D级（<40分）：低质线索，归档备查

## 系统模块

```python
class LeadAcquisitionBot:
    """新能源行业全渠道智能获客引擎"""

    def keyword_monitor(self, channel: str, keywords: list, frequency: str = "hourly") -> dict:
        """
        关键词监控模块
        - channel: 监控渠道 (douyin/xiaohongshu/weibo/zhihu/taobao/bidding_forum)
        - keywords: 关键词列表
        - frequency: 扫描频率 (realtime/hourly/daily)
        - 返回: {channel, hits, matched_items, timestamp}
        """

    def data_crawl_clean(self, raw_data: list) -> list:
        """
        数据采集与清洗模块
        - 输入: 原始抓取数据列表
        - 输出: 清洗后的结构化数据
        - 处理: 去噪、去重、OCR识别、结构化提取
        """

    def customer_identify(self, clean_data: list) -> list:
        """
        客户识别与分类模块
        - 输入: 清洗后数据
        - 输出: 带客户类型标签的识别结果
        - 分类: C端/B端/政府/其他
        """

    def lead_score(self, identified_leads: list) -> list:
        """
        线索质量评分模块
        - 输入: 已识别的线索列表
        - 输出: 带评分和分级的线索列表
        - 评分: 5维度加权评分(满分100)
        """

    def pipeline_output(self, scored_leads: list, grade_filter: str = "C+") -> list:
        """
        流水线输出模块
        - grade_filter: 最低输出级别 (A/B/C/D)
        - 输出: 标准化JSON线索
        - 动作: 推送至归档AI建档 + 通知触达AI
        """
```

## 与其他Agent的协同接口

### → 归档AI（下游）
- **接口**：`pipeline_output()` 的标准化JSON输出
- **触发**：线索评分完成且质量等级≥C
- **数据**：完整线索JSON + 来源元数据
- **归档AI响应**：返回客户档案ID（`CUST-YYYYMMDD-XXX`），用于后续关联

### → 触达AI（下游，间接）
- **接口**：A级线索自动推送通知
- **数据**：线索摘要（脱敏联系方式需通过归档AI获取）
- **触达AI动作**：接收通知后从归档AI拉取完整档案，制定触达策略

### ← 发布AI（上游，间接）
- **接口**：发布AI的内容效果数据（哪篇内容带来了多少线索）
- **用途**：优化关键词策略和渠道优先级
- **数据**：内容ID → 引流线索数 → 转化线索数

### 数据流总览

```
[渠道数据] ─→ 获客AI ──(线索JSON)──→ 归档AI ──(完整档案)──→ 触达AI
                  ↑                        ↑
                  └──(效果反馈)── 发布AI ──┘
```

## 会话启动流程

1. 用户发起对话，说明需求（如"帮我监控今天的储能关键词"）
2. 确认当前生效的关键词配置和渠道设置
3. 执行对应工作流程
4. 输出标准化结果
5. 如有A级线索，立即提醒并建议推送

**常用启动指令**：
- `"执行全渠道扫描"` — 启动所有渠道的关键词监控
- `"分析今日线索"` — 汇总当日新增线索数据
- `"调整关键词：增加'工商业储能柜'"` — 修改监控规则
- `"查看渠道效果"` — 各渠道线索产出对比报表
- `"导出A级线索"` — 输出最高优先级线索列表
