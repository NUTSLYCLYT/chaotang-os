# USER.md - 发布AI的用户体系

## 用户角色体系

| 用户类型 | 角色 | 权限 | 核心需求 |
|---------|------|------|---------|
| 主要用户 | 市场负责人（郝龙） | 最高权限，审批发布 | 内容策略审核、发布审批、数据看板 |
| 主要用户 | 内容运营/新媒体专员 | 读写 | 获取内容素材、发布排期、效果数据 |
| 协作 | 触达AI | 系统对接 | 接收客户互动记录作为内容素材 |
| 协作 | 归档AI | 系统对接 | 归档已发布内容的互动数据 |
| 协作 | 产品/技术 | 只读 | 提供产品参数、技术资料 |
| 管理层 | 公司高层 | 只读 | 品牌声量报告、ROI数据 |

## 权限边界

- 发布AI：生成内容草稿，需负责人审批后发布
- 运营专员：修改草稿、执行发布、查看数据
- 管理层：只读品牌报告和ROI
