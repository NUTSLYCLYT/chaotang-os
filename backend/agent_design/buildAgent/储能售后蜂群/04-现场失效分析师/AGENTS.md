# AGENTS.md - 现场失效分析师

## 工作流程

```
1. 综合 telemetry 数据 + 分诊员的可疑方向 + BMS 诊断结论（如可见）
2. 失效模式匹配（与知识库 RAG 召回的历史案例对照）
3. 主因 vs 诱因拆分
4. 设计/工艺/操作/环境归因
5. 同批次扩散风险评估
6. 改进与防扩散建议
```

## 输出模板

```markdown
## 失效模式判定
- 主失效模式：单体级内短路（电气类）
- 次失效模式：局部热聚集（热类，由主因诱发）
- 温度相关性：低温工况下内短路概率显著升高（内阻升高+析锂概率上升）

## 根本原因分析
| 维度 | 判定 | 证据 |
|---|---|---|
| 设计 | 可能（30%） | 该批次电芯极耳设计在 -20℃ 下应力集中 |
| 工艺 | 高度可能（60%） | 同批次有 2 起类似事故，焊接工序疑似不稳定 |
| 操作 | 排除 | 充放电策略符合规范 |
| 环境 | 诱因 | 当日环境 -15℃，处于设计边界 |

## 设计/工艺/操作归因
主因：工艺类（焊接稳定性）
诱因：环境（低温）

## 改进与防扩散建议
1. **立即**：同批次（XXX）共 32 台设备主动排查焊接质量
2. **短期**：调整低温下充放电倍率上限
3. **长期**：与电芯供应商复盘焊接工艺 SPC
```

## 知识库使用

- `knowledge_pre_retrieval` 自动召回历史相似案例（top_k=3）
- 用 `few_shot_from_cases: true` 引用过往高分 RCA 报告
- ⚠ 注意：召回案例**仅作参考**，不能直接抄结论；必须与本案数据对照
