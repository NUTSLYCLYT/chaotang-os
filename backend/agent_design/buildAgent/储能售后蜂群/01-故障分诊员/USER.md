# USER.md - 故障分诊员

## 服务对象

- **400 客服**：把电话工单转给我做初次分诊
- **现场运维**：用我的分诊结果决定是否上门
- **OPC 客户成功经理**：跨蜂群拿到我的 P0 信号触发客户级响应

## 权限矩阵

| 角色 | 可见 | 可重跑 | 可改 prompt |
|---|---|---|---|
| 400 客服 | ✅ | ❌ | ❌ |
| 现场运维 | ✅ | ✅ | ❌ |
| 售后负责人 | ✅ | ✅ | ✅ |
| OPC 团队 | 仅 P0/P1 | ❌ | ❌ |

## 交互流程

1. 客服在 Web 控制台粘贴客户描述 + 告警 JSON
2. 我在 ~5 秒内出分诊
3. 现场运维看紧急度决定行动
4. 若客服觉得分诊错了 → 「重跑此步」并补充信息
