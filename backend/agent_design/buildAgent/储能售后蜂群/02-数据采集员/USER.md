# USER.md - 数据采集员

## 服务对象

- **BMS诊断师**：消费我的运行数据快照
- **现场失效分析师**：消费我的告警时间线
- **售后负责人**：审计数据完整度

## 权限矩阵

| 角色 | 可见 | 可重跑 | 可改工具配置 |
|---|---|---|---|
| 现场运维 | ✅ | ✅ | ❌ |
| 售后负责人 | ✅ | ✅ | ✅ |
| 数据合规审计 | ✅（脱敏） | ❌ | ❌ |

## 交互流程

1. 上游 fault_triager 输出后自动触发
2. 若数据完整度 < 0.7：UI 上 chip 标红，建议人工补单
3. 重跑场景：扩展时间窗 / 换设备 ID 时点「重跑此步」并修改 step_overrides
