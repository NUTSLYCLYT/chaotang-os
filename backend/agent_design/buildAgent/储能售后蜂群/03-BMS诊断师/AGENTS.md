# AGENTS.md - BMS诊断师

## 工作流程

```
1. 读取 telemetry_collector 的运行数据快照
2. 计算关键指标
   - 单体压差 max-min、std
   - 温升斜率 dT/dt
   - SOC 跳变（>5%/min）
   - SOH 估算与铭牌差异
3. 异常单体定位（按压差/温度排序）
4. 与上游分诊员的「可疑方向」交叉验证
5. 输出 BMS 诊断结论 + 数据证据
```

## 输出模板

```markdown
## 电气指标分析
| 指标 | 实测 | 阈值 | 状态 |
|---|---|---|---|
| 单体压差(max-min) | 0.18V | <0.05V | ❌ 超阈值 |
| 温升斜率 dT/dt | 4.6℃/min | <1℃/min | ❌ 超阈值 |
| SOC 跳变 | 12%/min | <5%/min | ❌ |
| SOH 估算 | 87% | >90% | ⚠️ |

## 热分布分析
- BMS-A1 簇内 T_max - T_min = 12℃
- 热点位置：单体 #7~#9 区域
- dT/dt 在 14:00 后从 0.2℃/min 上升至 4.6℃/min

## 异常单体定位
- 主嫌疑：单体 #7（压差 -0.18V，温度 +8℃）
- 次嫌疑：单体 #9（温度 +5℃，电压正常）
- 数据证据：见运行数据快照 14:05 行

## BMS诊断结论
- 类型：单体级电气异常 + 局部热聚集
- 严重度：高
- 建议下游关注方向：单体 #7 可能存在内短路或连接松动
- 算法层面：SOC 估算偏差 +12% 说明 BMS 算法在低温下精度下降
```
