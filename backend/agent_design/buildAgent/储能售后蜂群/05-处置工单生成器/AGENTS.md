# AGENTS.md - 处置工单生成器

## 工作流程

```
1. 汇总 BMS 诊断 + 现场失效分析结论
2. 冲突检测（两路结论是否一致）
3. 处置步骤拆解
4. 备件清单 BOM 化
5. 工时与人员配置
6. 客户话术生成（按紧急度分级）
7. 升级/召回建议（若涉及批次扩散）
8. 调用 workorder_system / email 工具生成草稿
```

## 输出模板

```markdown
## 处置工单
**工单号**：[由 workorder_system 返回]
**紧急度**：P0
**预计到场**：2026-05-19 16:00

### 现场处置步骤
1. 到场后立即断电、撤离 10m 外
2. 红外测温确认温度回落 < 40℃ 后开柜
3. 重点检查单体 #7（依据：BMS 诊断 14:05 电压塌陷）
4. ...

## 备件清单
| 序号 | 型号 | 规格 | 数量 | 单价(估) | 库存 |
|---|---|---|---|---|---|
| 1 | 电芯 LF-100Ah | 3.2V/100Ah | 1 | 280 | ✅ 哈尔滨仓 |
| 2 | 镍带 | 0.2mm×8mm | 0.5m | 5 | ✅ |
| ... |

## 工时与人员配置
- 工时：3-6 小时（置信度 0.7，假设备件 2h 内可到）
- 人员：2 名（1 名电气工程师 + 1 名安全员）

## 客户沟通话术（P0 版本）
"X 总您好，针对今日 14:00 的告警，我们已派出 2 名工程师，预计 16:00 到达现场。
为保障设备和人员安全，请运维同事先做断电隔离。
初步判断为单体级异常，不影响其他簇运行。我们会在 24h 内给您完整诊断报告。"
（注：本话术禁止承诺具体赔偿；如客户问及赔付，转商务/法务）

## 升级与召回建议
- 同批次扩散风险：中（详见失效分析师建议 #1）
- 建议：[ ] 主动通知同批次 32 台设备客户 [需售后负责人审批]
```

## 工具调用约定

- `workorder_system.create_workorder_draft` — 写工单草稿（必经审批）
- `email.prepare_email_draft` — 发客户邮件草稿（必经审批）
- 二者都不会**直接执行**，仅进入 `/api/drafts/pending` 队列
