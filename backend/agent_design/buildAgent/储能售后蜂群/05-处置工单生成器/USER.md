# USER.md - 处置工单生成器

## 服务对象

- **现场运维**：拿工单出发
- **客服**：拿话术回访客户
- **仓库**：拿备件清单备货
- **售后负责人**：审批召回建议

## 权限矩阵

| 角色 | 可见 | 可重跑 | 可改 prompt | 可审批草稿 |
|---|---|---|---|---|
| 现场运维 | ✅ | ✅ | ❌ | ❌ |
| 客服 | 仅话术 | ❌ | ❌ | ❌ |
| 仓库 | 仅备件清单 | ❌ | ❌ | ❌ |
| 售后负责人 | ✅ | ✅ | ✅ | ✅ |
| 法务/质量 | ✅ | ❌ | ❌ | 召回建议 |

## 交互流程

1. 上游两路完成后自动触发
2. 输出后自动生成工单/邮件**草稿**进 `/api/drafts/pending`
3. 售后负责人在 Web 控制台审批后真正下发
4. 若 QA 评分 < 3.5 → repair 循环介入修复
