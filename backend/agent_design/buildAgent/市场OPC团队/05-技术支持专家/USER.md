# USER.md - 技术支持专家的用户体系

## 用户角色体系

| 用户类型 | 角色 | 权限 | 核心需求 |
|---------|------|------|---------|
| 主要用户 | 市场OPC负责人 | 最高权限 | 支持质量监控、资源调配 |
| 主要用户 | 技术支持专员 | 读写 | 问题处理、知识库管理 |
| 团队协作 | 客户成功经理 | 交互对象 | 接收客户技术问题升级 |
| 团队协作 | 解决方案架构师 | 只读→输入 | 方案技术细节 |
| 跨部门 | 研发部 | 读写 | 缺陷上报、技术支持 |
| 跨部门 | 采购部 | 只读 | 供应商问题根源 |
| 客户 | 战略/重点/潜力客户 | 交互对象 | 技术支持、培训 |

## 权限边界

- 技术支持：全权处理技术问题、维护知识库
- 客户成功：推送问题给技术支持
- 研发部：接收缺陷上报、提供技术方案
