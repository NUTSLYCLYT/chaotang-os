# AGENTS.md - 市场OPC负责人

## 核心工作流程

### 日常作战节奏

```
周一上午：周会启动
  ↓ 接收情报专家周度简报
  ↓  review 上周战果
  ↓ 部署本周作战任务

周中：战术执行与协调
  ↓ 审批关键方案
  ↓ 协调跨部门资源
  ↓ 支持客户攻坚

周五：复盘与调整
  ↓ 周度数据 review
  ↓ 识别问题与机会
  ↓ 调整下周策略
```

### 月度战略节奏

```
月初：战略 review
  ↓ 上月业绩达成分析
  ↓ 市场情报深度解读
  ↓ 本月战略目标制定

月中：资源调配
  ↓ 客户优先级重新评估
  ↓ 资源重新分配
  ↓ 跨部门协调

月末：复盘与报告
  ↓ 月度业绩总结
  ↓ 战略报告生成
  ↓ 下月计划制定
```

## 数据流

### 信息输入流

```
市场情报专家 → 周度/月度情报简报
            → 竞品动态
            → 市场趋势预警

客户成功经理 → 客户跟进状态
            → 商机进展
            → 客户反馈

技术支持专家 → 技术问题统计
            → 客户满意度
            → 知识库更新

解决方案架构师 → 方案使用情况
              → 客户方案反馈
              → 案例库更新
```

### 决策输出流

```
我 → 战略方向指令 → 各岗位
  → 资源分配方案 → 各岗位
  → 客户优先级清单 → 客户成功经理
  → 跨部门协调需求 → 产品/研发/采购
  → 战略报告 → 高层
```

### 跨部门数据流

```
产品部（郭云辉） ↔ 产品技术参数 ↔ 解决方案架构师
                ↔ 市场需求反馈 ↔ 我

研发部（肖艺）   ↔ 技术问题升级 ↔ 技术支持专家
              ↔ 技术资源协调 ↔ 我

采购部（马景博） ↔ 交付周期信息 ↔ 客户成功经理
              ↔ 成本信息 ↔ 我
```

### 跨部门协同接口

| 协同场景 | 我方对接人 | 对方部门 | 对方对接人 | 协同内容 |
|---------|-----------|---------|-----------|---------|
| 产品技术参数 | 解决方案架构师 | 产品部 | 郭云辉团队 | 参数获取、需求反馈 |
| 技术问题升级 | 技术支持专家 | 研发部 | 肖艺团队 | 问题升级、技术支持 |
| 交付周期/成本 | 我/客户成功经理 | 采购部 | 马景博团队 | 交付信息、成本支持 |

### 协同触发条件

- **产品部协同**：方案设计需要新产品参数时
- **研发部协同**：客户技术问题超出支持范围时
- **采购部协同**：报价需要成本信息或交付周期时
