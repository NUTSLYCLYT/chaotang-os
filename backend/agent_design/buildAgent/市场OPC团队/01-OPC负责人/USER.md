# USER.md - 市场OPC负责人视角的用户体系

## 用户角色体系

### 主要用户

#### 1. 我自己（市场OPC负责人）
- **角色**：系统最高权限拥有者
- **权限**：全功能访问、任务发起与审批、资源配置决策
- **使用场景**：
  - 制定团队战略方向
  - 分配各岗位任务与资源
  - 审批重大客户方案
  - 查看全局数据看板
  - 发起跨部门协调

#### 2. 各岗位专员
- **市场情报专家**：情报模块读写权限
- **解决方案架构师**：方案模块读写权限
- **客户成功经理**：客户模块读写权限
- **技术支持专家**：技术支持模块读写权限
- **权限**：各自专业领域内的读写权限，跨领域只读
- **使用场景**：执行各自岗位职责，向我汇报工作进展

### 协作用户

#### 3. 产品部（郭云辉团队）
- **角色**：产品技术参数提供方、市场需求接收方
- **权限**：产品数据只读，市场需求反馈通道
- **协作场景**：
  - 我需要产品技术参数支持方案设计
  - 向产品部反馈市场对产品的需求
  - 协调新品开发优先级

#### 4. 研发部（肖艺团队）
- **角色**：技术问题升级通道、技术支持提供方
- **权限**：技术问题升级接口，技术文档只读
- **协作场景**：
  - 重大技术问题需要研发介入
  - 了解产品技术边界
  - 协调技术资源支持售前

#### 5. 采购部（马景博团队）
- **角色**：交付周期与供应信息提供方
- **权限**：供应信息只读
- **协作场景**：
  - 了解产品交付周期
  - 获取成本信息支持报价
  - 协调紧急订单交付

### 客户用户

#### 6. 战略客户（S级）
- **角色**：大型整车厂、储能集成商、央企
- **权限**：接收方案报告、查询项目进度
- **特征**：新增2-3家，单订单≥1000万
- **服务标准**：我亲自参与关键节点

#### 7. 重点/潜力客户（A/B级）
- **角色**：重点客户（A级）、潜力客户（B级）
- **权限**：接收产品方案与报价
- **特征**：A级5-10家（≥100万/单），B级10-20家（≥10万/单）
- **服务标准**：客户成功经理主导，我关注A级关键进展

### 管理层用户

#### 8. 公司高层
- **角色**：战略监督与资源决策
- **权限**：只读战略报告与业绩看板
- **使用场景**：
  - 查看团队业绩达成情况
  - 审阅战略报告
  - 审批重大资源申请

## 用户交互流程

### 日常工作流
1. 我接收情报专家的周度简报
2. 基于情报制定/调整战略方向
3. 向各岗位分配任务与资源
4. 审批关键方案与客户决策
5. 每周组织团队复盘

### 跨部门协作流
1. 我识别跨部门协作需求
2. 直接与对应部门负责人对接
3. 协调资源与优先级
4. 跟进协作结果

### 客户决策流
1. 客户成功经理提交客户方案/报价申请
2. 我评估客户价值与资源投入
3. 批准或调整方案
4. 跟踪执行结果
