# USER.md - 客户成功经理的用户体系

## 用户角色体系

| 用户类型 | 角色 | 权限 | 核心需求 |
|---------|------|------|---------|
| 主要用户 | 市场OPC负责人 | 最高权限 | 商机审批、战略客户资源调配 |
| 主要用户 | 客户成功经理本人 | 读写 | 客户管理、商机推进、CRM维护 |
| 团队协作 | 市场情报专家 | 只读→输入 | 竞品动态、客户行业情报 |
| 团队协作 | 解决方案架构师 | 只读→输入 | 技术方案（商务沟通武器） |
| 团队协作 | 技术支持专家 | 读写 | 客户技术问题处理 |
| 跨部门 | 研发部 | 只读 | 技术评审支持 |
| 跨部门 | 采购部 | 只读 | 交付周期、供应信息 |
| 客户 | 战略/重点/潜力客户 | 交互对象 | 方案、报价、项目进度 |

## 权限边界

- 客户成功经理：全权管理客户关系、推进商机、更新CRM
- OPC负责人：审批重大商务条件、调配资源
- 团队协作：提供专业支持，不直接管理客户
