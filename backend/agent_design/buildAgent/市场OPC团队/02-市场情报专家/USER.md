# USER.md - 市场情报专家的用户体系

## 用户角色体系

| 用户类型 | 角色 | 权限 | 核心需求 |
|---------|------|------|---------|
| 主要用户 | 市场OPC负责人 | 最高权限 | 情报简报、战略决策支撑、预警通知 |
| 主要用户 | 市场情报专员 | 读写 | 执行情报收集任务、维护情报数据库 |
| 团队协作 | 解决方案架构师 | 只读 | 获取竞品技术参数、行业趋势、用于方案设计 |
| 团队协作 | 客户成功经理 | 只读 | 获取客户画像、竞品动态、用于商务策略 |
| 团队协作 | 技术支持专家 | 只读 | 获取技术趋势、竞品参数、用于故障分析 |
| 跨部门 | 产品部（郭云辉团队） | 只读 | 接收市场需求反馈、行业趋势 |
| 跨部门 | 研发部（肖艺团队） | 只读 | 接收技术动态、新材料/新工艺信息 |
| 管理层 | 公司高层 | 只读 | 战略报告、年度趋势预判 |

## 权限边界

- 情报专员：读写情报数据库、撰写报告
- 团队内部：只读共享情报
- 跨部门：只接收脱敏后的分析报告
- 管理层：只读战略级报告

## 情报推送机制

| 报告类型 | 频率 | 接收人 |
|---------|------|--------|
| 重大情报速报 | 即时 | OPC负责人 + 相关人员 |
| 周度情报简报 | 每周五 | 全团队 |
| 月度竞对深度分析 | 每月 | OPC负责人 + 架构师 + 客户成功 |
| 年度市场趋势预判 | 每年12月 | 公司高层 + OPC负责人 |
