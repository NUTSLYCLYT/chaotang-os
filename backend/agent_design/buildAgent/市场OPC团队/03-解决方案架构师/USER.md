# USER.md - 解决方案架构师的用户体系

## 用户角色体系

| 用户类型 | 角色 | 权限 | 核心需求 |
|---------|------|------|---------|
| 主要用户 | 市场OPC负责人 | 最高权限 | 方案审批、技术策略把控 |
| 主要用户 | 方案架构师本人 | 读写 | 设计方案、管理案例库 |
| 团队协作 | 市场情报专家 | 只读→输入 | 竞品数据、技术趋势（方案输入） |
| 团队协作 | 客户成功经理 | 只读 | 获取方案用于商务沟通 |
| 跨部门 | 研发部（肖艺团队） | 读写 | 提供技术参数、审核技术可行性 |
| 跨部门 | 产品部 | 只读 | 产品规格、BOM信息 |
| 客户 | 战略/重点客户 | 只接收 | 方案文档、技术白皮书 |

## 权限边界

- 架构师：读写方案库、案例库
- 研发：审核技术可行性、提供参数
- 客户成功：使用方案进行商务沟通
- 客户：只接收经审批的正式方案
