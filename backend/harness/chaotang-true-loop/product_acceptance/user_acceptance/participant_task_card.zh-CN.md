# W08 非开发用户验收任务卡

你正在帮助验证一个中文制造业/B2B 合同审查流程。请按自己的理解完成任务，不需要知道系统内部实现。

## 任务目标

请在浏览器里完成一次合同审查闭环：

```text
上传合同
-> 查看系统解析出的合同任务
-> 审查风险与证据
-> 补充证据或确认证据不足
-> 作出风险裁决
-> 生成 ContractReviewPack
-> 下载交付文件
-> 打开 /shiguan 回看审计记录
```

## 允许使用

- `/shangshufang`
- `/shiguan`
- 主持人提供的合同样本
- 页面上已经提供的按钮、输入框、下载入口和审计入口

## 不允许

- 让工程师一步一步告诉你点哪里
- 使用开发者工具、数据库、接口调试工具或代码仓库
- 用截图替代系统生成的下载文件或审计记录
- 让主持人替你完成审查、下载或审计回看

## 完成标准

你认为任务完成时，应能做到：

- 已看到合同被解析成可审查任务
- 至少审查过一个带证据的风险项
- 对证据不足的地方做过补证或明确确认
- 已作出风险裁决
- 已生成并下载 ContractReviewPack 或对应交付包
- 已在 `/shiguan` 打开只读审计回看

## 反馈

完成或中途卡住后，请用自己的话说明：

- 哪一步最清楚
- 哪一步最困惑
- 是否需要别人解释才继续
- 下载文件和审计回看是否能被你重新找到

请不要在反馈里写入真实姓名、手机号、公司机密、客户名称或合同敏感金额。
