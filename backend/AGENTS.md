# 后端 Agent 工作入口

作用域：`backend/`。当前没有后端实现，也没有已批准的语言、运行时或命令。

## 边界

- 这里只放后端运行/评测工程及其验证，不实现前端内部功能。
- 不要猜测语言、服务形态、存储或 agent runtime；以已验证决策为准。

## 首次搭建要求

首次引入后端技术栈时，在同一变更中：

1. 用最小原型验证语言、运行方式和评测方式的关键假设。
2. 在 `docs/decisions/` 记录选择和取舍。
3. 更新本文件，登记准确的 setup、lint、test、run/eval 命令，并接入 CI。
4. 让 agent 能直接读取测试、日志和必要的本地运行状态；工具优先提供非交互接口、
   可操作错误信息和安全的 dry-run。
