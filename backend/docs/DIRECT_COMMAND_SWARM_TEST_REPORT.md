## 四、路由策略变更

本轮优化没有重构路由器，只增加了一层高精度业务词优先级：

1. 简单问答仍然直接走 `direct/llm`。
2. 命中明确业务域词时，优先路由到对应 `swarm`。
3. 未命中明确业务域词但包含策略、规划、方案、决策等泛战略词时，路由到 `court/court`。
4. 无明确领域时继续兜底到 `court/court`。

这个策略保留了 `新产品研发规划`、`多部门协作方案`、`公司年度规划` 等真正战略任务走 `court`，同时修复了 `PACK设计方案评审`、`小红书内容策略` 等领域任务被泛战略词抢走的问题。
