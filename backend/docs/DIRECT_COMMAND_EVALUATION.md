## 二、路由系统深度评估

### 2.1 路由算法分析

#### 决策流程
```
用户命令输入
     ↓
[1] 简单问答检测?
     ├─ 是 → Direct LLM (<1s)
     └─ 否 ↓
[2] 战略关键词检测?
     ├─ 是 → Court 丞相 (>10s)
     └─ 否 ↓
[3] 领域关键词匹配?
     ├─ 是 → Swarm 直连 (3-30s)
     └─ 否 ↓
[4] 默认 → Court 丞相
```

#### 复杂度评分机制
```python
复杂度 = 基础分(1.0)
        + 领域匹配分(0~2.0)
        + 战略关键词分(0~1.5)
        + 长度加成(0~1.5)
```

#### 关键词匹配策略
- 精确匹配: 完整单词匹配，权重 3.0
- 子串匹配: 包含关系，权重 1.0
- 优先级加权: 解决冲突

### 2.2 Swarm领域覆盖
