# 史馆的作用 + 全院飞轮 + 系统自我进化

> 定稿 2026-07-01。讲清三件事:① 史馆是什么、干什么;② 它怎么和各部门拧成飞轮;③ 整个系统怎么靠它越跑越聪明。
> 全部对应真实模块,不是概念。

## 一、史馆是什么:朝堂的「记忆 + 复盘脑」

史馆不产出对客决策(那是六部的活),它是**留住一切、回流一切**的器官。两个职能:

1. **护身符(对外)**:每个决策连同**证据链 + 来源标签 + 当时依据 + 谁签的字**一起封存。出事时一键调出"我当时基于这些做了合理决策"——这是让企业主睡得着的东西。
2. **进化燃料(对内)**:每次决策都是一条训练样本。史馆把它回流进系统,让下一次更准。

**真实模块**:
- `src/shiguan_archive.py` —— 四官流水线归档(`flow_shiguan_archive.yaml`)。
- `src/truth_ledger.py` —— 确定性留痕 + 可信度 + 幂等(脏数据入库前把关)。
- `src/db/models.py: Retrospective` —— 结构化复盘(score/successes/failures/lessons)。
- `src/court_flywheel.py` —— 朝会产出回流知识库(grounding)。
- `src/failure_memory.py` —— Reflexion 失败记忆(同类坑不再踩)。
- `src/signoff_learning.py` —— 皇帝签字=学习信号 + 失败自愈环。

## 二、史馆怎么和各部门拧成飞轮

每个部门一次产出,都走这条闭环,史馆是收口 + 回流的那一环:

```
六部执行(蜂群)→ 出 court_doc(灯+items+证据)
        ↓
御史定灯(绿黄红黑)
        ↓
【史馆归档】证据链 + 来源 + 灯 + 签字  ← 护身符就在这步成形
        ↓ 回流三股(都接史馆)
   ┌────────────────┬───────────────────┬────────────────────┐
   ① court_flywheel  ② failure_memory     ③ signoff_learning
   归档→知识库         红灯/失败→失败记忆      签字=学习信号→自愈
        ↓                ↓                    ↓
   下次同类问题          下次同类坑            下次同类决策
   检索得到过往          自动预警规避          带上人类偏好
        ↓
   六部决策更准（回到顶端，但起点更高）
```

**关键:回流是有方向的**——
- 部门**产出**喂史馆(归档);
- 史馆**回流**喂部门(下次检索到过往同类、避开记录在案的坑、带上签字偏好)。

所以每个部门和史馆之间是一对"产出↔回流"的小飞轮,11 个部门 = 11 个飞轮共享同一个史馆记忆池。

## 三、整个系统怎么自我进化(PDCA 大飞轮)

史馆的"归档+回流"是**每日大飞轮**的一环。完整一圈(`scripts/nightly_flywheel.py` 调度):

| 环节 | 干什么 | 真实零件 |
|---|---|---|
| ①跑 | golden cases + 真实/合成流量跑一遍 | `validate_flows` / 真实 runs |
| ②评 | 每域 / 每大神 / 每 skill 打分 | `eval_ci` / `persona_eval` |
| ③诊 | 找最弱域、最弱大神、回退项 | `flywheel.diagnose_weakest` / `baseline_compare` |
| ④提 | 生成改进候选(改 prompt/skill/大神/补料) | `prompt_versions` / `ab_test` |
| ⑤验 | **硬棘轮门**:候选须打败 `quality_baseline` 才晋升 | `nightly_flywheel.ratchet_gate` |
| ⑥升 | 赢了才晋升,输了丢弃 | `persona_eval.promotion_gate` |
| ⑦档 | **史馆**:写复盘 + 失败记忆,回流知识库 | `shiguan_archive` / `Retrospective` / `failure_memory` |
| ↑回流 | ⑦的产出回流到 ① 的 grounding | `court_flywheel` |

**史馆是 ⑦档 + 回流这一环**:它把每圈学到的固化下来、回流回去,让下一圈的**起点更高**。没有史馆,系统每天从零开始;有史馆,系统每天站在昨天的肩上。

### 两个保证,缺一不可

1. **硬棘轮门(只升不降)**:`ratchet_gate` 保证进化候选必须用数据打败基线才晋升,否则自动拒绝——防止系统把自己越进化越差(戴明:没有门的自动进化=自动退化)。
2. **史馆(学习不丢)**:`shiguan_archive` + 三股回流保证每次的学习被固化、被回流——防止系统"学了就忘"。

**棘轮门管"不退步",史馆管"会记事"。两者合起来,系统才真正越跑越聪明。**

## 四、一句话收口

> 六部是手(执行),大神/律师是嘴(参谋),御史是闸(裁决),court_doc 是脸(呈现),
> **史馆是记忆和复盘脑**——它把每张脸连同证据封存成护身符,又把每次决策回流成燃料,
> 配上硬棘轮门"只升不降",整个朝堂就成了一个**每天站在昨天肩上、越判越准**的自我进化系统。
