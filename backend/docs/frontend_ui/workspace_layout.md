# 朝堂工作台总布局 + 前后端对齐 + 各部门内容天才建议

> 2026-07-01。给前端仓 `chaotang-web-lyt`。在原设计上升级为**三栏 + 中卷轴 + 底部双 agent 对话**的单一工作台。
> 机器面 court_doc 在本后端;本文定"哪个字段进哪个区",确保信息能传递。

## 一、总布局(三栏 + 中卷轴 + 底部对话)

```
┌───────────┬──────────────────────────────┬───────────┐
│ 左栏·上下文 │      中·卷轴(court_doc 主角)   │ 右栏·证据行动│
│ 部门/任务流 │  ⚖️ 判决 案号  🟡灯  一句结论    │ 证据链 ⛓    │
│ 难度档徽章  │  🛡 为你挡了什么               │ 出场大神    │
│ 进度        │  致命项 Top(渐进展开,红置顶)  │ 接地/门/签字 │
│            │  …往下滚才见法条/细节…          │ [一键改][存证]│
│            │                              │ 军机处难度面板│
├───────────┴──────────────────────────────┴───────────┤
│ 💬 丞相：你说,我来办…                    〔钦天监·大事时探头〕│
└──────────────────────────────────────────────────────┘
```

**三区各司一职,不互抢**:左=你在哪、中=结论是什么、右=依据与行动、底=跟谁说。

## 二、前后端对齐(信息传递契约:哪个区 ← 哪个字段/接口)

| 区 | 绑定后端 | 展示 |
|---|---|---|
| **左栏** | `GET /api/tasks` + `difficulty_assessor.panel_row` | 任务列表 + 难度档徽章(P0-P3)+ 进度 |
| **中卷轴** | `court_doc`(`schemas/court_doc.json`)| `light/headline/shielded/items[]/adversarial/seal` —— 结论在上,细节滚下 |
| **右栏** | `court_doc.provenance` + `items[].evidence_ref` + `court_doc.actions` + `panel_row` | 证据链回链、出场大神、接地/门/签字态、行动按钮、难度分 |
| **底栏·丞相** | `shangshufang_entry.handle(command)` | 单一对话,后台六部/御史/史馆全藏,只回结果+面板 |
| **底栏·钦天监** | `handle` 返回 `needs_signoff=true` / 不可逆 → 钦天监探头 | ≤3 必答问题 + 签字闸 |

**渲染铁律(接宪法 C6/C8,全区必守)**:`gate=pending`/`grounding=none` 绝不渲染成绿;灯照搬不美化;`signed=false` 不可逆按钮置灰。

## 三、底部双 agent(单一门面的灵魂)

- **默认只有丞相一个对话框**:你一句话 → 丞相调度后台 → 中卷轴出卷宗、右栏出依据。老板全程只跟丞相说话。
- **钦天监只在大事探头**:`needs_signoff`/不可逆时,底栏右侧浮出钦天监——问你最多 3 个必答的、给选项、要签字。平时不出现。
- 御史/史馆/六部**经丞相之口**抵达(丞相说"御史拦了,这处改一下"),不做成用户要分别对话的衙门。

## 四、各部门·中卷轴内容天才建议(每部门一刀)

| 部门 | 中卷轴主视觉 | 天才建议(效率简洁) |
|---|---|---|
| **刑部** | 判决卡 | 灯 + "改哪 3 处" 置顶;红蓝对抗"对方会从这打你"放**右栏警示**;法条折二级 |
| **户部** | 三柱横排 | 赚不赚/现金跑道/最坏赔 **一屏三柱**,每个数字 hover 显来源;跑道条是主视觉;缺数据显"需补"不造假 |
| **礼部** | 单版本话术 | 中卷轴只放**推荐那一版**,语域 tab + 禁忌词红标放**右栏**;别一上来堆三版本 |
| **兵部** | 下一步动作清单 | 中卷轴=可勾选的成交动作;异议→话术做成**右栏抽屉**;SPIN/竞品折二级,一线只见"当场说的那句" |
| **工部** | 验收单 | 灯 + **重算偏差对比表(claimed vs 重算)**;UNKNOWN 盖"不予验收·需人工"印,禁假 PASS |
| **吏部** | 任免/权限判 | 中卷轴=权责判;**大神龙虎榜(persona_eval 分)放右栏**;升降席=签字动作 |
| **钦天监** | 3 必答问题卡 | 中卷轴=**≤3 张选择题**(不是问答),每问的大神可选答案+推荐放右栏;签字闸沉底 sticky |
| **史馆** | 证据链时间线 | 中卷轴=可回链 ⛓ 时间线;飞轮看板 + "一键调护身符"放右栏;无源一律标"待考" |
| **锦衣卫** | 异动 delta | 中卷轴=新增/消失/突变三态;可信度分级徽章 + 来源链放右栏;脏情报显"挡门外"不隐藏 |
| **御史** | 四灯总判 | 中卷轴=绿黄红黑总判;放行/驳回开关(两步签字)放右栏;**黑灯→隐藏放行键 + "落刑部"跳转** |
| **丞相** | 主线时间轴 | 中卷轴=各部门卡按灯严重度排,**源部门灯锁定不可改**(C8);拟旨预览 + "确认开工"在底栏 |

## 五、效率简洁三原则(全部门通用)

1. **一屏给结论,滚动给细节**:中卷轴首屏只要 灯+headline+shielded+Top3,法条/数据/理论全折二级。
2. **左右栏随中卷轴联动**:点中卷轴一条风险,右栏跳到它的证据/法条;不让用户来回找。
3. **底栏永远是丞相**:一个对话框解决一切,钦天监只在大事探头——**能藏住多少复杂度,就能卖多高的价。**
