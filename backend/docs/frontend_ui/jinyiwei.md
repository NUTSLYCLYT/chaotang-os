## ① UI 定位:这张卡到底回答客户什么

锦衣卫卡不是"行业现状报告",是**外部之眼的决策就绪预警**。一屏必须替客户回答四个问题,顺序固定:

1. **竞品/市场变了什么?** —— 异动雷达(本轮 vs 上轮 delta),不是快照。
2. **这条情报能不能信?** —— 每条异动右侧挂**可信度等级徽章**(一手 / 二手多源 / 二手单源 / 待核 / 未证实)。
3. **有没有该提前预警的?** —— 红/黄/绿灯异动卡,红项(突变追平卖点、强对手入局)置顶。
4. **锦衣卫替我挡了什么?** —— `shielded` 心意条:把"没让脏情报污染你决策"这个看不见的价值显性化。

与其他部门卡的差异(前端要做出区分,不能一套灰卡套到底):
- 别的部门 `items` 是风险/成本/情景;锦衣卫 `items` 是**异动项**,每项天然带 delta 类型(新增/消失/突变/持续)。
- 别的部门 `odds` 是赔率(高/中/低);锦衣卫 `odds` 承载的是**情报可信度等级**字符串(见 §3)。
- 锦衣卫独有"**挡库外**"语义:`decision=待核/拒` 的脏情报要可见地标"已挡在决策库外",而不是隐藏——挡门外本身是卖点。

视觉气质:夜行卫所的冷峻。**玄黑底 + 暗红描边**,楷体/宋体标题,现代无衬线正文。古典肃杀,现代可读。

## ② 主屏卷宗卡 ASCII(套 court_doc)

字段映射:`case_id`→案号;`light`→顶灯+边框色;`headline`→结论一行;`shielded`→心意条;
`items[]`→异动列表(`level`灯 / `title`异动描述 / `odds`可信度等级 / `impact`对我方影响 / `fix`建议动作 /
`evidence_ref`回链);`seal`→骑缝绣春刀印 + 史馆封存号;`actions[]`→底部按钮;`provenance.gate`→需人工复核印。

```
┌────────────────────────────────────────────────────────┐
│ 🗡 锦衣卫 · 谍报      〔绣春刀印〕   案号 JYW-20260701-014 │  ← 楷体标题 + 玄黑暗红官印(右上)
│ ════════════════════════════════════════════════════════ │  ← 顶部黄灯条 + 整卡暗红描边
│ 🟡 竞品 -40℃/90% 追平你的卖点,供应链冒出 1 个该盯的口子  │  ← headline 结论一行(楷体大字,人话在前)
│                                                          │
│ 🛡 锦衣卫为你挡了:1 条 AI/媒体编的『GJB 认证』脏情报没进库 │  ← shielded 心意条(高亮小字)
│                                                          │
│ 📡 异动雷达 · 本轮 vs 上轮(4 项变化)        〔展开 ▸〕  │  ← 渐进展开,默认折叠原始情报
│ ┌──────────────────────────────────────────────────────┐ │
│ │🔴 突变 宁德 -40℃ 容量 80%→90%(+12.5%) │一手·官网│追平卖点│→│  ← level红/odds可信度徽章/impact/回链↗

│ │🟡 待核 YY『GJB 认证』(媒体单源·硬声明) │待核·挡库外│?未定 │→│  ← 暗红边框 + "挡库外"标记
│ │🟡 消失 某低温电解液产品下架             │二手·2源 │供应险 │→│
```

二级展开(点某条异动 → 钻取详情):

```
  ▾ 🔴 突变 宁德 -40℃ 容量保持率 80%→90%

     可信度:一手(官网公告)· distinct_sources=1 · primary=true

```

## ③ 组件清单

### 共享卷宗组件(全院复用,锦衣卫只换印 + 主色)
- `CourtDocCard` —— 卷宗外壳(标题栏 / 灯条 / headline / items / actions / seal 落款)。
- `SealStamp` —— 官印组件,吃 `seal.stamp`+`seal.color`;锦衣卫传 `绣春刀印` / `玄黑暗红`。
- `LightBadge` —— 红黄绿黑灯,驱动顶条与整卡描边色。
- `ShieldedBanner` —— 心意条(`shielded`,可空则不渲染)。
- `ActionBar` —— `actions[]` → 按钮;`signed=false` 的不可逆动作置灰。
- `EvidenceLink` —— `evidence_ref`(`truth://...`)→ 回链史馆/truth_ledger。
- `ProvenanceFooter` —— `source_label` + `advisors` + `gate` + `signed` 落款。
- `PendingReviewStamp` —— `gate=pending` 半透"需人工复核"盖印。

### 锦衣卫特有组件
- `CredibilityBadge`(可信度分级徽章)—— 渲染 `odds` 字符串,5 档配色,见 §4。脏情报档(待核/未证实)走暗红 + "挡库外"角标。
- `ChangeRadar`(异动雷达 delta 视图)—— 把 `items[]` 按 delta 类型分组渲染,每项前缀 delta 图标:
  - 🔴/⊕ **新增**(detect_change `新增`)、⊖ **消失**(`消失`)、⤴ **突变**(`突变`,展示 from→to/delta)、≈ **持续**(`持续`,默认折叠或弱化)。
  - 提供"只看突变 / 只看新增消失 / 全部"切换;突变项渲染数值跳变条(from → to)。
- `IntelSourceChain`(情报来源链)—— 二级展开里展示 `distinct_sources` 来源条目、`primary` 是否一手、跨源印证数;
  支持点开"查看台账原文"跳 truth_ledger。
- `HardClaimFlag`(硬声明拦截标)—— `hard_claim=true` 且非一手时,贴"硬声明·非一手·已挡"暗红角标,解释为何判待核。

## ④ 状态映射(灯 + 可信度 + 闸)

### 顶灯 `light`(court_doc 标准四灯)
| light | 含义 | 卡描边 / 顶条 |
|---|---|---|
| green | 有利异动 / 无威胁 | 暗绿描边 |
| yellow | 出现该盯的异动(竞品追平、新对手) | 暗黄描边(默认锦衣卫常态) |
| red | 高危异动(卖点被全面超越、黑天鹅前兆) | 暗红描边 + 顶条闪烁一次 |
| black | 落刑部深查(疑似情报投毒/对手放假料) | 玄黑描边 + 獬豸转交提示 |

### 异动项 `odds`(可信度等级,真实来自 `vet_intel.grade`)
| odds 文案 | 来源 | 徽章配色 | 行为 |
|---|---|---|---|
| `一手(官网公告)` / `一手` | `grade=一手`,`primary=true` | 暗金 | 可直接采信,入库=PASS |
| `二手(N源印证)` / `二手·N源` | `grade=二手(多源印证)`,`distinct_sources≥2` | 钢灰 | 入库=PASS,标二手 |
| `二手(单源)` | `grade=二手(单源)` | 暗黄 | UNKNOWN,待补证 |
| **`待核(硬声明·非一手)`** | `decision=待核`,`hard_claim=true` | **暗红 + 挡库外角标** | **绝不渲染成已入库**,显式"需人工查原文" |
| `未证实` | `grade=未证实` / `decision=拒` | 灰红删除线感 | 拒入库=FAIL,可见但标"未进决策库" |

### 御史闸 `provenance.gate`
- `passed` → 正常渲染。
- `pending` → 整卡盖 `PendingReviewStamp` 半透印,**禁渲染成绿灯/已通过**,顶灯不得显示 green(接宪法 C6 禁假 PASS)。
- `blocked` → 顶部红条"已封驳",actions 仅留"查看封驳理由"。
- `n/a` → 不显示闸标。

### 脏情报特例(锦衣卫核心)
`decision ∈ {待核, 拒}` 的条目**必须可见**且标"**挡库外 / 未进决策库**",用暗红边框。这是把"为你挡了脏情报"
具象化的关键——不能因为没入库就隐藏掉。`shielded` 同步汇总"挡了几条"。

## ⑤ 交互(P0–P3 复杂度分档 + 异动钻取 + 来源核验)

接本仓管线复杂度分档(P0 琐碎 → P3 不可逆),前端按档位决定交互重度:

- **P0 浏览(看快照)**:卡只读渲染,异动雷达默认展开"突变+新增+消失",持续项折叠。无副作用。
- **P1 钻取(看某条为什么)**:点异动项 → 展开二级(delta from→to、可信度、来源链、建议动作、证据回链)。纯前端展开,不调后端。
- **P2 来源核验(信不信)**:点 `CredibilityBadge` 或"查看台账原文" → 跳 `evidence_ref`(`truth://jinyiwei/...`)
  打开 truth_ledger 该条留痕(等级/来源/理由/verdict)。待核项额外给"标记已人核 → 申请入库"入口(写回 vet)。
- **P3 不可逆下游动作**:`actions` 里 `push_battlecard`(改兵部 battlecard)、`escalate_qintianjian`(上呈钦天监预警)
  属影响下游决策的动作 → `signed=false` 时**置灰**,必须人工签字态才可点;点前弹确认("此动作将改写兵部弹药/触发钦天监参谋")。

核验交互细节:
- **异动钻取**:突变项展开必须显示 `from → to` 跳变条与 `delta`(detect_change 真数值),不能只给文字"提升了"。
- **来源核验**:来源链逐条列 `distinct_sources`,标每条是一手/二手;`hard_claim=true` 项高亮"硬声明",解释判待核逻辑。
- **挡库外可点**:待核/拒的脏情报点开后给"为什么挡"(vet `reason` 原文,如"含硬声明且非一手 → 必须人工核实再入库")。

## ⑥ 空 / 加载 / 错误态

- **加载态**:骨架屏保留卷宗外壳 + 绣春刀印灰印水印,文案"锦衣卫巡查中…(采集卫 → 核查卫 → 整理卫)",对应三卫蜂群三段进度。
- **空异动(本轮无变化)**:`items=[]` 时不画空表,显示绿灯 + "📡 本轮无异动 · 上轮 N 项均持续",给"查看上轮快照"次级入口。**空不是失败**,是"外面没动,你可以安心"。
- **未能获取真实信息**:后端铁律"绝不编造充数"。`source_label=FALLBACK` 或采集卫报空 → 显式横幅
  "⚠ 本轮未能获取可信外部情报,未生成异动(锦衣卫不编造充数)",**绝不**用旧快照伪装新预警。
- **被投毒/全待核**:所有 `items` 均 `decision=待核/拒` → 顶部暗红条"本轮情报可信度不足,均挡在库外,建议人工核验后再决策",顶灯禁 green。
- **错误态**:接口失败 → "锦衣卫失联,无法核查情报"占位,提供重试;不渲染任何未经 vet 的原始情报(防止脏数据漏网)。

## ⑦ 响应式

- **桌面(≥1024)**:卡片宽 ~720px,异动表四列(异动描述 / 可信度徽章 / 对我方 / 回链)。
- **平板(768–1023)**:可信度徽章换行到描述下方,impact 与回链合并到右侧小列。
- **移动(<768)**:异动项改纵向卡堆叠——每条:第一行 delta 图标 + 描述;第二行 可信度徽章 + impact;第三行 建议动作(可折叠)+ 回链。
  顶灯 / 官印 / shielded 始终置顶常驻。底部 actions 改吸底按钮条。
- delta 突变条在窄屏用紧凑 mini-bar(from→to),不显示完整刻度。

## ⑧ 对接 chaotang-web-lyt

- **数据源**:后端 `POST /api/intel/brief` 返回 §② 的 court_doc(`doc_type=brief`,`dept=jinyiwei`)。前端按 `schemas/court_doc.json` 校验。
- **组件落位**:复用 web 仓已有 `CourtDocCard` 骨架;新增锦衣卫特有组件(`CredibilityBadge` / `ChangeRadar` /
  `IntelSourceChain` / `HardClaimFlag`)放 `components/jinyiwei/`。
- **印章配置**:在全院印章品牌系统配置表补 `jinyiwei → { stamp: 绣春刀印, color: 玄黑暗红 }`,由 `SealStamp` 驱动,**不为锦衣卫单独写一套卡**。
- **回链路由**:`evidence_ref` 形如 `truth://jinyiwei/<case>#<chgN>` → web 仓路由到 truth_ledger / 史馆查看页。
- **渲染纪律(接 frontend_handoff §四,必须守)**:
  1. `gate=pending` / `decision=待核/拒` → **绝不**渲染成绿灯/已入库,显式"需人工 / 挡库外"。
  2. 丞相主线(`doc_type=edict`)引用锦衣卫灯时**照搬不改**,前端不得美化成更乐观。
  3. `signed=false` 的不可逆动作(push_battlecard / escalate_qintianjian)置灰,签字态才可点。
  4. 原始情报默认折叠二级,一屏先给"变了什么 + 该不该动"——情报是预警,不是阅读材料。
- **边界**:本卡的 CSS / 组件 / E2E 在 chaotang-web-lyt 实现;本仓只保证 court_doc 字段真实可用,不在此仓写页面。
