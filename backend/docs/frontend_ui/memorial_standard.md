# 奏折标准版式（全院统一 · 黄金分割 · 每部每司标准化）

> 2026-07-01。给前端仓 `chaotang-web-lyt`。全院一张奏折卡,换印换色换图表,骨架不变。
> 数据契约 = `schemas/court_doc.json`(已扩:opinion/endorsements/charts/attachments/workflow)。

## 二、区 ← court_doc 字段(前后端对齐)

| 区 | ← 字段 | 展示 |
|---|---|---|
| 顶栏 | `seal.stamp/color` `doc_type` `case_id` `light` | 部印 + 灯 + 案号 |
| **正文 0.618** | `headline` `shielded` `items[]`(+`charts`)| 精简结论 + 挡了什么 + Top(带图表)|
| **意见+附议 0.382** | `opinion{by,summary,detail,advice}` `endorsements[]` | 丞相/钦天监意见 + 部门附议 |
| 底栏(小字) | `provenance` `workflow[]` `seal.sealed_archive` | 数据来源 + 工作流 + 骑缝留痕 |
| 主行动 | `actions` + 标准四钮 | 准奏/驳回/批阅/裁决 |
| 附件 | `attachments[]` | 下载合同原文/证据/报表 |

## 三、标准按钮(全院一致)

- **裁决四钮**:`准奏`(通过执行,需 signed)/ `驳回`(打回源部门)/ `批阅`(人工加注)/ `裁决`(升皇帝终审)。
  - 铁律:`gate=pending`/`grounding=none`/`signed=false` → `准奏` 置灰(接宪法 C6/C8)。
- **展开**:正文/意见都有 `[展开→圣旨全文]`(精简版在卡上,详情在圣旨全文页 `detail`)。
- **导航**:`下一页`(多奏折翻页)/ `回首页` / `去军机处`(进度总览面板)。

## 四、每部每司·内容 + 图表标准化(数据尽量配图)

| 部/司 | 正文主内容 | 标准图表(charts.type) |
|---|---|---|
| 刑部 | 判决 + Top风险 | `bar` 风险赔率(B<P×L 条形) |
| 户部 | 三柱:赚不赚/跑道/最坏赔 | `line` 现金跑道 + `pie` 成本构成 |
| 工部 | 验收 + 重算对比 | `bar` claimed vs 重算 偏差柱 |
| 礼部 | 推荐话术单版本 | `bar` 触达/信任评分 |
| 兵部 | 下一步成交动作 | `funnel/bar` 客户路径漏斗 |
| 吏部 | 任免/权限判 | `radar` 绩效多维 + 大神龙虎榜 `bar` |
| 钦天监 | ≤3 必答问题 + 情景 | `radar` 情景概率 / 决策树 |
| 史馆 | 证据链 | `timeline` 时间轴 |
| 锦衣卫 | 异动 delta | `waterfall` 新增/消失/突变 |
| 御史 | 四灯总判 | `gauge` 灯态 + `line` drift 趋势 |
| 丞相 | 主线时间轴 | `timeline` 各部门灯(锁定不可改) |

> 司级(如户部下会计/出纳/预算司)复用同版式,只换该司的 items + charts 数据,**印章/骨架/按钮全不变**。

## 五、精简明了三原则

1. **卡上只放精简**:正文首屏只 结论+挡了什么+Top3+关键图表;法条/全文/详细分析全进 `[展开→圣旨全文]`。
2. **数据必配图**:凡数字相关(金额/赔率/跑道/绩效/异动)尽量给 mini 图表,一眼看懂胜过读数。
3. **黄金分割不破**:正文永远 0.618,意见+附议 0.382——主次一眼分明,全院一致的呼吸感。

## 六、边界

版式/图表/CSS/组件在前端仓 `chaotang-web-lyt` 实现;本文是**标准契约**,后端 court_doc 已能承载全部字段(opinion/endorsements/charts/attachments/workflow),前端照此渲染即信息无损传递。
