# 御史 · 功能 + 出场特效设计「獬豸投印」(天才设计)

> 它的"出场"不是装饰,**出场特效本身就是判决**——你还没读字,特效已告诉你这事多严重。
> 配套:[yushi.md](yushi.md)(御史 UI 策划)、[../dept_design/frontend_handoff.md](../dept_design/frontend_handoff.md)。

## 一、御史的功能与作用(先定清,再谈特效)

御史 = **全局放行总闸**,不是又一个评审。六部(刑部判法务、户部算 ROI、工部验 POC、钦天监定方向)产出后,**谁都不能自己宣布"可以上了"**,全部汇到御史定灯。

| 职能 | 干什么 | 真实台 |
|---|---|---|
| **release_gate** | 上线/发布/自动执行前定灯 绿/黄/红/黑 | `harness/yushi_global_gate/run_gate.py` + `rules.yaml` |
| **一票否决** | 数字无来源/越权自动执行/踩红线/证据缺 → 直接 block,收益不能赎买 | `src/yushi_gate.py` / `src/guard_rails.py` |
| **drift_monitor** | 蜂群/部门漂移 → 降权告警 | `src/governance.py` |
| **黑灯转刑部** | 最高危才落刑部红蓝对抗深查 | `EscalateToXingbuLink` |

**与刑部分工**:刑部是风险**护身符**(深查给依据),御史是放行**总开关**(定灯给放行)。獬豸——能辨曲直、触不直者——是这道闸的图腾。

## 二、天才设计:出场特效 =「獬豸投印」,特效即判决

**核心原则(don-norman):打扰强度 = 风险等级。** 绿灯几乎无感,黑灯獬豸现身。特效不是炫技,是**让人在读字之前就知道严重度**。一套"獬豸 + 官印 + 黑金"的视觉语言,按灯分四级出场:

### 🟢 绿灯 · 「金线一掠」(几乎无感,~220ms)
- 动作按钮旁,一道**金线**自左掠过(`transform: translateX` + `opacity`),獬豸金印**轻点**一下即隐。
- 无遮罩、无声、不挡操作。语义:**放行,别打扰你**。

### 🟡 黄灯 · 「卷宗落印」(就地展开,~400ms)
- 从你按的那个按钮位置,**卷宗自下而上展开**(`clip-path` 揭幕 + `transform: scaleY`),金线勾边。
- **獬豸金印盖下**(印章 `scale(1.2→1)` + `opacity`,带轻微墨晕),落在"放行条件"上方。
- 条件项逐条**渐显**(stagger 60ms)。语义:**能走,但带条件——看清这两条。**

### 🔴 红灯 · 「黑幕压顶 · 朱印驳」(阻断,~550ms)
- 半透**黑幕自上压下**(`opacity` 0→.55),獬豸纹在卡背**亮起暗金剪影**。
- 朱红"**驳**"印**重重盖下**(`scale(1.6→1)` + 一次性 6px 短震 `transform`,仅此一处用震),放行键同步**置灰锁死**。
- 语义:**挡住了,这事现在不能放。**

### ⚫ 黑灯 · 「獬豸现身 · 封」(最高仪式,需签字)
- 全屏**玄黑肃杀**(背景 `opacity` 压暗),屏幕中央**獬豸剪影自暗处浮现**(`opacity` + `filter: blur(8→0)`,金瞳点亮)。
- 朱砂"**封**"印**镇在案上** + **骑缝印**横贯,出现**落刑部光带**(金色 `clip-path` 流光指向"落刑部")。
- 这是**唯一接近"弹窗"的形态**——必须人工**两步签字**才解。语义:**高危,獬豸临门,落刑部 + 签字才动。**

## 三、贯穿四级的视觉母题(统一才高级)

- **獬豸**:越严重越清晰(绿=印上一角纹 → 黑=全兽现身)。
- **官印**:都是"盖"的动作,但力度/颜色随灯(金点 → 金盖 → 朱驳 → 朱封)。
- **黑金底 + 楷题**:御史台肃杀气一以贯之;金线是"放行",朱红是"否决"。
- **骑缝印**:每次放行/封驳都盖封存号(护身符具象,接 `seal.sealed_archive`)。

## 四、工程纪律(别让特效变负担)

1. **只用合成器友好属性**:`transform / opacity / clip-path / filter`,绝不动 `width/height/top/left`(防卡顿)。
2. **特效时长 ≤ 灯级**:绿 220ms → 黑约 800ms;**越严重越慢**,让人有时间反应。
3. **`prefers-reduced-motion`**:一律降级为**无动画的即时态 + 灯/印静态呈现**,语义不丢(护栏不因关动画消失)。
4. **特效不替代判定**:动画只表达**已定的灯**,绝不在前端"算"灯;`gate=pending`/`grounding=none` 一律走红/需人工态,不准用绿色金线"美化"(接宪法 C6)。
5. **黑灯签字闸**移动端 sticky 不随滚动消失(护栏在小屏也不能丢)。

## 五、一句话

> 御史出场 =「獬豸投印」:**绿灯金线一掠、黄灯卷宗落印、红灯朱印一驳、黑灯獬豸现身**。
> 特效即判决——打扰强度精确匹配风险,你在读字前就知道这事能不能放;最高危那一下獬豸临门、签字方解。
> 它不是炫技弹窗,是**让"按下放行键"既有底气、又有仪式、又留痕可回链**的那道肃杀金光。
