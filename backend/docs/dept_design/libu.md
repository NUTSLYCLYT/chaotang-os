# 礼部 · 天才设计与对外表达文书标准

> 定稿 2026-07-01。本文是"理一遍所有部门"中的礼部一份,套全院文书标准(真相源 `schemas/court_doc.json`,首份见 `docs/dept_design/xingbu.md`)。
> 视觉基调沿用全院:**卷宗×现代融合** —— 古典骨(青印/案号/骑缝/楷体)+ 现代肉(灯/卡/渐进展开)。
> 边界:本仓做**机器面(JSON 契约 + 后端)**;**人类面(话术卡渲染/CSS/组件)在前端仓 chaotang-web-lyt 实现**。

## 一、礼部定位

礼部 = 客户的**对外底气**,不是文案外包。卖的是"敢说、说得准、说得一致、不踩雷":
让客户拿着话术敢发、敢承诺、敢面对竞品,说的每句都有素材撑、有边界守、有多版本可选着用。
(协议定义:对外表达/品牌/客户话术/内容发布/关系礼仪;承诺缺证据、夸大 ROI、诱导话术、未签字 → 御史 red,落刑部。)

礼部的克制是产品级的:**客户看完应该知道下一步,而不是被话术绑架。**

## 二、五个震撼点

1. **一句话进,一张话术卡出**:内部方案大白话进 → 单屏话术卡(青灯+这么说行不行+Top3最打动客户的点+一句话改法+禁用词高亮),品牌规范藏二级。
2. **卖点反向工作(从客户摩擦倒推说什么)**:接兵部战情(`haolong`/`opc`)的真实客户摩擦反推"对这个客户说什么能打动",不堆参数;`customer_outcome` 回填后,被客户证伪的卖点自动降权。
3. **禁忌词/夸大雷达(发出去前拦)**:出稿前拦绝对化、无依据 ROI/交期承诺、贬损竞品、诱导话术——御史 red 门产品化(harness_gate 落地);硬声明无素材支撑必标红。
4. **品牌一致性指纹**:paula-scher 席守"一套口径"——主色青/语气/称呼/禁用句式做成品牌指纹,跨渠道(小红书/公众号/客户消息)一致,跑偏自动提示,接 `xiaohongshu`/`opc` 发布链路。
5. **多版本话术 + 留痕**:每条对外话术给 2-3 个语域版本(稳重/亲和/专业)客户挑着用;每发自动归档 `shiguan_archive`,带素材依据/签字,出事可调"基于真实素材的合规表达"。

## 三、文胆团(对外表达大神,带知识库)

复用大神体系(分席/RAG/eval),取 `advisor_protocols.yaml` 的 `content_growth` profile:

- **判官席**:zhang-xiaolong(克制·尊重·用完即走,守"会不会绑架客户")、seth-godin(许可式·"这话值不值得被听见",守"有没有真东西")坐堂——两席合判一句话:**真实且配得上客户的注意力**。
- **专科顾问**:
  - paula-scher —— 品牌视觉/口径一致性,守青色主色与品牌指纹;
  - zhang-yiming —— 渠道分发与算法适配,守"发对地方";
  - jobs —— 信息删减与"一句话讲清",守"别让客户猜";
  - naval —— 长期信任与杠杆,守"不为一次流量透支信誉"。
- **表达安全铁律**:对外稿**一律素材绑定**——硬声明(数字/ROI/交期/资质)无素材支撑必标红,命不中就降级为"需人工确认",不准当成已发布版。**幻觉话术比没话术更伤客户信任。**
- 每位配 golden 话术样本,过 eval(`persona_eval`)才升判官;成交/流失反馈回填后更新话术基线,同一套飞轮。

## 四、文书(brief)

套全院 `schemas/court_doc.json`,礼部 `doc_type=brief`、`dept=libu`、官印=**礼器印**、主色=**青**。

### 4.2 人类面 —— 礼部策案/话术卡(卷宗×现代渲染)

**艺术方向**:楷体/宋体标题 + 青色主色 + 宣纸微纹 + 现代无衬线正文 + 红黄绿灯卡 + 语域版本切换。古典庄重,现代可读。
(全院印章品牌系统见 `docs/dept_design/xingbu.md` §4.3:礼部=礼器印/青。)

## 五、心意三触点

1. 开头"**礼部为你争取了什么**"(把打动点/挡下的雷说出来,价值先于规则)。
2. 落款"**素材已核验·留痕已封存**"骑缝青印(对外底气具象化)。
3. 结论永远**人话在前、品牌规范在后**(表达不是规则手册,客户要的是下一步)。
