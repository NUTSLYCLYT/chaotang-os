# 刑部 · 天才设计与全院文书标准(第一份部门设计)

> 定稿 2026-06-30。本文是"理一遍所有部门"的第一份,顺带定下**全院文书标准**(后续部门复用)。
> 视觉基调(用户拍板):**卷宗×现代融合** —— 古典骨(朱印/案号/骑缝/楷体)+ 现代肉(灯/卡/渐进展开)。
> 边界:本仓做**机器面(JSON 契约 + 后端)**;**人类面(卷宗渲染/CSS/组件)在前端仓 chaotang-web-lyt 实现**。

## 一、刑部定位

刑部 = 客户的**风险护身符**,不是法务刹车。卖的是"底气":让客户敢签、敢上、敢承诺,出事有据可保命。
(协议定义:法务/合规/安全/红蓝对抗/事故惩戒;御史管全局闸,黑灯落刑部。)

## 二、五个震撼点

1. **一句话进,一张判决书出**:大白话进 → 单屏判决(灯+能不能+Top3赔率+一句话改法+自动留痕),法条藏二级。
2. **红蓝对抗(给合同做渗透测试)**:schneier 攻击者 + posner 法经济模拟"对方律师/监管/黑产怎么打你",指出"哪个口子没防住"。
3. **红线雷达(出事前拦)**:盯所有部门产出(报价/话术/承诺/高危自动化),踩红线主动拦——御史 release_gate/drift_monitor 产品化。
4. **证据链护身符**:每判自动归档 truth_ledger + shiguan_archive,带依据/赔率/签字;出事一键调取"基于这些做的合理决策"。
5. **豁免做成产品**:非要签风险单 → 给签字豁免("已知悉风险 X,自愿承担,已留痕"),把"不行"变"行,但记在案"。

## 三、律师团(法务大神,带知识库)

复用大神体系(分席/RAG/eval),建一个**法务分支**:

- **判官席**:richard-posner(法经济·B vs P×L)、bruce-schneier(攻击者视角)坐堂。
- **专科律师顾问**:合同律师、合规律师(储能/能源行业法规)、劳动法、IP、数据隐私、诉讼——各一个 persona + `references/` 真法条/判例知识库。
- **法务安全铁律**:律师 persona **一律 RAG 强制**(`gate_conclusion`)——发言必须命中知识库真法条才准下结论,没命中只提示"需人工律师"。**幻觉律师比没律师更危险。**
- 每位配 golden 判例,过 eval(`persona_eval`)才升判官,同一套飞轮。

## 四、全院文书标准「朝堂文书」(核心)

**一份内容,两副面孔。**

### 4.1 机器面 —— JSON 契约(标准清晰)

所有部门输出统一骨架(刑部为"判",户部为"奏",钦天监为"策"……):

```json
{
  "doc_type": "verdict",              // verdict|memorial|forecast|...
  "dept": "xingbu",
  "case_id": "XB-20260630-007",
  "light": "yellow",                  // green|yellow|red|black
  "verdict_oneline": "可签 —— 先改 2 处,否则尾款可能要不回来",
  "shielded": "为你挡了:80万尾款拖欠口子",   // 心意①
  "top_risks": [
    {"level":"red","title":"验收标准模糊","odds":"高","loss":"¥80万","fix":"加'验收以X报告为准,7日不反馈视同通过'","evidence_ref":"truth://..."}
  ],
  "red_blue": {"attacker":"schneier","weakest":"验收模糊","why":"..."},
  "actions": ["apply_fixes","escalate_court","archive_amulet"],
  "provenance": {"advisors":["richard-posner","bruce-schneier"],"archive_id":"XB-...007","yushi_gate":"passed"},
  "signed": false
}
```

机器面喂飞轮/归档/门禁,可解析、可 eval、可回链证据。

### 4.2 人类面 —— 卷宗×现代渲染(艺术 + 心意)

同一 JSON 渲染成有仪式感的判决卡(基调=用户选定样例):

```
┌───────────────────────────────┐
│ ⚖️ 刑部判决        〔朱印〕案号XB-007 │   ← 楷体标题 + 朱砂红官印
│ ───────────────────────────── │
│ 🟡 可签·须先改2处                │   ← 现代红黄绿灯,结论一行在前
│ 刑部为你挡了:80万尾款拖欠口子   │   ← 心意①
│ 致命风险 Top3        〔点击展开〕 │   ← 渐进展开,法条藏二级
│  1🔴 验收模糊  高×¥80万  →改…   │
│ ───────────────────────────── │
│ [一键改] [开庭] [存证]          │
│ 留痕已封存 · 史馆XB-007 〔骑缝朱印〕│   ← 心意②③:护身符具象化
└───────────────────────────────┘
```

**艺术方向**:楷体/宋体标题 + 朱砂红主色 + 宣纸微纹 + 现代无衬线正文 + 红黄绿灯卡。古典庄重,现代可读。

### 4.3 全院印章品牌系统(统一又各异)

同一骨架,每部门一枚专属官印 + 主色,形成可识别的"印章品牌系统":

| 部门 | 文书类型 | 官印 | 主色 |
|---|---|---|---|
| 刑部 | 判决书 | 天平印 | 朱砂红 |
| 户部 | 奏报 | 算盘印 | 金 |
| 礼部 | 策案 | 礼器印 | 青 |
| 钦天监 | 天象策 | 星盘印 | 靛蓝 |
| 史馆 | 卷宗 | 史笔印 | 墨 |

### 4.4 心意三触点

1. 开头"**刑部为你挡了什么**"(把价值说出来)。
2. 落款"**留痕已封存**"骑缝朱印(护身符具象)。
3. 结论永远**人话在前、法条在后**(决策不是知识)。
