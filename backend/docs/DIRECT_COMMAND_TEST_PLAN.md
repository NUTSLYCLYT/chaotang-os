## 二、路由智能性测试

### 2.1 简单问题 → Direct LLM
| 用例 | 命令 | 预期路由 |
|------|------|---------|
| 问候 | 你好 | direct/llm |
| 简单问答 | 什么是OPC？ | direct/llm |
| 操作指引 | 怎么新建客户？ | direct/llm |
| 快速计算 | 100加200等于多少？ | direct/llm |

**验证点：** 响应时间 < 2秒

### 2.2 领域关键词 → Swarm 直连
| 用例 | 命令 | 预期路由 |
|------|------|---------|
| 获客相关 | 分析今天的客户线索 | swarm/haolong |
| 市场商机 | 查看OPC市场的最新动态 | swarm/opc |
| 竞品分析 | 对比一下我们的产品和竞品 | swarm/product |
| 报价相关 | 这批物料的成本是多少？ | swarm/quotation |
| 合同合规 | 审阅这份采购合同 | swarm/legal |

**验证点：** 响应包含 swarm 特定输出，无通用 LLM 回复

### 2.3 复杂决策 → Court 丞相
| 用例 | 命令 | 预期路由 |
|------|------|---------|
| 多部门协调 | 帮我制定Q3销售策略，涉及市场、运营、财务 | court |
| 战略规划 | 分析公司未来一年的数字化转型方向 | court |
| 长文本任务 | 详细分析我们与竞争对手的差异化优势，给出具体建议方案... | court |

**验证点：** 触发多 agent 协作，有"丞相"风格输出

## 六、错误处理测试

| 场景 | 操作 | 预期结果 |
|------|------|---------|
| 空命令 | POST {"command": ""} | 返回 "空" 错误 |
| 超长命令 | 发送 5000 字 | 正常处理或优雅截断 |
| 无效 mode | mode=invalid | 回退到 auto 模式 |
| 外部服务异常 | 关闭 LLM 服务 | 返回 error，包含错误信息 |
| 超时 | 复杂任务运行 > 5 分钟 | 返回超时提示 |
