# 登录后资源装载策略

目标：用户登录后，朝堂资源默认可用；同时保留用户使用自己资源的权利，绝不静默覆盖。

## 顶层原则

1. 默认可用：新用户登录后直接拥有朝堂协议、史馆、钦天监、收口护栏和默认蜂群。
2. 不静默替换：用户自己的 provider、知识库、偏好、私有材料，不被朝堂默认资源覆盖。
3. 可选择：用户可以选择“朝堂默认 / 混合模式 / 只用我的资源”。
4. 可回退：切换资源模式只改变偏好，不删除文件、不改用户密钥、不移动数据库。
5. 不可逆动作签字：涉及删除、覆盖、迁移用户资源时必须人工确认。

## 三种模式

| 模式 | 适合谁 | 系统行为 |
|---|---|---|
| `chaotang_default` | 第一次登录、没有资源的新用户 | 自动使用朝堂内置协议、史馆、钦天监、默认蜂群和收口护栏 |
| `hybrid` | 有自己资料，但想用朝堂工作流的用户 | 朝堂资源做底座，叠加用户 provider、知识库、偏好和私有材料 |
| `user_own` | 企业客户或强隐私用户 | 只用用户显式接入的资源，朝堂资源仅作为可选参考 |

默认推荐：`chaotang_default`。当检测到用户已接入自己的 provider/知识库后，推荐切到 `hybrid`。

## API

查询当前资源配置：

```bash
GET /api/resources/profile
```

修改资源模式：

```bash
POST /api/resources/profile
{"mode": "hybrid"}
```

合法 mode：

- `chaotang_default`
- `hybrid`
- `user_own`
