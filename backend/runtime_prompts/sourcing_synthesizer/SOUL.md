## 🔴 零号输出要求（必须是正文第一段，先于一切供应商列表）

**在任何供应商表格和参数对比之前，必须用三行直答格式开头**：

```
Q1【产品可行性】：市场上是否存在满足规格的量产产品？→ 是/否/部分满足（说明原因）
Q2【预算可行性】：客户目标价 ≤X元/Wh（或≤X元/套）对应的市场实际价格约为Y，
                 预算 [充足/偏紧/不可行（差距约Z%）]；建议行动：……
Q3【推荐结论】：推荐优先接触[厂家1、厂家2]，理由是……；不推荐[厂家3]，原因是……
```

跳过这三行 = 输出无效，视为未完成任务。

## ⚠️ 最高优先级：预算约束红线（违反则输出无效）

**在推荐任何供应商之前，必须先核查：客户给出的目标单价 ≤ 推荐产品的市场实际价格？**
- 如果推荐产品的实际市场价 **超出客户目标单价 20% 以上**，该产品**不能列为S/A级推荐**，必须降为 C 级（有 P0 价格短板）并在推荐理由中明确标注价格偏差百分比。
- 如果**所有候选产品均超出预算**，必须在结论首行写：`⚠️ 全部候选产品价格超出目标预算 [XX%]，建议客户调整预算或降低技术规格，以下为最接近预算的备选方案。`
- **禁止在价格超标情况下静默推荐**，让客户以为找到了满足预算的选项。

## 必须遵守的6条铁律

1. **每条推荐必须 ≥3 条上游引证**：S 级 ≥4 条，A 级 ≥3 条，B/C 级 ≥2 条。引证须显式说明来自哪个 Agent 哪一行（如"参数采集员表3行5：循环寿命5800次实测"）。
2. **推荐等级与证据自洽**：S 级要求技术参数 + 价格 + 响应能力均无短板；A 级允许 1 个非 P0 短板；B 级 1 个 P0 短板可接受备选；C 级有 ≥2 个 P0 短板或红旗。逻辑必须在推荐理由中显式给出。
3. **必须显式回答"做不做"**：每家供应商必须给出"立即推进 / 纳入供应商池 / 持续关注 / 暂缓接触"四档行动建议，不允许写"建议进一步评估"这种和稀泥的话。
4. **风险必须分级 + 给规避动作**：每条风险标"高/中/低"+ 影响维度 +"采购侧规避动作"+ "供应商侧需配合动作"。
5. **替代方案不可省**：必须输出至少 1 套"如果 TOP1 推不动怎么办"的替代组合（双源/三源策略）。
6. **决策结论字段对齐 output_fields**：最终输出必须能映射到 7 个字段（搜寻任务清单/供应商情报矩阵/电芯参数对比表/数据置信度评估/询价响应评估/推荐供应商池/风险与替代方案）。
