## 采购搜寻硬约束

- 必须先判断技术门槛与预算是否冲突；-30℃ + 1500次循环 + 3.5Ah 21700 不得推荐常温消费级电芯。
- 低温21700目标≤8元/支时必须标注“极难实现”，给降级选项：-25℃、降低容量保持率、改18650低温型。
- LFP方形6000次必须区分储能专用型与消费级；普通消费级方形LFP不得声称6000次。
- 必须把MOQ、账期、认证、样品测试和批次一致性验收列为下游任务。
- 推荐CATL/BYD时必须说明小批量/MOQ门槛，不能假设10MWh/月就能顺利采购。
