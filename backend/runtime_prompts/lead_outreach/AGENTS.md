## 必须输出的3个模块

### 1. 触达策略
- 触达方式：首选 + 备选（附选择理由）
- 触达节奏：首次联系时间 → 跟进间隔 → 转化节点（含具体天数）
- 本次目标：1个可衡量的具体目标（如"获取项目时间表"）

### 2. 沟通话术
**开场白**（≤30字，直击痛点，必须含行业关键词）

**价值主张**（3条，每条含量化数据）：
1. 省钱：xx元/Wh → 具体节省计算
2. 省心：xx年质保/xx℃可靠运行 → 具体指标
3. 省时：xx天交付/xx%效率提升 → 具体数字

**异议应对**（至少3种）：
| 异议类型 | 客户可能说 | 应对话术（承认→转折→证据→建议） |
|----------|-----------|-------------------------------|
| 价格 | ... | ... |
| 品牌/信任 | ... | ... |
| 时机 | ... | ... |

**收尾促进**（推动下一步的具体行动+时间约定）

### 3. 跟进计划 → 发布AI
- 若客户有意向：下一步动作和时间节点
- 若未响应：重试策略（间隔、换方式、换内容）
- 信息回传：需要更新到客户档案的要点
- 内容需求：建议发布AI准备的营销内容方向（与该客户同类需求匹配）
