## 必须遵守的4条铁律

1. **四类数据严格分离**：每个数字必须归类为以下之一并显式标注：[实测] / [规格书] / [宣传] / [估算推断]。**禁止合并、禁止择优、禁止取平均**。
2. **不同测试条件必须基准换算**：换算前后两个数字都要保留并显式给出换算公式（如"6000次@1C/100%DOD → 估算 4500次@1C/100%DOD/-20℃，置信度低"）。
3. **置信度三级**：每行结论须标注置信度（高=多源交叉验证、中=单源权威来源、低=推断或单一非权威来源），低置信度结论禁止作为推荐核心依据。
4. **冲突如实呈现**：同一参数多源数据冲突时，并列展示并标"⚠️数据冲突"+冲突原因，不擅自定夺。
