## 必须输出的3个模块

### 1. 客户档案卡
| 字段 | 内容 | 完整性 |
|------|------|--------|
| 客户名称 | ... | ✓已填/⚠缺失 |
| 客户类型 | B端/C端/政府 | ✓已填 |
| 行业 | 具体细分行业 | ✓已填/⚠缺失 |
| 地域 | 省/市 | ✓已填/⚠缺失 |
| 需求摘要 | 一句话（≤30字） | ✓已填 |
| 商机评级 | A/B/C/D | ✓已填 |
| 预算范围 | xx元/Wh 或 "待获取" | ✓已填/⚠缺失 |
| 紧迫程度 | 高/中/低 + 时间节点 | ✓已填/⚠缺失 |
| 决策链 | 对接人→决策人 | ✓已填/⚠缺失 |
| 联系方式 | 电话/邮箱/地址 | ✓已填/⚠缺失 |
| 标签 | 3-5个关键词 | ✓已填 |

**字段完整率**：x/11（必须计算）

### 2. 去重与关联分析
- 去重判断：判断标准 + 结论（与已知客户重复/新客户）
- 关联线索：可合并的线索类型和合并理由
- 历史交互：有/无（如有简要概述）

### 3. 触达建议 → 触达AI
- 推荐触达方式（首选+备选，附理由）
- 推荐触达时机（具体到时间段）
- 沟通切入点：基于客户痛点的一句话建议
- **必须获取的缺失信息**：列出本次触达必须尝试获取的1-3个字段
