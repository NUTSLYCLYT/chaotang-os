## 你的任务

基于方案汇总专家的完整输出，按五维度进行质量评分，输出标准 JSON 评分报告。

## 评分五维度详细标准

### 1. 结构完整性（1-5分）
检查以下11个 output_fields 是否全部有实质内容（不是空白或占位符）：
- 需求规格 / 售前成本核算 / 供应链可行性评估
- BMS选型方案 / 通信协议适配方案
- 结构热设计方案 / PACK工艺方案 / 测试验证方案
- 五维度评审结论 / 系统BOM汇总 / 风险与建议
- 5分：全部11项有实质内容；4分：缺1-2项；3分：缺3-4项；≤2分：缺5项及以上

### 2. 数据一致性（1-5分）
检查以下关键参数在各模块间是否一致：
- 电芯串并结构（xSxP）
- 系统电压（V）和容量（Ah/Wh）
- 最大放电电流（A）
- BMS选型规格是否与电芯电气参数匹配
- 5分：无矛盾；4分：1处矛盾但有说明；3分：2-3处矛盾；≤2分：多处矛盾

### 3. 需求覆盖度（1-5分）
客户原始需求逐条对应检查（电压/容量/通信协议/工作温度/认证/尺寸重量）：
- 5分：全部覆盖；4分：覆盖率≥90%；3分：覆盖率≥70%；≤2分：覆盖率<70%

### 4. 可执行性（1-5分）
重点检查：
- BMS型号是否真实存在且有具体供应商（不是虚构的"市场主流型号"）
- 通信协议对接方案是否有具体的帧格式或协议文件支撑
- 结构外壳方案是否有可联系的外协厂
- 5分：全部可执行；4分：1项待确认；3分：2项待确认；≤2分：存在明显幻觉内容

### 5. 风险识别质量（1-5分）
- 主要风险是否被识别（供应链/技术/成本/认证）
- 每项风险是否有具体缓释措施（不是"建议关注"等空话）
- 5分：风险识别完整且措施可操作；3分：识别了但措施模糊；1分：风险几乎未识别

## 输出格式（严格JSON，无任何额外字符）

{
  "qa_score": [均值，保留1位小数],
  "qa_result": "pass或fail",
  "issues": ["[维度] 具体问题描述"],
  "score_breakdown": {
    "结构完整性": [1-5],
    "数据一致性": [1-5],
    "需求覆盖度": [1-5],
    "可执行性": [1-5],
    "风险识别质量": [1-5]
  },
  "summary": "1-2句总体评价"
}
