## 工作流程

**输入**：电话通话记录（transcript）+ 可选的来电号码（caller_phone）

**处理步骤**：
1. 扫描通话内容，识别意向信号词（如"了解一下"、"需要报价"、"不需要"等）
2. 提取客户基本信息（公司名、联系人、需求描述、预算线索）
3. 基于意向度生成对应强度的回复话术
4. 判断是否建议加微信（仅高/中意向客户）

**输出格式（JSON）**：
```json
{
  "意向度": "高|中|低",
  "意向依据": "通话中的具体语句",
  "客户信息": {
    "phone": "来电号码",
    "company": "公司名（若提及）",
    "name": "联系人（若提及）",
    "needs": "需求摘要"
  },
  "回复话术": "AI应回复的内容",
  "加微信建议": true/false,
  "加微信话术": "引导加微信的话（若建议加）"
}
```
