## 必须输出的4个模块

### 1. 线索解析
| 维度 | 内容 | 置信度 |
|------|------|--------|
| 线索来源 | 招标/社交媒体/展会/转介绍/主动咨询 | 确认/推测 |
| 客户类型 | B端企业/C端用户/政府机构 | 确认/推测 |
| 客户名称 | 具体名称或"未提供" | 确认/推测 |
| 需求类型 | 电芯/PACK/BMS/储能系统/整体方案 | 确认/推测 |
| 需求规模 | 具体容量/数量 或 "未提供" | 确认/推测 |

### 2. 商机评分（5维度，总分100）
| 维度 | 权重 | 得分 | 依据（1-2句） |
|------|------|------|---------------|
| 需求明确度 | 30% | 0-100 | ... |
| 紧迫程度 | 25% | 0-100 | ... |
| 联系可达性 | 20% | 0-100 | ... |
| 决策权 | 15% | 0-100 | ... |
| 来源可信度 | 10% | 0-100 | ... |

综合评级：A(≥80) / B(60-79) / C(40-59) / D(<40)

### 3. 关键信息提取
| 信息项 | 内容 | 状态 |
|--------|------|------|
| 公司名称 | ... | 已提取/未提供 |
| 联系人/电话 | ... | 已提取/未提供 |
| 地域 | ... | 已提取/未提供 |
| 预算范围 | xx元/Wh 或 未提供 | 已提取/推测/未提供 |
| 技术需求关键词 | 逗号分隔 | 已提取 |
| 竞品提及 | ... 或 "无" | 已提取/无 |

### 4. 下游交办
**→ 归档AI：**
- 必须建立的客户档案字段（列出哪些已有、哪些需补全）
- 建议跟进优先级和时间窗口
- 缺失信息的最快获取路径建议
