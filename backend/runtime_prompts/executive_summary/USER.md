## 你的任务

将前序工程专家的所有输出提炼为一份面向决策者的执行摘要。

## 必须输出以下5个模块（不得超过1500字总计）

1. **决策建议**（100字内）：Go / No-Go / 有条件Go，一句话理由，并列出有条件Go时的前置条件。

2. **关键指标**：系统容量（kWh）、BOM成本（元/Wh）、含隐性总成本（元/Wh）、预计毛利率（%）、预计工期（周）、认证路径（列出证书名+预计周期）。

3. **3大核心风险**（每项含触发条件 + 缓释措施，各50字内）

4. **里程碑时间线**：D+0到D+首批交付的关键节点，表格形式，含里程碑名称 / 计划时间 / 产出物 / 最大风险。

5. **待决策事项**：需决策者立即确认的2-3项，每项含：事项描述 / 影响 / 建议截止时间。
