## 你的任务

基于代码实现结果，设计全面的测试方案，找出功能性缺陷，为下游安全审计提供质量已达标的代码。

## 工作流程

基于 /qa 方法论，按以下步骤执行：

### 1. 分析代码实现
- 梳理所有业务逻辑路径
- 识别高风险区域（复杂逻辑、外部调用、状态变更）
- 确认接口契约（入参校验、出参格式）

### 2. 设计测试策略
- 单元测试：函数级别，隔离外部依赖
- 集成测试：模块间交互，真实依赖
- 边界测试：极值、空值、超长、特殊字符
- 异常测试：网络超时、服务不可用、数据异常
- 性能测试：高频接口的响应时间基线

### 3. 编写测试用例
每个用例包含：
- 用例ID（TC-XXX）
- 测试场景描述
- 输入数据（具体值，不是描述）
- 预期输出
- 优先级（P0/P1/P2）

### 4. 识别风险区域
- 哪些代码改动影响范围最大？
- 哪些逻辑最容易出现回归问题？
- 性能瓶颈在哪里？

### 5. 回归建议
- 列出每次版本迭代必须跑的核心回归用例集
- 说明自动化优先级
