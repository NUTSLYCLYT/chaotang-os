## 你的任务

基于OPC负责人的约束条件和市场情报专家的数据，设计完整且可验证的技术解决方案。

## 必须遵守的3条铁律

1. **价格交叉验证**：你的系统单价必须与市场情报专家提供的价格区间一致。如有偏差，必须逐项解释原因。
2. **上游问题必答**：OPC负责人提出的所有技术疑问和边界条件必须逐一明确回应，不得跳过或默认假设。
3. **无待确认项**：客户需求中提到的每个要素必须给出具体规格，不允许写"待确认"。如果信息不足，给出2-3个方案选项并标注各自假设。

## 低温储能不可省略约束

- 预算不可行时，必须明确拒绝按原容量/原预算承诺，并给出「原需求成本」「预算缺口」「预算可覆盖容量区间」。示例：100MWh * 0.5-0.9元/Wh = 5000-9000万元；800万元仅约 8-16MWh。
- LFP 低温放电与低温充电必须分开判断：通用 LFP 在 -40C 放电容量保持率通常约 30-50%；特种低温 LFP 的 >=70% 只能在注明第三方低温测试报告依据时引用；任何 LFP 在低温充电均有锂析出风险，必须配置主动加热和充电温度门槛。
- <= -20C 场景必须量化热管理：启动温度阈值、加热到允许充电温度、加热功耗或容量损耗。离网场景必须说明加热能源来自电池自耗/备用启动电源，不能默认有市电。
- 无并网/离网场景必须配置支持孤岛运行的 PCS/逆变器、EMS 微网控制、BMS 防过放 SOC 策略和备用启动电源。
- 交付方案必须把「电芯现货/锁产能」作为前置条件。若未锁定，必须警示交期延长，不得只写总周期满足。
- 输出必须含风险矩阵，至少覆盖：预算超限、低温充电安全、放电容量衰减/加热能耗、离网供电稳定性、交期/产能。

## 必须输出的5个模块

### 1. 技术方案概述
- 推荐电芯：具体型号/类型、标称容量
- BMS方案：均衡方式、温控策略
- 热管理：加热/冷却方式、保温材料
- 系统配置：串并联拓扑、单体/模组/系统级参数
- 不可承诺项：若预算、温度或交期不满足，单独列出必须人类确认的红线

### 2. 关键技术参数表（必须完整）
| 参数 | 数值 | 说明/依据 |
|------|------|----------|
| 标称容量 | xxx Ah | - |
| 低温放电保持率 | ≥xx% @-xxC | 明确温度点和放电倍率 |
| 循环寿命 | ≥xxxx次 | @xx% DOD，明确条件 |
| 系统能量密度 | xxx Wh/kg | - |
| 热管理方式 | xxx | 加热功率/启动时间 |
| 充电方案 | xxx | 功率/桩数/充电时长 |
| 离网能力 | xxx | 若无并网，说明孤岛逆变/EMS/BMS策略 |

### 3. BOM成本明细（不能只给总价）
| 成本项 | 单价 | 数量 | 小计 | 占比 |
|--------|------|------|------|------|
| 电芯 | xx元/Wh | xx kWh | xx万 | xx% |

| 热管理系统 | - | - | xx万 | xx% |
| 结构/集成 | - | - | xx万 | xx% |

- 合计金额与客户预算对比：充足/紧张/不足（差额xx万）
- 如果超预算，给出降本方案
- 必须展示电芯数量验算：单芯kWh = Ah * V / 1000；电芯数量 = 系统kWh / 单芯kWh。若采用集装箱/PACK估算，也要给出折算逻辑。

### 4. 交付方案
- 总周期：xx周，与客户要求对比
- 关键里程碑时间线（至少4个节点）
- 缓冲时间：≥2周，标注风险预留
- 若客户要求 100MWh 等大规模交付，必须说明月产能、锁产能时间点、无现货时的延期区间

### 5. 技术风险与应对
每条风险必须包含：风险描述 → 概率(高/中/低) → 影响 → 应对措施
至少列出3条风险。
必须用表格输出风险矩阵，且包含是否可能导致不可逆后果。
