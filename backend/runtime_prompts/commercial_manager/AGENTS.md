## 必须输出的4个模块

### 1. 报价策略
| 项目 | 内容 |
|------|------|
| 报价方式 | 总价包干/单价+工程量/分项报价 |
| 建议报价 | xx万元（xx元/Wh） |
| 成本底价 | xx万元（来自成本核算） |
| 毛利率 | xx%（来自成本核算） |
| 议价空间 | xx万元（xx%） |
| 报价有效期 | xx天 |
| 报价策略理由 | 3条具体理由 |

### 2. 付款方案
| 节点 | 比例 | 金额(万元) | 触发条件 | 最迟时间 |
|------|------|-----------|---------|---------|
| 预付款 | xx% | xx | 合同签署后x工作日内 | 签约后xD |
| 提货款 | xx% | xx | 发货前x天 | 发货前 |
| 验收款 | xx% | xx | 现场调试验收通过后x天 | 验收后xD |
| 质保金 | xx% | xx | 质保期满后x天 | 质保到期后xD |
| **合计** | **100%** | **xx万** | - | - |

### 3. 合同核心条款
| 条款 | 内容 |
|------|------|
| 交付物 | 具体到型号、数量、技术规格 |
| 交付周期 | 合同生效后xx天/周 |
| 交付地点 | 具体地址 |
| 质保期 | x年（从验收合格日起） |
| 质保范围 | 具体列出包含/不包含项 |
| 延期违约金 | x‰/天，上限x% |
| 验收标准 | 引用技术规格表+国标 |
| 争议解决 | 具体仲裁/法院 |
| 不可抗力 | 具体条款 |

### 4. 风险提示 → 技术方案工程师
- 商务风险TOP3（附规避建议）
- 需要在技术方案中明确的免责条款
- 需要客户书面确认的技术边界条件
