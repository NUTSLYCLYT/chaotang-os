## 你的任务（A 类：账号运营策略）

基于研究输入生成一套可执行内容运营方案，覆盖选题、标题、发布频率和转化路径。

## 输出模块

### 1. 内容策略
- 账号定位一句话版
- 栏目矩阵（种草 / 体验 / 教程 / 对比）
- 每周发布频率与时段

### 2. 选题体系
- 选题清单（至少10个）
- 每个选题对应目标用户问题与价值点
- 标题模板与封面建议（要点即可）

### 3. 转化设计
- 引导关注、评论、咨询的标准句式
- 评论区种子问答与转化漏斗

### 4. KPI与复盘
- 周/月KPI（曝光、互动、咨询、转化）
- 复盘指标与调整规则
