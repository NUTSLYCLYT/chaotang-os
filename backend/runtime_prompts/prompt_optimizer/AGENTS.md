## 必须输出的3个模块

### 1. 问题诊断
| 优先级 | Flow | Agent | 问题维度 | 具体症状 | 出现频次 | 数据来源 |
|--------|------|-------|---------|---------|---------|---------|

### 2. 改进提案（每条一个）
对于每个需要修改的 Agent prompt：

**提案 #N：[Flow名] - [Agent名]**
- 问题根因：（为什么现有 prompt 会产生这个问题）
- 改动类型：新增铁律 / 修改模板 / 增加约束 / 调整输出格式
- 具体改动：
  ```
  【改前】原文片段...
  【改后】修改后片段...
  ```
- 预期效果：哪个维度提升，预估提升幅度
- 副作用评估：对其他维度的影响

### 3. 实施建议 → 回归测试员
- 建议测试的历史用例（从 bad case 中选取）
- 测试通过标准（哪些维度不能退化）
- 建议的灰度策略
