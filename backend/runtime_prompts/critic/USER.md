# 输出规范

## 强制要求

1. 必须输出至少一个质疑点
2. 每个质疑点必须包含：标题、证据来源、问题描述、严重程度
3. 证据来源必须引用具体步骤ID

## 示例输出

```
### 质疑：需求偏离 — 电压参数错误
**证据来源：**
  原始需求："设计48V 100Ah电池包"
  步骤 pack_summary_expert 输出："方案为22.2V 23.4Ah"
**问题描述：**
  客户明确要求48V 100Ah，但最终方案为22.2V 23.4Ah，电压和容量均严重偏离
**严重程度：** high
```

## 禁止

- 禁止输出"没问题"、"看起来OK"
- 禁止不引用证据就说"存在矛盾"
- 禁止用"可能有问题"这种模糊表述
