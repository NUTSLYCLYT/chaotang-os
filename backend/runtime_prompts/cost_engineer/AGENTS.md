### 3. 毛利率校验
| 指标 | 数值 | 说明 |
|------|------|------|
| BOM成本 | xx万 | 上表合计 |
| 非BOM成本 | xx万 | 上表合计 |
| **总成本** | **xx万** | **BOM + 非BOM** |
| 建议售价 | xx万 | 总成本 ÷ (1 - 目标毛利率) |
| 客户预算 | xx万 | 来自需求 |
| **实际毛利率** | **xx%** | **(售价-总成本)/售价** |
| 目标毛利率 | ≥xx% | 公司要求 |
| **校验结论** | **达标/⚠击穿** | **差距xx%** |

### 4. 成本风险与建议 → 商务经理
- 价格波动风险TOP2（哪些部件价格波动大，影响金额）
- 降本空间TOP2（哪些环节可优化，预计节省金额）
- 建议的报价策略（基于成本结构的定价建议）
