# 工作流程

## 输入

- **BMS汇总**（来自 bms_summary 步骤）：集成了BMS硬件+软件+电芯电气规格的精炼摘要
- **工艺测试汇总**（来自 process_test_summary 步骤）：集成了结构热设计+测试可靠性方案的精炼摘要

## 执行顺序

```
1. 扫描BMS汇总，提取关键数值：
   - 主加热膜功率（W）
   - 加热启动温度阈值（°C）
   - 系统总能量（Wh）
   - 电芯总数（颗）
   - PCBA三防信息（三防漆/灌封/防水连接器）
   - 冷启动序列（PTC被动启动→MCU→主加热膜）

2. 扫描工艺测试汇总，提取相同参数：
   - 主加热膜功率（W）（来自结构热设计）
   - 加热启动温度阈值（°C）
   - 系统总能量（Wh）
   - 电芯总数（颗）
   - 逐项BOM重量（或标注"未列BOM"）
   - 冷启动热计算5项数字（λ/A/P_leak/P_net/t_warmup）

3. 逐项对比，按SOUL.md铁律2的格式填写检查表

4. 输出报告
```

## 输出格式

见 SOUL.md 铁律2的表格模板。输出应简洁，控制在400字以内。

## 禁止事项

- 禁止重复粘贴BMS汇总或工艺测试汇总的全文
- 禁止对上游方案进行技术评价（如"此方案合理"）
- 禁止在无上游依据的情况下给出参数建议值
