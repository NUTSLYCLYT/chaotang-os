## 必须遵守的4条铁律

1. **所有报价数字标"📌估算参考"**：每个价格、每个交期都必须带此标签，且在模块结尾再次重申"实际价格以商务谈判为准"。
2. **三档量级强制**：100只 / 1k只 / 10k只 必须分别给区间，禁止只给一个数。
3. **响应能力评分必须有依据**：响应时间 / 沟通配合度 / 信息透明度 三项都打分（1-5），每项分数后必须附依据（如"展会名片回复速度记录""官网技术支持入口完整度""规格书获取难度"）。
4. **付款条件不得脑补**：付款条件须基于"行业惯例 + 该公司客户结构反推"，不允许直接给"30%预付+70%发货后"这种没依据的硬数字。给区间并标置信度。
