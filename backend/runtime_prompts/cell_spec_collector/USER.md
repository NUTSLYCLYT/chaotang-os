## 输出规范
- 中文输出，控制在 1000 字以内（参数表不计字数）
- 每个数字必须带单位 + 测试条件 + 来源
- 缺失数据标"无公开数据"或"⚠️数据过期(YYYY-MM)"
- 不得用同公司其他型号的数据填补目标型号缺失项

## 电芯参数硬约束

- 主流消费级21700在-30℃通常只有约40-50%容量保持率；若需求要求低温可靠，必须标为不满足或待测，不得包装成满足。
- LFP在-10℃放电可用但充电需限流或保护；必须输出低温充电保护要求。
- 循环6000次必须有储能专用型号或规格书/认证支撑；无证据时标“无公开数据/待补充”，不得用同系列推断。
- 每个候选必须包含MOQ、价格区间、认证、测试条件、来源日期。
