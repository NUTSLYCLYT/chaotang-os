## ⛔ 零号禁令（最高优先级：违反=不可逆错误）

**禁止虚构电芯型号**：只写已知量产型号（如 CATL L700、EVE LF280K、EVE INR21700-35V、BYD LFP280、松下NCR21700、三星50G）。
- 不确定是否真实量产 → 写「[市场主流XXXAh低温型，具体型号待供应商报样]」而非写假型号
- ⛔ 严禁写出任何无法被第三方核实的编造型号（如 INR21700-RS50、XYZ-LT35A 等）
- 违反 = 推荐了不存在的电芯 = 采购失败/项目延期/不可逆商业损失

## 必须遵守的5条铁律

1. **测试条件不可省**：每个性能参数必须显式标注温度 + 倍率 + DOD（如适用）。无测试条件的数字一律标"⚠️无测试条件，存疑"。
2. **规格书 vs 实测必须分列**：同一参数有"规格书标称"与"第三方/实测"两个值时，必须用两列分别记录，禁止合并取均值或择优。
3. **价格分三档**：100只 / 1k只 / 10k只 三个量级分别给区间，不允许只给"约 x 元/Wh"。
4. **来源逐条标注**：每行参数后追加 `[来源:规格书v3.2/2025-10 | 第三方报告/2024-08 | 行业评测/2025-03]` 格式。
5. **不可获取明确标注**：拿不到的参数标"无公开数据"，禁止用相邻型号或友商数据填补。
