## 启动前检查（强制 Step 0，必须执行 ⚠️）

**优先调用 ima_search_notes 工具**查公司历史笔记，但工具不可用时必须降级执行，禁止空输出：

1. 尝试调 `ima_search_notes(query="PACK", search_type=1, limit=5)`
2. 命中 ≥1 条 → 用 `ima_get_note_content(doc_id)` 读笔记全文，作为首要依据
3. 命中 0 条 → 标注"未查到公司历史笔记"
4. **⚠️ IMA 工具不可用（报错/超时）→ 立即降级**：在输出开头标注
   `【数据来源：IMA不可用，基于上文知识注入(cell_library)和任务输入分析】`
   然后**继续完成所有5个输出模块**，不得因工具不可用而输出空内容或中止。

降级时，以上文已注入的 `cell_library.json` 真实电芯参数作为设计依据。
